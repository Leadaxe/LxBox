L×Box — VPN- и прокси-клиент для Android на базе sing-box-lx, форка sing-box с поддержкой AmneziaWG 2.0 и нативного XHTTP. Работает с несколькими подписками одновременно, маршрутизирует трафик по вашим правилам и измеряет задержку узлов, не выходя из приложения.

L×Box использует Android VpnService, чтобы создать локальный туннельный интерфейс и направлять трафик по вашим правилам. Это только клиент: серверы вы добавляете сами. Приложение не располагает собственной серверной сетью и не содержит встроенных серверов.

Всё работает на устройстве. Нет аккаунта, телеметрии и аналитики: приложение обращается только к тем серверам, которые вы добавили, и к настроенным вами адресам обновления.

Серверы и подписки

* 12 протоколов: VLESS (в том числе постквантовое шифрование ML-KEM-768), VMess, Trojan, Shadowsocks, Hysteria2, TUIC v5, NaiveProxy, AnyTLS, SSH, SOCKS, WireGuard (включая AmneziaWG 2.0) и MASQUE поверх QUIC/HTTP-3
* Импорт по ссылке на подписку, прокси-ссылке, WireGuard URI или INI, ссылке Amnezia vpn://, сырому JSON sing-box или из локального файла
* Форматы: Base64, JSON-массив Xray, обычный текст, сырой JSON sing-box
* Одинаковые узлы в подписке объединяются в одну запись
* Отдельные узлы можно отключать; выбор привязан к устойчивому хешу узла и переживает обновления и переименования на стороне провайдера
* Правила обработки меняют или отключают узлы при импорте и при каждом обновлении; перед сохранением видно, что именно попадёт под правило
* Фоновое автообновление с ограничением частоты запросов и отдельным интервалом для каждой подписки

Маршрутизация

* Правила по домену, IP, порту, протоколу, процессу и типу сети
* Маршрутизация по приложениям: выбираете, какие из них идут через туннель
* Наборы правил с автоматическим обновлением
* Полный контроль над DNS: несколько резолверов, правила DNS, FakeIP, выбор резолвера для каждого правила
* Встроенный редактор конфигурации с подсветкой синтаксиса для всего, чего нет в интерфейсе

Диагностика

* Тест скорости и замер задержки для узла, папки или целой подписки — как с запущенным туннелем, так и без него
* Список активных соединений, трафик по каждому соединению и по приложениям
* Статистика трафика и просмотр журнала в приложении

Cloudflare WARP

Одно нажатие регистрирует туннель WARP и добавляет его как узел. Приватный ключ создаётся на устройстве и никогда его не покидает — в Cloudflare уходит только публичный ключ. Поддерживаются транспорты WireGuard и MASQUE, при желании — обфускация AmneziaWG.

Английский и русский языки, светлая и тёмная темы.
