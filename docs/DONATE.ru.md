# Поддержать L×Box

L×Box бесплатный, без рекламы, без подписок и без сбора данных. Разработка идёт
в свободное время и живёт на поддержку пользователей — других источников у
проекта нет.

> English version: [DONATE.md](DONATE.md)

Поддержка — дело добровольное. Приложение работает одинаково для всех, никаких
платных функций нет и не планируется.

## Как ещё помочь, если не деньгами

Это не менее ценно:

- **Звезда на GitHub** — [L×Box](https://github.com/Leadaxe/LxBox) и
  [sing-box-lx](https://github.com/Leadaxe/sing-box-lx) (ядро, на котором всё
  работает). По звёздам проект находят новые пользователи.
- **Отзыв** — [Telegram-группа](https://t.me/singbox_launcher/4317). Честный
  опыт помогает другим решиться, а мне — понять, что чинить.
- **Баг-репорт** — [issues на GitHub](https://github.com/Leadaxe/LxBox/issues).
  Подробное описание проблемы экономит недели догадок.
- **Рассказать знакомым** — свежая сборка всегда на
  [странице релизов](https://github.com/Leadaxe/LxBox/releases/latest).
