# Сертификат участника закрытого тестирования

Макет и генератор сертификатов для тестировщиков L×Box в Google Play.

## Файлы

| Файл | Назначение |
| --- | --- |
| `certificate.html` | Шаблон, A4 landscape. Самодостаточный: логотип вектором, бейдж Google Play встроен base64 |
| `generate.sh` | Пакетная сборка PDF из списка имён |
| `recipients.tsv` | Список получателей — **не коммитится**, см. ниже |

## Персональные данные

Готовые PDF содержат имена участников, а исходный список — их email.
Ни то, ни другое в репозиторий не идёт: генератор по умолчанию пишет
в `localworkspace/certificates/`, который в `.gitignore`.

`recipients.tsv` держите там же и передавайте скрипту путём:

```bash
./generate.sh ../../../localworkspace/certificates/recipients.tsv
```

## Формат списка

TSV без заголовка: номер сертификата и имя получателя.

```
1	Alice
2	bob42
5	Иван Петров
```

Номер попадает в `LXB-CT-2026-NNN` и в имя файла. Нумерация сквозная —
номер закреплён за человеком, пропуски допустимы.

## Запуск

```bash
docs/design/certificate/generate.sh recipients.tsv
```

Версия трека и дата выдачи переопределяются переменными:

```bash
CERT_VERSION=v2.21.0 CERT_DATE="September 2026" ./generate.sh recipients.tsv
```

Рендер идёт через headless Chrome (`--print-to-pdf`). Путь к нему —
переменная `CHROME`, по умолчанию стандартный на macOS.

## Плейсхолдеры шаблона

`{{NAME}}` · `{{CERT_ID}}` · `{{DATE}}` · `{{VERSION}}`

## Бейдж Google Play

Официальный asset размещён **как ссылка на страницу тестирования**
(`play.google.com/apps/testing/com.leadaxe.lxbox`) — это разрешённый
лицензией сценарий. Бейдж нельзя перекрашивать, обрезать и перерисовывать,
а также использовать так, будто Google удостоверяет сам сертификат:
удостоверяющая сторона — автор приложения, его подпись стоит в футере.

Причастность к платформе выражена текстом («Google Play · Android»,
ряд фактов) — это факт, и он излагается словами свободно.
