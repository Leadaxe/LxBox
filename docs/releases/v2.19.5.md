# L×Box v2.19.5

A small release that lays the groundwork for F-Droid: the repository now
carries its own store page — descriptions, icon, changelog and screenshots —
and one ordering bug in the rules list is fixed.

Небольшой релиз, готовящий публикацию в F-Droid: в репозитории появилась
витрина приложения — описания, иконка, changelog и скриншоты, — плюс
исправлен порядок в списке правил.

<summary><h2>🇬🇧 English</h2></summary>

## 📌 Fixed — a pinned preset kept its place at the top

Adding a rule pushed a pinned preset out of the header. The order was
computed before normalization, so the preset drifted down together with
ordinary rules instead of staying pinned.

| Before | After |
|---|---|
| Adding a rule moved the pinned preset down the list | The pinned preset stays at the top |

## 🏪 Changed — F-Droid store metadata

The repository now ships fastlane metadata: short and full descriptions in
English and Russian, the launcher icon, a per-version changelog and eight
screenshots.

F-Droid reads this metadata from the release commit, not from the default
branch, which is why the store page only fills in with a new tag.

The submission is [merge request 44731](https://gitlab.com/fdroid/fdroiddata/-/merge_requests/44731)
against fdroiddata, with [RFP 4218](https://gitlab.com/fdroid/rfp/-/work_items/4218)
in their tracker. In the F-Droid build the core is compiled from source
instead of being pulled from a release artifact; the naive outbound is left
out there, because it depends on a prebuilt cronet binary. The builds
published here on GitHub are unaffected and still include it.

## ✅ Tests

`flutter analyze` clean, 2895 tests pass, all four l10n checkers green.

## 📌 Исправлено — закреплённый пресет остаётся в начале

Добавление правила выдавливало закреплённый пресет из шапки списка. Порядок
считался до нормализации, поэтому пресет уезжал вниз вместе с обычными
правилами вместо того, чтобы остаться закреплённым.

| Было | Стало |
|---|---|
| Добавление правила сдвигало закреплённый пресет вниз | Закреплённый пресет остаётся в начале |

## 🏪 Изменено — витрина для F-Droid

В репозиторий добавлены fastlane-метаданные: короткое и полное описания на
английском и русском, иконка приложения, changelog по версиям и восемь
скриншотов.

F-Droid читает эти метаданные из коммита релиза, а не из ветки разработки,
поэтому витрина наполняется только с новым тегом.

Заявка подана — [merge request 44731](https://gitlab.com/fdroid/fdroiddata/-/merge_requests/44731)
в fdroiddata и [RFP 4218](https://gitlab.com/fdroid/rfp/-/work_items/4218) в их
трекере. В сборке для F-Droid ядро компилируется из исходников, а не берётся
готовым из релиза; протокол naive там отключён, потому что тянет за собой
готовый бинарник cronet. На сборки с GitHub это не влияет — в них naive
остаётся.

## ✅ Тесты

`flutter analyze` чистый, 2895 тестов проходят, все четыре l10n-чекера зелёные.
