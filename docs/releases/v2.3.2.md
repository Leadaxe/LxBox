## 🔧 Changed

**WARP-обфускация под настоящий QUIC (§136).**

По field-report из региона с жёстким DPI прежний junk-шаблон (WG-traffic / SIP) провайдерский DPI **не пробивал**, а конфиги публичного `warp-generator` — работали из коробки. Реверс генератора показал, почему:

- его i1 — это **настоящий QUIC Initial** (голый SNI-ClientHello, RFC 9001 крипта) с CPS-нарезкой `<b>/<r>`, где `<r>` рандомит изменчивые байты на каждый пакет → нет общей сигнатуры, по которой DPI ловит туннель;
- endpoint — **чистый рандом** `IP:port` из зашитых Cloudflare-блоков, без скана: почти любой адрес в этих диапазонах = живой WARP anycast, DPI режет только дефолтный `engage…:2408`.

Слабый WG-traffic шаблон **заменён на QUIC** (SIP оставлен как второй вариант, выбор dropdown'ом). Параметры QUIC (SNI / level 0-4 / Jc-Jmin-Jmax) — в Advanced с рабочими дефолтами. При включённой обфускации с дефолтным endpoint адрес **рандомизируется** из блоков Cloudflare. Добавлен SNI combo-box (пул / `Random` / свой ввод). QUIC-маскировка подтверждена device-smoke.

> ⚠️ DPI читает SNI **внутри** QUIC Initial (крипта Initial публичная) → cloudflare-маркеры режутся. Поэтому SNI-пул собран только из массовых легитимных доменов (глобальные + критичная инфраструктура РФ), `cloudflare-quic.com` исключён.

**Осмысленные имена WARP-узлов + накопление (§137).** WARP-узлы теперь именуются по шаблону с эмодзи в теге:

| Случай | Тег |
|---|---|
| plain WARP | `🔥☁️ WARP` |
| plain WARP+ | `🔥☁️ WARP+` |
| AWG-обфускация | `🔥⛈️ WARP (AWG 1.5)` |
| AWG WARP+ | `🔥⛈️ WARP+ (AWG 1.5)` |

Гроза ⛈️ вместо облака ☁️ — визуальный сигнал «узел маскируется от DPI». Убрана авто-замена прежних WARP-узлов при повторном Get WARP: теперь узлы **накапливаются** (можно держать несколько конфигов с разными endpoint/SNI; лишние удаляются свайпом).

**Лейбл «Channel» inline.** Лейбл канала переехал на одну строку с выпадающим списком и ping-иконкой (`Channel [ VPN 1 ▾ ] [⚡]`) — экономия вертикали на главном экране.

## 🛠 Fixed

- **QS-плитка: белый квадрат в редакторе панели быстрых настроек (§139).** В режиме редактирования QS-панели (HyperOS/MIUI) плитка L×Box показывала сплошной белый квадрат. Статичная манифест-иконка TileService указывала на полноцветный лаунчер-логотип; Android прогоняет QS-иконку через монохромный tint и заливает всю непрозрачную область белым. Иконка перенацелена на монохром-vector `ic_lxbox_tile` — тот же, что в рантайме.
- **WARP: кастомный endpoint из Advanced больше не затирается (§135).** Свой `IP:port`, вписанный в Advanced (живой Cloudflare-endpoint на нестандартном порту), раньше перетирался дефолтным `engage.cloudflareclient.com:2408` из ответа Cloudflare — Advanced-поле было фактически мёртвым. Теперь пользовательский endpoint сохраняется. +2 теста.
- **Node-list: последний узел не уезжает под нижние controls (§134).** Добавлен запас в одну строку под прокруткой списка узлов — последний узел больше не прячется за нижней панелью управления.

## 🇷🇺 L×Box v2.3.2 на русском

- **WARP теперь маскируется под настоящий QUIC** — прежний junk-шаблон (WG-traffic) DPI у части провайдеров не пробивал. Теперь обфускация имитирует настоящий QUIC-трафик с рандомным адресом сервера из блоков Cloudflare — так же, как работают публичные WARP-генераторы, которые проходят там, где наш прежний шаблон резался. SNI выбирается из списка популярных сайтов, `Random` или свой.
- **Понятные имена WARP-узлов** — узлы получают теги вроде `🔥☁️ WARP` (обычный) и `🔥⛈️ WARP (AWG 1.5)` (с маскировкой от DPI). Повторный Get WARP больше не удаляет прежние узлы — можно держать несколько разных конфигов.
- **Фикс белого квадрата** — плитка L×Box в редакторе шторки быстрых настроек больше не отображается пустым белым квадратом.
- **Фикс Advanced-endpoint WARP** — свой `IP:port` в настройках WARP теперь действительно применяется, а не затирается дефолтным.
- **Мелочь по списку узлов** — последний узел больше не прячется под нижней панелью.
