## 11. F-Droid / Google Play — fastlane changelogs

**versionCode для v2.25.0** (`scripts/version-code.sh 2.25.0 <abi>`):

| ABI | versionCode |
|---|---|
| universal | 22500500 |
| armeabi-v7a | 22500501 |
| arm64-v8a | 22500502 |
| x86_64 | 22500504 |

F-Droid и Play (§2.3 п.4, §436) требуют тексты для **armeabi-v7a** и **arm64-v8a** в `fastlane/metadata/android/{en-US,ru}/changelogs/<versionCode>.txt` (≤ 500 символов). Локаль `zh` в fastlane **не** ведётся — только en-US и ru (как в `GOOGLE_PLAY.md`).

**Было:** файлов `22500501.txt` / `22500502.txt` не было.

**Сделано в этом прогоне:** добавлены черновики (361 символ EN, 325 RU) — по одному абзацу на ABI-блок, текст одинаковый внутри локали (как у v2.24.4).

**До тега:** после финализации release notes **перепроверить** текст changelogs на соответствие фактическому составу релиза; при необходимости уточнить формулировки. Прогнать лимит:

```bash
python3 -c 'print(len(open(f, encoding="utf-8").read().rstrip("\n")))' fastlane/metadata/android/en-US/changelogs/22500502.txt
```
