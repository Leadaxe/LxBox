## ☁️ Get WARP (features/025)

[Feature spec](docs/spec/features/025%20warp%20integration/spec.md).

Пункт **Get WARP** в overflow-меню Servers (⋮) открывает полноэкранный визард → одно нажатие **Register** → готовый WireGuard-узел к Cloudflare появляется в списке. Для большинства — free WARP в один тап.

**Главное — приватность.** Приватный ключ X25519 генерится прямо на телефоне и **никогда не покидает устройство** — в Cloudflare (`api.devices.cloudflare.com`) уходит только публичная часть. Мы **не** используем сторонние воркеры-генераторы (они отдают приватник, сгенерированный на их сервере, то есть знают ключ вашего туннеля).

- **WARP+** (опционально) — под *Advanced* вставьте license key, чтобы привязать WARP+ (Argo Smart Routing, меньше задержка; приватность та же, что у free). Пусто = free WARP. Битый ключ не ломает регистрацию — узел добавляется как free.
- **Идемпотентность** — повторный Get WARP переиспользует уже зарегистрированный аккаунт (кеш на устройстве), не плодя лишних регистраций в Cloudflare. *Re-register* под *Advanced* форсит свежий аккаунт.
- **Custom endpoint** — под *Advanced*: если дефолтный `engage.cloudflareclient.com:2408` заблокирован, впишите рабочий `IP:port`.

Под капотом добавлена поддержка WireGuard `reserved` (Cloudflare `client_id` → per-peer `reserved: [b0,b1,b2]`) — без неё handshake проходит, но трафик не идёт. Работает для любого WARP-источника, не только Get WARP.

## 🇷🇺 L×Box v2.3.0 на русском

- **Get WARP** — Cloudflare WARP в один тап. Пункт в меню «три точки» на экране Servers → визард → готовый WireGuard-узел к Cloudflare.
- **Ключи на устройстве** — приватный ключ генерится на телефоне и не покидает его; в Cloudflare уходит только публичный. Без чужих сайтов-генераторов.
- **WARP+** (по желанию) — вставьте license key под *Advanced* для Argo Smart Routing. Пусто = бесплатный WARP.
- **Без дублей** — повторное нажатие переиспользует тот же аккаунт; *Re-register* создаёт новый. Под *Advanced* можно сменить endpoint, если дефолтный заблокирован.
