# L×Box v2.15.7

**Глубокий сон туннелей.** Ядро обновлено до **v1.14.0-lx.7** — в нём появился
третий уровень энергосбережения: туннель, который проспал достаточно долго,
теперь не просто «заморожен», а **снесён полностью** — освобождается всё, что он
занимал, включая сетевой стек. Пробуждение автоматическое, на первом же
соединении. Проверено на устройстве: полный цикл засыпание → снос → пересборка
отработал на всех туннелях, включая AmneziaWG.

Настраивать ничего не нужно — уровень включается сам, наследуя окно от уже
существующей настройки «Suspend active-route tunnels» (5 минут по умолчанию).

## 🆕 Что нового

- **Третий уровень idle-suspend** (ядро SPEC 020). Полная лесенка сна теперь
  такая:

  | Что происходит | Когда (дефолты) |
  |---|---|
  | Туннель вне активного маршрута замерзает | через 30 с простоя |
  | Туннель активного маршрута замерзает | через 5 мин простоя |
  | **Любой спящий туннель сносится целиком** | ещё через 5 мин сна |
  | Пробуждение | первое же соединение: +1 RTT (замороженный) / ~0.5–1 с (снесённый) |

  Живые соединения не рвутся: туннель с активной передачей просто не засыпает,
  а сносятся только уже спящие.

- **Замечание об ожиданиях по памяти** (честно, по замерам): основную экономию
  RAM даёт первый уровень — заморозка (−134 МБ при 8 туннелях в старом замере).
  Снос добирает сетевой стек (~6 МБ на туннель) и заметен на конфигах с
  **многими** туннелями; на трёх разница в общей куче почти не видна, потому что
  большую её часть держит общий буферный пул ядра, живущий всё время работы VPN.
  Подробности и вся модель: [lx-energy.ru.md](https://github.com/Leadaxe/sing-box-lx/blob/lx/docs-lx/lx-energy.ru.md).
