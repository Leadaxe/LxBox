# L×Box v2.10.1

**Патч — фильтр профайлера.** Окно фильтра соединений получило две новые оси
(**Rule** и **Outbound**) и **поле поиска** над вкладками. Теперь видно, какой
текстовый фильтр активен, и его можно снять одним тапом. Ядро без изменений —
**v1.14.0-lx.2**.

## 🆕 Новое

- **Фильтр профайлера по правилам и каналам** (§230) — в окне фильтра
  соединений добавлены две оси:
  - **Rule** — фильтр по route-правилу, которое сматчило соединение (без
    правила → «final»);
  - **Outbound** — фильтр по любому звену маршрута: селектор, канал или
    detour-транспорт (например WARP).

  Плюс над вкладками появилось **поле поиска** (domain / IP / app). Клик по
  домену в детали соединения кладёт значение в это поле — теперь видно, какой
  фильтр активен, его можно отредактировать или очистить крестиком (раньше
  фильтр применялся, но нигде не отображался и снимался только через «Reset
  all»). Списки Rule/Outbound собираются из текущего трафика. *Проверено на
  устройстве.*

## 📲 Install

```bash
adb install -r LxBox-v2.10.1-arm64-v8a.apk
```

Без uninstall! Поверх существующей установки. Настройки и подписки сохранятся.
