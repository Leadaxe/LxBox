# L×Box v2.19.6

Packaging only — the app itself is unchanged since 2.19.5. Both changes come
from the F-Droid review.

Только упаковка — само приложение с 2.19.5 не менялось. Обе правки пришли из
ревью F-Droid.

<details open>
<summary><h2>🇬🇧 English</h2></summary>

## 🏪 Changed — store metadata moved to the repository root

F-Droid looks for fastlane metadata only at the root of a repository. Ours sat
in `app/`, so it was invisible: descriptions and screenshots would have had to
go through the F-Droid team instead of being maintained here.

| Before | After |
|---|---|
| `app/fastlane/metadata/android/` | `fastlane/metadata/android/` |

## 🔒 Changed — the Gradle wrapper verifies what it downloads

`gradle-wrapper.properties` had no `distributionSha256Sum`, so the Gradle
distribution was fetched without any integrity check. A compromised Gradle
server or an intercepted connection would have gone unnoticed.

The checksum now pins `gradle-8.14-all.zip`.

## ✅ Tests

`flutter analyze` clean, 2937 tests pass, all four l10n checkers green.

</details>

<details open>
<summary><h2>🇷🇺 Русский</h2></summary>

## 🏪 Изменено — витрина переехала в корень репозитория

F-Droid ищет fastlane-метаданные только в корне репозитория. У нас они лежали
в `app/` и потому были не видны: описания и скриншоты пришлось бы обновлять
через команду F-Droid, а не поддерживать здесь.

| Было | Стало |
|---|---|
| `app/fastlane/metadata/android/` | `fastlane/metadata/android/` |

## 🔒 Изменено — Gradle-обёртка проверяет, что скачала

В `gradle-wrapper.properties` не было `distributionSha256Sum` — дистрибутив
Gradle скачивался без проверки целостности. Подмена на стороне серверов Gradle
или перехват соединения прошли бы незаметно.

Теперь контрольная сумма фиксирует `gradle-8.14-all.zip`.

## ✅ Тесты

`flutter analyze` чистый, 2937 тестов проходят, все четыре l10n-чекера зелёные.

</details>
