# L×Box v2.4.2

**Движок шаблона переписан на типизированную подстановку с декларативными `#if` (§120).** VPN-mode больше не собирается императивным кодом — он описан прямо в `wizard_template.json` через условные конструкции `#if`. Вкладка **VPN Mode** стала data-driven: контролы рисуются из template-нод, а listen-адрес локального прокси теперь **произвольный IPv4** (комбобокс с подсказками `127.0.0.1` / `0.0.0.0`). Добавлен пресет **«Block unknown traffic»** — режет неатрибутированный трафик в туннеле. Ядро → `v1.13.13-lx.15`.

## ✨ Added

| # | Что |
|---|---|
| §033 | **Пресет «Block unknown traffic» (`block_unknown`).** Reject/direct трафика в туннеле без атрибуции к установленному приложению (фоновые / чужие процессы). Inline `rule_set {invert:true, package_name_regex:"^"}` матчит соединения с пустым `AndroidPackageNames`. Outbound настраивается `reject` (по умолчанию) или `direct`. ⚠ Ловит **всю** неатрибутированную атрибуцию (system/root UID, egress туннеля, сбой `find_process`), не только foreign-процессы |

## 🇷🇺 Кратко на русском

- **Движок шаблона переписан (§120)** — подстановка значений теперь строго по объявленному типу (пароль из цифр больше не превращается в число), а условную логику конфига можно писать прямо в шаблоне через `#if`. Внешне ничего не сломалось — это фундамент под более гибкие пресеты.
- **VPN Mode переведён на декларативный шаблон (§120/§119)** — режимы VPN / Proxy / VPN+Proxy и локальный socks/http-прокси больше не зашиты в код, а описаны в шаблоне. Сама вкладка теперь строится из шаблонных нод.
- **Адрес прокси — любой (§119)** — раньше можно было выбрать только `127.0.0.1` или `0.0.0.0`; теперь это комбобокс, куда можно вписать произвольный IP (например, конкретный LAN-адрес). Если адрес не локальный — пароль на прокси обязателен.
- **Пресет «Block unknown traffic» (§033)** — блокирует (или пускает напрямую) трафик в туннеле, который не привязан ни к одному установленному приложению. Полезно против фоновых/системных утечек, но учтите: под раздачу попадает **весь** неопознанный трафик.
- **Ядро → `v1.13.13-lx.15`**.
