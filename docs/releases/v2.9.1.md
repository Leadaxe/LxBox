# L×Box v2.9.1

**Релиз стабилизации.** Глубокий аудит всего кода (`develop` после v2.9.0)
вскрыл и закрыл серию багов логики, которые не ловит статический анализ. Новых
флагманских фич нет — единственная новая опция — переключатель **«Allow
rotation»** по фидбэку планшетных юзеров. Ядро обновлено до стабильного
**v1.14.0-lx.2** (correctness-пасс, device-verified).

## 🆕 Новое

- **Allow rotation** (§220) — App Settings → General. Снимает портретную
  фиксацию: ориентацию решает системный auto-rotate (удобно на планшетах).
  Default OFF (портрет, как раньше). Применяется сразу, без рестарта.

## 🐞 Исправления

Аудит §219 прошёл по всему коду. Ключевые баги (все — с реальным user-impact):

| Симптом | Причина | Фикс |
|---|---|---|
| **Туннель не стартует** (fatal sing-box) | `route.final` на auto-двойник канала с пустым node-set → висячая ссылка | validFinals из фактически эмитированных outbound'ов + validator проверяет `route.final` |
| **WARP-трафик не идёт** (handshake проходит) | JSON-парсер WireGuard не заполнял `reserved` (client_id) | заполняется, как в URI-парсере |
| **Разный MTU** у одной ноды | JSON и URI парсеры давали разный дефолт | унифицировано (1408) |
| **Backup терял всю модель роутинга** | `channels` (§125) был в allowlist restore, но не в backup-экспорте → потеря при переносе на новое устройство | §221 — `channels` + `channels_migrated` + `route_idle_suspend` + `profiler_retention_sec` в экспорт; тест-инвариант allowlist ⊆ export |
| **Backup терял MASQUE-аккаунт** | `masque_account` не в allowlist top-level ключей | добавлен |
| **Удалялась не та подписка** после drag-reorder | экран деталей брал устаревший `widget.index` | index по ссылке |
| **Профайлер терял тип outbound** (§204) | не копировался при resolve/backfill | копируется |
| **Утечки соединений** | `http.Client` не закрывался (подписки, community-loader, support-message) | закрывается |
| **Срок подписки «1970»** | `expire=0` при непарсимом значении трактовался как timestamp | → null |
| **Пустой SSID молчал** в ручном добавлении Wi-Fi | ошибка была привязана только к BSSID | отдельная ошибка SSID |
| Редкие краши при закрытии экрана | use-after-dispose гонки в `home_controller` | единый гейт `_disposed` |

## 🧹 Уборка

- **Мёртвый код:** неиспользуемая зависимость `crypto`; write-only поля;
  фикстуры старого Clash API (69 КБ); заглушка `widget_test`; видимый чип
  «Clash API» → «CommandClient».
- **Дедуп:** общие хелперы для snackbar / диалогов подтверждения / базовых
  outbound'ов парсера — вынесены из копипасты по экранам.
- **Оптимизация:** убраны лишние пересборки виджетов и повторные пересчёты в
  `build()` (главный экран, роутинг, DNS, статистика); RegExp-константы.
- **Документация:** Debug API reference синхронизирован с кодом; ARCHITECTURE.md
  актуализирован. Полный отчёт аудита — `docs/spec/tasks/219-deep-audit-2026-07.md`.

## ⚙️ Ядро v1.14.0-lx.2

Стабильный релиз (device-verified), correctness-пасс без новых фич и
config-изменений:

- **MASQUE (h2):** зависший CONNECT больше не клинит outbound навсегда —
  handshake ограничен dial-контекстом.
- **AmneziaWG:** guard-suspended endpoint не воскрешается дозвоном.
- Плюс: гонка XHTTP-ридера, DNS-события на свежем cache-hit, `GetPool` для
  вложенных групп, AmneziaWG `s4`-MTU.
