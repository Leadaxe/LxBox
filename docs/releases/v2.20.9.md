# L×Box v2.20.9

A maintenance release. The app no longer checks GitHub for new versions on its
own when it was installed from F-Droid or Google Play — the store's own client
already does that, and F-Droid's reviewer counts an unprompted call home as an
anti-feature. The "Check now" button stays everywhere. The core was also
re-pinned; that part is Windows-only and changes nothing on Android.

Технический релиз. Приложение больше не ходит на GitHub за новыми версиями
само, если установлено из F-Droid или Google Play — там о них сообщает клиент
магазина, а самостоятельный поход рецензент F-Droid засчитывает как
anti-feature. Кнопка «Check now» остаётся везде. Заодно перепинено ядро — та
правка касается только Windows и на Android ничего не меняет.

<summary><h2>🇬🇧 English</h2></summary>

## 🔧 Under the hood

**The background update check now runs only in sideloaded builds.** F-Droid's
reviewer blocked [MR!44731](https://gitlab.com/fdroid/fdroiddata/-/merge_requests/44731):
the app reached `api.github.com` five seconds after launch, with
`auto_check_updates` on by default. By the catalogue's rules that is the
`Tracking` anti-feature — an app phoning the developer's server and exposing
your IP to a third party without being asked.

In builds installed from F-Droid or Google Play the background check is off for
good: no timer, the "Check for updates on launch" switch is hidden, and the
snackbar no longer pops up from the cache. Nothing is lost — the store client
already tells you about new versions.

**"Check now" still works everywhere.** Pressing the button yourself is an
explicit action, not a background poll, so it stays in Settings › Updates in
every build, catalogue ones included.

If you installed the APK from GitHub Releases or from a browser, nothing
changes: the check, the switch and the daily throttle behave exactly as before.

The channel is resolved at runtime from `installingPackageName`, the value the
system writes at install time — not from a build flag. A `--dart-define` would
land inside the compiled Dart code, so the F-Droid APK and the GitHub one would
differ byte for byte and reproducible-build verification would fail.

## 🧱 Core

Pinned core `v1.14.0-lx.25-rc.5` → `v1.14.0-lx.27-rc.1`: a Windows-only
WireGuard fix, where a failed IPv6 bind used to tear down the working IPv4
socket and leave every WG/AWG node dead from the first second. Android is not
affected — the change is in the `wireguard-go` fork's socket layer — but the
pin is shared across builds, and the Java API is unchanged.

## 🔧 Под капотом

**Фоновая проверка обновлений теперь работает только в sideload-сборках.**
Рецензент F-Droid заблокировал [MR!44731](https://gitlab.com/fdroid/fdroiddata/-/merge_requests/44731):
приложение шло в `api.github.com` через пять секунд после запуска, причём
`auto_check_updates` был включён по умолчанию. По правилам каталога это
anti-feature `Tracking` — приложение само стучится на сервер разработчика и
показывает ваш IP третьей стороне, хотя его об этом не просили.

В сборках из F-Droid и Google Play фоновая проверка выключена насовсем:
таймера нет, переключатель «Check for updates on launch» скрыт, снек из кеша
больше не всплывает. Ничего не теряется — о новых версиях сообщает клиент
магазина.

**Кнопка «Check now» остаётся везде.** Нажатие — явное действие пользователя,
а не фоновый опрос, поэтому кнопка есть в «Настройках › Updates» во всех
сборках, включая каталожные.

Если вы ставили APK из GitHub Releases или из браузера, для вас не меняется
ничего: проверка, переключатель и суточный throttle работают как раньше.

Канал определяется в рантайме по `installingPackageName` — значению, которое
система записывает при установке, — а не флагом сборки. `--dart-define` попал
бы в скомпилированный Dart-код, APK из F-Droid и APK с GitHub разошлись бы
побайтово, и сверка воспроизводимой сборки упала бы.

## 🧱 Ядро

Пин ядра `v1.14.0-lx.25-rc.5` → `v1.14.0-lx.27-rc.1`: фикс WireGuard, который
касается только Windows — там провалившийся bind IPv6 закрывал уже работающий
сокет IPv4, и все WG/AWG-узлы были мертвы с первой секунды. Android это не
затрагивает (правка в сокетном слое форка `wireguard-go`), но пин у сборок
общий; Java-API не изменился.
