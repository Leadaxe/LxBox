## 🎭 MASQUE для WARP (§130)

**WARP — это сервис Cloudflare, а транспорт к нему теперь на выбор.**

| Транспорт | Что это |
|---|---|
| **WireGuard** (как раньше) | UDP + WireGuard, привычный WARP |
| **MASQUE** (новое) | CONNECT-IP (RFC 9484) поверх QUIC/HTTP-3, fallback HTTP/2 |

**Зачем MASQUE:**

- **Другой пул выходных нод** — часто иностранные IP там, где WireGuard-WARP даёт локальные.
- **Маскировка** — для DPI выглядит как обычный HTTPS/QUIC к Cloudflare на 443, а не как «странный UDP».
- **Работает там, где режут UDP** — переключение на HTTP/2 (TCP).

**Как включить:** ⋮ → **Get WARP** → переключатель **WireGuard / MASQUE** → **Register**.

**Приватность:** ECDSA-ключ генерируется **на телефоне**, приватная часть не покидает
устройство (как и у WireGuard-WARP). В Cloudflare уходит только публичный ключ.

## ⚙️ Параметры MASQUE

В визарде при выборе MASQUE доступны:

| Параметр | Значения | По умолчанию |
|---|---|---|
| **Transport** | HTTP/3 (QUIC) / HTTP/2 (TCP) | HTTP/3 |
| **SNI** | combo-box из легит-доменов + свой ввод | случайный домен из пула |
| **Idle timeout** | минуты (пусто = дефолт ядра) | 5 min |
| **Keep-alive** | секунды (только h3) | 30 sec |

SNI-поле — выбор из пула массовых легитимных доменов (`www.cloudflare.com`,
`cdn.jsdelivr.net`, `aws.amazon.com`, google/microsoft/… + крупные РФ-сайты) с
кубиком для случайного и свободным вводом своего.

## 🐞 Исправления

### Debug API `/help?format=json` больше не падает

Секция `errors.codes` имела целочисленные ключи (HTTP-код → описание), а
JSON-кодировщик требует строковые — сериализация роняла весь ответ, соединение
обрывалось (`format=text` при этом работал). Исправлено, добавлен тест.

### Debug API `/help` синхронизирован с реальными роутами (§218)

Самодокументация `/help` разошлась с фактически смонтированными хендлерами —
карта приведена в соответствие.
