# L×Box v2.9.2

**Релиз новых протоколов и правил.** Добавлен транспорт **HTTP(S)-прокси**
(§222) и новый тип правила маршрутизации **Raw JSON** (§225) — power-user'ы
теперь могут задать любой sing-box route-action прямо в правиле. Плюс серия
исправлений уведомления (§223) и понятный текст при перехвате VPN другим
приложением (§224). Ядро без изменений — стабильное **v1.14.0-lx.2** с v2.9.1.

## 🆕 Новое

- **HTTP(S)-прокси** (§222) — поддержка sing-box `type: http`. URI-схемы
  `proxy-http://` / `proxy-https://` (голые `http(s)://` заняты URL-ами
  подписок), полный набор полей sing-box (auth / path / headers / TLS). Приём
  через тела подписок, paste URI, paste JSON и JSON-редактор ноды. Новый таб
  **HTTP** в Add server wizard: host / port / auth + переключатель «HTTPS (TLS)».

- **Правило «Raw JSON»** (§225) — третий тип кастомного правила рядом с Inline
  и Remote (.srs). Вставляете сырое тело route-правила (JSON-объект или массив
  объектов), оно уходит в `route.rules` как есть. Открывает **любой**
  sing-box route-action (`hijack-dns` / `sniff` / `resolve` / `route-options`)
  без отдельной формы под каждое поле — действие часть тела. Битый JSON
  пропускается с предупреждением (конфиг не падает); висячий `outbound` внутри
  тела ловит существующий валидатор перед стартом.

## 🐞 Исправления

| Симптом | Причина | Фикс |
|---|---|---|
| **Подтекст уведомления замерзал** на ноде момента старта (§223, #20) | смена ноды слала свежие лейблы, но native их только кэшировал — рендер был лишь на connect | перерисовка шторки при смене лейбла на работающем туннеле (кнопки Stop/Reconnect не дублируются) |
| **Пустой подтекст при старте с плитки** (§223, #23) | старт с QS-плитки / shortcut без UI — лейблы прислать некому, оставалось `Connected` | native сам читает выбранную ноду через ~3 с одним запросом (без фоновой подписки — батарея не страдает) |
| **«VPN taken by another app»** вводило в заблуждение (§224) | системный VPN-слот (он один) в окне Stop→Start перехватывает другой Always-on / kill-switch VPN — revoke настоящий, но текст непонятный | три revoke-строки переписаны: объясняют, что слот занял другой VPN, и что нужно нажать Start |

## 📲 Install

```bash
adb install -r LxBox-v2.9.2-arm64-v8a.apk
```

Без uninstall! Поверх существующей установки. Настройки и подписки сохранятся.
