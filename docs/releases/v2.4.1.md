# L×Box v2.4.1

**Per-app trace — редизайн (§160).** Вкладка App (детальный трейс по приложению) переехала с 4 саб-табов на тогл **Live / Aggregated** с общим фильтром и drill-down деталями по тапу — и тот же движок (`TraceExplorer`) теперь питает экран **Stats → Live**, так что оба места ведут себя одинаково. Connections удалён (дубль Live), Domains+IPs слиты в `AggregatedView`. Общий фильтр сверху (поиск + чипы типа события) на оба режима + пауза Live ([task](../spec/tasks/160-perapp-trace-live-aggregated-redesign.md), [feature spec](../spec/features/044%20per-app%20traffic%20profiler/spec.md)) |

## 🛠 Fixed

| # | Что |
|---|---|
| §160 | **Чужие приложения протекали в сессию профайлера.** Атрибуция считалась на `open` (чужие отбрасывались), но `tcpClose` писался в сессию **безусловно** — отсюда `verified`-события от youtube/imo/gsf/heytap и пр. в сессии целевого приложения (по Debug API — 14/54 чужих `tcpClose` в сессии Telegram). Фикс: атрибуция фиксируется на `open` (`_ConnSnapshot.inSession`) и наследуется `close`'ом — чужие close уходят, target + unattributed остаются. Сессия / JSON / API / агрегаты / байты снова чистые |

## 🇷🇺 Кратко на русском

- **App-трейс переделан (§160)** — вместо четырёх вкладок (Live / Domains / IPs / Connections) теперь два режима: **Live** (живая лента событий, с паузой) и **Aggregated** (свод по доменам/IP, переключатель оси). Общий фильтр сверху работает в обоих. По тапу на любой строке открываются детали; внутри можно ткнуть домен/IP/процесс, чтобы кинуть его в поиск.
- **Stats → Live теперь такой же** — оба экрана используют один движок, ведут себя одинаково (детали, агрегат, пауза появились и в Stats → Live).
- **Фикс «чужие приложения в статистике»** — раньше в трейс выбранного приложения иногда попадали соединения посторонних приложений. Больше не попадают.
- **Ядро без изменений** — `v1.13.13-lx.14`.
