# L×Box v2.15.3

**Лимит памяти ядра стал настраиваемым.** С v2.10.0 ядру был жёстко задан
потолок памяти 200 MB. На конфигах с большими WireGuard-пулами живая память
упиралась в него постоянно, и сборщик мусора Go работал без остановки —
процессор грелся на ровном месте. Захват pprof показал 304% CPU, из которых
~88% приходилось на GC. Теперь потолок задаётся в настройках, а по умолчанию
подбирается по объёму памяти устройства. Ядро без изменений — **v1.14.0-lx.3**.

## 🆕 Новое

- **Memory limit — новая настройка** (§271). VPN Settings → **System** →
  **Optimization** → **Memory limit**:

  | Значение | Что делает |
  |---|---|
  | **Auto** (по умолчанию) | Потолок по объёму RAM устройства: <3.5 GiB → 200 MB, 3.5–7 GiB → 384 MB, ≥7 GiB → 512 MB |
  | **Off** | Потолка нет — как в v2.5–v2.9 |
  | 200 / 384 / 512 / 768 MB | Фиксированное значение |

  - **Применяется мгновенно** — переподключать VPN не нужно.
  - **Off не отключает защиту от нехватки памяти**: сторож ядра переключается
    на слежение за свободной памятью системы, так что процесс по-прежнему
    защищён от аварийного завершения при её нехватке.
  - Значение сохраняется в резервной копии (блок настроек VPN).

  Что было и что стало:

  | | Было (v2.10.0–v2.15.2) | Стало (v2.15.3) |
  |---|---|---|
  | Потолок памяти ядра | 200 MB, жёстко зашит | Auto по RAM устройства (512 MB на 8 GB-телефоне) |
  | Настройка пользователем | нет | Auto / Off / 200–768 MB |
  | Применение | — | сразу, без переподключения |

```bash
adb install -r LxBox-v2.15.3-arm64-v8a.apk
```
