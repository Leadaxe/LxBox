# L×Box v2.10.0

**Релиз про IPv6 и FakeIP.** Туннель теперь поднимает полноценный **IPv6**
(§227) — если провайдер выдаёт v6, трафик идёт по нему, а не сваливается в
IPv4. И новый DNS-режим **FakeIP** (§228) — мгновенный DNS без утечки провайдеру
плюс точный роутинг по доменам. Заодно правила **BitTorrent**, **Private IPs** и
**Russia-only** получили выбор канала. Ядро без изменений — **v1.14.0-lx.2**.

## 🆕 Новое

- **Полноценный IPv6 в туннеле** (§227) — раньше TUN поднимал только IPv4, и
  даже при рабочем IPv6 у провайдера трафик сваливался в IPv4. Теперь на
  интерфейсе два адреса (v4 + v6), весь IPv4 и весь IPv6 заворачиваются в
  туннель, а стратегия резолва по умолчанию — `prefer_ipv6` (сначала IPv6, при
  отсутствии AAAA — IPv4; безопасно и для сетей без v6). Новое поле **IPv6
  address** в VPN Settings → Core → TUN. Работает на всех Android, включая < 13
  (явный IPv6-маршрут). *Проверено на устройстве.*

- **FakeIP — быстрый DNS без утечки** (§228) — новый пресет правил (по умолчанию
  выключен). На запрос имени приложение мгновенно получает placeholder-IP из
  пула `198.18.0.0/15` (v4) / `fc00::/18` (v6), а настоящий резолв домена
  происходит **внутри туннеля**. Что это даёт:
  - **скорость** — DNS-ответ без похода в интернет (0 latency);
  - **нет утечки** — провайдер не видит реальных доменов, только коннект на
    служебный IP;
  - **точный роутинг** — по имени, а не по IP (один CDN-IP = сотни сайтов).

  Таблица «фейк ↔ домен» переживает реконнекты (`store_fakeip`), поэтому после
  переподключения соединения не залипают. Пресет стоит после «Russian domains
  & IPs», чтобы русские домены резолвились по-настоящему и GeoIP-роутинг
  работал. Не заменяет обход DPI (DPI режет по SNI, а не по DNS). *Проверено на
  устройстве.*

- **Выбор канала для BitTorrent / Private IPs / Russia-only** (§228) — эти
  правила больше не прибиты к «direct»:
  - **BitTorrent** — можно увести в отдельный канал;
  - **Private IPs** — направить в канал, чтобы достучаться до удалённого
    роутера/LAN через VPN;
  - **Russia-only services** — пустить через российский канал, чтобы открывать
    их из-за рубежа.

  По умолчанию — по-прежнему direct. Названия правил BitTorrent и Private IPs
  упрощены (убран суффикс «direct»); ранее выбранные настройки сохраняются
  автоматически при обновлении.

## ⚙️ Изменения

| Область | Что изменилось |
|---|---|
| **DNS-стратегия** | Дефолт `prefer_ipv4` → `prefer_ipv6` — сайты с IPv6 открываются по IPv6, остальные по IPv4. Кто хочет прежнее поведение — переключает в App Settings. |
| **Порядок обработки трафика** | `sniff` теперь идёт до `resolve` — домен извлекается раньше резолва (нужно для FakeIP, корректно и для обычного роутинга). |
| **Outbound-переключатель в правилах** | Показывается только у правил, где выбор канала имеет смысл. У чисто-блокирующих (Block Ads) и DNS-правил (FakeIP) переключателя больше нет — он там ничего не делал. |
