# L×Box v1.8.3

«Pre-commit hook auto-sync» release. v1.8.2 убрал hardcoded const, но требовался manual `scripts/build-local-apk.sh` для realistic версии в dev sessions. v1.8.3 — финал: git pre-commit hook делает sync автоматом, `flutter run` показывает realistic версию без extra шагов.

**Кому актуально**: разработчикам — упрощается dev workflow. Юзеру невидимо.

---

## 🛠 Что внутри

### Pre-commit hook auto-sync ([§066](../spec/tasks/066-pubspec-sync-hook.md))

```bash
# .githooks/pre-commit (3 строки)
#!/usr/bin/env bash
"$(git rev-parse --show-toplevel)/scripts/sync-pubspec-version.sh"
git add "$(git rev-parse --show-toplevel)/app/pubspec.yaml"
```

```bash
# scripts/sync-pubspec-version.sh (~10 строк)
TAG=$(git describe --tags --abbrev=0)
SINCE=$(git rev-list "$TAG..HEAD" --count)
TOTAL=$(git rev-list HEAD --count)
VER="${TAG#v}"
[ "$SINCE" = 0 ] || VER="$VER-dev.$SINCE"
sed -i.bak "s/^version: .*/version: $VER+$((TOTAL+1))/" app/pubspec.yaml
```

Каждый `git commit` запускает hook → pubspec.yaml автоматически правильный.

### Setup для нового clone

```bash
git clone https://github.com/Leadaxe/LxBox.git
cd LxBox
./scripts/setup-hooks.sh   # one-shot — git config core.hooksPath .githooks
```

### UpdateChecker `-dev` skip

`hydrate()` и `maybeCheck()` теперь exit early если version содержит `-dev` или начинается с `0.0.0`. Никаких раздражающих snackbar'ов «v1.8.3 available» при dev sessions.

Manual «Check now» из UI всё ещё работает — юзер явно нажал кнопку.

### Что упрощено

- `scripts/build-local-apk.sh` — убраны 5 `--dart-define BUILD_*` флагов
- `app/lib/screens/about_screen.dart` — удалены 5 `String.fromEnvironment` const'ов + `_LocalBuildBadge` widget
- `.github/workflows/ci.yml` — inject step остался (для tag override), но без BUILD_* передач

### Dev workflow до vs после

**До (v1.8.2)**:
```bash
# Хочешь правильную версию в `flutter run`? Нет, увидишь 0.0.0-dev.
# Хочешь правильно собрать APK? Запусти build-local-apk.sh (он sed + revert).
flutter run                         # видишь v0.0.0-dev в About
scripts/build-local-apk.sh          # APK с правильной версией
```

**После (v1.8.3)**:
```bash
./scripts/setup-hooks.sh            # один раз после clone
# Дальше — обычный workflow:
git commit -m "..."                 # hook auto-sync pubspec
flutter run                         # видишь v1.8.2-dev.3 в About
scripts/build-local-apk.sh          # APK с той же версией
```

## 🇷🇺 LxBox v1.8.3 на русском

**Что изменилось для разработчиков**: pubspec.yaml теперь обновляется автоматически на каждом `git commit` через pre-commit hook. После clone репозитория нужно один раз сделать `./scripts/setup-hooks.sh`, после этого версия в pubspec всегда синхронизирована с git state.

**Для пользователя**: никаких видимых изменений. Production APK как и раньше получает чистую `X.Y.Z` версию (CI override'ит при tag push).

**Bonus**: UpdateChecker больше не предлагает «обновиться» в dev sessions — `-dev` версии игнорируются автоматически.
