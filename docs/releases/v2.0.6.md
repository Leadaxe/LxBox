## ✨ DNS (§117)

[Feature spec](docs/spec/features/117%20dns-rework/spec.md).

Field report (4PDA, Pixel 7): DNS-запросы приложений шли мимо туннеля — забугорный DNS видел реальный IP провайдера, а не VPS. Раньше это собиралось вручную из трёх кусков (routing-правило + DNS-сервер + DNS-правило) без UI-управления. Теперь DNS управляемый и связный:

- **Per-server detour + IP-профиль в UI.** Каждый DNS-сервер шаблона — обёртка с переменными: через какой канал ходит (`detour`) и какой IP/профиль. У adguard-сервера выбрал Outbound = VPN-канал → DNS уходит через туннель.
- **Опция DNS у правила.** Routing-правило само регистрирует DNS-правило на выбранный сервер — не надо руками собирать тройку. Inline и srs, гейт по ports/protocols.
- **Полноэкранный редактор DNS-сервера** (паттерн как у правил): табы Params/JSON, **форма создания UDP / DoT / DoH** (раньше надо было писать sing-box JSON руками), inline-detour, переименование тега с каскадом по всем ссылкам.
- **DNS Rules причёсаны**: DNS-аспект пресета и DNS-опция правила — единый вид со switch; фикс обрезки контента по высоте.

Проверено `sing-box check` на ядре lx.6: server-vars, inline+dns, srs+dns конфиги валидны.

## 🌐 Subscriptions (§118)

[Feature spec](docs/spec/features/118%20subscription-fetch-identity/spec.md).

Новый таб **App Settings → Subscriptions** (туда же переехало авто-обновление):

- **Custom User-Agent** — override дефолтного `LxBox-android/<версия>` на каждом фетче подписки. Часть панелей отдаёт конфиг по подстроке в UA — поле для тех, кому надо подменить (с предупреждением про токен).
- **Send HWID** (off по умолчанию) — для панелей с HWID-device-limit (Remnawave): шлёт `x-hwid` (UUID, генерится один раз, Regenerate ↻) + device-meta `x-device-os` / `x-ver-os` / `x-device-model`. **Все четыре заголовка переписываемые** — у каждого device-дефолт + override.

## 🇷🇺 L×Box v2.0.6 на русском

- **DNS через VPN-канал**: у каждого DNS-сервера в UI выбирается, через какой канал он ходит (detour) и какой IP/профиль. Нужным приложениям DNS можно пустить через туннель — забугорный резолвер увидит IP VPS, а не провайдера.
- **Опция DNS у правила**: правило само регистрирует DNS на выбранный сервер — не надо собирать вручную из трёх частей.
- **Удобный редактор DNS-серверов**: тап → полноэкранный редактор с формой UDP / DoT / DoH (раньше — только сырой JSON), переименование сервера с авто-обновлением всех ссылок.
- **Новый таб Subscriptions**: кастомный User-Agent и HWID (для панелей с лимитом устройств, Remnawave) — все заголовки переписываемые.
