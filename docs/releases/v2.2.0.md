## 🧭 Режим работы VPN (features/119)

[Feature spec](docs/spec/features/119%20vpn-mode/spec.md).

Раньше L×Box работал в единственном режиме — системный TUN-туннель, весь трафик устройства заворачивается через VPN. Теперь в **VPN Settings → вкладка Mode** можно выбрать, как ядро ловит трафик:

| Режим | Что делает |
|---|---|
| **VPN** (по умолчанию) | системный туннель через TUN — весь трафик, как раньше |
| **Proxy** | локальный HTTP/SOCKS-порт **без** TUN — приложения настраиваются вручную, нет иконки ключа VPN, нет системного перехвата |
| **VPN+Proxy** | системный туннель И локальный порт одновременно |

Локальный прокси настраивается:

- **Протокол**: `Mixed` (HTTP+SOCKS5 на одном порту), `HTTP` (только HTTP, без UDP) или `SOCKS5`.
- **Порт**: по умолчанию `2080`.
- **Listen-адрес**: `127.0.0.1` (только это устройство) или `0.0.0.0` (доступен другим устройствам в локальной сети).
- **Авторизация**: логин/пароль с автогенерацией пароля. На `0.0.0.0` (LAN) авторизация обязательна — отключить нельзя.

Реализовано **чисто конфигом** (sing-box `mixed`/`http`/`socks` inbound + трансформация маршрутов), без изменений в native-коде: при отсутствии tun-inbound libbox просто не поднимает Android VpnService. **Backward-compat:** у существующих пользователей режим = `VPN`, конфиг байт-в-байт прежний.

## 🇷🇺 L×Box v2.2.0 на русском

- **Режим работы VPN**: новая вкладка **Mode** в настройках. Три режима — **VPN** (системный туннель, как раньше), **Proxy** (локальный прокси-порт без захвата всего трафика — настраиваешь приложения вручную, нет иконки ключа VPN) и **VPN+Proxy** (и то, и другое сразу).
- **Локальный прокси**: выбор протокола (Mixed = HTTP+SOCKS5, либо отдельно HTTP / SOCKS5), порт (по умолчанию 2080), адрес прослушивания (`127.0.0.1` только для этого устройства или `0.0.0.0` для доступа из локальной сети) и логин/пароль с автогенерацией. На `0.0.0.0` авторизация обязательна.
- Существующие пользователи ничего не заметят — по умолчанию остаётся режим VPN с прежним поведением.
