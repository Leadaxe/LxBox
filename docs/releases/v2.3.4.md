## 🔧 Changed

| # | Было | Стало |
|---|---|---|
| §143 | Junk-пакет `i1` генерировался в Dart (один QUIC-вариант) | Маскировка задаётся полями `ip`/`id`/`ib`, пакет генерирует **ядро**. 4 протокола: **QUIC / DNS / STUN / SIP** |
| §143 | — | В визарде (Advanced): выбор **протокола**, **домена (id)**, **браузера (ib)** (Chrome/Firefox/cURL, при QUIC) |
| Ядро | `v1.13.13-lx.10` | **`v1.13.13-lx.11`** (поддержка `id/ip/ib` masquerade) |

**Где домен виден цензору:** `DNS` (как QNAME) и `SIP` (как host) несут домен на провод; `QUIC`/`STUN` — нет (домен декоративен). Выбирай протокол под задачу.

## 🗑 Removed

| # | Что |
|---|---|
| §143 | Dart-генератор `i1` (`quic_i1.dart`, самописный AES, генератор имён для SIP) — заменён генерацией на стороне ядра |
| §143 | Выбор шаблона QUIC/SIP и параметр QUIC level — заменены полем `ip` |

## 🇷🇺 Кратко на русском

- **WARP-обфускация: 4 протокола маскировки** (QUIC / DNS / STUN / SIP) вместо одного. Теперь сам junk-пакет собирает ядро по трём полям: протокол / домен / браузер — выбираются в Advanced при создании WARP.
- **DNS и SIP показывают домен на проводе** (под популярный сайт), QUIC/STUN — нет. Выбирай под свою сеть.
- **Новое ядро** `v1.13.13-lx.11` с поддержкой этого механизма.
