## ✨ Added

| # | Что |
|---|---|
| §148 | **Лейблы уровня AWG** — нода показывает `awg` / `awg1.5` / `awg2` по официальной классификации AmneziaWG (по старшему присутствующему маркеру в сыром JSON). Masquerade (`ip`/`id`/`ib`) добавляет суффикс **`+`** |
| §149 | **Servers → «Import from file…»** — новый пункт overflow-меню (⋮), в группе «добавить контент извне» (после `Scan QR code`). Импорт конфига/подписки из локального файла |
| §147 | **Debug API: `POST /warp`** — программная регистрация WARP-узла без UI (тот же путь, что кнопка Get WARP). Все поля опциональны (`licenseKey`/`endpoint`/`obfuscate`/`forceNew`/`includeReserved`/`quicParams`); `obfuscate=true` → §143 masquerade; `?rebuild=true` регенерирует конфиг. Debug-only (bind 127.0.0.1, bearer-token) |

## 🛠 Fixed

| # | Что |
|---|---|
| §141 | **JNI no-throw** — `BoxService.serviceReload`/`getSystemProxyStatus`/`setSystemProxyEnabled`: внешнее тело обёрнуто `runCatching` + fail-safe. Unchecked exception через JNI = `Runtime::Abort` всего процесса (крашило старые API) |
| §141 | `cancelMassPing()` теперь зовётся в disconnected/revoked-ветке `_handleStatusEvent` (симметрия с `_onTunnelDead`) |
| §141 | `.handleError` на status-broadcast перед `asBroadcastStream` — анти-зомби стрима |
| §141 | Гонки read-after-await: снимок `tunnelUp` снимается один раз после `await` (не по устаревшему статусу) |
| §148 | Чистка WARP endpoint-пула: убраны дохлые/режущиеся на LTE-DPI 8.x-блоки. Остались твёрдые anycast `162.159.192/195` + `188.114.96-98` |

## 🇷🇺 Кратко на русском

- **Метки AWG** на нодах: `awg` / `awg1.5` / `awg2` (по официальной классификации Amnezia), а `+` означает включённый masquerade. `awg+` больше не бывает — masquerade всегда поднимает уровень минимум до `awg1.5+`.
- **Импорт серверов из файла** — в меню «⋮» экрана Servers появился пункт «Import from file…».
- **Стабильность (§141):** закрыт класс крашей старых Android из-за исключений на границе JNI; убраны гонки в обработке статуса туннеля; имена платформенных каналов сведены в одно место.
- **Новое ядро** `v1.13.13-lx.12`.
