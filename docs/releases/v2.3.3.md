## 🛠 Fixed

| # | Что было | Что стало |
|---|---|---|
| §142 | В WARP-узел всегда писался `reserved` (Cloudflare `client_id`) — привязка к нашей регистрации устройства, которая на части сетей отбрасывалась | `reserved` стал опцией. При обфускации — выключен по умолчанию (обезличенное подключение); plain WARP — включён. Чекбокс «Bind to this device» в Advanced |
| §136 | Junk-пакет i1 нарезался на `<b>/<r>` — такой узел не поднимался | i1 = цельный валидный QUIC Initial 1250 байт (как у рабочих генераторов). Проверен расшифровкой против RFC 9001 / NIST |
| §138 | При уже созданном WARP-аккаунте выбранный в Advanced endpoint игнорировался — в узел шёл старый | Endpoint применяется к узлу независимо от кеша аккаунта |
| §140 | После обновления «поверх» VPN не стартовал: `Clash API: Connection refused` / `VPN taken by another app`. Причины: гонка освобождения порта 63130 при force-stop + force-kill здорового `Connecting` | Force-stop ждёт завершения teardown до `stopSelf()`; таймаут на `Connecting` больше не убивает живой коннект. Проверено на устройстве |

## 🔧 Changed

| # | Изменение |
|---|---|
| §142 | Убран выбор шаблона junk (QUIC/SIP) — всегда QUIC. Убран параметр QUIC level |
| §142 | SNI-пул маскировки: + `ozon.ru`, `telemost.yandex.ru`; − `youtube`, `amazon` (замедляются в RU-сетях). SNI выбирается из списка / `Random` / вручную |
| §137 | WARP-узлы: теги с эмодзи (`🔥☁️ WARP`, `🔥⛈️ WARP (AWG 1.5)`), накопление вместо замены при повторном Get WARP |

- §140: force-stop и повторный старт проверены на устройстве.

## 🇷🇺 Кратко на русском

- **WARP-обфускация теперь подключается** там, где раньше нет: убрана привязка к устройству (`reserved`), исправлен формат junk-пакета, фикс выбора сервера.
- **Стабильный Start после Stop**: исправлен сбой `Connection refused` / «VPN taken by another app» при перезапуске поверх обновления.
- **Проще настройка WARP**: один режим обфускации (QUIC), домены маскировки под RU-регион.
