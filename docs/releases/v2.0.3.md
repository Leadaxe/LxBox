## ✨ New

### §110 — Импорт Amnezia `vpn://`-ссылок

[Task spec](docs/spec/tasks/110-amnezia-vpn-link-import.md).

Контейнерный share-формат Amnezia / awg2 — то, что отдаёт «Поделиться подключением» и лежит внутри `.vpn`-файла — теперь распознаётся при вставке в Subscriptions «+». Скопируй `vpn://…`-строку → вставь → готово: декодируются **все** WG/AWG-контейнеры ссылки (по ноде на контейнер), карточка подтверждения показывает endpoint и число контейнеров. Раньше единственным путём было открыть `.conf` в редакторе и скопировать текст — теперь оба пути работают.

Технически: `vpn://` + base64url(qCompress(JSON)) → `containers[]` → `last_config.config` → существующий INI-парс. Принимаются и несжатый payload, и base64 с padding; `$PRIMARY_DNS`/`$SECONDARY_DNS` подставляются из конфига; не-WG контейнеры (openvpn/xray/…) скипаются; защита от zlib-бомб (ссылка ≤ 64 KiB, payload ≤ 4 MiB). Оригинальная ссылка хранится как источник — ноды переживают рестарт.

### §112 — AmneziaWG ranged magic headers (`H1 = N-M`) + ядро lx.6

[Task spec](docs/spec/tasks/112-awg-ranged-magic-headers.md).

Свежие awg2-экспорты несут magic headers диапазонами (`H1 = 43613244-384550127`) — формат AWG 2.0. Раньше такие поля молча терялись на импорте, и handshake тихо не проходил (worst case: нода выглядит валидной, коннекта нет). Теперь `h1`–`h4` принимают «число-или-диапазон» во **всех** входах: `.conf`, `awg://`/`wireguard://` URI, sing-box JSON и `vpn://`-импорт §110.

Ядро обновлено: **sing-box-lx `v1.13.13-lx.5` → `v1.13.13-lx.6`** (поддержка ranged headers на уровне endpoint-опций; диапазоны эмитятся строками, одиночные значения — числами, как раньше). Некорректные диапазоны (пересечение, start > end) дают явную ошибку ядра при старте — без молчаливых отказов.

### §111 — Detour для подписок без родных detour-серверов

[Task spec](docs/spec/tasks/111-subscription-detour-without-native-chain.md).

Секция «Detour» на Settings-табе подписки показывалась только если у нод уже есть detour-цепочки из конфига — подписке с плоским списком серверов прописать detour было негде. Теперь для таких подписок появляется компактный пикер **«Detour server»**: выбранный сервер прописывается всем нодам подписки (1-hop), без неприменимых режимов и тоглов. Заодно починен случай, когда ранее выбранный «None» молча гасил новый выбор.

## 🐛 Fixes

### §109 — Tunnel apps: установленные приложения помечались «uninstalled, auto-skipped»

[Task spec](docs/spec/tasks/109-tun-apps-false-uninstalled.md).

На медленных устройствах с длинным списком приложений хвост проверок выбивался за таймаут, и живые приложения до перезапуска помечались «uninstalled, auto-skipped» (field report, 4PDA). Метка была косметической — в туннель пакеты уходили корректно — но уводила диагностику в ложный след. Теперь «не установлено» и «не удалось проверить» — разные состояния: сбой ретраится (2s/5s/15s), иконки тянутся отдельным вызовом и не тормозят метаданные, метка ставится только при подтверждённом отсутствии пакета.

## 🇷🇺 L×Box v2.0.3 на русском

Релиз про Amnezia:

- **`vpn://`-ссылки вставляются напрямую**: скопировал из Amnezia/awg2 (или из `.vpn`-файла) → вставил в Subscriptions «+» → ноды появились. Раньше приходилось добывать `.conf` и копировать текст.
- **Конфиги с диапазонными magic headers (`H1 = N-M`) работают**: новый формат awg2-экспортов раньше молча терял H-поля и коннект не поднимался. Ядро обновлено до sing-box-lx v1.13.13-lx.6, цепочка проверена живым подключением к реальному AWG2-серверу.
- **Detour для плоских подписок**: подписке без родных цепочек теперь можно выбрать detour-сервер одним пикером — пропишется всем нодам.
- **Tunnel apps больше не пугают**: ложные метки «uninstalled, auto-skipped» на установленных приложениях исправлены — сбой проверки ретраится, а не запоминается как «удалено».

Предыдущий релиз: [v2.0.2](docs/releases/v2.0.2.md).
