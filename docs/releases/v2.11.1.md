# L×Box v2.11.1

**Фиксы по горячему фидбэку 4PDA.** Главное — починена регрессия v2.11.0 с
именами импортированных WireGuard-конфигов (§243): теперь **имя файла — это и
есть tag сервера**. Одно имя везде — в списке Servers, в пикере detour и на
главном экране — и правка Tag наконец меняет его во всех местах. Фильтр
профайлера больше **не слетает при переключении вкладок** (§244). Режимы
detour у подписки/папки переименованы в честные **Replace all / Fill missing**
(§245). Плюс кнопка **VPN settings** в диалоге «VPN занят другим приложением»
(§241) и **попап детализации памяти** на Stats (§242). Ядро без изменений —
**v1.14.0-lx.2**.

## 🛠 Фиксы

- **Имя импортированного `.conf` снова редактируется** (§243, регрессия
  v2.11.0, фидбэк 4PDA). В v2.11.0 имя файла записывалось в отдельное
  «имя записи», которое показывалось только в списке Servers и не имело
  отношения к tag — из-за этого правка Tag в настройках сервера не меняла
  имя в списке, а в пикере detour и на главном экране все WireGuard-импорты
  выглядели одинаковым «WireGuard». Теперь **имя файла становится tag'ом
  узла**: одно имя, видно везде, правка Tag работает везде. Отдельное «имя
  записи» у одиночных серверов упразднено.
  ⚠️ У серверов, импортированных на v2.11.0, заголовок в списке сменится с
  имени файла на tag — переименуйте tag один раз, и имя снова будет везде.

- **Члены папки из `.conf`-файлов больше не называются одинаково** (§243,
  фидбэк 4PDA). При импорте нескольких WireGuard/AWG-файлов в папку каждый
  член теперь получает имя своего файла — раньше все назывались «WireGuard»
  (имя файла отбрасывалось из-за служебной пометки парсера).

- **Фильтр профайлера переживает навигацию** (§244, фидбэк 4PDA). Фильтр
  (протокол/домен/приложение/rule/outbound) на вкладках App и Profiler больше
  не сбрасывается при переключении вкладок Stats или уходе с экрана — живёт
  до перезапуска приложения. Сброс руками — Filter → Reset all.

## 🆕 Новое

- **Кнопка «VPN settings» в диалоге «Another VPN is active»** (§241) — когда
  VPN-слот занят другим приложением, третья кнопка диалога открывает системный
  экран Settings → VPN: там активный VPN помечен как «Connected», и виновник
  виден сразу (имя чужого пакета приложению недоступно by design — приватность
  Android).

- **Stats: попап детализации памяти + живые чипы** (§242) — тап по чипу
  памяти открывает разбивку по типам (Dalvik / Native / Code / Stack /
  Graphics / Other) из `Debug.MemoryInfo`; тап по чипу Connections ведёт на
  вкладку Conns. Подпись чипа памяти исправлена: `LxBox` вместо `sing-box`
  (цифра — RSS всего процесса приложения, а не только ядра).

## ⚙️ Изменения

| Область | Что изменилось |
|---|---|
| **Add detour: явные режимы** (§245) | Невнятный toggle «Replace existing chain» у подписки/папки заменён на два режима: **Replace all** (существующие detour-цепочки нод дропаются, все идут через выбранный outbound) и **Fill missing** (ноды со своим detour сохраняют его; outbound получают только ноды без detour — цепочки собираются сами). Fill missing = прежний default, поведение не менялось — только формулировки. |
| **Визард SOCKS/HTTP: одно поле имени** (§243) | Поля «Tag» и «Display name (optional)» слиты в одно **Tag (optional)** — введённое имя и есть заголовок сервера; пустое поле даёт прежний дефолт (`local-socks5-out` / `local-http-out`). |
| **Версия вычисляется при сборке** (внутреннее) | `pubspec.yaml` заморожен на placeholder, версия и versionCode вычисляются из git-тега в момент сборки (CI и локальный скрипт); pre-commit hook удалён. На пользователей не влияет. |

## 📲 Install

```bash
adb install -r LxBox-v2.11.1-arm64-v8a.apk
```

Без uninstall! Поверх существующей установки. Настройки и подписки сохранятся.
