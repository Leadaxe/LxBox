# L×Box v2.6.0

Каналы роутинга стали **настраиваемыми**. Раньше `vpn-1..vpn-4` и `✨auto`
были зашиты в шаблон — можно было только включить/выключить тоглом. Теперь это
полноценные объекты: своё имя, собственный regex-фильтр нод (с инверсией),
default-нода, персональный auto-режим (urltest) и галки `direct` / `block` /
`interrupt`. Вокруг — серия доводок главного экрана и роутинга.

## ✨ Новое

### §125 — Настраиваемые каналы

| Возможность | Что это даёт |
|---|---|
| **CRUD** | Создавать до 10 каналов и удалять (кроме `vpn-1`). Удаление переводит ссылки на канал (`route_final` / правила) на `vpn-1` |
| **Имя** | Своё отображаемое имя («Моя Германия» вместо «vpn-1») — видно в селекторе на главной и в пикерах роутинга |
| **Regex node-filter** | Один regex по имени ноды — в канал попадают только подходящие ноды (как фильтр на главной). Инверсия (`!`) — «всё КРОМЕ …» |
| **Default-нода** | Отдельный regex: первая подходящая нода становится выбором канала по умолчанию |
| **Auto-двойник** | Галка `auto` создаёт парный urltest для канала (свои url / interval / tolerance / idle). Раньше `✨auto` был один общий — теперь у каждого канала свой |
| **Галки селектора** | `include direct`, `include block` (§201), `interrupt connections on switch` |
| **Редактор** | Полноэкранный, с live-превью regex (matched N/total + выбранная нода) и защитой «Save / Keep / Discard» при выходе |

Технически: каналы переехали из `wizard_template.json` (`preset_groups[]`) в
storage (`channels[]`). Шаблон стал seed'ом на первый запуск — миграция
`enabled_groups[]` → `channels[]` происходит автоматически, существующие
настройки переносятся.

### §195–201 — Главный экран и роутинг

| # | Что |
|---|---|
| §195 | На главной справа от regex-фильтра — кнопка 💾: открывает редактор активного канала с предзаполненным фильтром (явное сохранение, видно куда легло) |
| §196 | Активная нода закреплена в списке сразу после direct/auto — при любой сортировке всегда на виду |
| §197 | Инверсия node-filter канала (`!`-тогл) — исключающий фильтр |
| §198 | Имена каналов по умолчанию — с цифрой-в-кружке (①②③④) |
| §199 | В строке auto-ноды выбранный сервер (`→ нода`) важнее транспорта: транспорт обрезается первым |
| §200 | Если фильтр канала не пропустил ни одной ноды — предупреждение в баннере конфига (трафик блокируется) |
| §201 | **Block-outbound**: дроп трафика как опция канала (галка «Include block») и цель route-final (красным, как reject). На главной — иконка 🚫, закреплён сверху, не пингуется |

## 🐛 Исправлено

| # | Было | Стало |

каналы мигрируют автоматически на первом запуске.
