# L×Box v2.15.5

**Ядро энергорелиза промоутнуто в стабильное.** После проверки на устройстве
(v2.15.4: и прежнее поведение, и новая suspend/wake-механика подтверждены
вживую) pre-release ядро `v1.14.0-lx.4-rc.2` выпущено как стабильный
**`v1.14.0-lx.5`** — этот релиз просто перевзводит L×Box на него. Код ядра
идентичен rc.2; функциональных изменений в приложении нет.

Что даёт энергосвязка (введена в [v2.15.4](docs/releases/v2.15.4.md)):
секция **WireGuard connections** (сон туннелей вне маршрута через 30s и на
активном маршруте через 5m), **Passive health check** (пробы молчат, пока ваш
трафик сам подтверждает сервер), интервал проб новых каналов 15m. Ночью с
включённым VPN — полная тишина; пробуждение автоматическое, +1 RTT на первом
соединении. Полная модель: [lx-energy.ru.md](https://github.com/Leadaxe/sing-box-lx/blob/lx/docs-lx/lx-energy.ru.md).

```bash
adb install -r LxBox-v2.15.5-arm64-v8a.apk
```

Без uninstall! Поверх существующей установки. Настройки и подписки сохранятся.
