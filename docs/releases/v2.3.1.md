## 🛠 Fixed

**AmneziaWG detour на WireGuard больше не вешает VPN.**

Раньше: если у AmneziaWG-узла в `detour` указан WireGuard-туннель, VPN намертво вис в «Connecting…» — другие узлы не подключались, кнопка не реагировала, помогал только перезапуск приложения. AmneziaWG поверх WireGuard вешает ядро на Android.

Исправлено на трёх уровнях:

- **Ядро** (sing-box-lx `v1.13.13-lx.10`) — такой узел теперь отклоняется с понятной ошибкой в логе вместо зависания. Остальные узлы продолжают работать ([#2](https://github.com/Leadaxe/sing-box-lx/issues/2)). Заодно AmneziaWG-конфиг с `jmin > jmax` отвергается на старте, а не роняет ядро паникой ([#3](https://github.com/Leadaxe/sing-box-lx/issues/3)).
- **UI** — при редактировании AmneziaWG-узла из списка **Detour** убраны все WireGuard-цели (собрать сломанную цепочку больше нельзя), а в строке Protocol теперь видно «AmneziaWG (wireguard)». Уже сохранённый невалидный detour сбрасывается при открытии настроек узла.
- **Приложение** — если туннель всё же завис, VPN-сервис принудительно останавливается по таймауту вместо того, чтобы висеть вхолостую. Кнопка снова работает сразу, без перезапуска приложения.

**Краш на старых GPU (Adreno 3xx, Android ≤11) исправлен.**

На старых устройствах (например HTC One M8 с Adreno 330) приложение открывалось, но любое действие в интерфейсе мгновенно его роняло. Причина — несовместимость GPU-рендерера Flutter (Impeller) со старым драйвером Adreno. На Android ≤11 рендерер теперь откатывается на Skia; на Android 12+ всё без изменений (§131).
