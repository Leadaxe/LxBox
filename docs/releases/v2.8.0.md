# L×Box v2.8.0

Полная поддержка XHTTP-нод (Xray splithttp). Расширенные xhttp-подписки —
с настраиваемыми placement'ами, X-Padding obfs-режимом и tuning-полями, в том
числе упакованными в `extra`-JSON — теперь парсятся целиком и поднимают коннект.
Плюс качество жизни: единый стартовый визард онбординга, подтверждение при
перехвате чужого VPN, открытие приложения долгим нажатием на плитку. Ядро
обновлено до rc.16.

## ✨ Новое

### Полный XHTTP — все параметры из ссылки (§127)

Парсер ссылок `vless://…type=xhttp` вырос с 6 полей до **полного клиентского
набора** Xray splithttp:

| Группа | Что добавилось |
|---|---|
| **Placement** | куда класть session id / seq / payload: path · query · header · cookie |
| **X-Padding obfs** | анти-DPI режим набивки: `repeat-x` / `tokenish`, свои ключи/заголовки |
| **Uplink** | метод upload, размер чанка, ключ данных |
| **Tuning** | `sc_max_each_post_bytes`, `sc_min_posts_interval_ms` (packet-up) |

Два источника полей в одной ссылке:

- **плоские** query-параметры (`path`, `mode`, `sessionPlacement`, …);
- параметр **`extra`** — это URL-encoded JSON с дополнительными полями. Теперь он
  декодируется и вливается в transport. Битый/обрезанный `extra` не роняет
  ссылку — она остаётся рабочей на плоских параметрах.

Ключи читаются и в camelCase (Xray), и в snake_case (sing-box); `path` с
`?`-хвостом обрезается; числа из `extra` приводятся к строке. Раньше расширенные
xhttp-ноды теряли почти все поля — сервер на obfs-режиме не обслуживался.

### Стартовый визард первого запуска (§126)

Онбординг-промпты (уведомления → battery → добавить плитку) теперь идут
**последовательно** — следующий показывается только после закрытия предыдущего.
Раньше они всплывали одновременно и наезжали друг на друга. Добавился шаг
«добавить плитку L×Box в быстрые настройки».

### Long-press плитки открывает приложение (§212)

Долгое нажатие на плитку L×Box в шторке быстрых настроек открывает приложение.
Короткий тап по-прежнему включает/выключает VPN.

### Версия ядра в Debug API (§213)

`GET /device` теперь отдаёт `core_version` (sing-box-lx, реально вкомпилированное
в APK) рядом с версией приложения.
