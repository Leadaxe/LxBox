# L×Box v2.11.0

**Флагман — папки серверов.** Ручные серверы теперь можно собирать в
**папки** (§234): общий вкл/выкл, общие настройки, перенос между папками. И
внутри папки — **проверка серверов без запуска VPN** (§236): пинг всей пачки
одним нажатием, цветовая шкала задержки, отсев мёртвых. Заодно: фильтр нод на
главном стал **Sources** (подписки + папки, §235), полный контроль над
папками и каналами в **Debug API** (§238), и мелочь — MASQUE-ноды теперь
показывают транспорт **h3/h2** в списке (§130). Ядро без изменений —
**v1.14.0-lx.2**.

## 🆕 Новое

- **Папки серверов** (§234, по фидбэку 4PDA) — контейнер для ручных серверов.
  Создайте папку и складывайте в неё конфиги: **импорт нескольких файлов
  разом** (multi-select — 10 файлов провайдера сразу в одну папку, имена нод
  берутся из имён файлов), вставка из буфера, добавление по ссылке
  (одноразовый снимок, без авто-обновления). У папки — **общий тумблер**
  (гасит все серверы разом), общий tag-префикс (папка целиком ловится каналом
  роутинга) и общие detour-настройки. Сервер можно **перенести из одиночных в
  папку**, между папками и обратно. Подписки в папки не кладутся — у подписки
  свой контейнер.

- **Test servers — проверка серверов без запуска VPN** (§236, по фидбэку
  4PDA) — кнопка в папке пингует **все** серверы (в т.ч. выключенные), пока
  VPN выключен: у каждого появляется задержка **цветом шкалы**
  (зелёный/жёлтый/оранжевый/красный, пороги настраиваются), `err` у
  недоступных, `broken` у нечитаемых конфигов. Дальше — массовые действия:
  **Disable slower than N ms**, **Delete unreachable**, **Sort by ping**.
  Внутри — временный экземпляр ядра без туннеля: иконка VPN-ключа не
  загорается, честный тест протокола (не просто ping хоста).

- **Настройка серверов в папке — как у одиночных** (§237/§239) — тап по
  серверу в папке открывает те же настройки, что и у отдельного сервера (тег,
  эмодзи, detour, JSON). Личный detour сервера можно направить на **другой
  сервер этой же папки** — получается цепочка целиком внутри папки, с полной
  симметрией поведения с подписками (переписать / дополнить / выключить).

- **MASQUE-транспорт в списке** (§130) — MASQUE-ноды на главном теперь
  показывают `masque • h3` (или `h2`) — раньше транспорт не отображался.

## ⚙️ Изменения

| Область | Что изменилось |
|---|---|
| **Фильтр нод: «Subscribes» → «Sources»** (§235) | Таб фильтра на главном переименован в **Sources** и теперь фильтрует ноды не только по подпискам, но и по папкам (по общему tag-префиксу). Одиночные серверы, как и раньше, не участвуют. |
| **Debug API: полный контроль папок и каналов** (§238) | Новые эндпоинты `/folders/*` (CRUD папок, состав, detour членов, запуск Test servers через `POST /folders/{id}/probe`) и `/channels/*` (CRUD каналов роутинга). Раньше через API правился только выходной канал по умолчанию. |
| **Импорт из файла — имя из имени файла** (§234) | При добавлении одиночного сервера из файла имя подставляется из имени файла. |

## 📲 Install

```bash
adb install -r LxBox-v2.11.0-arm64-v8a.apk
```

Без uninstall! Поверх существующей установки. Настройки и подписки сохранятся.
