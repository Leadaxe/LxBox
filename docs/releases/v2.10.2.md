# L×Box v2.10.2

**Патч про совместимость и предохранители.** Приложение теперь ставится на
**Android 7.0+** (§233). IPv6 и кастомные маршруты стали **opt-in** (§232) —
если после v2.10.0 у вас что-то сломалось с сетью, это обновление чинит само.
Плюс метки **DNS** на правилах маршрутизации (§231). Ядро без изменений —
**v1.14.0-lx.2**.

## 🆕 Новое

- **Метка «DNS» на правилах маршрутизации** (§231, по фидбэку 4PDA) — в списке
  Routing Rules теперь видно, какие правила затрагивают настройки DNS (вносят
  DNS-сервер или DNS-правило). Чип **DNS** — у пресетов с DNS-аспектом (FakeIP,
  Russian domains) и у своих правил с включённым DNS-mirror: в строке — под
  переключателем канала, в редакторе — в шапке + блок-пояснение. Раньше связь
  правила с DNS Settings была неочевидна.

## ⚙️ Изменения

| Область | Что изменилось |
|---|---|
| **Минимальный Android: 8.0 → 7.0** (§233) | Приложение ставится на Android 7.0/7.1 (по запросам владельцев старых устройств). Тир 7.x — best-effort: базовый VPN работает, регулярно не тестируется. Ограничение Android 7.0: в системе нет корня Let's Encrypt (ISRG Root X1) — подписки с таких HTTPS-источников не загрузятся (на 7.1.1+ корень есть). |
| **IPv6 и кастомные маршруты — opt-in** (§232) | Две новые галки в VPN Settings → TUN, по умолчанию **выключены**: **Enable IPv6** (v6-адрес на туннеле + переключение стратегий резолва) и **Custom tunnel routes** (явный заворот v4+v6 вместо автоматического). С выключенными галками конфиг идентичен поведению до v2.10.0 — если IPv6/маршруты v2.10.0 что-то ломали в вашей сети, после обновления это уйдёт само. Пользуетесь IPv6 — включите галку заново. |
| **Настройки стали реактивными** (§232) | Связанные поля обновляются мгновенно (галка IPv6 сразу переключает стратегии резолва на экране). Исправлен баг, из-за которого автопереключение стратегий не сохранялось. |

```bash
adb install -r LxBox-v2.10.2-arm64-v8a.apk
```

Без uninstall! Поверх существующей установки. Настройки и подписки сохранятся.
