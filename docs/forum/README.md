# Архив темы 4PDA 1122662

Локальная копия обсуждения LxBox на 4PDA — чтобы читать и грепать тему из репозитория,
не листая форум в браузере.

**Содержимое архива в гит не идёт** — это чужие сообщения с никами и личными
деталями. `posts/`, `INDEX.md` и `state.json` в `.gitignore`; в репозитории живут
только этот README и скрипт снятия. Архив собирается локально командой ниже.

- `INDEX.md` — таблица всех постов (номер, автор, файл).
- `posts/` — по файлу на пост, `NNNNN.md`, с автором, датой и `entry`-якорем.
- `state.json` — номер последнего скачанного поста; по нему видно, что нового.

Ссылка на пост в теме собирается из якоря:
`https://4pda.to/forum/index.php?showtopic=1122662&st=<st>#<entry>`

## Почему в цикле участвует браузер

4PDA стоит за Cloudflare managed challenge. Проверено: `requests` с браузерными
заголовками, `curl_cffi` с TLS-отпечатком Chrome и запрос под видом Googlebot дают
403 на весь домен — даже на `robots.txt`. Челлендж требует выполнить JS, поэтому
страницы снимает браузер, где сессия уже пройдена. Скрипты только разбирают и хранят.

Полностью автономный вариант — headless-браузер (Playwright): он проходит челлендж
честно, но тянет свой Chromium (~150 МБ). Пока не заведён.

## Как обновить архив

**1. Снять страницы.** В браузере на любой странице темы выполнить: скачать все
страницы (форум отдаёт `windows-1251`, декодировать нужно явно — иначе кириллица
превращается в `?`), затем собрать записи из DOM и выгрузить JSONL порциями по 200
постов (Chrome блокирует множественные загрузки — разрешить для 4pda.to).

Рабочий скрипт целиком — в [`browser_snippet.js`](browser_snippet.js).

**2. Разобрать в архив:**

```bash
python3 scripts/forum/parse_posts.py --out docs/forum --jsonl ~/Downloads/4pda_j*.jsonl
```

Скрипт перезаписывает файлы по номеру поста, так что повторный прогон безопасен,
а отредактированные на форуме посты обновляются. `state.json` и `INDEX.md`
пересобираются автоматически.

## Форматы входа

У [`parse_posts.py`](../../scripts/forum/parse_posts.py) три режима:

| Режим | Когда |
|---|---|
| `--jsonl` | основной: структурный экстракт из DOM (автор/дата/тело отдельно) |
| `--slim` | текстовый экстракт, посты через `@@@POST@@@` |
| stdin | сырой HTML одной страницы (или `--stdin-json` — массив страниц) |

`--jsonl` предпочтителен: `innerText` склеивает абзацы и мешает служебную обвязку
профиля с телом поста, а из DOM поля берутся по отдельности.

[`receiver.py`](../../scripts/forum/receiver.py) — локальный HTTP-приёмник страниц.
Для 4PDA бесполезен (страница по https не может слать на http-localhost, mixed
content), оставлен на случай сайта без такого ограничения.
