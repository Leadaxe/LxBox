in spare time and runs on user support — the project has no other income.

## Other ways to help

Just as valuable:

- **A star on GitHub** — [L×Box](https://github.com/Leadaxe/LxBox) and
  [sing-box-lx](https://github.com/Leadaxe/sing-box-lx) (the core everything
  runs on). Stars are how new users find the project.
- **A review** — the [Telegram group](https://t.me/singbox_launcher/4317).
  Honest experience helps others decide, and helps me see what to fix.
- **A bug report** — [GitHub issues](https://github.com/Leadaxe/LxBox/issues).
  A detailed description saves weeks of guesswork.
- **Telling people about it** — the latest build is always on the
  [releases page](https://github.com/Leadaxe/LxBox/releases/latest).
