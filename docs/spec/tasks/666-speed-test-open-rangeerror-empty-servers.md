## Проблема

Сообщение владельца 18.10.2026: «Когда открываю тест скорости» — в ленте
ошибок приложения запись

```
Flutter error: RangeError (length): Invalid value: Valid value range is empty: 0
@ Instance of 'ErrorDescription'
```

Запись приходит из `FlutterError.onError` (`main.dart`), то есть ошибка
падает в `build`. «RangeError (length) … range is empty: 0» — так VM в
AOT-сборке сообщает об индексе `[0]` у пустого списка (имя `length` даёт
runtime-entry проверки границ, не наш код). Пользователь видит красный
fallback вместо экрана до первого `setState`.

## Диагностика

- `_SpeedTestScreenState._servers` заполняется асинхронно в `_loadConfig`
  (`TemplateLoader.load()` через `TemplateAwareState`). Первый кадр строится
  **всегда** с пустым списком, даже при тёплом кэше шаблона — `await` уводит
  заполнение за первый `build`.
- Виджеты списка серверов и «Upload n/a» это учитывают
  (`_servers.isEmpty ? null : …`, `_serverHasUpload` проверяет `isNotEmpty`).
- §634 добавил в `build` подпись маршрута `_routeLabel`: при поднятом туннеле
  она сравнивает `_observedRouteServerId == _serverId(_selectedServer)`, а
  `_serverId(0)` — это `_servers[0]`. Без VPN ветка не достигается (ранний
  `return "Direct (no VPN)"`), поэтому дефект проявляется только с поднятым
  туннелем — ровно сценарий владельца.
- Тот же `_servers[0]` ждёт в `_runTest` → `_serverDownloadUrl` /
  `_testPing`, если нажать Start до загрузки шаблона; на практике недостижимо
  (загрузка — миллисекунды), но защита той же природы.

## Решение

`app/lib/screens/speed_test_screen.dart`:

1. `_routeLabel`: признак «протестировано» требует `_servers.isNotEmpty`,
   иначе подпись «Route depends on your rules, shown after the test» — что и
   есть правда до загрузки.
2. `_runTest`: ранний выход при пустом `_servers`.
3. Кнопка Start неактивна, пока `_servers` пуст (те же миллисекунды до
   `_loadConfig`; визуально неотличимо от прежнего поведения).

Модель, шаблон и тексты не менялись.

## Риски и края

- Шаблон без `speed_test_options.servers` (повреждённый или урезанный):
  раньше экран падал при поднятом туннеле; теперь показывает подпись
  маршрута, пустой выпадающий список и неактивную кнопку. Отдельного
  сообщения «серверов нет» нет — не было и раньше, вне задачи.

## Проверка

- Widget-тест `app/test/screens/speed_test_open_tunnel_up_test.dart`:
  экран открывается с `tunnelUp == true`; первый кадр не бросает, после
  загрузки шаблона список серверов заполнен и кнопка активна. До правки тест
  падал на первом кадре с тем же RangeError.
- Прогон — CI. На устройстве владелец проверит после следующей сборки.
