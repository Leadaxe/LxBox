## Что было

Экспорт бэкапа по умолчанию не включает категорию «Debug config»
(`debug_enabled`, `debug_token`, `debug_port`): токен даёт полный доступ к
приложению по HTTP. Импорт с заменой (`merge=false`, дефолт UI-импорта и
`POST /backup/import`) писал входящий `vars` поверх текущего целиком — и
Debug API устройства исчезал вместе с портом и токеном. Приложение после
рестарта поднимало сервер на дефолтном порту с новым токеном, а стенд
продолжал стучаться на старый.

Так умер Debug API у агента-тестировщика 03.09: бэкап с телефона (без
Debug-ключей) → импорт на эмулятор → рестарт → порт 8642 молчит.

## Что стало

`_replaceRaw` при `merge=false` переносит из текущего стораджа те ключи
Debug API, которых во входящем `vars` нет. Ключ, который в файле есть
(категория «Debug config» включена при экспорте, или сырой снимок через
API), по-прежнему побеждает. Остальной `vars` заменяется целиком, как и
раньше.

Набор ключей вынесен в `SettingsStorage.debugApiVarKeys`; `BackupService`
ссылается на него вместо своей копии.

## Тесты

`test/services/backup_service_test.dart`: замена без Debug-ключей сохраняет
их; замена с Debug-ключами применяет входящие, недостающий переносится.
