# §317 — DNS-группа не сохраняется: «Server address is required»

**Тип:** таска (bug, P1)
**Статус:** исправлено 27.07.2026 — DEVICE-PENDING (устройство отвалилось)
**Затронутый релиз:** v2.18.0 (регрессия введена вместе с §312)
**Связано:** §312 (DNS-группы), §117 (редактор DNS-сервера, гейт адреса)

---

## 1. Проблема

Жалоба: в v2.18.0 группа DNS не сохраняется, снекбар «Server address is
required». Воспроизводится на **любой** группе — и новой, и правке
существующей.

## 2. Причина

Гейт сохранения в [dns_server_edit_screen.dart](../../../app/lib/screens/dns_server_edit_screen.dart):

```dart
// §117 задача 4b: для форменных режимов (UDP/DoT/DoH) адрес обязателен.
if (_ctrl.serverMode != null && _ctrl.addressCtrl.text.trim().isEmpty) → отказ
```

`serverMode` возвращает не-null для любого значения из `kDnsServerModes`, а
§312 добавил туда четвёртым элементом `'group'`:

```dart
const kDnsServerModes = ['udp', 'tls', 'https', 'group'];
```

Значит для группы гейт срабатывал как для адресного сервера. При этом **форма
группы поля адреса не рисует вовсе** (`server_form_section.dart`: при
`mode == 'group'` рендерится `_GroupSection` с участниками) — заполнить его
было нечем. Гейт непроходим по построению: сохранить группу из UI было
нельзя никак.

Почему не поймали: Shield DNS (§314) приезжает готовой группой из шаблона, а
тесты §312 покрывали контроллер (round-trip body↔поля), но не гейт экрана.

**Урок:** расширение перечисления (`kDnsServerModes` += `'group'`) молча
поменяло смысл всех проверок вида «`serverMode != null` ⇒ это адресный
сервер». Признак «сервер имеет адрес» должен быть выражен явно, а не
выводиться из «режим формой поддержан».

## 3. Решение

Явный признак в контроллере:

```dart
/// §312 — это DNS-группа? У неё нет адреса: вместо `server` — участники.
bool get isGroup => serverMode == 'group';
```

Гейт исключает группу: `serverMode != null && !_ctrl.isGroup && адрес пуст`.

Группа намеренно остаётся формным режимом (`serverMode == 'group'`) — от
этого зависит отрисовка вкладки; чинить переименованием режима нельзя.

## 4. Изменения

1. [edit_controller.dart](../../../app/lib/screens/dns_server_edit/edit_controller.dart)
   — геттер `isGroup`.
2. [dns_server_edit_screen.dart](../../../app/lib/screens/dns_server_edit_screen.dart)
   — `!_ctrl.isGroup` в гейте адреса.

## 5. Тесты

`test/screens/dns_group_edit_controller_test.dart` — `isGroup` истинен для
группы и ложен для udp/tls/https; отдельно закреплено, что `serverMode` у
группы остаётся `'group'` (гейт нельзя строить на `serverMode != null`).
