# §497 — вкладка Notifications в деталях узла

| | |
|---|---|
| **Статус** | Реализовано (вкладка объединена с Diagnostics задачей §501) |
| **Дата** | 2026-09-19 |
| **Источник** | решение владельца 19.09.2026: уведомления узла должны быть внутри деталей, отдельной вкладкой на уровне Diagnostics |
| **Связанные** | §479 (компонент уведомлений, значки в списке), фича 478 (`core_rejected`) |

## Что было

В списке подписки значок ⓘ/⚠ под именем узла открывает шторку уведомлений
(§479). Тап по самому узлу ведёт на экран деталей с вкладками JSON / Source /
Diagnostics — уведомлений там нигде не было. У одиночного сервера и члена
папки (§237) раздел Notifications жил внизу вкладки Settings
(`node_settings_screen.dart`), а не рядом с JSON и Diagnostics.

## Что сделано

Общий виджет `NodeNotificationsTab` / `NodeNotificationsTabLabel`
(`app/lib/widgets/node_notifications_tab.dart`):

- **Подпись вкладки** — `Notifications`; при наличии предупреждений — значок
  старшего уровня и счётчик (стиль §479).
- **Тело** — [NodeNotificationsView], тот же виджет, что шторка из списка
  (§479) и шторка отказа ввода (§500). Все `NodeSpec.warnings` (разбор +
  `core_rejected`, если проставлен `stampStoredVerdicts`), сортировка
  error → warning → info. Пустое состояние одной строкой: «No notifications
  for this server».

Вкладка добавлена **перед Diagnostics** (до §501):

| Экран | Порядок вкладок |
|---|---|
| `node_inspect_screen.dart` (узел подписки) | JSON, Source, [Replacements], **Notifications**, Diagnostics |
| `node_settings_screen.dart` (одиночный / член папки) | Settings, Source, JSON, **Notifications**, Diagnostics |

Раздел Notifications с вкладки Settings убран — дублирования нет. Тап по
значку/строке в списке подписки не менялся (шторка §479).

**§501:** отдельная вкладка Notifications убрана; уведомления — секция
сверху вкладки Diagnostics, точка на ярлыке вкладки при наличии предупреждений.

## Критерии приёмки

- Вкладка Notifications есть на обоих экранах деталей узла; порядок — перед
  Diagnostics.
- Счётчик и значок старшего уровня на подписи вкладки при наличии
  уведомлений; без уведомлений — только текст вкладки и пустое состояние.
- Содержимое — [NodeNotificationsView], заголовки из реестра; свои тексты
  не выдумываются.
- Виджет-тест: `uri_param_unknown` (info) — счётчик, заголовок реестра;
  узел без уведомлений — вкладка и пустое состояние.
- `flutter analyze`, l10n-чекеры `--strict`. Спека §479 (точки входа),
  CHANGELOG (Unreleased → Added).
