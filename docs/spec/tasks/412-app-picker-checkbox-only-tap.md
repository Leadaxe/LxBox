4PDA #1702 (аndrey): в длинном списке приложений галочка ставилась и снималась
тапом по всей строке. При прокрутке палец задевает строку, выбор снимается
незаметно, и потом не вспомнить, что именно убрал.

## Что стало

`AppPickerScreen` (выбор приложений в правиле и на вкладке приложений
туннеля): строка — `ListTile` без `onTap`, чекбокс — обычный `Checkbox` в
`trailing`. Переключает только тап по самому чекбоксу с его штатной областью
касания (48dp по Material), тап по названию или иконке ничего не делает.

Без изменений: иконка слева, название и пакет, счётчик «N selected», поиск,
возврат результата.

Второй пикер — `app_multi_picker.dart` во вкладке профилировщика — короткий
список фильтра, оставлен как есть.

## Тесты

`test/screens/app_picker_row_tap_test.dart`: тап по названию строки выбор не
меняет, тап по чекбоксу — меняет.
