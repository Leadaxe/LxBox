# §486 — реестровые тесты на CI и безопасный sync_contract

| | |
|---|---|
| **Статус** | **Released в v2.25.0** (20.09.2026, ядро `v1.14.1-lx.8`). **Реализовано** |
| **Дата** | 2026-09-19 |
| **Связанные** | фича 460 (зеркало реестра), SPEC 103 |

## Проблема

1. **Молчаливый skip на CI.** Около 130 тестов в `app/test` грузили реестр из
   gitignored `app/contract/` и гейтировались на `existsSync`. На CI и в чистом
   worktree каталога нет — тесты пропускались без заметного сигнала. С
   протухшей локальной копией те же тесты ложно краснели.

2. **Небезопасный `sync_contract.sh`.** Без аргументов скрипт тянул контракт из
   рабочего дерева `~/projects/singbox-launcher` как есть — любая случайная
   версия, что дважды давало ложные падения (105 и 37 тестов).

## Решение

### Часть 1 — пути и гейты в тестах

- Общий хелпер `app/test/contract_paths.dart`:
  - `kRegistryRoot` = `assets/contract` — для тестов, которым нужен только
    реестр;
  - `kVendorRoot` = `contract` — для корпуса и `schema/`;
  - `loadTestRegistry()`, `corpusTestSkip()`, `corpusSuiteUnavailable()`.
- Реестровые тесты грузят зеркало и **не скипаются** на CI.
- Corpus-тесты остаются за гейтом; пропуск громкий: строка
  `corpus skipped: app/contract отсутствует, N тестов` и сторож
  `corpus_skip_guard_test.dart` (на `CI=true` перечисляет сьюты, не падает).
- `corpus_warnings.dart` и `engine_test_setup.dart` переведены на хелпер.

### Часть 2 — sync_contract.sh

- **Без аргументов** — восстановление `app/contract` из коммита `source_sha` в
  `contract.lock` (`git archive`); если старый lock не содержит SHA, скрипт
  безопасно отказывает и требует явного бампа. Зеркала и lock не меняются.
- **Бамп** — `LX_CONTRACT_SRC=<path>` или `--to <sha>`: полная синхронизация,
  пересчёт lock (с полями `launcher_repo`, `source_sha`) и зеркал.
- `check_contract_lock.dart` не ломается: новые поля lock опциональны для
  проверки `sha256`.
- В `contract.lock` добавлено `source_sha` (полный SHA коммита лаунчера
  `dfed276c…`) — `tool/worktree_bootstrap.sh` (§487) и restore без аргументов
  читают одно и то же поле. `LX_CONTRACT_REPO` из bootstrap принимается и
  `sync_contract.sh`.

## Критерии приёмки

- [x] На чистом worktree без `app/contract` реестровые тесты исполняются и
  зелёные.
- [x] Corpus-тесты скипаются с заметным сообщением; сторож на CI перечисляет
  сьюты.
- [x] `sync_contract.sh` без аргументов не меняет зеркала и восстанавливает
  копию только по SHA из lock; старый lock без SHA не допускает случайный
  источник. Бамп — только явно.
- [x] Документация скрипта обновлена (`AGENTS.md`, шапка скрипта).
- [x] `flutter analyze` без новых issues; затронутые тесты зелёные.
