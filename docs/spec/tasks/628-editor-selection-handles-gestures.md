# §628 — Ручки выделения в редакторе JSON уводят вкладку и страницу

| Поле | Значение |
|------|----------|
| Тип | Исправление |
| Статус | D (done), выпущено в v2.25.13 |
| Дата | 2026-10-12 |
| Связанные | §624 (sora-editor во всех JSON-полях), issue #167 |

## Проблема

Экран узла, вкладка Source, клавиатура открыта. Выделяешь слово
долгим тапом, тянешь ручку выделения — вместо неё едет вкладка
(TabBarView уходит к JSON) или скроллится страница.

## Диагностика

`LxCodeEditor._buildNative` раздаёт жесты platform view так:

- текст не помещается в поле (`scrollable`) — `EagerGestureRecognizer`,
  все жесты у редактора;
- текст помещается — только `HorizontalDragGestureRecognizer` и
  `LongPressGestureRecognizer`; вертикальный свайп уходит странице.

На Source поле растёт по содержимому (`_Fit.grow`), текст помещается,
работает вторая ветка. Ручку тянут в любом направлении: вертикальная
составляющая достаётся скроллу страницы, горизонтальную выигрывает
свайп TabBarView.

Вторая причина нашлась на эмуляторе. `PlatformViewLink` кэширует
поверхность (`_surface ??= surfaceFactory(...)`) вместе с её
`gestureRecognizers`. Набор фиксируется при создании view, а пересборка
виджета его не меняет. Значит, и прежнее переключение по `scrollable`
работало только на старте: поле, которое выросло за предел строк уже
после открытия, продолжало отдавать вертикальные свайпы странице.

## Решение

- Натив в событии `cursor` шлёт `selected` (`Cursor.isSelected`).
- Набор распознавателей постоянный: горизонтальный свайп, долгий тап и
  `_GatedEagerGestureRecognizer`. Это `EagerGestureRecognizer`, который
  на каждом касании проверяет условие «текст не помещается или есть
  выделение» и берёт касание целиком, только если оно истинно.
- Без выделения в коротком поле поведение прежнее: вертикальный свайп
  листает страницу.

## Проверка

- Source, текст помещается: выделить слово, тянуть ручки вверх, вниз,
  вбок — двигается выделение, вкладка и страница стоят.
- Снять выделение тапом — вертикальный свайп по полю снова скроллит
  страницу.
- Длинный текст (поле со скроллом) — как раньше.
- Поле выросло за предел строк после открытия — вертикальный свайп
  листает редактор, а не страницу.
