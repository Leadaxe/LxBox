## Проблема

Владелец хочет заменять подписку или папку одной группой в списке каналов
и Направлениях: ручным селектором, авто-группой или обоими. Норма контракта —
поле `replace {mode: manual | auto | both, tag, auto{…}}` внутри записи
источника, одинаковое у лаунчера, в бэкапе и у LxBox (§74). У LxBox поле не
читается, не пишется и не разворачивается; четыре кейса корпуса бэкапа
(`replace_roundtrip`, `legacy_fold_to_replace`, `v10_direction_include`,
`v10_sources_union`) стоят в `_pendingCases` `backup_corpus_test`.

## Решение

Норма и факты — **читать §74 целиком**, здесь только привязка к LxBox.

1. **Модель источника.** У `FolderServers` и подписки — поле `replace`
   (`mode`, `tag`, `auto` в форме авто-группы Направления — переиспользовать
   существующую модель `auto` Направления, не заводить вторую). Нет объекта —
   не свёрнут. Неизвестный `mode` → `manual`.
2. **Кодек и бэкап.** Писатель пишет только `replace`, читатель читает
   только `replace`. **Уточнение владельца 26.09.2026 (бамп 1.1.79):** старая
   форма `fold`/`fold_tag` НЕ читается и НЕ мигрируется ни из 1.0, ни из 0.x —
   при импорте это неизвестные ключи, отбрасываются с предупреждением, свёртку
   человек настраивает заново. Существующее чтение `fold` (если есть) снять
   вместе с тестами. Кейс корпуса `legacy_fold_to_replace` в 1.1.79 становится
   `legacy_fold_dropped`.
3. **Сборка** (паритет с `folder_replaces.go`, §74 п.1–4): для каждого
   включённого источника с `replace` — группы по режиму: `manual` → selector
   `tag` (`interrupt_exist_connections: true`); `auto` → urltest `tag` с
   опциями `auto`, провайдерские группы источника в состав не входят;
   `both` → urltest `<tag>-auto`, затем selector `tag` с первой опцией
   `<tag>-auto` и `default = <tag>-auto`. Суффикс двойника — тот же, что у
   двойников Направлений в LxBox (найти существующую формулу). Порядок опций и
   outbounds — §74 п.3. Ноль узлов / все выключены — §74 п.4: группа не
   пишется, ссылки на выпавший тег вычищаются существующими механизмами
   (member/default → `group_member_dropped`, detour, правило → `route.final`).
   Род групп — из фазы A (`group_genus.dart`), имена схем в коде не появляются.
4. **Направления и каналы** (§74 п.5): узлы свёрнутого источника уходят из
   пула кандидатов Направлений, вместо них кандидат `tag` (при `both` — только
   selector). Свёртка — корневое имя: цель правил, `route.final`, опций
   Направлений. В списке каналов/групп главного экрана свёртка видна одной
   записью (selector `tag` попадает в `selectorGroupTags`, как провайдерский
   selector после фазы A).
5. **UI.** В настройках папки и подписки — переключатель «Replace with a
   group» и режим (Manual / Auto / Both), имя `tag` (по умолчанию — имя
   источника), параметры `auto` — той же формой, что у авто-группы Направления.
   Строки английские, без §NNN.
6. Документация: фича 565 (итог фазы B), §234 (папка), CHANGELOG Unreleased
   (видимое изменение).

## Риски и edge cases

- Коллизия `tag` с тегом узла или другой свёртки — как у лаунчера (сверить в
  §74/BACKUP; если норма молчит — записать в «Нерешённое», не выдумывать).
- Обновление подписки меняет состав свёртки автоматически; `default` у
  `manual` не хранится (выбор в рантайме).
- Identity узлов не меняется; теги групп свёртки — новые корневые имена.

## Нерешённое / follow-up

- **Коллизия `tag` свёртки с тегом узла или другой свёртки.** UI закрыт
  задачей 570 (`ae072a52`): редактор свёртки предупреждает, если имя занято
  узлом, другой свёрткой или Направлением; норма — у лаунчера (1.1.80). Норма (§74,
  BACKUP.md) о ней молчит. Сделано по аналогии с тегами Направлений: имена
  свёрток в резерве аллокатора (узел-тёзка получает суффикс `-N`) и заняты
  для Направлений и цепочек на импорте. Две свёртки с одним `tag` дадут
  дубль группы — редактор этого не запрещает. Запрос лаунчеру: норма на
  коллизию.
- **Закрыто задачей 570 (`06d566be`, контракт 1.1.80):** коллизия — код
  `replace_tag_conflict {tag, other}` в отчёте сборки, свёртка не
  собирается, источник идёт несвёрнутым; пустая свёртка — один
  `replace_group_empty {tag, mode}`.
- **Кода реестра на выпавшую группу свёртки нет.** Группа без узлов и
  правило, перенаправленное с неё на `route.final`/снятое, называются
  строкой отчёта сборки без кода `warnings.json`. У лаунчера — только лог
  (`Skipping empty local selector`). Запрос: код в реестр.
- **Закрыто задачей 570 (`06d566be`):** носитель detour на свёртку,
  опустевшую после отбраковок, выпадает (каскадом — кто ходил через него),
  имя свёртки помечено выпавшим для позиций цепочек. Было: **detour на свёртку, опустевшую только после отбраковок** (fail-closed
  detour, гард реестра): корневое имя регистрируется, если у плана были
  члены на `ServerList.build`; если все члены отпали позже, санитайзер графа
  снимет висячий `detour` (узел пойдёт напрямую), а не носителя.
  Свёртка без узлов изначально (выключена, все члены off) — ссылка не
  разрешается, носитель выпадает (fail-closed), как у лаунчера.
- **Закрыто задачей 570 (`06d566be`):** вложенные правила логических тел
  перенаправляются рекурсивно, логическое правило без вложенных снимается.
  Было: **правило в логических (`type: logical`) телах** с целью-свёрткой не
  перенаправляется — только верхний уровень `route.rules`.
- **Закрыто задачей 570 (`ae072a52`):** группы свёрток — кандидаты
  `include` в редакторе Направления. Было: **опция `include` Направления на свёртку** принимается сборкой, но
  редактор Направления кандидатами `include` показывает только
  Направления выше; выбрать свёртку в UI нельзя (только бэкап/Debug API).
- **Закрыто задачей 570 (`06d566be`):** по §74 п.3 (пул в порядке модели)
  порядок совпадает; тест `source_replace_build_test` «провайдерская группа
  в селекторе свёртки». Было: **порядок провайдерской группы в селекторе свёртки** — по позиции в
  модели источника; у лаунчера пул локальной группы — «узлы источника в
  порядке модели». Корпусного кейса со смесью узлов и групп нет.
- **Закрыто задачей 570 (`06d566be`):** `@имя` в параметрах автовыбора
  свёртки раскрывается переменной шаблона на сборке, кейс
  `direction/fold_auto_inherits_template_vars` без skip. Было: **`@urltest_*` в `auto`** свёртки (как у Направления) у LxBox не
  поддерживаются: значения хранятся литералами.
