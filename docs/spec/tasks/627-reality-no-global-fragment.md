# §627 — Глобальная фрагментация TLS не применяется к REALITY-узлам

| Поле | Значение |
|------|----------|
| Тип | Исправление |
| Статус | D (done), выпущено в v2.25.12 |
| Дата | 2026-10-12 |
| Связанные | §457 (ядро lx.4: fragment/record_fragment действуют на REALITY), §606 (`tls_fragment_fallback_delay`), §574 (fragment уступает detour) |

## Проблема

Узел VLESS + REALITY (`xtls-rprx-vision`, SNI `*.mail.ru`, сервер Xray)
в LxBox не отвечает, тот же узел в Happ работает. Телефон владельца, LTE,
12.10.2026.

## Диагностика

У владельца включён глобальный тумблер `tls_record_fragment`. Пост-шаг
`applyTlsFragment` дописывает узлу `tls.record_fragment: true` и
`fragment_fallback_delay`. С ядра lx.4 (SPEC 088, §457) фрагментация
реально действует на REALITY; до lx.4 ядро её для REALITY молча пропускало,
и в §457 это записано как «поведение приложения не меняется».

A/B на телефоне через `PUT /config` + `reload-vpn`, пинг узла:

| shortId | fingerprint | record_fragment | Результат |
|---|---|---|---|
| старый | chrome | вкл | таймаут |
| новый | chrome | вкл | таймаут |
| новый | firefox | вкл | таймаут (дважды) |
| новый | firefox | выкл | 210 мс |
| старый | chrome | выкл | 196 / 195 мс |

Ломает узел только фрагментация. Отпечаток и shortId роли не играют.
Сервер REALITY не принимает ClientHello, разрезанный на несколько записей.
REALITY и так маскируется под чужой сайт, фрагментация ему не нужна.

## Решение

`applyTlsFragment` пропускает outbound, у которого `tls.reality.enabled == true`:
ни `fragment`, ни `record_fragment`, ни `fragment_fallback_delay` ему не
дописываются. Касается только глобального тумблера: авторское тело узла
с явными полями фрагментации не трогается (пост-шаг их не снимает).

Глобальный тумблер в будущем, вероятно, уступит месту настройке на
узле/папке/подписке по образцу detour — отдельная задача.

## Проверка

- Тест `app/test/builder/tls_fragment_reality_test.dart`: REALITY-узел при
  обоих включённых тумблерах остаётся без полей фрагментации; обычный TLS-узел
  их получает.
- На телефоне: узел `AL: 🇳🇱⚡Нидерланды` при включённом `tls_record_fragment`
  после сборки без `record_fragment` и пингуется.
