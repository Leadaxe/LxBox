## Problem

В редакторе текста (JSON, INI, ссылки) при выделении есть Copy и Cut, но
нет удаления. Стереть выделенное из меню можно только через Cut: текст
уходит в буфер обмена и затирает то, что там было.

## Diagnosis

Меню над выделением — не системный `ActionMode`, а собственная панель
sora-editor `EditorTextActionWindow` (компонент редактора, макет
`text_compose_panel`: кнопки-иконки Select all, Copy, Paste, Long select,
Cut; подписи — `contentDescription` из `@android:string/*`). Набор кнопок
захардкожен в библиотеке, расширять его снаружи можно только заменой
компонента: `CodeEditor.replaceComponent(EditorTextActionWindow::class, …)`.

## Solution

Подкласс `LxTextActionWindow` (`SoraEditorPlatformView.kt`), ставится
вместо штатной панели при создании редактора:

- в ряд кнопок после Cut добавляется кнопка-иконка Delete (корзина, тот же
  размер 45dp, тот же фон и цвет иконки из схемы редактора, что у соседних);
  подпись `contentDescription` и подсказка при долгом нажатии — `Delete`;
- видна при тех же условиях, что Cut: есть выделение и редактор не
  только для чтения; без выделения и в режиме чтения её нет;
- нажатие стирает выделение тем же путём, что Cut, но без копирования:
  `CodeEditor.deleteText()` + `notifyIMEExternalCursorChange()`, панель
  закрывается. Буфер обмена не меняется;
- правка идёт через `Content.delete` — попадает в undo-историю редактора
  и отправляет `changed` во Flutter, как любая другая правка.

Остальное поведение панели (позиция, скрытие при прокрутке, остальные
кнопки) — штатное, из библиотеки.

## Risks and edge cases

- Ширина панели ограничена библиотекой 230dp; шестая кнопка в ней не
  помещается целиком только когда видны все сразу. Одновременно видны
  максимум Select all, Copy, Paste, Cut, Delete (Long select виден только
  без выделения) — 5 × 45 = 225dp, влезает; при большем — ряд в
  `HorizontalScrollView` прокручивается.
- Бамп sora-editor: подкласс опирается на `panel_hv` в макете и на
  protected-методы `applyColorScheme` / `applyColorFilter` / `displayWindow`.
  Если макет изменится, кнопка не добавится (поиск по id вернёт `null`),
  панель останется штатной.
