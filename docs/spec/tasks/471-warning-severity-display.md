# §471 — раздельный показ info / warning / error у узла

| | |
|---|---|
| **Статус** | Реализовано, тесты зелёные (5069 passed / 15 skipped) |
| **Дата** | 2026-09-18 |
| **Источник** | решение владельца 18.09.2026: «info синий и в списке только значок, а текст в ноде; warning жёлтый; error красный»; рекомендация лаунчера `TASKS_LXBOX.md` §24.11 |
| **Связанные** | фича 460 W2b (шторка Warnings), §468 (`reality_fp_not_chrome` → info) |

## Проблема

`NodeWarningRow` показывает одну строку: старшее предупреждение текстом и
«+N more». Уровни различаются только цветом, info — серый. После §469 у
QUIC-узлов и после §468 у REALITY-узлов info-кодов стало много: в списке
подписки под каждым вторым узлом висит строка текста о том, что действий не
требует. Строки, требующие внимания, в этом тонут.

## Решение

Цвета уровней — одни на всё приложение (строка, шторка, шапка подписки):

| Уровень | Цвет | Значок |
|---|---|---|
| error | красный (`colorScheme.error`) | `error_outline` |
| warning | жёлтый (янтарный, читаемый в обеих темах) | `warning_amber` |
| info | синий (читаемый в обеих темах) | `info_outline` |

Цвета вынести в одно место (функция/расширение от `WarningSeverity` и
`ColorScheme`), а не повторять `switch` в каждом виджете.

**Список узлов** (`subscription_node_list.dart` и любые другие списки, где
стоит `NodeWarningRow`):

- есть error или warning → строка как сейчас: значок и текст старшего
  предупреждения цветом уровня, «+N more» считает только error и warning;
- если у узла при этом есть и info — в конце той же строки синий значок
  info без текста;
- только info → **только синий значок**, без текста. Место — там же, где
  строка (в `subtitle`), высота строки минимальная; вёрстку `ListTile` не
  перестраивать;
- тап по строке или значку открывает шторку Warnings, как сейчас.

**Экран узла** (`node_settings_screen.dart`): текст показывается для всех
уровней, включая info — строка как сейчас, цвет по таблице. Это и есть
«текст в ноде». Параметр виджета (`compact`/`showInfoText`) выбирает режим;
значение по умолчанию — полный текст.

**Шторка Warnings:** цвета по таблице; записи сгруппированы по уровню в
порядке error → warning → info (сортировка уже такая), отдельных заголовков
групп не вводить.

**Шапка подписки** (счётчик узлов с предупреждениями, оранжевая полоса):
логика `actionableCount` не меняется (info не считается), цвет — жёлтый из
общей таблицы, если сейчас он задан отдельно.

Новых видимых строк нет. Семантика для значка info без текста: `Semantics`
с меткой из текста предупреждения (скринридер читает то, что зрячий видит
в шторке).

## Критерии приёмки

Виджет-тесты:

- только info в компактном режиме → значок есть, текста нет, тап открывает
  шторку;
- warning + info → текст warning, «+N more» без учёта info, синий значок в
  конце;
- error + warning → как раньше, красный;
- полный режим (экран узла) с одним info → текст виден, цвет синий;
- цвета берутся из общего места (тест на функцию).

`flutter analyze` всего проекта, `flutter test -j 2` — «All tests passed»,
l10n-чекеры зелёные. Доки: USER_GUIDE.md/.ru.md (абзац про предупреждения
узла), GUARDS.md при упоминании цветов, CHANGELOG, спека 460 — ссылка на
§471 в разделе W2b.

## Как сделано

### Палитра уровней

Цвета и значки уровней собраны в `warningSeverityStyle(BuildContext,
WarningSeverity) → (Color, IconData)` в `app/lib/widgets/banner_palette.dart`
плюс обёртка `warningSeverityColor` для мест, где иконка своя. Новый файл не
заводили: `banner_palette.dart` — уже принятое место theme-aware цветов
уровней в проекте (§206, `BannerSeverity`), и второй реестр цветов рядом с
ним разошёлся бы. Слить `WarningSeverity` с `BannerSeverity` не стали: у
плашек четыре уровня (есть `success`) и четыре цвета на уровень
(фон/рамка/текст/action), у предупреждения узла — один цвет и значок; общий
тип потребовал бы маппинга в обе стороны ради экономии одного `switch`.

Цвета — hex по темам:

| Уровень | Светлая | Тёмная | Источник |
|---|---|---|---|
| error | `colorScheme.error` | `colorScheme.error` | семантический токен темы; hex не фиксируем — схема собрана `fromSeed`, и цвет зависит от seed'а |
| warning | `#FF8F00` (`Colors.amber.shade800`) | `#FFD54F` (`Colors.amber.shade300`) | те же shade'ы, что у `bannerIconColor` |
| info | `#1976D2` (`Colors.blue.shade700`) | `#64B5F6` (`Colors.blue.shade300`) | Material blue, симметрично amber |

error взят токеном темы — он корректен в обеих из коробки. warning и info
зафиксированы пресетами по тем же соображениям, что и `bannerColors`: тема
собрана `ColorScheme.fromSeed`, где `primary` зависит от seed'а и синим быть
не обязан, а уровень должен читаться уровнем, а не акцентом темы. Раньше
info был `onSurfaceVariant` — то есть цветом выключенной подписи, из-за чего
сведения выглядели не «к сведению», а «неважно».

### Строка под узлом

У `NodeWarningRow` появился флаг `compact`; по умолчанию `false` — полный
текст любого уровня, как было. Экран узла (`node_settings_screen.dart:521`)
вызов не менял и получает полный режим тем же кодом, что и раньше.

В компактном режиме (список узлов подписки) строка собирается из двух
независимых частей: текстовая — старшее из error/warning, «+N more» считает
только их; значковая — синий `info_outline` в конце, если info у узла есть.
Узел с одними info даёт `Row` из одного значка — новой строки в вёрстке нет,
это тот же `subtitle`, только схлопнувшийся до 12-пиксельной иконки.
`mainAxisSize: min` добавлен, чтобы такой `Row` не растягивался на всю
ширину и тап в пустоту справа не открывал шторку.

Семантика: когда текста в строке нет, `Semantics.label` проставляется явно —
текстом info-предупреждения. Когда текст есть, метку собирает сам `Text`, и
явный `label` её бы затёр (поэтому он `null`, а не всегда заданный).

### Остальные места

- шторка Warnings (`node_warnings_sheet.dart`) — свой `switch` заменён
  вызовом палитры; сортировка error → warning → info уже была, заголовков
  групп не вводили;
- шапка подписки (`subscription_node_list.dart`) — `actionableCount` не
  тронут (info по-прежнему не считается), а плоский `Colors.orange` у полосы,
  значка и текста заменён на `warningSeverityColor(..., warning)`: полоса
  перестала быть одинаковой в светлой и тёмной теме;
- список узлов на Home (`node_row.dart`) предупреждений узла не показывает
  вовсе — трогать было нечего.

### Что видит пользователь

В списке узлов подписки: у узла с error/warning — та же строка, что и
раньше, цветом уровня, плюс синий значок в конце, если у узла есть ещё и
info. У узла с одними info — только синий значок. Тап по строке или по
значку открывает шторку со всеми предупреждениями и их текстами. На экране
узла — строка с текстом любого уровня, включая info, цветом по таблице.
