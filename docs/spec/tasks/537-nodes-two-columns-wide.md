## Зачем

На планшете и в альбомной ориентации список узлов главного экрана растягивает
строку `NodeRow` на всю ширину: справа пустота, на экране помещается мало
узлов. Решение владельца 24.09.2026: две колонки при ширине ≥ 600 dp, только
этот список.

## Решение

- Гейт по тумблеру — §541: App Settings → Appearance → «Two columns on wide
  screens» (по умолчанию включён); выключен — всегда одна колонка.
- Порог `kNodeListTwoColumnsMinWidth = 600` dp (граница Material «compact →
  medium»), нестрогий: 600.0 — уже две колонки. Число колонок —
  `nodeListColumnCount(width, isManual:)` в
  `app/lib/screens/home/widgets/node_list.dart`.
- Ширина берётся у `LayoutBuilder` секции списка, а не у `MediaQuery`: поворот,
  split-screen и изменение окна переключают раскладку на лету.
- Сетка = `ListView`, строка которого несёт две ячейки равной ширины. Порядок
  построчный (1-2 / 3-4 …), визуальный порядок совпадает с `displayList`.
  Хвост последней строки — пустая ячейка; между колонками — тонкий разделитель.
- Ячейка (`_buildNodeCell`) общая для обеих раскладок: тап, long-press-меню,
  подсветка, пинг и §203-GlobalKey для перехода к узлу живут внутри `NodeRow`
  и работают одинаково.
- Скролл: `_NodeListColumns` держит `ScrollController`; при смене числа колонок
  смещение масштабируется на отношение числа строк, на экране остаются те же
  узлы. Подсветка и выбор живут в `HomeState`, раскладка их не трогает.

### Жесты, несовместимые с сеткой

- **Ручная сортировка (`NodeSortMode.manual`) — всегда одна колонка.**
  Перетаскивание идёт через одномерный `ReorderableListView`; в сетке позиция
  «индекс → место» неоднозначна. В ручном режиме список на любой ширине
  остаётся прежним, с видимой ручкой перетаскивания.
- В остальных режимах сортировки одноколоночный список позволяет long-press по
  левому краю строки начать перетаскивание (оно переключает в ручной режим). В
  сетке этого входа нет; ручную сортировку включает меню сортировки, после
  чего список сам уходит в одну колонку.

### Папки и группы

Заголовков папок/групп в этом списке нет: `NodeListPresenter.computeListData`
отдаёт плоский список тегов, папки (§234-239) доходят до главного экрана только
как чипы фильтра. Span на всю ширину делать не для чего; появятся заголовки —
им отдельная строка сетки.

## Проверка

- `app/test/screens/home/node_list_two_columns_test.dart`: порог 599/600 dp
  (функция и виджет), равная ширина колонок, построчный порядок, ручная
  сортировка на 1280 dp — одна колонка, сужение окна на лету, сохранение
  скролла при переходе 1 → 2 → 1 колонки.
- Эмулятор `LxBox_test`, `adb shell wm size 1280x800` и `wm size reset` —
  скриншоты обеих раскладок (в репозиторий не кладутся).

## Что осталось

- Перетаскивание в сетке (двумерный reorder) не сделано — см. выше.
- Другие экраны (подписки, Routing, редактор) не менялись.
