## Problem

1. Отменить правку можно только Ctrl+Z с аппаратной клавиатуры. На телефоне
   случайный Delete, Cut или Paste в редакторе не откатить.
2. Ядро называет номер строки конфига с ошибкой; дойти до неё в длинном
   тексте можно только прокруткой.
3. Заменить всё тело поля текстом из буфера — это Select all, затем Paste
   через меню выделения.
4. Номера строк включает экран, пользователь их не выключит; на узком экране
   они отнимают ширину у длинных полей (`i1` у AWG).
5. Размер текста задан экраном; масштаб жестом выключен (624:
   `setScalable(false)`, жесты делит Flutter).
6. При просмотре конфига легко задеть текст и поменять его.

## Solution

Всё — у нативного редактора (Android). Заглушка `TextField` (тесты,
desktop) новых кнопок и пунктов не показывает, кроме размера текста.

«Редактируемое поле» ниже — поле без `readOnly` и без Lock editing.

### Строка кнопок над рамкой

**Undo, Redo** — иконки `Icons.undo` / `Icons.redo`, размер 18, compact,
первыми в строке (перед Find). Только у редактируемого поля. Недоступны
(серые), когда отменять / повторять нечего. Нажатие — `undo()` / `redo()`
редактора sora; клавиатура не открывается, фокус не забирается.

Состояние «есть что отменить / повторить» натив шлёт событием
`undoState {canUndo, canRedo}` — только при смене значений, после каждой
правки (в том числе после самого undo/redo), после `setText` и
`replaceAll`. Текст, выставленный из Dart (`setText`: Paste и Load
экрана, пересоздание view), историю отмены sora начинает заново — так было
и раньше; Dart при пересоздании view считает обе кнопки недоступными до
первого события.

### Меню ⋮, по порядку

1. **Format / Show original** — как в 660. У запертого поля (Lock editing)
   пункта нет.
2. **Go to line** — у любого поля, где больше одной строки текста. Диалог:
   заголовок `Go to line`, числовое поле (подсказка — диапазон `1–N`),
   кнопки `Cancel` / `Go`; Enter = Go. Номер вне диапазона прижимается к
   1 или N. Курсор встаёт в начало строки, строка прокручивается в вид.
   Клавиатура после перехода закрыта (владелец 28.11.2026: переходят, чтобы
   посмотреть строку); тап по тексту редактируемого поля открывает её, как
   обычно.
3. **Replace with clipboard** — только у редактируемого поля. Весь текст
   заменяется текстом из буфера одной правкой (тот же путь, что Format:
   метод `replaceAll`), правка в undo — подтверждения нет. Буфер пуст —
   снек `Clipboard is empty`, текст не меняется.
4. **Line numbers** — галочка, у любого поля. Исходное значение —
   `showLineNumbers` экрана; выбор живёт в `State`, нигде не хранится (как
   кнопка переноса 649). Поиск (Find) от галочки не зависит.
5. **Text size** — строка меню: подпись `Text size`, кнопки − и + и
   текущий размер между ними; меню при нажатии − / + не закрывается.
   Шаг 1 логический пиксель, поправка к размеру экрана от −4 до +8,
   итоговый размер не меньше 8. Настройка одна на всё приложение и
   сохраняется (`SettingsStorage`, ключ `editor_text_size`, целое, по
   умолчанию 0; не config-significant; едет в бэкапе с настройками
   приложения, как `editor_magnifier`). Применяется сразу в текущем
   редакторе, в остальных — при следующем создании view (как Magnifier).
6. **Magnifier** — как в 660.
7. **Lock editing** — галочка, только у поля без `readOnly`. Включённая
   делает поле только для чтения (`setReadOnly`): прячет Undo/Redo, Replace
   with clipboard и Format, закрывает клавиатуру. Выбор в `State`, не
   хранится; при пересоздании view передаётся в creation params.

### Канал Dart ↔ натив (новое)

- Dart → натив: `undo`, `redo`, `goToLine {line}` (с 1), `setLineNumbers
  {enabled}`, `setFontSize {fontSize}` (логические пиксели). После смены
  номеров строк и размера натив шлёт `changed` без текста (новые
  `rowHeight`, `textOffsetX`, `lines`).
- Натив → Dart: `undoState {canUndo, canRedo}`.
- Creation params: `lineNumbers`, `fontSize`, `readOnly` — из состояния
  `State` (с учётом галочек и поправки размера).

## Risks and edge cases

- Undo после Replace with clipboard и Format возвращает текст целиком —
  это одна правка sora.
- Пересоздание view (уход с вкладки, тема) теряет историю отмены: натив
  создаётся с текстом из Dart. Так было и до этой задачи.
- Строка кнопок у мелких полей с подписью (`header`) становится шире на две
  иконки; подпись переносится в оставшейся ширине (так она устроена).
