| | |
|---|---|
| Тип | bugfix (потеря данных при регидрации) |
| Статус | ✅ Released v2.19.3 — тесты зелёные |
| Дата | 2026-08-02 |
| Связанные | [`348`](348-two-month-revision-parser-fixes.md) (находка P3-8 ревизии), [`322 balancer-node`](../features/322%20balancer-node/spec.md) §7 (URI-форма) |

## Проблема

`ExplicitMembers` сериализуется в `autogroup://` как
`members=keys.join(',')` и парсится `split(',')`. Ключ =
`protocol|server|port|credential`, а credential (пароль ss/trojan) может
нести запятую — такой ключ рвался при регидрации из папки, член молча
выпадал из пула после рестарта.

## Решение

Узкое экранирование per-key при join: `%` → `%25`, `,` → `%2C`
(и обратный порядок на unescape). Решения по месту:

| вопрос | решение |
|---|---|
| Почему не `Uri.encodeComponent` на ключ? | Полный percent-decode на fromUri бросает `ArgumentError` на легаси-ключах с голым `%` в credential — узкий unescape (`%2C`/`%25`) таких не трогает |
| Миграция персистентных URI? | Не нужна: старые URI с чистыми ключами проходят unescape как есть; ключи с запятой и ДО фикса были битыми (член выпадал) — рабочих состояний не регрессируем |
| Даунгрейд приложения? | Старый парсер увидит `%2C` внутри ключа → член выпадет — ровно сегодняшнее (до фикса) поведение, не хуже |

## Тесты

`test/builder/auto_group_folder_test.dart`: round-trip с запятой и literal
`%2C` в credential; легаси-URI с чистыми ключами читается без изменений.
