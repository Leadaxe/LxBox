# §505 — значок уведомлений на главном экране после холодного старта

| | |
|---|---|
| **Статус** | Реализовано |
| **Дата** | 2026-09-19 |
| **Источник** | дефект §502: у одиночного AWG-сервера «🏠 awg2-home» на экране Servers предупреждение «AmneziaWG: MTU lowered to 1280» видно сразу, на главном экране значок появлялся только после Start в текущем сеансе и пропадал после перезапуска |
| **Связанные** | §502, §501, §497, §473 |

## Что было

§502 добавил значок старшего уровня в список Nodes главного экрана.
Presenter строил `warningsByTag` только из `lastEmittedTagMap` — обратной
карты **последней сборки конфига в памяти**. До первой пересборки после
холодного старта карта пуста, хотя экран Servers и Diagnostics уже показывают
предупреждения из разбора узла и хранимого вердикта (`mergedNodeWarnings`).

## Что сделано

1. **Общий источник.** [warningsForConfigTag]: сначала карта последней сборки
   (хоп цепочки, alias-теги), иначе [nodeSpecForConfigTag] — тот же обход
   bare-тега / суффикса / хопа, что [ownerOfTag]; далее
   [warningsForEmittedNode] = разбор + вердикт (как Servers и §501).
2. **Presenter.** [NodeListPresenter.computeListData] заполняет `warningsByTag`
   для всех тегов списка через [warningsForConfigTag], а не только для ключей
   `lastEmittedTagMap`.
3. **Паритет.** Одиночный сервер с префиксом «🏠 », узел подписки, член
   папки, хоп цепочки — сопоставление по тегу в конфиге, не сравнением строк
   записи.

## Критерии приёмки

- После холодного старта у «🏠 awg2-home» с `awg_mtu_clamped` — warning-значок
  на главном экране без Start и без пересборки; то же предупреждение, что на
  Servers и в Diagnostics.
- Presenter: холодный старт (пустая карта сборки) → warning для AWG; info для
  узла подписки; error при вердикте страховки.
- Виджет-тест строки главного экрана — значок есть/нет, тап → лист (§502).
- `flutter analyze`, затронутые тесты; l10n без новых строк.
