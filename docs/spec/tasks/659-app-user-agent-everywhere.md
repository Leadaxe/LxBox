# §659 — единый User-Agent приложения для всех исходящих запросов

| Поле | Значение |
|------|----------|
| Тип | U (порядок) |
| Статус | I (implemented) |
| Дата | 2026-10-17 |
| Связанные | 114 (бренд-токен `LxBox-android`), 118F (идентичность фетча подписки), §219 (версия в UA скрывалась — этой задачей отменено), §392 (диагностика узла), §610 (Custom User-Agent), §622 (передача на TV) |

## Проблема

Каждый HTTP-запрос приложения представлялся по-своему:

| Где | Было |
|---|---|
| Подписки | `LxBox-android/<версия>` или Custom |
| Rule-set'ы (`.srs`) | `LxBox` |
| Проверка обновлений (GitHub) | `LxBox/1.x` |
| Donate, support-лента | `LxBox/1.x` |
| Speed test, community-серверы | не задан → `Dart/<версия> (dart:io)` |
| Диагностика узла (ядро, SPEC 058) | заголовки `null` → `Go-http-client/1.1` |
| Передача телефон→TV | без `User-Agent` |

## Решение (владелец, 17.10.2026)

1. Все запросы, перечисленные выше, шлют брендовый UA приложения
   `LxBox-android/<версия>` (`resolveAppUserAgent()`, та же строка, что
   дефолт подписки).
2. Custom User-Agent (глобальный и у подписки, §610) действует **только**
   для подписок. На остальные запросы не распространяется.
3. Версия в UA больше не скрывается: §219 подставлял `1.x` в запросы к
   GitHub, но подписки и так шлют точную версию произвольным панелям.
4. Исключения:
   - WARP-регистрация остаётся с `okhttp/3.12.1`: это клиент Cloudflare,
     API ждёт официальный клиент;
   - пинг и автовыбор (`urltest` в ядре) не трогаем: у sing-box нет
     параметра заголовков, доработка ядра не нужна (решение владельца);
   - локальный pprof-клиент (`127.0.0.1`, отладка ядра) — не запрос в сеть.

Диагностика: Dart передаёт строку в `ccGetUrlViaOutbound` / `probeGetUrl`
аргументом `userAgent`, Kotlin собирает `HTTPHeaders` с одним
`User-Agent`. Пустая строка → `null`, как раньше.

Передача на TV: строка уходит в `lanPost` аргументом `userAgent` и
пишется заголовком в ручной HTTP-запрос; Dart-ветка ставит
`HttpClient.userAgent`.

## Проверка

- `test/subscription/user_agent_test.dart`: `resolveAppUserAgent()`
  совпадает с дефолтом подписки.
- `test/vpn/cc_get_url_test.dart`: `userAgent` уходит в канал.
