# §489 — вердикт страховки не едет в бэкап

| | |
|---|---|
| **Статус** | Реализовано |
| **Дата** | 2026-09-19 |
| **Источник** | решение владельца 19.09.2026 |
| **Связанные** | фича 478, §221 (симметрия allowlist ↔ экспорт), `docs/STORAGE.md` |

## Проблема

Вердикт `core_rejected` и выключение, поставленное страховкой от отказа ядра,
попадали в LX-бэкап вместе с отметкой `disabled` / `enabled: false`. После
восстановления на другой машине узел оставался выключенным без повторной
проверки ядром, хотя диагностика — локальный кэш, а не настройка пользователя.

Плашка «выключено N» в спеке 478 была описана как переживающая перезапуск;
в коде она живёт только в [CoreRejectState] (память процесса).

## Решение

| Слой | Было | Стало |
|---|---|---|
| Экспорт | `warnings` с `core_rejected`, `disabled` страховки | вердикты не пишутся; узел, выключенный страховкой, в файле **включён**; ручное выключение — как раньше |
| Импорт | вердикт и отметка из файла сливались в хранилище | `core_rejected` из файла отбрасывается; узел с вердиктом в старом бэкапе восстанавливается **включённым** |
| Локальное хранилище | вердикт рядом с `disabled` | без изменений |
| Плашка | in-memory [CoreRejectState] | без персиста; после перезапуска не показывается (значок и причина на узле остаются в хранилище) |

Санитизация — `sanitizeCoreRejectInBackupRecord` (`core_reject_backup.dart`):
на экспорте после `sourceToRecord`, на импорте до кодека. Формат и версия
бэкапа не меняются, коды `backup_warnings` не добавляются. Различие
«страховка / человек» — по наличию `core_rejected` у узла.

## Критерии приёмки

- Экспорт не содержит `core_rejected`; узел, выключенный только страховкой,
  в файле `enabled` / без ключа в `disabled`.
- Ручное выключение без вердикта экспортируется и импортируется как раньше.
- Импорт старого файла с вердиктами: вердикты игнорируются, узел включён.
- Локальный вердикт после перезапуска приложения на устройстве сохраняется;
  плашка после перезапуска не восстанавливается.
- Спека 478 (раздел про бэкап) и CHANGELOG (Unreleased) обновлены.
- `flutter analyze` — без новых issues; тесты `core_reject_backup_test.dart`
  и проверка плашки — зелёные.
