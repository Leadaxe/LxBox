# §649 — Кнопка переноса строк в просмотрщике JSON

| Поле | Значение |
|------|----------|
| Тип | Доработка фичи [019-CONFIG_EDITOR](../features/019-CONFIG_EDITOR/FEATURE.ru.md) (функция [json-fragment-view](../features/019-CONFIG_EDITOR/FUNCTIONS/json-fragment-view.ru.md)), согласовано владельцем 14.10.2026 |
| Статус | P (в работе) |
| Дата | 2026-10-14 |
| Связанные | §624 (нативный sora-editor, липкие заголовки) |

## Проблема

Просмотрщики JSON с липкими заголовками (`LxJsonView` с `stickyHeaders: true`
и языком JSON) показывают текст без переноса строк: sora-editor 0.23.6
липкие заголовки при переносе не рисует, и §624 отдал приоритет заголовкам.
Компактный JSON в одну строку (вкладка Source подписки, тело Liberty VPN)
уходит вправо, читать его можно только прокруткой вбок.

## Решение

В строке кнопок над рамкой редактора — кнопка переключения переноса строк.

### Где показывается

Только там, где перенос по умолчанию выключен, то есть в `LxJsonView` при
`stickyHeaders: true` и языке JSON (вкладка Source подписки, JSON узла,
инспектор узла, outbound, правило, DNS-сервер — где эти условия выполняются).
В редактируемых полях и в просмотрщиках с переносом по умолчанию кнопки нет.

### Поведение

- Иконка `Icons.wrap_text`, размер 18, `VisualDensity.compact` — как у лупы.
  Порядок: лупа, перенос, затем `actions` экрана.
- Подсказка (tooltip): `Wrap lines` (выключено) / `Unwrap lines` (включено);
  либо одна `Wrap lines` с выделенным состоянием кнопки (`isSelected`) —
  исполнитель выбирает один вариант, переводы ru/zh в `assets/l10n/*/ui.json`.
- По умолчанию перенос выключен (как сейчас). Нажатие включает перенос,
  повторное выключает.
- При включённом переносе липких заголовков нет (ограничение sora), подсветка
  текущей строки выключена — то же, что сейчас делает натив при
  `wordWrap: true`. При выключении возвращается исходный режим: липкие
  заголовки и подсветка текущей строки.
- Переключение на лету, без пересоздания platform view и без потери позиции
  прокрутки сверх того, что делает сама sora при смене раскладки.
- Состояние нигде не хранится: открыли экран заново — перенос выключен.
  Пока виджет жив, выбор держится в его `State`: если platform view
  пересоздаётся (смена темы), текущее значение уходит в creation params.
- На время панели поиска кнопка прячется вместе с остальными (как сейчас).

### Натив

`SoraEditorPlatformView.kt`: метод канала `setWordWrap(bool)` — выставляет
`isWordwrap` и `isHighlightCurrentLine = !wordWrap` (как при создании).
Липкие заголовки (`stickyHeaders`) не трогать: sora сама их не рисует при
переносе.

### Не на Android

Заглушка на `TextField` (тесты, desktop) — кнопка есть, переключает перенос
заглушки, если это дёшево; иначе только состояние кнопки. Виджет-тест:
кнопка есть у `LxJsonView` со sticky JSON, нет у редактируемого поля;
нажатие меняет состояние.

## Проверка

- CI зелёный.
- Эмулятор: подписка Liberty VPN → вкладка Source → кнопка переноса включает
  перенос длинной строки, выключение возвращает липкие заголовки; уход с
  экрана и возврат — снова без переноса.
