## Проблема

Провайдеры часто ставят эмодзи в название подписки (`profile-title`). Пример
владельца: `Liberty VPN 🗽`. Префикс тегов (`tagPrefix`) у новой подписки
сейчас всегда пустой, и узлы двух подписок с похожими именами
(`🇫🇮⚡Финляндия-1`) на экране не различить. Пользователь вынужден вписывать
префикс руками.

## Решение

Когда у подписки **впервые** появляется непустое имя, а `tagPrefix` пустой,
из имени извлекается группа эмодзи (правило ниже). Если группа не пустая, она
становится `tagPrefix` (с дедупликацией). Больше префикс автоматически никогда
не меняется.

### Когда срабатывает

Ровно один раз на подписку, в момент первого присвоения непустого имени.
Источники имени:

1. Первое успешное обновление подписки без имени: имя из `profile-title` или
   `Content-Disposition` (`subscription_controller.dart`, ветка `nextName`).
2. Импорт подписки из файла: имя из `profile-title` или имени файла.
3. Любой другой путь создания подписки, где имя известно сразу (исполнитель
   проверяет мастер добавления и вставку ссылки; где имя задаётся при
   создании, правило применяется там же).

Правило **не** срабатывает в этих случаях:

- у подписки уже было непустое имя (существующие подписки не мигрируются);
- `tagPrefix` не пустой;
- пользователь очистил префикс у уже названной подписки (имя не «первое»);
- переименование подписки пользователем;
- UserServer (одиночные узлы, WARP, Tailscale и т.п.), правило только для
  подписок.

### Извлечение группы (`emojiPrefixFromTitle`)

Имя разбирается на графемные кластеры (`package:characters`). Каждый кластер
относится к одному из классов:

- **E — эмодзи:** пара Regional Indicator (флаг); keycap (`1️⃣`, `#️⃣`);
  кластер, в котором есть символ с `Emoji_Presentation`; кластер
  `Extended_Pictographic` + `U+FE0F`. Склейки ZWJ (`👨‍💻`) и тона кожи — один
  кластер. Текстовые символы без эмодзи-представления (`©`, `®`, `™`, `↔`
  без `U+FE0F`) **не** эмодзи.
- **T — текст:** первая кодовая точка кластера — буква `\p{L}` или цифра `\p{N}`
  (кроме keycap, он уже E).
- **S — прочее:** пробелы, пунктуация, точки, глифы, символы (`·`, `|`, `-`,
  `•`, `★` без эмодзи-представления и т.п.).

Алгоритм:

1. Найти первый кластер E. Нет ни одного — результат пустой.
2. Начать группу с него и идти вправо:
   - следующий кластер E — добавить;
   - серия из `k` подряд кластеров S, за которой сразу идёт E, при `k < 3` —
     добавить серию и этот E;
   - иначе (T, конец строки, серия S длиной `≥ 3`, серия S без E после неё) —
     остановиться.
3. Длина группы не больше **4 кластеров**. Если следующий шаг превысил бы
   лимит, остановиться на том, что набрано, и срезать хвостовые S.
4. Группа никогда не начинается и не кончается кластером S.

Примеры (таблица идёт в тест как есть):

| Имя | Префикс |
|-----|---------|
| `Liberty VPN 🗽` | `🗽` |
| `🇩🇪🔥 Germany` | `🇩🇪🔥` |
| `MyVPN 🚀⚡ Premium` | `🚀⚡` |
| `🇩🇪 🔥 Germany` | `🇩🇪 🔥` |
| `🇩🇪·🔥 DE` | `🇩🇪·🔥` |
| `🇩🇪 · 🔥 DE` | `🇩🇪` (серия S из 3) |
| `🔥🔥🔥🔥🔥 Fast` | `🔥🔥🔥🔥` |
| `🔥 🚀 ⚡ X` | `🔥 🚀` (лимит 4, хвостовой пробел срезан) |
| `🔥 VPN 🚀` | `🔥` (после пробела текст) |
| `👨‍💻 Dev` | `👨‍💻` |
| `1️⃣ Server` | `1️⃣` |
| `Provider™` | пусто |
| `© Corp ★` | пусто |
| `Plain name` | пусто |
| `--- 🗽 ---` | `🗽` |

### Дедупликация

Кандидат сравнивается с `tagPrefix` **всех остальных** источников списка
(подписки и UserServer). Если кандидат занят, к нему дописывается индекс без
пробела: `🗽2`, `🗽3`, … первый свободный. Лимит в 4 кластера к индексу не
применяется. Сравнение — точное совпадение строк.

### Что не меняется

- Формат тега: `'$tagPrefix $bare'` (`TagResolver.displayTag`).
- Каскад на фильтры Направлений (§393 A6) не нужен: префикс появляется раньше,
  чем на него кто-то ссылается. Прямую запись префикса делать мимо
  `relinkServerTagPrefix`.
- UI не меняется: префикс просто оказывается заполнен в настройках подписки.

## Реализация (ориентиры)

- Чистая функция `emojiPrefixFromTitle(String) → String` рядом с
  `services/node_emoji.dart` (или в нём), без зависимостей от Flutter.
- Функция дедупликации отдельной чистой функцией (`String dedupTagPrefix(String
  candidate, Iterable<String> taken)`).
- Вызов — в местах первого присвоения имени (см. «Когда срабатывает»).
