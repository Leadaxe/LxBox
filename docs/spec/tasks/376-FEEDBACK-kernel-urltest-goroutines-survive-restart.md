## Наблюдаемые последствия

1. **Память.** В том же дампе 5 OOM-снимков ядра, все на `1.14.0-lx.17-rc.3`:
   memory 396–428 МБ, heap inuse 153–168 МБ, goroutines 285–397. Зависший
   групповой прогон держит ссылку на весь массив outbound'ов, по которому шёл
   тест (2806 элементов), и он не освобождается после остановки ядра.
2. **Пропадают задержки узлов.** Пользователь сообщил, что «утерялся пинг».
   Группа, чей `batch.Wait()` не возвращается, прогон не завершает — результаты
   замеров не публикуются.
3. **Перезапуск ядра не лечит.** Пользователь перезапускал VPN (в логе клиента
   виден полный Stop → Started в 22:17:56); зомби-горутины 100- и 43-минутной
   давности это пережили. Помог только ребилд конфига.

## Условия воспроизведения

Что видно по конфигу из дампа:

- Группа `vpn-1-auto`, `type: urltest`, 592 члена, `url: http://ipv4.ipleak.net/json/`,
  `interval: 3m`. Прогоны идут через `balancePoolTolerant` (SPEC 020 pool-балансировка),
  то есть тестируются **все** члены группы, а не выборка. На момент зависаний
  в группе было 2806 узлов.
- Все шесть зависших handshake'ов — на узлах VLESS с транспортом `xhttp`
  и включённым слоем `encryption` (`mlkem768x25519plus`, SPEC 032).
  В сохранённом конфиге таких узлов уже нет (подписка отключена), но в момент
  зависания они были в пуле.
- В конфиге 7 узлов с `xhttp`, режимы `auto` (в том числе с REALITY),
  `packet-up`.

Гипотеза о минимальном сценарии: большая urltest-группа + хотя бы один
недоступный/полуживой узел `vless + xhttp + encryption` + несколько перезапусков
ядра. Проверить на стенде мы не смогли — узлы из подписки пользователя, повторить
их состояние нечем.

## Что просим

Разобраться, почему `testNodes` не завершается при остановке ядра и почему
блокировки такого рода переживают перезапуск. Диагностический критерий, который
мы можем проверить на устройстве: **после Stop → Start в `dumpStacks()` не должно
оставаться горутин `URLTestGroup.testNodes` от предыдущей сессии** (сейчас
их две, возрастом 100 и 43 минуты).

Готовы прогнать любую сборку на устройстве и снять дамп горутин.

канал доставки улик команде ядра.
