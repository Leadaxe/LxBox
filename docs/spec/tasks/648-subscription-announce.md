## Проблема

Провайдеры отдают в заголовке `announce` описание подписки, Happ показывает его
над списком узлов. Пример владельца (Liberty VPN, заголовок приходит при любом
User-Agent, включая LxBox):

```
announce: base64:4pqhIOKAlCDQm9GD0YfRiNC40LUg0YHQtdGA0LLQtdGA0LAK…
```

Расшифровка — легенда к эмодзи в именах узлов:

```
⚡ — Лучшие сервера
💳 — Зарубежная оплата
🎮 — ПОДХОДЯТ ДЛЯ ИГР
📋 — БЕЛЫЕ СПИСКИ В САМОМ НИЗУ
```

LxBox заголовок не читает: его нет ни в `SubscriptionMeta`, ни в спеке
`subscription-meta`, на вкладке Source он спрятан под раскрывашкой.

## Решение

### Разбор

- Заголовок `announce` (регистр имени не важен). Значение `base64:…`
  декодируется как UTF-8 (тем же путём, что `profile-title`), иначе берётся как
  есть.
- Если заголовка нет — строка-комментарий `announce: …` в начале тела, тем же
  механизмом, что остальные ключи (`#`, `//`, `;`). HTTP-заголовок приоритетнее.
- Нормализация: `\r\n` → `\n`, обрезка пробелов по краям всего текста, больше
  двух переводов строки подряд схлопываются в два. Пустой результат = поля нет.
- Ограничение длины хранимого текста — 2000 символов (графем), лишнее
  отрезается.
- Битый base64 — поля нет, предупреждение в AppLog, подписка обновляется как
  обычно.

### Хранение

Поле `announce` в `SubscriptionMeta` (JSON-ключ `announce`, опционально).
Заменяется вместе с остальными метаданными на каждом успешном ответе; провал и
пустой ответ поле не трогают. Старые сохранённые подписки без ключа читаются
без ошибок.

### Показ

Шапка подписки (`subscription_detail_screen/widgets/subscription_meta.dart`):

- Блок текста под строкой `Expires`, над чипами `Support` / `Web page`; при
  отсутствии `Expires` — на том же месте в порядке блоков.
- Стиль как у соседних строк шапки (`bodySmall`), без рамки и заголовка.
- Текст показывается как есть: многострочный, без перевода, без разметки,
  ссылки не кликабельны.
- В свёрнутом виде — не больше 4 строк с многоточием. Если текст длиннее,
  тап по блоку раскрывает его целиком, повторный тап сворачивает. Короткий
  текст на тап не реагирует.
- Поля нет — блока нет.

Вкладка Source: `announce` добавить в список важных заголовков
(`_importantHeaders` в `subscription_detail_screen.dart`).

Новых UI-строк нет, l10n не меняется.

## Проверка

- Юнит-тест разбора: `base64:` значение из примера выше → четыре строки
  легенды; открытый текст; `\r\n`; пустое значение; битый base64; ключ из
  комментария тела при отсутствии заголовка; заголовок приоритетнее тела.
- Тест сериализации `SubscriptionMeta`: с полем и без (обратная совместимость).
- Виджет-тест шапки: блок есть при поле, нет без поля; длинный текст свёрнут
  до 4 строк и раскрывается тапом.
