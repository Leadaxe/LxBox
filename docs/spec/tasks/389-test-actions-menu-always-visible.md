# §389 — меню Test actions всегда на месте, пункты серые до теста

| Поле | Значение |
|------|----------|
| Статус | Done, DEVICE-PENDING |
| Дата старта | 2026-08-11 |
| Дата завершения | 2026-08-11 |
| Связанные spec'ы | [§388](388-subscription-probe-bulk-disable.md) — bulk-действия на подписке; §284/§296 — меню папки |

## Проблема

Кнопка `⋮` («Test actions») в probe-баре появлялась только при готовых
результатах (`_probe.isNotEmpty && !_testing`) — и в папке (§284), и в
подписке (§388). Итог: контрол то возникает, то исчезает, соседние кнопки
разъезжаются, а до первого теста меню не найти вовсе — не видно, что такие
действия вообще существуют.

## Решение

Кнопка рендерится **всегда**; готовность результатов гейтит не её наличие, а
доступность пунктов: `PopupMenuItem.enabled = _probe.isNotEmpty && !_testing`.
Отключённый пункт Material сам рисует серым и не реагирует на тап —
собственного стиля не требуется, `onSelected` для него не вызывается.

Флаг считается в `itemBuilder` (на каждое открытие), а не в поле состояния:
меню строится в момент показа, поэтому вердикт всегда свежий — в том числе
если тест закончился, пока меню открыто.

| Экран | Пункты |
|---|---|
| Папка ([`folder_detail_screen.dart`](../../../app/lib/screens/folder_detail_screen.dart)) | Disable slower than… / Disable unreachable / Delete unreachable / Sort by ping |
| Подписка ([`subscription_detail_screen.dart`](../../../app/lib/screens/subscription_detail_screen.dart)) | Disable slower than… / Disable unreachable (§388) |

L10n не затронут — ключи те же.

## Verify

Устройством: открыть папку и подписку до теста → `⋮` на месте, оба/все пункта
серые, тап по ним ничего не делает и меню не закрывает. Прогнать тест →
пункты активны, действия работают как в §388/§284. Во время теста
(`_testing`) пункты снова серые.
