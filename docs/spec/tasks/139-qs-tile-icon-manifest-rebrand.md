## Проблема

Юзер прислал скрин шторки (HyperOS/MIUI, режим редактирования панели быстрых
настроек): плитка **L×Box** показывала **сплошной белый квадрат** вместо иконки.

Это рецидив того же класса бага, что чинила task 015 — но в другом месте.
Task 015 закрыла **рантайм**-иконку (`LxBoxTileService.renderTile()` ставит
`Icon.createWithResource(ic_lxbox_tile)`). А белый квадрат вылезал из
**статичной** иконки, которую система берёт когда плитка ещё не bound:
в редакторе QS, в списке доступных плиток, до первого `onStartListening`.

## Диагностика

QS-плитка использует две иконки:

| Когда | Источник |
|---|---|
| Плитка живая/активная (`onStartListening` → `renderTile()`) | `tile.icon` = `ic_lxbox_tile` ✅ |
| Редактор / список доступных / до первого binding'а | **статичная** иконка из манифеста |

В `AndroidManifest.xml` у `LxBoxTileService` стояло
`android:icon="@mipmap/ic_launcher"` — полноцветный лаунчер-логотип.
Android для QS-тайла прогоняет иконку через монохромный tint, который красит
**всю непрозрачную область** в белый. У лаунчер-иконки фон непрозрачный →
заливается весь квадрат целиком → белый квадрат.

Проверка, что дело не в старом APK: вытащил установленную сборку (`dev.11`),
через `aapt2 dump xmltree` декодировал ресурс `ic_lxbox_tile` — внутри
корректный монохром-vector. То есть рантайм-иконка правильная; ломалась
только статичная манифест-иконка.

## Решение

1. **Манифест** — статичную иконку TileService перенацелил на тот же
   монохром-vector, что и в рантайме:
   ```diff
   - android:icon="@mipmap/ic_launcher"
   + android:icon="@drawable/ic_lxbox_tile"
   ```
   Теперь плитка показывает glyph и активной, и в редакторе/превью.

2. **Ребренд `ic_lxbox_tile.xml`** — был generic Material `verified_user`
   (щит-заглушка из task 015). Заменён на фирменный знак **L×**:
   - буква **L** (вертикаль + низ, stroke round-cap);
   - **×** в центре (две диагонали);
   - закрашенный **наконечник ↗** в правом верхнем углу (outbound), угол
     при острие = 90° (прямоугольный треугольник → «жирная» стрелка, не
     иголка). Без линии-древка.

   Геометрия мотивирована `docs/design/icon/W1_pack/W1_master.svg`. Полноцветный
   W1 (ivory L-рамка + navy стрелка + узлы на оранжевом) в монохром «в лоб»
   не переносится — цвета сливаются в белое пятно; поэтому нарисован
   single-color силуэт, читаемый при tint в 24dp.

## Файлы

- `app/android/app/src/main/AndroidManifest.xml` — `android:icon` TileService.
- `app/android/app/src/main/res/drawable/ic_lxbox_tile.xml` — новый glyph L×.

## Проверка

- aapt2-декод установленной сборки → подтвердил, что баг в манифест-иконке, не в APK.
- Локальный рендер drawable (qlmanage) в активном/неактивном/24px состояниях.
- Device-проверка: пересборка release+arm64, установка поверх, скрин шторки.

## Связь с предыдущими

Продолжение [task 015](015-android-9-11-quickconnect-regression.md): тот же
корень (mipmap.ic_launcher тинтится как сломанный monochrome), не закрытый
для статичной манифест-иконки. На будущее: **обе** точки (рантайм `tile.icon`
И манифест `android:icon`) должны указывать на монохром-vector — нельзя
оставлять `@mipmap/ic_launcher` ни в одной.
