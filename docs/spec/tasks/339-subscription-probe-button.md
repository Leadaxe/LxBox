# §339 — Test servers на экране подписки

| | |
|---|---|
| Статус | Реализовано |
| Дата | 2026-08-02 |
| Связанные | §296 (общий probe над ServerList), [`236 folder-server-testing`](../features/236%20folder-server-testing), [`336 probe-skips-group-nodes`](336-probe-skips-group-nodes.md), [`283 node-disable`](283-subscription-node-disable.md), §326 (ключи результатов) |

## Проблема

§296 вынес probe-обвязку (раннер, гейт, пороги, ping-опции) из папки в общий
`ProbeController` «для папок/подписок/серверов», но кнопку теста получила
только папка. На экране подписки протестировать ноды нечем — жалоба юзера
02.08.2026 при проверке §336.

## Решение

Зеркало папки (§236) на вкладке Nodes экрана подписки, минус то, чего у
подписки нет.

### Контрол-бар

Полоса между `SubscriptionMeta` и списком, паттерн `_buildControlBar` папки:
слева инфо (`Test servers` → `Testing… N done` → `N ok · N err · N broken`),
справа кнопка `Icons.speed`/`stop` (тап = старт/отмена). Настроек по long-press
нет — у подписки нет per-list ping-опций, глобальные правятся с главного
экрана и из папки.

### Прогон

- Гейт — общий `ProbeGateMixin` (`ensureVpnStoppedForProbe`, гонка →
  `onProbeVpnRaceGate`).
- Ноды — `ProbeController.probeNodesOf(entry.list)`: top-level узлы как есть.
  **Выключенные (§283) тестируются тоже** — как в папке: probe отвечает на
  «жив ли сервер», а не «в конфиге ли он»; вердикт виден на выключенной
  строке. Chained-дети отдельно не тестируются — цепочка живёт внутри emit
  родителя.
- Группы §322 получают вердикт `group` (§336) — нейтральный бейдж.
- Ping-опции — глобальные (`resolvePingOptions()` без override).
- Флаш результатов — таймер 120мс (§286, как в папке).

### Ключи результатов

`ProbeController.probeKeysForNodes(nodes)` — тот же механизм, что §326 у
папки: `nodeIdentityHash`, дубли — суффикс `#2`. Общий дедуп вынесен в
`_dedupKeys`, `probeKeys(members)` делегирует. Ключ-идентичность переживает
refresh подписки (инстансы нод подменяются, хеш — нет); состав изменился →
новые ноды просто без бейджа до следующего теста.

### Бейдж строки

Общий виджет `ProbeBadge` (`lib/widgets/probe_badge.dart`) — извлечён из
`_MemberRow._probeBadge` папки как есть (цвет по порогам шкалы, `~`-набор
статусов §336 включён); папка переведена на него же. Тап по бейджу с
непустым `message` — SnackBar с текстом ошибки (как в папке).

В `SubscriptionNodeList` бейдж — `trailing` строки; для chained-детей и
UserServer-строк без результата не рисуется (map просто не содержит ключа).

## Границы

Bulk-решения по результатам (Disable unreachable / slower / sort by ping) на
подписку не переносятся: у подписки свой механизм выключения (§283 hash) и
нет ручного порядка нод — перенос решений требует отдельного маппинга
«индекс → hash» и обсуждения UX. При спросе — отдельная таска.

## Тесты

- `probe_controller_test.dart`: `probeKeysForNodes` — хеш-ключи, суффиксы
  дублей, `slot:` для null-слота; делегация `probeKeys` не сломана (старые
  тесты).

UI-прогон — device-check (кнопка, бейджи, гейт при VPN-on, отмена).
