# §502 — значок уведомлений в списке Nodes на главном экране

| | |
|---|---|
| **Статус** | **Released в v2.25.0** (20.09.2026, ядро `v1.14.1-lx.8`). Реализовано |
| **Дата** | 2026-09-19 |
| **Источник** | явное поручение владельца: «в списке серверов я тоже хочу видеть самый страшный значок — либо (i), либо треугольник, либо ×» |
| **Связанные** | §479 (уровни и [NodeInfoBadge]), §497 (источник уведомлений), §499 ([EntryWarningBadge] в списке источников), фича 478 (`core_rejected`) |

## Что было

На главном экране в списке Nodes у строки узла были эмодзи+тег, подпись
протокола (`WG·awg2`, `VLESS·tcp·TLS`), задержка и кнопка ▶/✓ — без
индикатора уведомлений. Значки и шторка §479 работали в списке узлов
подписки и на экране Servers; на главном экране пользователь не видел
проблему, пока не открывал детали.

## Что сделано

1. **Модель строки.** [NodeListPresenter.computeListData] один раз на
   обновление списка строит `warningsByTag` по `lastEmittedTagMap`:
   `warningsForEmittedNode` = предупреждения разбора + вердикт страховки из
   хранилища (та же логика, что вкладка Notifications §497).
2. **Значок.** Во второй строке, **перед** подписью протокола — [NodeInfoBadge]
   с `showTopSeverity: true`: один значок старшего уровня (error → ✖, warning
   → ⚠, info → приглушённый ⓘ). Цвета и иконки — [warningSeverityStyle] §479.
   Тап по значку — [showNodeWarningsSheet]; тап по остальной строке без
   изменений.
3. **Исключения.** Служебные строки Direct / Auto / Block — значка нет
   (`notificationWarnings: null`). У узла автовыбора подписки — только
   собственные уведомления, без агрегата по членам пула.
4. **Узлы, выключенные страховкой.** При сборке конфига они не эмитятся
   (`disabledHashes` в `build_config` / `server_list_build`) и **не попадают**
   в selector главного экрана — отдельный значок для «отсутствующих» не
   нужен. Если узел всё же присутствует в списке (кастомный конфиг без
   записи в хранилище), вердикт в карте не найдётся; разборные error/warning
   по-прежнему дают значок.

## Критерии приёмки

- У узла с уведомлениями — один значок старшего уровня перед протоколом;
  без уведомлений — как раньше.
- Direct / Auto / Block — без значка; высота строки и колонка задержки не
  менялись.
- Тап по значку открывает шторку Notifications; тап по строке — прежнее
  поведение.
- Presenter: `topWarningSeverity` / `warningsByTag` — info, warning, error,
  пусто; виджет-тест [NodeRow] — значок есть/нет, тап → лист.
- `flutter analyze`, затронутые тесты; l10n без новых строк. §479 (точки
  входа), CHANGELOG (Unreleased → Added).
