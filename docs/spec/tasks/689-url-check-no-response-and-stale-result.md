# 689 — URL Check: итог без HTTP-ответа и результат прошлых параметров

| Поле | Значение |
|------|----------|
| Статус | Done — эмулятор не гоняли |
| Дата начала | 2026-10-28 |
| Источник | владелец, скрины с телефона (v2.25.18-rc.2, `https://ya.ru`, Full): зелёный «HTTP 0 · 230 ms» при `http` SKIPPED; «при смене параметров надо очищать результаты, иначе не понятно» |
| Ядро | sing-box-lx#59: редирект `302` уводит HTTP-клиент проверки во второе соединение, которое через роутер запрещено; ошибка теряется (сообщено сессии ядра 28.10) |
| Связанные спеки | [687](687-diagnostics-url-check.md), [688](688-url-check-stage-details.md) |

## Проблема

1. Итог при глубине Full выбирается так: ошибка теста → ошибка; есть корневая
   стадия → «Failed at …»; иначе — зелёный «HTTP %d · %d ms». Ядро rc.2 на
   редиректе отдаёт `http_status = 0` без ошибки и без FAILED-стадии, и экран
   рисует зелёную галку с «HTTP 0». Это неправда: ответа сайта нет.
2. После прогона можно сменить URL, приложение, глубину или From scratch —
   дерево прошлого прогона остаётся под новыми параметрами, и не видно, к
   каким параметрам оно относится.

## Решение

1. При глубине Full, без ошибки и без корневой стадии, если `http_status = 0`
   — итог «No HTTP response · %d ms», уровень warning (жёлтый), иконка
   предупреждения. Любой ненулевой статус (в том числе `3xx`, когда ядро
   перестанет ходить по редиректу) — как раньше, «HTTP %d · %d ms».
   Атрибут `location` у стадии `http` показывается как прочие атрибуты.
   Текст Copy не меняется: `HTTP 0` в машинной выгрузке — факт ответа ядра.
2. Смена любого параметра проверки сбрасывает результат (дерево, итог,
   раскрытия, подсветку находки):
   - правка URL (ввод, кнопка очистки);
   - выбор или снятие приложения;
   - смена глубины;
   - переключение From scratch.

   Если в этот момент идёт проверка (менять можно только URL — остальные
   элементы во время прогона неактивны), она останавливается. Без
   изменений значения (тот же сегмент, то же приложение) результат остаётся.

## Файлы

  и его вызовы у полей.
- `app/assets/l10n/{ru,zh}/ui.json`: «No HTTP response · %d ms».

## Проверка

На эмуляторе:

1. `https://ya.ru` Full через роутер (ядро rc.2/rc.3 до исправления #59):
   итог жёлтый «No HTTP response · N ms».
2. После любого прогона сменить сегмент, From scratch, приложение, URL —
   дерево и итог исчезают.
