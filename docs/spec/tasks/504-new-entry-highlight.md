# §504 — подсветка и прокрутка к новой записи на экране Servers

| | |
|---|---|
| **Статус** | **Released в v2.25.0** (20.09.2026, ядро `v1.14.1-lx.8`). Реализовано |
| **Дата** | 2026-09-19 |
| **Источник** | явное поручение владельца: новая запись в длинном списке незаметна, SnackBar перекрывает низ |
| **Связанные** | §255 (focusEntryId / detour-cycle), §500 (отказ без прокрутки) |

## Проблема

На экране Servers (Subscriptions & proxy) при добавлении источника через поле
ввода и «+» (и соседние пути: буфер, QR, файл, визард) новая строка часто
оказывается ниже видимой области. Одновременно снизу всплывает SnackBar
«Config regenerated & applied: N nodes» и закрывает низ списка — добавление
проходит незаметно.

## Решение

- После **успешного** добавления записи (все пути, сходящиеся в новую строку
  списка) список плавно (~300 мс) прокручивается к новой записи; при пакетном
  добавлении — к первой новой. Выравнивание ближе к середине экрана, чтобы
  строка не оказалась под SnackBar. SnackBar показывается после завершения
  прокрутки.
- Новая запись подсвечивается: мягкий фон из `primaryContainer` темы (с
  прозрачностью) и метка «New» (l10n) рядом с названием.
- Подсветка снимается по первому из: действие пользователя (тап по строке/
  переключателю, перетаскивание, ввод в поле, ручной скролл > высоты экрана),
  уход с экрана, таймер 7 с — с плавным затуханием ~400 мс.
- Состояние «новая запись» — только на экране (`id` + таймер), в хранилище и
  бэкап не пишется.
- При отказе добавления (§500, `lastError != null`) прокрутки и подсветки нет.
- §255 (`focusEntryId` из detour-cycle) сохранён: отдельный режим без метки
  «New», авто-снятие через 2.2 с.

## Критерии приёмки

- [x] Длинный список: после добавления новая строка в видимой области и выше
  SnackBar; метка «New» и подсветка на месте.
- [x] Через 8 с подсветки нет (таймер 7 с + затухание).
- [x] Тап по другой строке снимает подсветку сразу.
- [x] Отказ ввода (§500) — без прокрутки.
- [x] `flutter analyze` без новых issues; l10n-чекеры `--strict` зелёные;
  затронутые тесты зелёные.


## Тест

`app/test/screens/subscriptions_new_entry_highlight_test.dart` (восстановлен
§511). Зависание было не от `pumpAndSettle`: настоящий файловый I/O
(засев, `addFromInput`, `generateConfig`) в fake-async зоне `testWidgets` не
завершается. Хранилище прогревается в `setUp`, записи подменяются в памяти,
`generateConfig` фейковый — весь путь «+» → прокрутка → подсветка →
SnackBar идёт на фейковых часах через `pump(Duration)`.

Восстановленный тест поймал три дефекта, починены там же (§511):

- новая запись встаёт в хвост, а хвост длинного списка прокручивается только
  до нижнего padding — строка оставалась под SnackBar. На время жизни экрана
  после первой подсветки у списка запас 80 dp снизу;
- фон подсветки (DecoratedBox) закрывал ink строки — строка обёрнута в
  прозрачный `Material`, debug-assert ListTile снят;
- `deactivate()` снимал подсветку через `setState` — assert «setState during
  build» при уходе с экрана с активной подсветкой. Поля сбрасываются напрямую.
