# 461 — Ядро v1.14.1-lx.5 (hotfix SPEC 090: REALITY `short_id` длиннее 16 hex)

| Поле | Значение |
|------|----------|
| Статус | **Released в v2.25.0** (20.09.2026, ядро `v1.14.1-lx.8`). Реализовано, тесты зелёные |
| Дата | 2026-09-18 |
| Ядро | `v1.14.1-lx.5` — hotfix SPEC 090: REALITY `short_id` длиннее 16 hex-символов теперь даёт ошибку `invalid short_id` до декодирования (клиент `common/tls/reality_client.go` и сервер `reality_server.go`); раньше в этом месте была паника `index out of range` — `hex.Decode` писал в массив `[8]byte`. Найдено DRIFT-инвентарём контракта (TASKS_LXBOX §24.4 г), передано агенту ядра 18.09. Провод, конфиг, наборы тегов AAR и Go-тулчейн без изменений, сабмодули не двигались; libbox-API не менялся |
| Связанные | §343 (гард LxBox: `short_id` длиннее 16 hex отбрасывается — остаётся как UX-защита; ядро теперь отвечает ошибкой, а не паникой), §457 (предыдущий бамп, та же процедура) |

## Решение

- `app/android/libbox.version`: `v1.14.1-lx.4` → `v1.14.1-lx.5`;
  `scripts/fetch-libbox.sh` качает AAR с проверкой SHA256.
- Java-поверхность: javap-обход всех классов одной командой (память
  `kernel-bump-emulator-verify`; sha256 `classes.jar` не показатель),
  дифф lx.4 → lx.5 ожидается пустым. Непустой дифф — стоп и отчёт.
- `docs/KERNEL.md`: блок «The current pin» → lx.5 (что принёс, Java-поверхность),
  строка в «Version history»; абзац про lx.4 остаётся ниже как история.
- `CHANGELOG.md` → Unreleased / Changed: бамп ядра.

## Проверка

- javap-дифф lx.4 → lx.5 пуст (списки классов совпадают).
- В собранном APK `lib/arm64-v8a/libbox.so` строка версии — ровно
  `1.14.1-lx.5`.
- `flutter analyze`, `flutter test`, четыре l10n-чекера (новых строк нет).
