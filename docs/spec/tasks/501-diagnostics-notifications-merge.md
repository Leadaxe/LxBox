# §501 — уведомления узла внутри вкладки Diagnostics

| | |
|---|---|
| **Статус** | **Released в v2.25.0** (20.09.2026, ядро `v1.14.1-lx.8`). Реализовано |
| **Дата** | 2026-09-19 |
| **Источник** | решение владельца 19.09.2026: вкладки Notifications и Diagnostics не помещаются на экране одиночного сервера (пять вкладок) |
| **Связанные** | §497 (отдельная вкладка Notifications — объединена), §498 (лист страховки), §479 (компонент карточек) |

## Что было

Задача §497 добавила вкладку Notifications перед Diagnostics на экранах
деталей узла (`node_inspect_screen`, `node_settings_screen`). У одиночного
сервера стало пять вкладок (Settings, Source, JSON, Notifications,
Diagnostics) — подписи наезжали друг на друга. Лист страховки «N servers
disabled» (§498) открывал узел на вкладке Notifications.

## Что сделано

1. Отдельная вкладка **Notifications** убрана на обоих экранах деталей.
2. Вкладка **Diagnostics**: сверху прежнее содержимое диагностики (Check,
   Endpoint, Run и результат); при непустых уведомлениях ниже — разделитель,
   заголовок «Notifications» (в стиле секции «Check») и `NodeNotificationsView`.
   При отсутствии уведомлений секции нет. Один вертикальный скролл с
   `.withSafeBottom`. Активная диагностика важнее уведомлений.
3. На ярлыке вкладки Diagnostics — маленький кружок у правого верхнего края
   подписи (не счётчик): жёлтый/янтарный при наличии уведомлений, красный если
   среди них есть error (в т.ч. `core_rejected`). Без уведомлений точки нет.
4. Переход из листа страховки «N servers disabled» (§498) и любой другой
   переход «к уведомлениям узла» открывает **Diagnostics** и после первого
   кадра прокручивает к секции уведомлений (`Scrollable.ensureVisible`). При
   обычном открытии вкладки прокрутки нет.
5. Тап по значку (i)/⚠ в списке — без изменений (шторка с карточкой).
6. Ярлыки четырёх вкладок одиночного сервера на 360dp не наезжают (`TabBar`
   с `isScrollable`).

Вкладка объединена с Diagnostics задачей 501 (спеки §497, §498 обновлены).

## Критерии приёмки

- Вкладки Notifications нет; на Diagnostics — диагностика сверху, уведомления
  снизу (если есть), один скролл.
- Точка на ярлыке Diagnostics: есть при уведомлениях, жёлтая / красная при
  error, отсутствует без уведомлений; четыре вкладки одиночного сервера на
  360dp не наезжают.
- Лист страховки и прочий переход «к уведомлениям» → Diagnostics с прокруткой
  к видимой секции уведомлений; обычное открытие вкладки — без прокрутки.
- Тесты `node_notifications_test.dart`, `core_reject_ui_test.dart`; страж
  `bottom_inset_contract_test.dart`; l10n-чекеры `--strict`.
