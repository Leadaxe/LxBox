## Как этим пользоваться

Ниже — сырой список того, что авторы фич увидели, читая код и тесты против старых спек
(`NNNF`). Каждый пункт — кандидат, не факт: часть окажется задуманным поведением, часть —
устаревшей спекой, часть — багом.

Порядок разбора: владелец проходит по пунктам и помечает каждый одним из трёх исходов —
**задача** (заводится `tasks/NNN-…`, номер вписывается рядом с пунктом), **спека устарела**
(правится F-спека или фича, пункт помечается «doc»), **так задумано** (пункт помечается
«by design», при необходимости в фичу добавляется граница). Когда все пункты помечены,
аудит закрывается статусом `C`, а обещания «без свидетеля» из фич становятся задачами на тесты.

Крупные находки, которые стоит смотреть первыми: экран Routing на чистой
установке выключает дефолтный `ru-direct` до первого автообновления (004); режим замены бэкапа
стирает невыбранные категории (017); флаги `wizard_*` ломают чистый импорт бэкапа (017).


Черновой список кандидатов в задачи, собранный из отчётов по фичам. Каждый пункт
требует подтверждения владельцем перед заведением задачи. Разделы по фичам.
