## Docs to update

- нет: поведение строки не меняется, меняется только её положение.

## Problem

На главном экране при трёхкнопочной навигации красная строка «Errors (N)»
(§614) рисуется под системными кнопками «◁ ○ |||»: видна сквозь панель,
тап попадает в системную кнопку, журнал ошибок не открыть.

## Diagnosis

`ErrorsCounterRow` — последний ребёнок `body: Column(...)` главного экрана
(`home_screen.dart`). Приложение рисует edge-to-edge (§516), а ни `Column`, ни
строка нижний системный отступ не учитывают. Правило §429 и его контрактный
тест ловят только скроллеры с явным `padding:`; список узлов над строкой
отступ прибавляет (`withSafeBottom`), а строка под ним — нет.

## Solution

Нижний отступ строки = 8 + `MediaQuery.paddingOf(context).bottom`
(`EdgeInsets.withSafeBottom`, §429). Когда строки нет (N = 0), ничего не
меняется. Список узлов свой отступ оставляет: при видимой строке под списком
остаётся лишний зазор высотой с панель — приемлемо, строка видна редко.

## Verification

- widget-тест `test/screens/home/errors_counter_row_inset_test.dart`: при
  `viewPadding.bottom = 48` текст строки целиком выше полосы панели, тап по
  тексту открывает журнал.
- Эмулятор / телефон — не проверялось.
