# §466 — «Copy link» у узла с приватным ключом: предупреждение и подтверждение

## Проблема

§463 по правилу 7.16 контракта сделал «Copy link» у SSH-узла с `private_key`
отказом со снэкбаром. У WireGuard приватный ключ при этом уходил в ссылку
молча. Получилось непоследовательно: один ключ нельзя вынести вовсе, другой
уносится без единого слова. Отказ к тому же ломает перенос своего узла между
своими устройствами.

## Решение

Одно поведение для всех узлов, чья ссылка несёт приватный ключ.

1. Признак — геттер на `NodeSpec` (`bool get linkCarriesPrivateKey`, по
   умолчанию `false`), `true` у:
   - `SshSpec` с непустым `privateKey`;
   - `WireguardSpec` (включая AWG) — приватный ключ интерфейса есть всегда;
   - `MasqueSpec` с непустым приватным ключом (`privateKeyDer`/аналог) — если
     `toUri()` его эмитит; если не эмитит, геттер `false`.
   Пароли, UUID и PSK признаком не считаются: это секрет прокси, а не ключ,
   которым владелец опознаётся где-то ещё.
2. `copyNodeUri` (`app/lib/screens/home/node_actions.dart`) — единственная
   точка выдачи ссылки узла. Если `linkCarriesPrivateKey`:
   - `AlertDialog`, заголовок `Link contains a private key`;
   - текст `Anyone who gets this link can use the key. Copy it only to move
     the node to your own device.`;
   - кнопки `Cancel` и `Copy anyway`;
   - по `Copy anyway` — обычное копирование и снэкбар `URI copied`;
   - по `Cancel` и по тапу мимо — ничего.
   Отказ-снэкбар `This node holds a private key — …` из §463 удаляется вместе
   со строкой из словарей.
3. `toUri()` не меняется: это форма хранения, ключ в ней обязан остаться.
4. Строки — английские ключи, переводы ru и zh в словари; четыре l10n-чекера
   зелёные.

## Контракт

7.16 у лаунчера — «не эмитить» (`ErrShareURINotSupported`). Наше расхождение —
на уровне экрана, не эмиттера: `toUri()` и раньше нёс ключ (форма хранения),
корпус это не проверяет. Сессии лаунчера сообщить решение владельца, чтобы
7.16 в `TASKS_LXBOX.md` получил пометку «LxBox: с подтверждением».

## Критерии приёмки

- виджет-тест: SSH с ключом → диалог; `Cancel` → буфер пуст; `Copy anyway` →
  в буфере `toUri()`;
- WG-узел → диалог; vless-узел → копирование без диалога;
- SSH с паролем без ключа → без диалога;
- `flutter analyze` всего проекта чистый, `flutter test` — «All tests passed»,
  l10n-чекеры зелёные;
- CHANGELOG, USER_GUIDE.md и USER_GUIDE.ru.md (раздел про копирование
  ссылки), GUARDS.md (строка 7.16) обновлены.
