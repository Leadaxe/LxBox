# Псевдо-направление NETWORKS — узлы Tailscale вне списков выхода

Строка NETWORKS появляется в списке Направлений на главном экране только при
поднятом VPN.

| Поле | Значение |
|------|----------|
| Фича | [012-LIVE_STATE](../FEATURE.ru.md) |
| Обещания | P19 |
| Состояние | ✅ написана по коду, 2026-09-28 |

## Что делает

Показывает на главном экране узлы, которые не попали ни в один список выбора
выхода, — сейчас это узлы Tailscale без `exit_node` — вместе с их живым
состоянием. Пользователь видит, что узел поднялся, требует входа или
остановлен, и может открыть его экран.

## Параметры

Своих настроек нет.

## Входы / Выходы

**Входы:** работающий конфиг (при опущенном туннеле — последний собранный);
статус туннеля; поток ядра `SubscribeTailscaleStatus` — `BackendState`,
`StateText` по тегу узла.

**Выходы:** пункт `NETWORKS` последним в перечне направлений; список его
узлов; состояние в строке на месте задержки.

| Условие | В строке |
|---------|----------|
| VPN выключен | ничего |
| VPN включён, записи ядра об узле нет | `starting` |
| `Running` | `running` |
| `NeedsLogin` | `sign-in needed` (цвет предупреждения) |
| `Stopped` | `stopped` (цвет предупреждения) |
| прочее | `StateText` ядра как есть (пусто — `BackendState`) |

## Правила и инварианты

- Узел входит, если он в `endpoints[]`, тип `tailscale` и реестр не считает
  его выходом (нет `exit_node`). Tailscale в `outbounds[]`, WireGuard и
  Tailscale с выходом — не входят.
- NETWORKS показывается только при поднятом VPN и непустом составе; если
  настоящих направлений нет — показывается один.
- В конфиг и хранилище не пишется; в списках выбора целей правил, DNS и
  звеньев цепочки его нет; переименовать, удалить, настроить нельзя.
  Направление пользователя с тегом `NETWORKS` с ним не путается.
- При выбранном NETWORKS: счётчик — число его узлов, кнопок сортировки и
  фильтров нет; выбранное настоящее направление и выход трафика не меняются.
- Строка узла: нет отметки активного, нажатие открывает экран узла и не
  выбирает выход; в меню нет выбора и замера задержки; общий замер
  недоступен.
- Подписка на состояние живёт, пока VPN включён и есть узлы NETWORKS;
  смена состава или снимка конфига ядра (перезагрузка) переподнимает её.
  Перерисовка — только при смене состояния или числа устройств.
- Сообщения потока без тега отбрасываются.

## Границы

- Вкладка Network узла Tailscale (устройства, exit node, проверка) —
  008-NODE_EDITOR / 009-NODE_HEALTH.
- Какие узлы попадают в обычные направления — 007-NODE_LIST.
