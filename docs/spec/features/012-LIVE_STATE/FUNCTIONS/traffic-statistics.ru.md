# Статистика трафика — объём, активные соединения и трафик по правилам маршрутизации

Вкладка Stats отвечает на вопрос «сколько и по какому правилу» за текущую
сессию ядра.

| Поле | Значение |
|------|----------|
| Фича | [012-LIVE_STATE](../FEATURE.ru.md) |
| Обещания | P6 |
| Состояние | ✅ написана по коду, 2026-09-28 |

## Что делает

Вкладка Stats экрана Statistics: сколько передано за сессию, сколько
соединений активно сейчас, сколько памяти занимает приложение и как текущие
соединения распределены по правилам маршрутизации — с раскрытием до
отдельного соединения.

## Параметры

Своих настроек нет. Пока экран открыт, тик статуса — 0,1 с (см.
[data-channels](data-channels.ru.md)).

## Входы / Выходы

**Входы:** тики `CommandStatus`; снимок соединений (только живые —
`closedAt == 0`); справочник пользовательских правил; работающий конфиг
(для detour-цепочки под карточкой).

**Выходы:**

| Блок | Содержимое |
|------|-----------|
| Сводка | Upload, Download (объём), Connections (число живых; тап → Conns), LxBox (память; тап → разбивка) |
| Traffic by Rule | карточка на правило: ↑/↓ суммой, число соединений, под именем — `↳ via …` detour-цепочка; сортировка по объёму; раскрытие — соединения `host:port`, TCP/UDP, правило, возраст, ↑/↓ |
| By routing rule | распределение числа соединений по правилам полосками |
| Память | лист: RSS/PSS процесса, разбивка по категориям памяти ОС, горутины ядра, `connectionsIn` / `connectionsOut`; тап по строке копирует |

## Правила и инварианты

- Закрытые соединения в статистику не входят: иначе число и распределение
  раздувались бы историей.
- Имя правила: сырая строка правила ядра сопоставляется со справочником
  пользовательских правил (нормализация пробелов, устойчиво к обрезке ядром
  длинных списков); ненайденное или пустое — `final`; результат кэшируется.
- Хост соединения — домен, если есть, иначе хост из адреса назначения.
- «Память» — всего процесса приложения, а не только ядра: ядро живёт в том
  же процессе. Размер Go-кучи ядра отдельно не доступен.
- Пересчёт карточек — не чаще раза в 0,7 с, окно отсчитывается от конца
  предыдущего пересчёта; первый снимок — сразу.
- Пока первый снимок не пришёл — индикатор загрузки; нет соединений —
  «No active connections».

## Границы

- Разбивки по приложениям на Stats нет и не планируется
  (решение владельца 2026-09-29, аудит [591](../../../tasks/591-spec-kit-revision-audit.md)) — она в профайлере
  ([028-TRAFFIC_PROFILER](../../028-TRAFFIC_PROFILER/FEATURE.ru.md)).
- Скорость не показывается — только объём и число соединений.
- Правила и их тексты — 004-ROUTING.
