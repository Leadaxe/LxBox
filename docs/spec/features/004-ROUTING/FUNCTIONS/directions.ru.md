# Направления — именованные выходы со своими селекторами узлов

Направление — именованный выход (`vpn-1`, `vpn-2` или свой) со своим набором узлов; правила и
Default traffic отправляют трафик в Направления.

| Поле | Значение |
|------|----------|
| Фича | [004-ROUTING](../FEATURE.ru.md) |
| Обещания | P15 P16 P17 P18 |
| Состояние | ✅ написана по коду, 2026-09-28 |

## Что делает

Направление — именованная точка выбора маршрута, куда правила отправляют
трафик: `vpn-1` («VPN ①»), `vpn-2`, свои (`ru-exit`)… Каждое — отдельный
селектор узлов со своим составом, в котором на главном экране выбирается
активный узел. Таб **Directions** экрана Routing: список Направлений,
«Add direction», тайл **Default traffic** (куда идёт всё, что не совпало).

## Параметры

| Поле | Значения | Умолчание | Ключ ядра |
|---|---|---|---|
| Tag | `vpn-N` (первый свободный) или свой; неизменяем | `vpn-N` | тег `selector` |
| Title | любое имя | «VPN ⓝ» для `vpn-N`, иначе тег | — (только клиент) |
| Вкл/выкл | — | `vpn-1` вкл, `vpn-2` выкл | Направление не эмитится |
| Include direct-out / Include block | галки | выкл | опции `direct-out` / `block` |
| Other directions | только Направления выше по списку | — | опции-теги других селекторов |
| Node filter (regex) + Exclude matching (invert) | регистронезависимо | пусто = все узлы | состав `outbounds` |
| Default (regex) | первый совпавший узел | пусто | `default` |
| Interrupt connections on switch | вкл/выкл | вкл | `interrupt_exist_connections` |
| Default traffic | `direct` · Направление · `block` | `vpn-1` | `route.final` |

Автовыбор (`<tag>-auto`), балансировка, «Use as detour» (⚙ в имени) —
[006-DETOUR_AND_BALANCE](../../006-DETOUR_AND_BALANCE/FEATURE.ru.md).

## Входы / Выходы

**Входы:** список Направлений; узлы подписок и свои; действия пользователя.
**Выходы:** по `outbounds[type=selector]` на каждое включённое Направление;
цели для пикеров правил, пресетов и Default traffic; предупреждения сборки;
уведомление о перенаправленных ссылках.

## Правила и инварианты

- Пикер целей: `direct` первым, затем включённые Направления (`vpn-1` всегда,
  detour-Направления с ⚙), `block` последним, красным. Выключенные скрыты.
- `vpn-1` нельзя выключить и удалить — это запасная цель для всего.
- Новый тег: пустой, служебный (`direct-out`, `block`, `block-out`,
  `dns-out`, `reject`, `drop`, `direct`), дубль или коллизия с `<tag>-auto`
  отвергаются с причиной в диалоге. Потолка на число Направлений нет.
- **Удаление или выключение** Направления переводит на `vpn-1` в хранении:
  цели правил, переопределения цели пресетов, Default traffic, канал
  DNS-серверов (см. 005); detour-ссылки узлов снимаются (006). Итог — одно
  уведомление «Direction "…" deleted/disabled — …». Повторное включение
  ссылки не возвращает.
- Ссылки из «Other directions» вычищаются только при удалении; при
  выключении остаются (обратимо), сборка их пропускает с предупреждением.
- Ссылка на Направление ниже по списку, несуществующее или выключенное не
  эмитится (антицикл), предупреждение.
- Фильтр отсёк все узлы (или инверсия исключила всё) → состав `[block,
  direct-out]`, по умолчанию `block`, предупреждение; невалидный regex → все
  узлы. Подпись тайла показывает «N of M nodes» по снимку работающего ядра.
- Default traffic на исчезнувшую цель → `vpn-1`, предупреждение сборки.
- Правило или Default traffic с целью, которой нет в конфиге, — fatal
  проверки перед стартом; до него штатно не доходит благодаря лечению выше.
