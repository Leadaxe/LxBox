# Обмен правилами файлом — перенос выбранных правил между устройствами

Выбранные свои правила, при желании с их DNS-серверами и DNS-правилами, можно выгрузить в файл и
загрузить в другую установку LxBox без полного бэкапа.

| Поле | Значение |
|------|----------|
| Фича | [004-ROUTING](../FEATURE.ru.md) |
| Обещания | P19 |
| Состояние | ✅ написана по коду, 2026-09-28 |

## Что делает

Переносит выбранные свои правила (и, по желанию, связанные DNS-серверы и
DNS-правила) между установками LxBox одним файлом, без полной резервной
копии. Меню ⋮ на табе Rules: «Export rules...» и «Import rules...».

## Параметры

| Шаг | Что выбирает пользователь |
|---|---|
| Export rules | галки по своим правилам (Select all / Deselect all); пресетов в списке нет |
| Include DNS | DNS-серверы и DNS-правила без пресетных ссылок; «Export (+N DNS)» или «Export without DNS» |
| Import rules | файл; список элементов с состоянием; «Import (N)» |

Файл `lxbox-rules-YYYYMMDD-HHMM.json` — конверт
`{app: "lxbox", kind: "rules", format: 2, created_at, source_app_version,
rules[], dns_servers[], dns_rules[]}`; элементы — записи хранения. Читается
и `format: 1` (форма хранения 2.23.2).

## Входы / Выходы

**Входы:** выбранные правила; файл обмена.
**Выходы:** файл в Загрузки или через «поделиться»; новые правила в списке;
новые DNS-серверы и правила; снекбары «Rules exported», «Imported N rules»,
«Imported N DNS entries», «Import failed: …».

## Правила и инварианты

- «Export rules...» доступен всегда; без своих правил экран подскажет, что
  можно выгрузить только DNS. Экспорт пишет правила как есть, вся санация —
  на импорте.
- Отказ на весь файл: не JSON, чужое приложение, пустой список, файл
  резервной копии (понятной ошибкой), `format` новее 2.
- Отказ по элементу (остальные живут): не объект или неизвестный вид —
  «Unsupported entry — skipped»; пресет — «Presets are not transferable —
  this app has its own»; правило с уже занятым видимым именем.
- Санация импортируемого правила: новый id; номер — в конец своей зоны
  1000–1100 (чужой номер не переносится); `.srs` приезжает выключенным до
  загрузки; висячая цель → `vpn-1` и правило выключено, с предупреждением;
  `direct-out`, `block`, `reject` и существующие Направления не лечатся;
  висячий DNS-сервер DNS-опции → опция выключена (Force IPv4 сохраняется);
  висячий сервер resolve → «auto».
- DNS-элементы: сервер с новым тегом импортируется; тег уже есть — «Already
  on this device», настройки не трогаются; шаблонный сервер, неизвестный
  этой версии, — «Not available in this app version»; пресетный — «Managed
  by presets automatically». DNS-правило-дубль — «Already on this device».
- Имя при вставке не меняется (суффиксов нет) — занятое имя отказывает.

## Границы

- Пресеты и их переменные не переносятся — у получателя свой шаблон.
- Направления не переносятся; цели, которых нет у получателя, лечатся.
- Полный перенос состояния — резервная копия,
  [017-BACKUP_AND_STORAGE](../../017-BACKUP_AND_STORAGE/FEATURE.ru.md).
- Сохранение файла и выбор файла зависят от возможностей ОС.
