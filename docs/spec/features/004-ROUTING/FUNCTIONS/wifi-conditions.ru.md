# Условия Wi-Fi

| Поле | Значение |
|------|----------|
| Фича | [004-ROUTING](../FEATURE.ru.md) |
| Обещания | P20 |
| Состояние | ✅ написана по коду, 2026-09-28 |

## Что делает

Делает правило условным по сети: оно действует, только когда телефон
подключён к одной из перечисленных сетей Wi-Fi (по имени SSID и, при
желании, по точке доступа BSSID). Например, «дома — напрямую, в остальных
сетях — через VPN».

## Параметры

| Поле | Формат | Ключ ядра |
|---|---|---|
| Сеть (чип) | SSID, необязательно BSSID `xx:xx:xx:xx:xx:xx` | `wifi_ssid`, `wifi_bssid` |

Способы добавить чип: **Add current** (текущая сеть), **Pick saved** (из
истории увиденных сетей), вручную. Доступно у inline- и `.srs`-правил.

## Входы / Выходы

**Входы:** текущая сеть от ОС; история сетей; ввод пользователя.
**Выходы:** у inline — в headless rule_set; у `.srs` — на уровне правила
маршрута. Проверку условия в работе делает ядро, спрашивая ОС о текущем
Wi-Fi.

## Правила и инварианты

- Нет чипов — условия нет, правило действует на любой сети («No Wi-Fi
  conditions — rule is active on every network»).
- Условие Wi-Fi складывается по И с остальным матчем правила.
- BSSID нормализуется к нижнему регистру; пустой BSSID допустим (матч только
  по имени). Повторы не пишутся.
- Несколько чипов с разными парами дают независимые списки SSID и BSSID —
  возможно перекрёстное совпадение (SSID одной пары + BSSID другой);
  осознанный риск, на практике BSSID уникален.
- Чтение текущей сети называет конкретную причину отказа: нет разрешения
  на устройства Wi-Fi рядом, нет точного местоположения, геолокация
  выключена, нет фонового местоположения; «Not connected to Wi-Fi», если
  сети нет. Совет «переключите Wi-Fi» не выдаётся там, где причина — в
  разрешениях.
- Без нужных разрешений ядро не видит имя сети — условие не совпадает.

## Границы

- Условий «мобильная сеть», «тип сети», «нет сети» нет — только Wi-Fi.
- Чтение SSID/BSSID зависит от возможностей ОС и выданных разрешений
  (местоположение, в т.ч. фоновое и точное; устройства рядом на новых ОС).
- Диагностика разрешений в журнале — [013-DIAGNOSTICS](../../013-DIAGNOSTICS/FEATURE.ru.md).
