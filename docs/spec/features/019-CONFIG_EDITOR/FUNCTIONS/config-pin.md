# Закрепление конфига

| Поле | Значение |
|------|----------|
| Фича | [019-CONFIG_EDITOR](../FEATURE.md) |
| Обещания | P6, P7 |
| Состояние | ✅ написана по коду, 2026-09-28 |

## Что делает

Даёт проверить конфиг, который приложение собрать не умеет (экспериментальная
возможность ядра, своя схема DNS): записать его целиком через Debug API или
редактор и закрепить, чтобы действия в интерфейсе его не перетирали. Снял
закрепление — следующее действие снова собирает конфиг из настроек.

## Параметры

| Ручка | Значения | Дефолт |
|-------|----------|--------|
| Lock config (debug) — переключатель в диагностике настроек | вкл/выкл; виден только при включённом Debug API | выкл |
| `PUT /settings/config_locked` | тело `{"locked": true\|false}` | — |
| `GET /state/config_locked` | ответ `{"locked": bool}` | — |
| `PUT /config` | тело — сырой JSON-объект конфига | — |

## Входы / Выходы

**Входы:** переключатель; запросы Debug API; любое действие интерфейса,
запускающее пересборку.

**Выходы:** сохранённый конфиг не меняется при пересборках; ответы Debug
API; снеки «Config locked. UI actions will not rebuild config.» /
«Config unlocked. Next UI action will rebuild from settings.».

## Правила и инварианты

- **`PUT /config` без закрепления — временно.** Ответ прямо говорит: любая
  пересборка сотрёт запись; чтобы удержать — закрепить.
- **`PUT /config` принимает только JSON-объект** в UTF-8; иначе 400.
  Комментарии JSON5 здесь недопустимы (в отличие от редактора).
- **При закреплении** пересборка от интерфейса тихо пропускается (в журнале —
  запись о пропуске из-за закрепления), ложный лист
  фатальной ошибки сборки прошлой генерации не показывается;
  `POST /action/rebuild-config` и то же действие автоматизации отвечают
  409 с подсказкой, как снять закрепление.
- **Снятие** само ничего не пересобирает — пересоберёт следующее действие.
- **Нет сироты.** Переключатель скрыт при выключенном Debug API; выключение
  Debug API в настройках снимает закрепление.
- Закрепление хранится среди настроек приложения и, как они, принадлежит
  текущему набору ([018-WORKSPACES](../../018-WORKSPACES/FEATURE.md)).

## Границы

- Защиты от невалидного для ядра конфига нет: принятый JSON-объект уходит в
  ядро как есть; ошибку покажет старт/перезапуск.
- Транспорт, токен и порт Debug API — [013-DIAGNOSTICS](../../013-DIAGNOSTICS/FEATURE.md).
- Правка из редактора при закреплении держится так же, как `PUT /config`.
