# Редактор итогового конфига

| Поле | Значение |
|------|----------|
| Фича | [019-CONFIG_EDITOR](../FEATURE.ru.md) |
| Обещания | P1–P5, P8, P9 |
| Состояние | ✅ написана по коду, 2026-09-28 |

## Что делает

Экран «Config Editor» (боковое меню: «View, edit, import JSON») показывает
сохранённый конфиг ядра отформатированным JSON с нумерацией строк и
подсветкой синтаксиса, даёт его поправить, подставить текст из буфера или
файла, скопировать, поделиться и сохранить в ядро.

## Параметры

| Действие | Где | Поведение |
|----------|-----|-----------|
| Save | AppBar | разбор JSON5 → канонический JSON → сохранение; снек «Config saved» |
| Paste from clipboard | меню ⋮ | текст буфера, отформатированный, в редактор; пустой буфер — «Clipboard is empty» |
| Load from file | меню ⋮ | текст файла (UTF-8), отформатированный, в редактор |
| Copy to clipboard / иконка Copy | меню ⋮ / угол редактора | весь текст редактора в буфер |
| Share | меню ⋮ | файл `lxbox_config.json` с текстом редактора |
| Порог только-чтения | — | свыше 1 048 576 символов |

## Входы / Выходы

**Входы:** сохранённый конфиг на момент открытия; буфер обмена; выбранный
файл; жесты выделения.

**Выходы:** сохранённый в ядро конфиг; буфер обмена; файл для Share;
снеки и ошибки на экране.

## Правила и инварианты

- **Форматирование в фоне.** Открытие и подстановка текста форматируют JSON5
  с отступом 2 пробела вне главного потока; пока идёт — полоса прогресса.
  Неразбираемый текст — как есть.
- **Сохранение строгое по смыслу, мягкое по синтаксису.** Комментарии и
  хвостовые запятые допустимы; в ядро уходит компактный канонический JSON.
  Пусто — «Config is empty»; синтаксис — «Failed to parse config: …» с
  позицией; конфиг ядра не меняется.
- **Подстановка ≠ сохранение.** Paste и Load from file меняют только текст
  редактора.
- **Только чтение** для слишком большого конфига: плашка «File is too large
  to edit on device. Share it, edit externally, then load it back.», Save
  недоступен.
- **Одностороннесть.** Сохранённая правка работает, пока любое действие в
  интерфейсе не пересоберёт конфиг из настроек; экраны меню её не видят.
  Удержать правку — закрепление ([config-pin.md](config-pin.ru.md)).
- **Поднятый туннель.** Сохранение не перезапускает ядро; если конфиг
  отличается от работающего — признак «config changed».
- **Меню выделения** (общее для всех JSON-полей приложения): долгий тап —
  Cut / Copy / Paste / Select all над живым выделением; действие, затем
  меню снимается. Меню одно; снимается тапом по пустому месту (выделение
  схлопывается), скроллом, уходом с экрана; перерисовка экрана копий не
  плодит.
- Ошибка выбора файла или отсутствие файлового менеджера — понятный текст,
  не техническое исключение.

## Границы

- Показывает сохранённый файл, не срез работающего ядра.
- Сравнение с работающим конфигом и перезапуск — [003-CONFIG_BUILD](../../003-CONFIG_BUILD/FEATURE.ru.md),
  [010-VPN_SERVICE](../../010-VPN_SERVICE/FEATURE.ru.md).
- Обратного разбора в настройки нет (issue #3).
