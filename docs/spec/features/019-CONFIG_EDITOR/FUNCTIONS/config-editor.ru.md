# Редактор итогового конфига — конфиг ядра как редактируемый JSON с подсветкой

Экран Config Editor показывает сохранённый конфиг sing-box с нумерацией строк и
подсветкой синтаксиса и сохраняет в ядро исправленный, вставленный или
загруженный конфиг.

| Поле | Значение |
|------|----------|
| Фича | [019-CONFIG_EDITOR](../FEATURE.ru.md) |
| Обещания | P1–P5, P8, P9 |
| Состояние | ✅ написана по коду, 2026-09-28 |

## Что делает

Экран «Config Editor» (боковое меню: «View, edit, import JSON») показывает
сохранённый конфиг ядра отформатированным JSON с нумерацией строк и
подсветкой синтаксиса, даёт его поправить, подставить текст из буфера или
файла, скопировать, поделиться и сохранить в ядро.

## Параметры

| Действие | Где | Поведение |
|----------|-----|-----------|
| Save | AppBar | разбор JSON5 → канонический JSON → сохранение; снек «Config saved» |
| Paste from clipboard | меню ⋮ | текст буфера, отформатированный, в редактор; пустой буфер — «Clipboard is empty» |
| Load from file | меню ⋮ | текст файла (UTF-8), отформатированный, в редактор |
| Copy to clipboard / иконка Copy | меню ⋮ / строка кнопок над полем | весь текст редактора в буфер |
| Share | меню ⋮ | файл `lxbox_config.json` с текстом редактора |
| Порог только-чтения | — | свыше 1 048 576 символов |

## Входы / Выходы

**Входы:** сохранённый конфиг на момент открытия; буфер обмена; выбранный
файл; жесты выделения.

**Выходы:** сохранённый в ядро конфиг; буфер обмена; файл для Share;
снеки и ошибки на экране.

## Правила и инварианты

- **Форматирование в фоне.** Открытие и подстановка текста форматируют JSON5
  с отступом 2 пробела вне главного потока; пока идёт — полоса прогресса.
  Неразбираемый текст — как есть.
- **Сохранение строгое по смыслу, мягкое по синтаксису.** Комментарии и
  хвостовые запятые допустимы; в ядро уходит компактный канонический JSON.
  Пусто — «Config is empty»; синтаксис — «Failed to parse config: …» с
  позицией; конфиг ядра не меняется.
- **Подстановка ≠ сохранение.** Paste и Load from file меняют только текст
  редактора.
- **Выход с несохранёнными правками** — как на соседних экранах правки.
  Правка = текст редактора отличается от того, с которым экран открылся или
  который сохранил последний Save; Paste и Load from file тоже правка. Back
  (системный, жест, стрелка AppBar) при правке показывает общий диалог
  «Unsaved changes»: Save — то же, что кнопка Save (при ошибке разбора экран
  остаётся открытым с ошибкой); Discard — выйти без сохранения; Keep или
  закрытие диалога — остаться. Нет правок, только чтение, идёт загрузка —
  выход без диалога.
- **Только чтение** для слишком большого конфига: плашка «File is too large
  to edit on device. Share it, edit externally, then load it back.», Save
  недоступен.
- **Одностороннесть.** Сохранённая правка работает, пока любое действие в
  интерфейсе не пересоберёт конфиг из настроек; экраны меню её не видят.
  Удержать правку — закрепление ([config-pin.md](config-pin.ru.md)).
- **Поднятый туннель.** Сохранение не перезапускает ядро; если конфиг
  отличается от работающего — признак «config changed».
- **Ввод — как в обычном текстовом поле системы** (общее для всех
  JSON-полей приложения): клавиатура видит весь текст, её стрелки двигают
  курсор, её Copy копирует всё выделение; строка с курсором держится над
  клавиатурой.
- **Меню выделения** — системное меню редактора на языке приложения:
  Cut / Copy / Paste / Select all над живым выделением (в поле только для
  чтения — только Copy / Select all, §607).
- **Кнопки поля — над рамкой, справа** (поиск, Copy, Format), внутри рамки
  их нет: текст начинается с обычного отступа. Подпись поля (пояснение к
  Source узла, к JSON DNS-сервера) стоит слева в той же строке и переносится
  в ширине, оставшейся от кнопок.
- **Поиск** — кнопка открывает панель на месте строки кнопок: запрос, счёт
  совпадений, предыдущее / следующее; пустой запрос снимает подсветку
  совпадений.
- **Format** (редактируемые JSON-поля, кроме этого экрана: Source узла, Edit
  server в папке, JSON DNS-сервера, JSON правила маршрута, шторка
  DNS-правила, поле JSON мастера) — видна, когда текст похож на JSON. Текст
  разбирается как JSON5, тем же разбором, что у Save, и заменяется JSON с
  отступом в два пробела. Это обычная правка: отменяется undo, экран считает
  её несохранённой. Ошибка разбора — снек «Failed to parse JSON: …» с
  позицией, текст не меняется. Комментарии JSON5 не сохраняются: если в
  тексте есть `//` или `/*` вне строк, сначала диалог «Comments will be
  removed» (Format / Cancel). На этом экране Format нет: конфиг
  форматируется при открытии.
- **Растущие поля** (Source узла, JSON правила, Edit server) растут по
  экранным строкам с учётом переноса до своего предела, дальше текст
  прокручивается внутри. В полях с переносом строк текущая строка не
  подсвечивается (одна строка компактного JSON залила бы всё поле).
- **Липкие заголовки.** При прокрутке сверху закреплены до трёх строк
  объемлющих блоков (`"outbounds": [` → `{` → …). Редактор рисует их только
  без переноса строк, поэтому на этом экране перенос по умолчанию выключен:
  длинные строки прокручиваются вбок. Кнопка переноса над полем включает
  перенос (липкие заголовки на это время пропадают); выбор не сохраняется,
  экран открывается снова без переноса. Включённая кнопка — на тональной подложке. Есть также в JSON узла и в
  JSON-Source подписки.
  Свёртки блоков нет.
- **Жесты на поле** (все JSON-поля). Есть выделение — касание целиком у
  редактора: ручки тянутся в любую сторону, вкладки и страница стоят. Без
  выделения решает направление, когда палец сдвинулся на порог перетаскивания:

  | Движение | Кому |
  |---|---|
  | вбок, текст выходит за поле по ширине | редактору |
  | вбок, по ширине всё видно | вкладкам / странице |
  | вертикально, в эту сторону есть куда прокрутить | редактору |
  | вертикально, текст у края или помещается по высоте | странице |

  Решение — на весь жест: довёл текст до края, отпустил — следующий свайп в
  ту же сторону листает страницу. Долгий тап — выделение. Экран Config (поле
  во всю высоту) забирает касание целиком.
- **Лупа выделения** рисуется из самого редактора и показывает текст под
  пальцем при любой прокрутке поля и страницы.
- **Индикатор раскладки.** Пока редактор пересчитывает разбиение на строки
  дольше 300 мс (перенос большого тела), у верхнего края рамки идёт тонкая
  полоса прогресса; быстрые пересчёты её не показывают.
- **Подсветка** JSON; в полях, куда вставляют что угодно, — по виду текста:
  JSON, WireGuard INI, ссылки (`схема://…`) или без подсветки.
- Ошибка выбора файла или отсутствие файлового менеджера — понятный текст,
  не техническое исключение.

## Границы

- Показывает сохранённый файл, не срез работающего ядра.
- Сравнение с работающим конфигом и перезапуск — [003-CONFIG_BUILD](../../003-CONFIG_BUILD/FEATURE.ru.md),
  [010-VPN_SERVICE](../../010-VPN_SERVICE/FEATURE.ru.md).
- Обратного разбора в настройки нет (issue #3).
