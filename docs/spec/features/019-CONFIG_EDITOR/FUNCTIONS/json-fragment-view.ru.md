# Просмотр JSON-фрагментов конфига

| Поле | Значение |
|------|----------|
| Фича | [019-CONFIG_EDITOR](../FEATURE.ru.md) |
| Обещания | P10, P11 |
| Состояние | ✅ написана по коду, 2026-09-28 |

## Что делает

Показывает кусок итогового конфига там, где он нужен: вкладка JSON на экране
деталей узла (с копированием узла и его detour-цепочки) и вкладка View
редактора пользовательского правила (как правило ляжет в конфиг). Просмотр
только для чтения, с подсветкой и тем же меню выделения, что у редактора.

## Параметры

| Место | Действие | Что копируется |
|-------|----------|----------------|
| Узел без detour | иконка «Copy JSON» | outbound узла без поля `detour` |
| Узел с detour | «Copy server JSON» | outbound узла без `detour` |
| — | «Copy detour» | первый detour-хоп без `detour`; нет хопа — «No detour for this node» |
| — | «Copy server + detour» / «+ detours(N)» | массив: узел и вся цепочка хопов, каждый без `detour` |
| Правило | кнопка копирования у каждого блока | запись правила в хранении; превью для ядра |

## Входы / Выходы

**Входы:** тег узла из списка; модель конфига; редактируемое правило.

**Выходы:** JSON на экране; буфер обмена; снек о копировании или «данных по
тегу нет».

## Правила и инварианты

- **Узел — из того, что крутит ядро.** При поднятом туннеле JSON и копии
  берутся из среза работающего конфига, иначе из сохранённого; тега нет —
  сообщение, а не молчание.
- **Вкладка JSON узла** показывает сам outbound, а при detour — массив
  «узел + хопы».
- **Копии самодостаточны:** поле `detour` снимается у каждого элемента,
  чтобы вставка не ссылалась на отсутствующий тег.
- **Превью правила не фильтрует по `enabled`:** выключенное правило
  показывает, что оно родит при включении; сборка конфига выключенные
  по-прежнему пропускает. Пресет показывает только непустые секции
  (`dns_options`, `route`); не скачанный rule-set — плейсхолдер пути.
  Сломанный пресет или ошибка — комментарий в тексте, не падение.

## Границы

- Правки здесь нет — узел правится в [008-NODE_EDITOR](../../008-NODE_EDITOR/FEATURE.ru.md),
  правило — в [004-ROUTING](../../004-ROUTING/FEATURE.ru.md).
- Ссылка узла (`Copy URI`) — не JSON, живёт в меню узла ([002-NODE_IMPORT](../../002-NODE_IMPORT/FEATURE.ru.md)).
