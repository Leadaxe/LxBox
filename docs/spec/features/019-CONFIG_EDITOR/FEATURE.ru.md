# Редактор конфига — просмотр, правка и закрепление итогового конфига sing-box

LxBox показывает итоговый конфиг sing-box, с которым работает ядро,
отформатированным JSON и даёт опытному пользователю править, импортировать,
экспортировать или закрепить его. Config Editor принимает JSON5, проверяет текст
перед сохранением и держит очень большие конфиги только для чтения. Тот же
просмотр JSON есть у узла, с копированием его detour-цепочки, и в превью правила
маршрутизации; через Debug API собственный конфиг можно закрепить, чтобы
пересборки его не перетирали.

| Поле | Значение |
|------|----------|
| Фича | 019-CONFIG_EDITOR |
| Тип | Продуктовая фича |
| Поглотила | `§007F` |
| Состояние | ✅ написана по коду, 2026-09-28 |

## Назначение

Опытному пользователю нужно видеть, что именно получит ядро, и иногда
подправить это руками или подсунуть свой конфиг. Фича даёт экран «Config
Editor» (боковое меню) — сохранённый конфиг ядра в отформатированном JSON с
подсветкой, правкой, импортом и экспортом; просмотр JSON-фрагментов конфига
в других местах (узел, превью правила); и закрепление конфига для экспериментов
через Debug API.

Фича защищает три принципа:

- **Источник истины — настройки, а не текст.** Конвейер односторонний:
  настройки → сборка → конфиг. Ручная правка живёт до следующей пересборки
  (issue #3, `docs/ARCHITECTURE.md` «Known limitations»).
- **Правка не ломает ядро.** В ядро уходит только разобранный и
  канонизированный JSON; синтаксическая ошибка — сообщение, а не запись.
- **Выделил — то и скопировал.** Контекстное меню действует на настоящее
  выделение и не множится.

## Обещания

- **P1. Конфиг открывается отформатированным.** Отступ 2 пробела;
  неразбираемый текст показывается как есть, без падения. Свидетель: юнит
  «форматирование в фоне совпадает с синхронным»; невалидный — ручная проверка
  (Paste from clipboard мусора). Мутация: падение на невалидном тексте.
- **P2. Принимается JSON5, в ядро уходит канонический JSON.** Комментарии
  `//` `/* */` и хвостовые запятые допустимы; сохраняется компактный JSON.
  Свидетель: юниты «канонизация принимает комментарии JSON5»,
  «канонизация в фоне совпадает с синхронной». Мутация: в ядро
  уходит текст с комментариями.
- **P3. Ошибка синтаксиса — сообщение с позицией, конфиг не меняется.**
  Пустой текст — «Config is empty». Свидетель: юниты «синтакс-ошибка JSON5
  приводится к ошибке формата», «фоновая канонизация отдаёт ошибку с
  текстом»; пустой — ручная проверка. Мутация: необработанное исключение.
- **P4. Большой конфиг — только чтение.** Свыше 1 048 576 символов редактор
  не даёт править и предлагает Share → внешний редактор → Load from file.
  Свидетель: юнит «граница порога только-чтения». Мутация: правка
  многомегабайтного текста на устройстве.
- **P5. Ручная правка не переживает пересборку.** Свидетель: ручная проверка —
  правка в редакторе, Save, переключить любую настройку маршрутизации,
  вернуться: в редакторе собранный конфиг (автотеста нет). Мутация: правка
  «приклеивается» без закрепления.
- **P6. Закреплённый конфиг не перетирается.** При закреплении пересборки от
  действий в интерфейсе тихо пропускаются; явная пересборка через Debug API
  отвечает 409. Свидетель: ручная проверка через Debug API (`PUT
  /settings/config_locked {"locked":true}`, `POST /action/rebuild-config` →
  409; автотеста нет). Мутация: пересборка при закреплении.
- **P7. Закрепление не остаётся сиротой.** Переключатель виден только при
  включённом Debug API; выключение Debug API в настройках снимает
  закрепление. Свидетель: ручная проверка (автотеста нет). Мутация: лок
  остаётся при выключенном API.
- **P8. Меню выделения работает с выделенным.** Долгий тап — меню Cut / Copy
  / Paste / Select all, выделение не схлопывается. Свидетель: юниты «долгий
  тап: меню показано, выделение не схлопнуто», «тап Copy кладёт в буфер
  выделенный фрагмент», «тап Cut…», «тап Paste…», «тап Select all…».
  Мутация: меню модальным окном (выделение слетает до действия).
- **P9. Меню одно и снимается.** Тап по пустому месту, скролл, уход с экрана
  убирают меню; повторные долгие тапы и перерисовка не плодят копий.
  Свидетель: юниты «§521 …» (восемь сценариев). Мутация: новый экземпляр
  меню на каждой перерисовке.
- **P10. JSON узла копируется в нужной форме.** Без detour — «Copy JSON»; с
  detour — «Copy server JSON» / «Copy detour» / «Copy server + detour(s)»;
  копии без поля `detour`, цепочка — целиком. Свидетель: ручная проверка
  (автотеста нет). Мутация: копия с висячим `detour`.
- **P11. Превью правила не зависит от его включённости.** Свидетель: ручная
  проверка (выключенное правило → вкладка View непуста); сборка выключенное
  пропускает — юнит «disabled json-правило пропускается (skipDisabled)».
  Мутация: пустое превью у выключенного правила.

## Контролируемые параметры

| Ручка | Где | Значения | Дефолт |
|-------|-----|----------|--------|
| Lock config (debug) | Настройки → Диагностика, при включённом Debug API | вкл/выкл | выкл |
| Порог только-чтения | — | 1 048 576 символов | фиксирован |

Debug API (контракт — [013-DIAGNOSTICS](../013-DIAGNOSTICS/FEATURE.ru.md)):
`GET /config` (`?pretty`), `PUT /config` (сырой JSON-объект),
`GET /state/config_locked`, `PUT /settings/config_locked {"locked": bool}`,
`POST /action/rebuild-config` (409 при закреплении). Ключей конфига ядра
фича не порождает — показывает и пишет конфиг целиком.

## Входы / Выходы

**Входы:** сохранённый конфиг; текст из редактора, буфера обмена или файла;
запросы Debug API; жесты выделения.

**Выходы:** конфиг, сохранённый в ядро (и признак «config changed» при
поднятом туннеле); буфер обмена; файл `lxbox_config.json` для Share;
снеки «Config saved», «Pasted from clipboard», «Loaded from file», ошибки.

## Data flow

```
сохранённый конфиг → форматирование (в фоне) → редактор
редактор / буфер / файл → разбор JSON5 → канонический JSON → сохранение в ядро
                                   └─ ошибка → сообщение, конфиг прежний
любое действие в UI → [закреплено?] ─ нет → пересборка из настроек (правка стёрта)
                                   └─ да  → пропуск, конфиг прежний
```

## Правила и гарантии

- Редактор показывает сохранённый файл, а не срез работающего ядра;
  просмотр JSON узла при поднятом туннеле — срез ядра.
- «Paste from clipboard» и «Load from file» только подставляют текст в
  редактор; в ядро он уходит по Save.
- Save доступен, пока нет занятости и конфиг не только-для-чтения.
- Закрепление хранится в настройках; снятие само пересборку не запускает —
  её сделает следующее действие.

## Границы

- Обратного разбора конфига в настройки нет: правка невидима экранам меню.
- Сборка, её гейты и признак «config changed» — [003-CONFIG_BUILD](../003-CONFIG_BUILD/FEATURE.ru.md);
  хранение и бэкап настроек — [017-BACKUP_AND_STORAGE](../017-BACKUP_AND_STORAGE/FEATURE.ru.md).
- Правка отдельного узла и его формы — [008-NODE_EDITOR](../008-NODE_EDITOR/FEATURE.ru.md).
- Выбор файла зависит от возможностей ОС (на ТВ без файлового менеджера —
  подсказка про буфер).

## Связанные фичи

- [003-CONFIG_BUILD](../003-CONFIG_BUILD/FEATURE.ru.md) — односторонний конвейер
  настройки → сборка → конфиг, результат которого показывает редактор; гейты
  сборки, сравнение с работающим конфигом и признак «config changed».
- [013-DIAGNOSTICS](../013-DIAGNOSTICS/FEATURE.ru.md) — транспорт, токен и порт
  Debug API, через который конфиг пишется и закрепляется.
- [017-BACKUP_AND_STORAGE](../017-BACKUP_AND_STORAGE/FEATURE.ru.md) — хранение и
  бэкап настроек, из которых собирается конфиг.
- [008-NODE_EDITOR](../008-NODE_EDITOR/FEATURE.ru.md) — правка отдельного узла;
  здесь JSON узла только просматривается и копируется.
- [004-ROUTING](../004-ROUTING/FEATURE.ru.md) — правила правятся там; вкладка
  View правила — превью из этой фичи.
- [002-NODE_IMPORT](../002-NODE_IMPORT/FEATURE.ru.md) — ссылка узла (`Copy URI`)
  не JSON и живёт в меню узла.
- [010-VPN_SERVICE](../010-VPN_SERVICE/FEATURE.ru.md) — перезапуск работающего
  ядра; сохранение из редактора его не перезапускает.
- [018-WORKSPACES](../018-WORKSPACES/FEATURE.ru.md) — закрепление хранится среди
  настроек приложения и принадлежит текущему набору.

## Особенности сопровождения

- **Большой текст — только построчный редактор.** Однопараграфное поле на
  конфиге в сотни КБ давало 100 % CPU и смерть процесса (333).
- **Контекстное меню — не модальное окно.** Модальное забирает фокус, и
  выделение схлопывается до действия (517); экземпляр меню обязан жить
  столько же, сколько редактор (521).
- **`PUT /config` строже редактора:** принимает только чистый JSON-объект.
