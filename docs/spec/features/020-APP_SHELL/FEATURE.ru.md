# Оболочка приложения — тема, язык, навигация, первый запуск, проверка обновлений и лента поддержки

Оболочка LxBox — всё, что вокруг VPN-туннеля: тема, язык интерфейса, навигация,
вопросы первого запуска, вибрация и сообщения о новых версиях. Строка Language
живёт здесь; сам механизм локализации — отдельная фича (029). Ни проверка
обновлений, ни лента поддержки автора не обращаются к GitHub, пока пользователь
не согласится при первом запуске.

| Поле | Значение |
|------|----------|
| Фича | 020-APP_SHELL |
| Тип | Продуктовая фича |
| Поглотила | `§009F` `§022F` `§029F` `§034F` `§036F` `§105F` `§126F` |
| Состояние | ✅ написана по коду, 2026-09-28 |

## Назначение

Всё, что окружает VPN, но не сам VPN: как приложение выглядит, на каком
языке говорит, как по нему ходить, что оно спрашивает при первом запуске, как
сообщает о новой версии и как просит поддержать автора. Предметные настройки
(туннель, подписки, диагностика, автоматизация) здесь не описываются — фича
даёт им дом (экран App Settings, боковое меню) и общие соглашения.

Фича защищает три принципа:

- **Без согласия — ни одного запроса «домой».** Проверка обновлений и лента
  сообщений ходят в сеть только после явного «да» на первом запуске или
  включения переключателя; до этого приложение живёт на встроенных данных.
- **Оболочка не мешает работе.** Сообщение о новой версии появляется только
  при запуске, просьба о поддержке — не чаще раза за запуск и только тому,
  кто давно пользуется VPN; вибрация — только на значимых событиях;
  случайное «назад» не выбрасывает из приложения.
- **Настройка применяется сразу.** Переключатели оболочки сохраняются в момент
  изменения и действуют без перезапуска; кнопки «Сохранить» нет.

## Обещания

- **P1. Тема следует выбору и применяется сразу.** System / Light / Dark, по
  умолчанию System (следует теме устройства); смена перекрашивает всё
  приложение без перезапуска и переживает перезапуск. Свидетель: ручная
  проверка — App Settings → Appearance → Dark, закрыть и открыть приложение.
  Мутация: тема читается только при старте.
- **P2. Портрет по умолчанию, поворот — по согласию.** Без «Allow rotation»
  интерфейс зафиксирован в портрете; включение сразу отдаёт ориентацию
  системному автоповороту (и его блокировке). Свидетель: ручная проверка на
  планшете. Мутация: поворот разрешён по умолчанию.
- **P3. Две колонки списка узлов — от 600 dp и только при включённом
  переключателе.** Ручная сортировка всегда одноколоночная. Свидетель: юниты
  «599 dp — одна колонка», «600 dp — две колонки (порог нестрогий)», «§541
  тумблер выключен — одна колонка на любой ширине», «ручная сортировка
  остаётся одноколоночной». Мутация: строгий порог `> 600`.
- **P4. Вибрация — только на перечисленных событиях и не чаще раза в 100 мс.**
  Выключенный переключатель глушит все события сразу, без перезапуска.
  Свидетель: юниты «enabled=false → no platform calls», «throttle blocks rapid
  duplicate fires», «toggling enabled mid-flight applies immediately».
  Мутация: троттлинг убран.
- **P5.** перенесено в [029-LOCALIZATION · P1](../029-LOCALIZATION/FEATURE.ru.md#обещания).
- **P6.** перенесено в [029-LOCALIZATION · P2](../029-LOCALIZATION/FEATURE.ru.md#обещания).
- **P7.** перенесено в [029-LOCALIZATION · P7](../029-LOCALIZATION/FEATURE.ru.md#обещания).
- **P8.** перенесено в [029-LOCALIZATION · P11](../029-LOCALIZATION/FEATURE.ru.md#обещания).
- **P9.** перенесено в [029-LOCALIZATION · P3](../029-LOCALIZATION/FEATURE.ru.md#обещания).
- **P10.** перенесено в [029-LOCALIZATION · P4](../029-LOCALIZATION/FEATURE.ru.md#обещания).
- **P11. Первый запуск — вопросы по одному и по одному разу.** Разрешение на
  уведомления → фоновая работа → плитка быстрых настроек → проверка
  обновлений; следующий вопрос появляется после ответа на предыдущий; ответ
  запоминается, в том числе при полной замене настроек из копии. Свидетель:
  юнит «replaceRaw merge=false keeps startup prompt flags»; порядок — ручная
  проверка на чистой установке. Мутация: вопросы запускаются параллельно.
- **P12. До согласия приложение не спрашивает GitHub о релизах и ленте.**
  Проверка обновлений по умолчанию выключена; лента без согласия читается из
  кэша или встроенной копии. Свидетель: юниты «§422: без согласия на
  обновления — ни одного запроса, читаем кэш», «без согласия и без кэша —
  bundled-копия, сеть не трогается»; для проверки обновлений — `без
  свидетеля`. Мутация: дефолт проверки обновлений `true`.
- **P13. Автопроверка — не чаще раза в сутки, dev-сборки молчат, «Check now»
  работает всегда.** Свидетель: `без свидетеля`. Мутация: суточный порог
  считается от неудачной попытки.
- **P14. Сообщение о новой версии — только при запуске и только из
  сохранённого.** Результат сетевой проверки появляется на следующем запуске;
  поверх работающего приложения сообщение не всплывает. Свидетель: ручная
  проверка — «Check now» при доступной новой версии не поднимает всплывашку,
  перезапуск поднимает. Мутация: показ по приходу ответа сети.
- **P15. «Later» — до следующего запуска, «Ignore» — навсегда для этой версии,
  тап — в свой магазин без запоминания.** Следующая версия показывается снова.
  Свидетель: виджет-тесты ««Later» не персистит», ««Ignore» персистит тег»,
  «уже проигнорированную версию не показываем», «клик по телу: переход в стор,
  но БЕЗ персиста». Мутация: «Later» запоминает версию.
- **P16. Ссылка на обновление ведёт туда, откуда приложение поставлено.**
  GitHub — страница релиза, Google Play — карточка магазина, F-Droid —
  страница пакета. Свидетель: виджет-тесты «github-канал ведёт на страницу
  релиза», «f-droid ведёт на страницу пакета»; юниты канала установки
  («Obtainium ставит APK с GitHub → github»). Мутация: все каналы → GitHub.
- **P17. Сравнение версий строгое, мусор не будит.** Свидетель: юниты «equal
  returns false», «malformed input returns false (no false-positive notify)».
  Мутация: сравнение строк.
- **P18. Просьба о поддержке — только тому, кто пользуется VPN прямо сейчас и
  давно.** Показ при подключённом туннеле с сессией не короче порога и
  наработкой не меньше порога от последней точки отсчёта; очередь строгая.
  Свидетель: юниты «session-gate: VPN не активен / короткая сессия → null»,
  «baseline: порог считается от точки отсчёта», «очередь строгая». Мутация:
  порог наработки от нуля.
- **P19. После обновления приложения лента не вываливается разом.** Смена
  версии сдвигает точку отсчёта; само обновление прочитанное не
  распрочитывает. Свидетель: юниты «смена версии приложения сдвигает
  baseline», «обновление приложения САМО не распрочитывает». Мутация:
  отсчёт от первого запуска.
- **P20. «Later» глушит всю ленту на часы наработки, «Got it» не нажать
  вслепую.** Свидетель: юниты «snooze поднимает порог от текущего total»,
  виджет-тест «таймер: «Got it (N)» disabled → тикает → активна». Мутация:
  снуз в календарных часах.
- **P21. Кнопки сообщения не делают опасного сами.** Незнакомое действие
  скрывается; `add:` только заполняет поле ввода; `share:` не закрывает
  сообщение. Свидетель: юниты «route: неизвестный экран … → false», «share:
  непустой payload резолвится и НЕ уводит с экрана»; виджет-тест «кнопки:
  https видна; будущее действие скрыто». Мутация: `add:` сразу добавляет узел.
- **P22. Выход — двойным «назад».** На главном экране первое «назад» —
  подсказка, второе в течение 2 с — выход; открытое меню закрывается без
  подсказки. Свидетель: виджет-тесты «первое нажатие: сообщение, выхода нет»,
  «второе нажатие в пределах 2 секунд: выход», «второе после 2 секунд: снова
  сообщение», «открыто боковое меню». Мутация: окно без срока.
- **P23. Переключатели App Settings сохраняются сразу.** Свидетель: ручная
  проверка — переключить, убить процесс, открыть. Мутация: запись по кнопке.

## Контролируемые параметры

| Настройка | Где | Значения | Дефолт | Когда действует |
|-----------|-----|----------|--------|-----------------|
| Тема | App Settings → Appearance | System / Light / Dark | System | сразу |
| Allow rotation | там же, Layout | вкл/выкл | выкл (портрет) | сразу |
| Two columns on wide screens | там же, Layout | вкл/выкл | вкл | сразу |
| Language | там же | System default / English / Русский / 中文（简体） | System default | сразу; механизм — [029-LOCALIZATION](../029-LOCALIZATION/FEATURE.ru.md) |
| Haptic feedback | App Settings → General → Feedback | вкл/выкл | вкл | сразу |
| Check for updates on launch | App Settings → General → Updates | вкл/выкл | выкл до ответа на вопрос первого запуска | со следующего запуска |
| Check now | там же и About | кнопка | — | сразу |

Фиксированные значения: окно двойного «назад» — 2 с; порог двух колонок —
600 dp; троттлинг вибрации — 100 мс; интервал автопроверки — 24 ч, первая
попытка — через 5 с после открытия главного; таймаут запроса — 10 с;
всплывашка о версии — 6 с.

Ключей конфига ядра фича не отдаёт.

Форматы: манифест последней версии (`tag`, `name`, `html_url`,
`published_at`); лента сообщений (`snooze_active_hours`, `messages[]` с `id`,
`since_version`, `skip`, `min_active_hours`, `min_session_minutes`,
`read_delay_seconds`, `i18n.<язык>.{title, message, links[]}`); ссылки
`lxbox://route:<экран>[/<вкладка>]`, `lxbox://add:<ссылка>`,
`lxbox://share:<текст>`.

## Входы / Выходы

**Входы:** касания и «назад»; тема устройства; язык, выбранный в 029; канал
установки; ответы GitHub о последнем
релизе и лента сообщений; наработка туннеля и длительность текущей сессии;
события туннеля и обновления подписок (для вибрации).

**Выходы:** тема и раскладка интерфейса; вибрация; вопросы первого запуска;
всплывашка
о новой версии и блок в About; полноэкранное сообщение ленты; событие
автоматизации «доступна новая версия» (если включено в 014).

## Data flow

```
первый запуск: уведомления → фоновая работа → плитка → согласие на обновления
обновления: [согласие] 5 с после главного → API релизов ─ сбой → свой манифест
      → кэш версии → (следующий запуск) всплывашка Later / Ignore / тап → магазин канала
лента: [согласие] сеть → кэш → встроенная копия → очередь → гейты (сессия,
      наработка от точки отсчёта, снуз) → полноэкранное сообщение → Got it / Later / X
события туннеля и подписок → переключатель → троттлинг → вибрация
```

## Правила и гарантии

- Одно согласие на первом запуске управляет двумя сетевыми каналами:
  проверкой релизов и обновлением ленты сообщений.
- Закрытие вопроса о проверке обновлений системной «назад» — выбор по каналу
  установки: из магазина — выкл, иначе — вкл.
- Отклонённая версия не показывается ни при запуске, ни в кэше; About всё
  равно показывает известную новую версию.
- Лента в процессе загружается один раз и показывает не больше одного
  сообщения за запуск; «X» закрывает сообщение без пометок — оно придёт
  снова при следующем запуске.
- Тема — свойство устройства: не входит в резервную копию и в наборы
  настроек (018). Язык, вибрация, поворот, колонки и согласие на обновления —
  входят.

## Особенности сопровождения

- Каталоги F-Droid считают фоновый запрос к GitHub без согласия слежкой
  (anti-feature Tracking): любой новый сетевой канал оболочки обязан встать за
  то же согласие (§395, §422).
- Анонимный лимит API GitHub (60 запросов в час на адрес) исчерпывается общим
  выходным адресом VPN: без своего манифеста проверка молча не работала бы.
- Подписи вариантов темы, строки результата проверки обновлений в About и
  сообщения «Add tile» отрисованы не через локализатор и остаются английскими
  (аудит 588; механизм — 029).
