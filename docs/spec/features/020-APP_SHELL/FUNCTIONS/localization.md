## Что делает

Показывает приложение на языке пользователя: интерфейс, тексты шаблона
(названия пресетов, подсказки, описания правил), системное уведомление,
плитку и ярлыки. Язык меняется на лету, без перезапуска и без остановки
туннеля.

## Параметры

| Настройка | Где | Значения | Дефолт |
|-----------|-----|----------|--------|
| Language | App Settings → Appearance | System default · English · Русский · 中文（简体） | System default |

Названия языков — эндонимы: каждое на своём языке, при любом текущем.
Тот же выбор доступен в системных настройках языка приложения (Android 13+)
и через Debug API (`app_language`: `system` \| `en` \| `ru` \| `zh`).

## Входы / Выходы

**Входы:** выбор в приложении; язык устройства; язык приложения в системных
настройках; значение из резервной копии, набора настроек или Debug API.
**Выходы:** текст интерфейса и шаблона, формат дат, системные поверхности на
выбранном языке.

## Правила и инварианты

- System default — язык устройства, если он среди поддержанных, иначе
  английский. Смена языка устройства при System default подхватывается на лету.
- Неизвестное сохранённое значение читается как System default.
- Первый кадр после запуска уже на сохранённом языке.
- Английский — базовый: исходный текст и есть ключ перевода; отдельного
  английского словаря нет.
- Нет перевода строки — английский текст; нет формы множественного числа —
  английская строка с числом; пропущенное значение — пустое место, не код
  формата. Сбой загрузки словаря — всё по-английски, язык всё равно
  переключается.
- Множественное число — по правилам языка: русский one/few/many, китайский —
  одна форма.
- Системные поверхности (уведомление, плитка, ярлыки, окна автоматизации)
  переводятся и при неработающем интерфейсе, и переименовываются сразу при
  смене языка.
- Сверка с системным выбором (Android 13+) при старте: система изменилась с
  нашего последнего выбора — побеждает система; изменилось только
  хранилище — выбор хранилища отправляется в систему; System default очищает
  системный выбор.
- Язык входит в резервную копию и наборы настроек; загрузка набора сразу
  применяет его язык.
- Английскими остаются всегда: журналы, ответы Debug API, события
  автоматизации, предупреждения о конфиге в машинном виде, значения и теги
  конфига, имена файлов, данные пользователя (имена подписок, узлов,
  правил), сообщения ОС, библиотек и ядра, название «L×Box», названия сетей
  в списке пожертвований.
- Сохранённые ранее снимки текста (подписи каналов, запасные имена правил из
  пресетов) задним числом не переводятся.
- CI не пропускает строку интерфейса мимо переводчика, непереведённый или
  осиротевший ключ и несовпадение подстановок в переводе.

## Границы

- RTL-языки не поддерживаются.
- Подписи вариантов темы и строки состояния проверки обновлений в About —
  не переводятся (см. отчёт о расхождениях).
- Тексты ленты поддержки переводит её автор внутри самой ленты
  ([support-feed](support-feed.md)).
- Зависит от возможностей ОС: язык приложения в системных настройках
  (Android 13+).
