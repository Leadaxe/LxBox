# Внешний вид

| Поле | Значение |
|------|----------|
| Фича | [020-APP_SHELL](../FEATURE.ru.md) |
| Обещания | P1, P2, P3 |
| Состояние | ✅ написана по коду, 2026-09-28 |

## Что делает

Определяет, как приложение выглядит и ведёт себя под пальцами: светлая или
тёмная тема, фиксация ориентации, раскладка списка узлов на широком экране,
жест «потянуть, чтобы обновить» и иконка приложения.

## Параметры

| Настройка | Значения | Дефолт | Когда действует |
|-----------|----------|--------|-----------------|
| Тема | System / Light / Dark | System | сразу |
| Allow rotation | вкл/выкл | выкл | сразу |
| Two columns on wide screens | вкл/выкл | вкл | сразу |

Порог двух колонок — ширина окна от 600 dp включительно.

## Входы / Выходы

**Входы:** выбор в App Settings → Appearance; тема устройства (для System);
ширина окна; положение устройства и системный автоповорот; жест вниз по
списку.
**Выходы:** палитра приложения; ориентация; число колонок списка узлов;
обновлённые данные списка.

## Правила и инварианты

- Одна палитра на обе темы, от одного базового цвета (индиго), Material 3.
- System следует теме устройства и меняется вместе с ней на лету.
- Выбор темы переживает перезапуск; в резервную копию и наборы настроек не
  входит — это свойство устройства.
- Allow rotation выкл — только портрет; вкл — ориентацию решает система,
  включая её блокировку поворота.
- Две колонки: построчный порядок (1-2 / 3-4); при ручной сортировке список
  всегда в одну колонку; переключение без мигания раскладки на старте.
- Pull-to-refresh:

  | Где | Что делает |
  |-----|-----------|
  | Главный, список узлов | перечитывает группы у работающего ядра; без туннеля — перерисовывает из последних известных |
  | Servers | обновляет все подписки, как кнопка обновления; при идущем обновлении — ничего |

- Иконка: оранжевый градиент, светлая рамка-«L» и крест из двух стрелок с
  тремя узлами («routing cross»); на Android 8+ — адаптивная (форму задаёт
  лаунчер). Название под иконкой — «L×Box» на всех языках. У плитки быстрых
  настроек — своя одноцветная иконка.

## Границы

- Подписи вариантов темы (System / Light / Dark) не переводятся.
- Тематической (одноцветной) иконки Android 13+ нет — иконка всегда цветная.
- Выбора акцентного цвета и динамических цветов обоев нет.
- Ярлыки Connect / Disconnect и их иконки — 014.
- Зависит от возможностей ОС: системная тема, автоповорот, формы иконок
  лаунчера.
