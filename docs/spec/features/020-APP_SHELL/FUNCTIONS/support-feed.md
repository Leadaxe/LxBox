# Лента поддержки

| Поле | Значение |
|------|----------|
| Фича | [020-APP_SHELL](../FEATURE.md) |
| Обещания | P12, P18, P19, P20, P21 |
| Состояние | ✅ написана по коду, 2026-09-28 |

## Что делает

Показывает сообщения автора («поддержи проект», новости, подсказки) тем, кто
действительно пользуется VPN: полноэкранно, не чаще, чем задано, по очереди.
Тексты, ссылки, пороги и очередь автор меняет без релиза приложения.

## Параметры

Настроек у пользователя нет. Параметры задаёт лента:

| Поле | Смысл | По умолчанию |
|------|-------|--------------|
| `snooze_active_hours` | на сколько часов наработки «Later» глушит всю ленту | 10 |
| `messages[].id` | постоянный ключ «прочитано» | — (без него сообщение отбрасывается) |
| `since_version` | с какой версии приложения видно; подъём выше прочитанной — повторный показ | `0.0.0` |
| `skip` | вывести из ротации | false |
| `min_active_hours` | наработка туннеля от точки отсчёта | 3 |
| `min_session_minutes` | длительность текущей сессии туннеля | 5 |
| `read_delay_seconds` | сколько секунд «Got it» неактивна | 10 |
| `i18n.<язык>` | `title`, `message`, `links[]` (`label`, `url`, `mark_read`) | английский блок обязателен |

## Входы / Выходы

**Входы:** лента из репозитория проекта (только при согласии на проверку
обновлений), её последний удачный снимок, встроенная в приложение копия;
наработка туннеля; длительность текущей сессии; язык интерфейса; версия
приложения.
**Выходы:** полноэкранное сообщение; переход на экран приложения; поле
ввода Servers с подставленной ссылкой; системное «Поделиться»; внешний
браузер.

## Правила и инварианты

- Источник: сеть (если есть согласие) → последний удачный снимок →
  встроенная копия. Лента читается один раз за процесс.
- Момент показа — пока приложение на экране, открыт главный и туннель
  подключён: при открытии, возврате или в тот момент работы, когда сессия и
  наработка дорастут до порогов. Без туннеля и в фоне — нет. Не больше
  одного сообщения за запуск приложения.
- Наработка — время работы туннеля, в том числе при закрытом интерфейсе;
  перезапуск туннеля начинает новую сессию, двойного счёта нет.
- Очередь строгая: берётся первое видимое непрочитанное; не прошло своих
  порогов — лента молчит, следующее не перескакивает вперёд.
- Точка отсчёта наработки сдвигается при «Got it» и при смене версии
  приложения; «Later» её не трогает, а поднимает общий порог тишины.
- Язык сообщения — язык интерфейса в момент показа, иначе английский.
  Плейсхолдеры (`@guideLink`, `@appVersion` и др.) подставляются при показе.
- Кнопки:

  | Кнопка | Что делает | Закрывает сообщение | Помечает прочитанным |
  |--------|-----------|---------------------|----------------------|
  | https-ссылка | открывает браузер | нет | нет |
  | `lxbox://route:<экран>[/<вкладка>]` | открывает экран приложения | да (заменяется экраном) | да, если не `"mark_read": false` |
  | `lxbox://add:<ссылка>` | открывает Servers с заполненным полем; добавляет сам пользователь | да | как выше |
  | `lxbox://share:<текст>` | системное «Поделиться» | нет | нет |
  | Got it (N) | активна через `read_delay_seconds` | да | да |
  | Later | снуз всей ленты | да | нет |
  | X | закрыть; придёт при следующем запуске приложения | да | нет |

- Экраны `route:` — servers, routing, dns, vpn-settings, app-settings,
  speedtest, stats, config, debug, about, profiler. Незнакомое действие или
  экран — кнопка скрыта (лента новее приложения не ломает его).
- Сообщение без английского блока, битые ссылки и битая лента
  отбрасываются молча, без сбоя.
- Разработчику: Debug API `GET /support/state`, `POST /support/reset`,
  `POST /support/preview` (показ вне гейтов, `dry` — без записи состояния).

## Границы

- Выключить ленту целиком нельзя; без согласия на обновления она не
  обновляется из сети, но встроенная копия показывается.
- Автоматического добавления узлов по ссылке ленты нет — намеренно.
- Способы пожертвований — отдельный список в About ([navigation](navigation.md)).
- Зависит от возможностей ОС: системное «Поделиться», браузер.
