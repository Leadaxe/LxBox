# Первый запуск — вопросы о разрешениях и согласии по одному

При первом открытии главного экрана LxBox по одному задаёт вопросы: разрешение
на уведомления, фоновая работа, плитка быстрых настроек и согласие на проверку
обновлений.

| Поле | Значение |
|------|----------|
| Фича | [020-APP_SHELL](../FEATURE.ru.md) |
| Обещания | P11, P12 |
| Состояние | ✅ написана по коду, 2026-09-28 |

## Что делает

При первом открытии главного экрана по очереди задаёт вопросы, без которых
туннель в фоне работает плохо или без которых приложение не имеет права
ходить в сеть: разрешение на уведомления, фоновая работа, плитка быстрых
настроек, согласие на проверку обновлений.

## Параметры

Своих настроек нет. Шаги (от «нужно для работы» к «приятно иметь»):

| # | Шаг | Когда показывается | Что предлагает |
|---|-----|--------------------|----------------|
| 1 | Allow notifications | нет разрешения на уведомления и ещё не спрашивали | объяснение, затем системный запрос; Skip / Allow |
| 2 | Allow background activity | приложение не исключено из оптимизации батареи и ещё не спрашивали | Later / Allow → системные настройки → совет про ограничители производителя (Open Settings) |
| 3 | Плитка быстрых настроек | ещё не спрашивали | системный диалог добавления плитки (Android 13+); на старших версиях — молча пропуск |
| 4 | Check for updates? | ещё не спрашивали, сборка не dev | Skip / Enable автопроверки обновлений |

## Входы / Выходы

**Входы:** открытие главного экрана; состояние разрешений и оптимизации
батареи; канал установки.
**Выходы:** системные запросы; значение «Check for updates on launch»;
отметки «уже спрашивали».

## Правила и инварианты

- Следующий шаг — только после закрытия предыдущего; диалоги не наезжают друг
  на друга.
- Каждый шаг показывается один раз: отметка ставится до показа, поэтому
  убитое посреди вопроса приложение не спросит снова.
- Шаги 1 и 4 не закрываются касанием мимо окна; шаг 2 закрывается.
- Шаг 4: Enable — автопроверка вкл, Skip — выкл; закрытие системной «назад» —
  по каналу: установлено из магазина — выкл, иначе вкл.
- До ответа на шаг 4 приложение не запрашивает ни релизы, ни ленту поддержки
  (дефолт автопроверки — выкл).
- Отметки «уже спрашивали» — свойство устройства: полная замена настроек из
  резервной копии, в которой их нет, сохраняет текущие — после
  восстановления вопросы не всплывают заново.
- Вручную то же делается в App Settings: Diagnostics → System setup
  (уведомления, оптимизация батареи — сразу системные настройки, без
  объяснения) и General → Quick connect → Add (плитка, с итогом добавления).
- Сообщения о новой версии и ленты поддержки в онбординг не входят.

## Границы

- Мастера настройки сети, выбора пресетов и добавления первого сервера здесь
  нет: пустой главный экран с призывом добавить сервер — 007 / 008.
- Разрешение на VPN запрашивается при первом подключении — 010.
- Отозванное позже разрешение на уведомления заново не спрашивается.
- Зависит от возможностей ОС: запрос уведомлений (Android 13+), исключение
  из оптимизации батареи, сторонние ограничители производителей (OnePlus /
  OPPO / Realme, MIUI, MagicOS), системный диалог плитки (Android 13+).
