# Навигация и выход

## Что делает

Даёт одну точку входа во все экраны — главный экран с боковым меню — и
защищает от случайного выхода: на главном экране приложение закрывается
только вторым нажатием «назад».

## Параметры

Своих настроек нет. Фиксированные значения: окно второго нажатия — 2 с;
подсказка «Press back again to exit» держится столько же.

Боковое меню (сверху вниз, группы разделены чертой):

| Группа | Пункты |
|--------|--------|
| Настройка | Servers · Routing · DNS Settings · VPN Settings · App Settings |
| Инструменты | Speed Test · Statistics · Config Editor · Debug |
| О приложении | About |

Заголовок главного экрана — «L×Box» (не переводится) и меню наборов
настроек (018). About: версия и канал установки, руководство пользователя,
исходный код, версия ядра, благодарности, «Support the project», «Where to
get L×Box» (все каналы установки всегда видны), блок обновлений.

## Входы / Выходы

**Входы:** тап по пункту меню; «назад» — кнопка, жест от края, кнопка мыши
или клавиатуры.
**Выходы:** открытый экран поверх главного; закрытие меню; подсказка или
закрытие окна приложения.

## Правила и инварианты

- Пункт меню закрывает меню и открывает экран поверх главного; «назад» с
  экрана возвращает на главный.
- Двойное «назад» действует, только когда на главном экране нет открытых
  экранов, меню, диалогов, листов и выпадающих списков; иначе «назад»
  закрывает верхний из них.
- Первое нажатие — подсказка, выхода нет; второе в течение 2 с — выход;
  позже 2 с — снова первое.
- Открытое боковое меню «назад» закрывает без подсказки.
- Выход закрывает окно, туннель продолжает работать.
- Первое нажатие не запускает системную анимацию закрытия (предиктивный
  жест).
- На телевизоре фокус пульта при открытии главного стоит на главной кнопке.
- Пожертвования: «Support the project» открывает список способов (кошельки с
  копированием адреса, ссылки); список приходит из сети по нажатию, иначе из
  последнего удачного ответа или встроенной копии. Фонового запроса нет.

## Границы

- Вкладок внизу экрана нет; разделы — только через меню.
- Сворачивание вместо выхода и игнорирование «назад» отвергнуты владельцем.
- Содержимое пунктов меню — в своих фичах; здесь только вход.
- Публичный документ о пожертвованиях — `docs/DONATE.md`; фича его не
  показывает.
- Зависит от возможностей ОС: предиктивный жест «назад» (Android 13+).
