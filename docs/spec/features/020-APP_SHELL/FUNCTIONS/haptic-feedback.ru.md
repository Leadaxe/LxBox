# Тактильный отклик — вибрация на событиях туннеля и подписок

LxBox вибрирует на значимых событиях туннеля и подписок, чтобы без взгляда на
экран было понятно, подключился ли VPN.

| Поле | Значение |
|------|----------|
| Фича | [020-APP_SHELL](../FEATURE.ru.md) |
| Обещания | P4 |
| Состояние | ✅ написана по коду, 2026-09-28 |

## Что делает

Подтверждает вибрацией значимые события, чтобы не смотреть в экран: нажал
«подключить» и убрал телефон — по отклику понятно, поднялся ли туннель.

## Параметры

| Настройка | Где | Значения | Дефолт | Когда действует |
|-----------|-----|----------|--------|-----------------|
| Haptic feedback | App Settings → General → Feedback | вкл/выкл | вкл | сразу |

Включение переключателя само даёт короткий пробный отклик.

## Входы / Выходы

**Входы:** события туннеля, касания главных кнопок, итог ручного обновления
подписки.
**Выходы:** вибрация одной из трёх сил.

| Событие | Сила |
|---------|------|
| Касание Start/Stop, «Tap to connect», Reload и пункт его меню | щелчок выбора |
| Туннель поднялся | средняя |
| Туннель остановлен из состояния «подключено» | лёгкая |
| Туннель отозван системой или другим VPN из «подключено» | сильная |
| Туннель перестал отвечать (проверка жизни не прошла) | сильная, один раз |
| Ручное обновление подписки: успех | лёгкая |
| Ручное обновление подписки: ошибка | средняя |

## Правила и инварианты

- Выключенный переключатель глушит все события, изменение действует со
  следующего события без перезапуска.
- Не чаще одного отклика в 100 мс: пачка событий даёт один.
- Отклик на остановку — только если туннель был поднят; обрыв подключения
  на полпути не вибрирует.
- Автоматические обновления подписок не вибрируют — только ручные.
- Системный «Touch feedback» выкл или нет вибромотора — отклика нет, ошибок
  тоже.
- Значение настройки входит в резервную копию и наборы настроек.

## Границы

- Вибрации на каждое касание, прокрутку и переключатели нет — намеренно.
- Своих рисунков вибрации и силы по событиям нет.
- Выбор узла и применение пресета отклика не дают.
- Зависит от возможностей ОС: вибромотор, системная настройка отклика на
  касание.
