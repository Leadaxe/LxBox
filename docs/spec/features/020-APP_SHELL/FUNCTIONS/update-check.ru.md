# Проверка обновлений — ежедневная проверка релиза с согласия и ссылка на источник установки

С согласия пользователя LxBox не чаще раза в сутки проверяет новый релиз на
GitHub и сообщает о нём при следующем запуске со ссылкой туда, откуда приложение
установлено.

| Поле | Значение |
|------|----------|
| Фича | [020-APP_SHELL](../FEATURE.ru.md) |
| Обещания | P12, P13, P14, P15, P16, P17 |
| Состояние | ✅ написана по коду, 2026-09-28 |

## Что делает

Раз в сутки (с согласия) узнаёт у GitHub номер последнего релиза и при
следующем запуске тактично сообщает о новой версии со ссылкой туда, откуда
приложение было установлено. Установки внутри приложения нет.

## Параметры

| Настройка | Где | Значения | Дефолт |
|-----------|-----|----------|--------|
| Check for updates on launch | App Settings → General → Updates | вкл/выкл | выкл до ответа на вопрос первого запуска |
| Check now | там же (строка «Last check: …») и About | кнопка | — |

Фиксированные: первая автопопытка — 5 с после открытия главного; не чаще
раза в 24 ч от последней удачной проверки; таймаут запроса 10 с; всплывашка
держится 6 с.

Источники: API релизов GitHub (последний стабильный релиз); при любой его
неудаче — собственный манифест проекта (`tag`, `name`, `html_url`,
`published_at`), публикуемый при каждом релизе. Запрос подписан общим
именем клиента без точной версии.

## Входы / Выходы

**Входы:** согласие; версия приложения; канал установки (GitHub, Google Play,
F-Droid; неизвестный установщик — GitHub); ответы источников.
**Выходы:** всплывашка «vX available» на главном; блок в About (известная
новая версия, дата релиза или «(cached info)», кнопка «View release» / «Open
in <магазин>»); строка результата под «Check now»; событие автоматизации
`UPDATE_AVAILABLE` (если включено в 014).

## Правила и инварианты

- Автопроверка пропускается молча: выключена; dev-сборка; с последней
  удачной меньше суток; оба источника недоступны (сбой не сдвигает порог).
- «Check now» работает всегда, даже на dev-сборке; одновременно идёт одна
  проверка. Результат: «%s available», «You're up to date» или «Check failed:
  …» — «Couldn't reach GitHub — check network or try later».
- Удачная проверка запоминает время и последнюю известную версию,
  независимо от того, новее ли она.
- Сравнение: `vX.Y.Z`, `X.Y.Z` или `X.Y`, префикс `v` любого регистра,
  хвост после цифр (`-rc1`, `-dirty`) отбрасывается; нераспознанная строка —
  «не новее»; равные — «не новее».
- Всплывашка показывается только на запуске и только из запомненной версии:
  ответ сети в этом же сеансе её не поднимает — версия всплывёт при
  следующем запуске.
- Действия всплывашки:

  | Действие | Эффект |
  |----------|--------|
  | Тап по тексту | открыть страницу обновления своего канала; ничего не запоминается |
  | Later | скрыть; напомнить при следующем запуске |
  | Ignore | не напоминать об этой версии; более новая покажется снова |

- Адрес по каналу: GitHub — страница релиза этой версии; Google Play —
  карточка в магазине с веб-запасным адресом; F-Droid — страница пакета.
- На узком экране (до 320 dp) кнопки всплывашки уходят под текст, а не
  обрезаются.
- Проигнорированная версия всё равно видна в About.

## Границы

- Скачивания и установки APK нет; принудительного обновления нет.
- Бета-канала нет — только стабильные релизы.
- Фоновой проверки при свёрнутом приложении нет.
- Для магазинов обновлениями управляет их клиент; приложение только ведёт
  на страницу.
- Зависит от возможностей ОС: открытие ссылки магазина или браузера.
