## Что делает

Собирает в одном экране App Settings настройки, не относящиеся к конфигу
ядра, и сохраняет каждую в момент изменения. Экран — дом; содержание
большинства разделов принадлежит соседним фичам.

## Параметры

Вкладки (по центру, прокручиваются при узком экране):

| Вкладка | Разделы | Чья фича |
|---------|---------|----------|
| General | Region | 015-WARP |
| | Behavior: автозапуск, автоперезапуск VPN при изменении настроек | 010, 003 |
| | Quick connect: плитка, ярлык | 014 |
| | Updates: автопроверка, Check now | эта ([update-check](update-check.md)) |
| | Feedback: автопинг после подключения · Haptic feedback | 009 · эта ([haptic](haptic-feedback.md)) |
| | Backup & restore | 017 |
| Appearance | тема, Layout, Language | эта ([appearance](appearance.md), [localization](localization.md)) |
| Subscriptions | автообновление, идентичность запроса | 001 |
| Diagnostics | System setup, журналы, Developer | 013 |
| Automation | Intent API | 014 |

## Входы / Выходы

**Входы:** касания; открытие из бокового меню (на General), с соседних
экранов сразу на нужной вкладке (Subscriptions, Diagnostics), из ссылки ленты
поддержки `lxbox://route:app-settings[/appearance|subscriptions|diagnostics|automation]`.
**Выходы:** сохранённые значения; немедленный эффект там, где он возможен.

## Правила и инварианты

- Кнопки «Сохранить» нет: переключатель пишется в хранилище при изменении.
- Пока значения не прочитаны из хранилища, переключатели неактивны — нельзя
  записать значение, которого пользователь не видел.
- Тема и язык перерисовывают экран сразу, не закрывая его.
- Экраны правки (маршрутизация, DNS, режим VPN) сохраняют правку сразу в
  памяти, а на диск — при уходе с экрана или сворачивании приложения;
  сборка конфига видит правку уже при возврате на главный (003).
- Настройки хранятся вместе с остальными настройками приложения: входят в
  резервную копию и в наборы настроек; исключение — тема.

## Границы

- Смысл, дефолты и эффекты чужих разделов — в их фичах.
- Сброса всех настроек приложения к умолчанию нет.
- Подпись пункта меню «Theme, appearance» уже содержания экрана.
