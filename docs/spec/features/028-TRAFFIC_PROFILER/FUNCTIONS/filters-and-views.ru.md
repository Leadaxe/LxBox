# Фильтры и виды — отбор по приложению, правилу и выходу, своды и экспорт

Один журнал смотрится потоком или сводом по домену / IP, режется фильтром
по четырём осям и тексту и выгружается в JSON.

| Поле | Значение |
|------|----------|
| Фича | [028-TRAFFIC_PROFILER](../FEATURE.ru.md) |
| Обещания | P10, P11, P12 |
| Состояние | ✅ написана по коду, 2026-09-29 |

## Что делает

Отвечает на «куда ходит именно это приложение», «что ушло через это
правило или Направление» и «какие домены и адреса самые тяжёлые» без выбора
приложения заранее: фильтр сужает общий журнал, свод группирует его по
домену или IP, детали любой строки ведут в поиск, экспорт отдаёт журнал
наружу.

## Параметры

| Ручка | Значения | Дефолт |
|-------|----------|--------|
| Grouping | Event stream / Group by Domain / Group by IP | поток |
| Filter · Protocol | DNS, TCP, UDP | пусто |
| Filter · App | замеченные пакеты, «Unattributed (no owner)», «Add app from full list» | пусто |
| Filter · Rule | замеченные правила, пустое — «final» | пусто |
| Filter · Outbound | замеченные звенья цепочек и detour | пусто |
| Search | подстрока домена / IP / приложения | пусто |

## Входы / Выходы

**Входы:** журнал записи; окно «Filter events» с вкладками осей, полем
«Search domain / IP / app» и кнопкой «Reset all»; тап по домену, IP или
пакету в деталях; «View in Aggregated» из деталей агрегата; кнопка экспорта в
заголовке.

**Выходы:** кнопка «Filter (N)» с жёлтой точкой при активном фильтре; поток
событий (новые сверху) со строкой правила, цветной меткой типа (`DNS`, `DNS×`,
`TCP`, `TCP·` закрытое, `UDP`), ⚠ при проблеме и бейджем `cached`; свод по
домену или IP (соединения, ↑/↓, порты, выходы, первое и последнее появление);
лист события с копируемыми полями; лист агрегата со сводом и всеми
соединениями по ключу; «Share N events (JSON)» / «Copy JSON to clipboard» и
снэкбар «Export JSON copied».

## Правила и инварианты

- **Оси независимы.** Внутри оси — ИЛИ, между осями — И; поиск — поверх
  всех осей, подстрока без регистра (IP — как есть). Protocol ловит
  семейство: DNS — резолв и сбой, TCP — открытие и закрытие, UDP — открытие.
  App — пакет из выбранных ИЛИ (потеряшка и выбрано «Unattributed»). Rule —
  строка правила, пустая ловится пунктом «final». Outbound — любое звено
  цепочки групп или detour (селектор, Направление, транспорт).
- **Списки осей — из замеченного.** Вкладки App, Rule и Outbound
  предлагают то, что уже есть в журнале; «Add app from full list» открывает
  полный список установленных приложений с иконками.
- **Счётчик.** «Filter (N)» — число выбранных пунктов плюс поиск.
- **Фильтр живёт всю сессию приложения.** Переключение вкладок, уход с
  экрана и остановка туннеля его не сбрасывают; сброс — «Reset all» или
  перезапуск приложения. На диск не пишется.
- **Поиск из деталей.** Тап по домену, IP или пакету подставляет ключ в
  поиск; повторный тап тем же ключом снимает его. «View in Aggregated»
  подставляет ключ и переключает на свод по домену.
- **Своды.** Считаются из полного журнала (без осей фильтра), поиск
  применяется к строкам свода; события без владельца в своды не входят.
  Своды по домену собирают IP, цели CNAME, выходы, число соединений, объём и
  признаки проблем; по IP — порты, выходы, соединения, объём.
- **Экспорт.** JSON с `exported_at`, `event_count`, `events` и
  пересчитанными `by_domain` / `by_ip`; событие — все поля, включая
  `confidence`, `outbound_chain`, `detour_chain`, `issues` и `extra`.
  Кнопка недоступна при пустом журнале.
- Пауза замораживает снимок потока; свод паузу снимает.

## Границы

- Экспорт выгружает весь журнал, а не отфильтрованный список, хотя
  сериализатор рассчитан на отфильтрованный
  ([591](../../../tasks/591-spec-kit-revision-audit.md)).
- Правила из журнала не создаются («Add to ru-direct», «Block this domain»
  нет).
- Сравнения двух записей и задержек по доменам нет.
- Сохранение фильтра между запусками не предусмотрено намеренно.
