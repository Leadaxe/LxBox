# Конвейер сборки — фиксированные стадии от настроек до итогового JSON sing-box

Каждая пересборка проходит одну и ту же последовательность стадий: переменные, каркас, узлы, группы,
правила, post-steps, лечение и проверку.

| Поле | Значение |
|------|----------|
| Фича | [003-CONFIG_BUILD](../FEATURE.ru.md) |
| Обещания | P8 P13 |
| Состояние | ✅ написана по коду, 2026-09-28 |

## Что делает

Одна точка, которая из шаблона, источников узлов и всех настроек делает
итоговый JSON для ядра. Все пути запуска (возврат на главный экран, тап
по плашке, Start, холодный запуск, реакция на обновление подписки, Debug
API) идут через неё. Стадии фиксированы по порядку: каждая следующая
видит результат предыдущей, а лечения стоят после всего, что может
породить битую ссылку.

## Параметры

Своих ручек нет. Порядок стадий:

| # | Стадия | Что происходит |
|---|---|---|
| 1 | Переменные | Умолчания шаблона ← значения пользователя; пустое обязательное и вне границ → умолчание; режим VPN и параметры прокси — прямым присваиванием поверх сохранённого |
| 2 | Каркас | Копия `config` шаблона, подстановка `@var` и условий (inbounds по режиму, адреса TUN) |
| 3 | Узлы | Эмиссия узлов источников, уникальные теги; теги Направлений (включая выключенные) зарезервированы — тёзка получает суффикс `-N` |
| 4 | Ссылки detour | Ссылки узлов на узлы — в финальные теги; неразрешённая — носитель выпадает (fail-closed) |
| 5 | Гейт реестра ядра | Тела узлов чистятся по схеме контракта и версии/тегам ядра; неприемлемая запись снимается |
| 6 | Свёртки и цепочки | Источник-свёртка → группа; цепочки → узлы с гейтом возможностей ядра |
| 7 | Группы Направлений | Селекторы и `-auto`-двойники; Tailscale получает `state_directory` |
| 8 | Правила | Нормализация оси порядка (`traffic-processing` первым), раскрытие пресетов (включая `for_each`) и пользовательских правил → `route.rule_set`, `route.rules` |
| 9 | Сон туннелей | `lx.wg.*` при заданном пороге |
| 10 | `route.final` | Цель, которой нет среди эмитированных, → `vpn-1` с предупреждением; правила на пустую свёртку → на `route.final` или сняты |
| 11 | Post-steps | Уступки собранному `detour` (порт WireGuard, `tls.fragment`); TLS-трансформации; DNS-секция; пакеты split tunneling (последний трансформ tun) |
| 12 | Лечения | Миграция тегов пресетов в неймспейс; `resolve` на пропавший DNS-сервер — `server` снят; битые `dns.final`/резолвер → умолчание шаблона (с сохранением); legacy `strategy` DNS-правил снят; неизвестный uTLS-отпечаток → `chrome`; битый REALITY — `short_id` очищен или блок снят |
| 13 | Граф-санитайзер | Висячий detour снят (одна строка на цель), члены-призраки групп исключены, `default` вне состава исправлен, кольца разорваны по минимальному ребру; тайминги urltest выправлены |
| 14 | Проверка | [Проверка итогового конфига](config-validation.ru.md) |

## Входы / Выходы

**Входы:** см. фичу. Версия ядра и теги его сборки влияют на гейты стадий
5–6; пустая версия — fail-open (цепочки эмитятся).
**Выходы:** JSON; предупреждения (коды шаблона первыми, затем строки
деградаций); значения, исправленные сборкой, для сохранения; карта
«финальный тег → исходный узел»; список Направлений, оставшихся без узлов
(транзиентный снек); карта предупреждений узлов по тегу.

## Правила и инварианты

- Конфиг, собранный из одних и тех же входов, одинаков по составу, кроме
  случайных полей, которые рандомизирует сама настройка (mixed-case SNI).
- Лечение никогда не меняет выбор пользователя в хранении, кроме явно
  возвращаемых значений (умолчания резолверов DNS) — битая ссылка чинится
  в конфиге, а вернётся цель — вернётся и ссылка.
- Узел, снятый на любой стадии, не попадает ни в пулы Направлений, ни в
  `for_each`, ни в карту тегов.
- Авторский JSON узла реестр только комментирует, не правит (кроме того,
  без чего ядро не стартует).
- Пересборка одна за раз: второй триггер присоединяется к текущей; старт
  VPN дожидается текущей и при незаписанных изменениях запускает свою.
- Конфиг, закреплённый через Debug API, пересборкой не перезаписывается.
