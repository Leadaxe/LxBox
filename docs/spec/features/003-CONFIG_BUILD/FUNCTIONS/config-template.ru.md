# Шаблон конфига — встроенный шаблон, задающий настройки, каркас и пресеты

Один файл шаблона, встроенный в приложение, объявляет каждую настройку конфига с её типом и экраном,
каркас конфига ядра и каталог пресетов.

| Поле | Значение |
|------|----------|
| Фича | [003-CONFIG_BUILD](../FEATURE.ru.md) |
| Обещания | P4 |
| Состояние | ✅ написана по коду, 2026-09-28 |

## Что делает

Даёт сборке единственный источник структуры и умолчаний: поставляемый
внутри приложения файл `wizard_template.json`. В нём объявлено, какие
настройки существуют, какого они типа и где показываются, как выглядит
каркас конфига ядра и какие пресеты можно включить. Экраны настроек и
сборка читают один и тот же шаблон — умолчание на экране и в конфиге
совпадает по построению.

## Параметры

Верхние разделы шаблона:

| Раздел | Что несёт | Чья фича наполняет |
|---|---|---|
| `sections[]` | Карточки переменных: `id`, `name`, `chapter`, `description`, `vars[]` | эта (механизм), владельцы секций |
| `config` | Каркас конфига ядра с `@var` и условиями | эта |
| `selectable_rules[]` | Каталог пресетов | [004-ROUTING](../../004-ROUTING/FEATURE.ru.md) |
| `dns_options` | Каталог DNS-серверов и правил | [005-DNS](../../005-DNS/FEATURE.ru.md) |
| `group_templates`, `default_directions` | Шаблоны групп Направлений, стартовый набор | [006-DETOUR_AND_BALANCE](../../006-DETOUR_AND_BALANCE/FEATURE.ru.md) |
| `ping_options`, `speed_test_options`, `parser_config` | Параметры проб и разбора | 009, 002 |

`chapter` секции решает, какой экран её рисует: `core` — VPN Settings,
`routing` — экран маршрутизации, `dns` — экран DNS, `internal` — нигде
(глобальные переменные, которые правятся только через пресет по ссылке).
`wizard_ui` переменной: `edit` — поле, `fix` — только чтение в общем
списке (правится на своём экране), `hidden` — не показывается.

Текущие секции: General, Network, Internal, Auto Proxy, DNS, TUN, VPN Mode,
TLS Fragmentation. Пресетов 11; первый — `traffic-processing` (закреплён,
не выключается и не двигается, его правила идут первыми в `route.rules`).

Метаданные пресета — объект `ui`: `label`, `description`, `default`
(включён на чистой установке), `locked`, `num` (место на оси порядка),
`isSortable`. Тело пресета: `vars`, `rule_set`, `rule`/`rules`,
`dns_rule`/`dns_rules`, `dns_servers`, `for_each`.

## Входы / Выходы

**Входы:** файл шаблона из поставки; оверлей отображаемых текстов для
активного языка.
**Выходы:** загруженная модель шаблона для экранов и сборки; ошибка загрузки
при кривой конструкции.

## Правила и инварианты

- Шаблон грузится один раз на язык; смена языка не отравляет кэш другого
  языка. Английский — сам шаблон, для него оверлея нет.
- Оверлей меняет только отображаемые поля (`name`, `description`, `title`,
  `tooltip`, подписи вариантов и пресетов), не данные. Недостающий ключ в
  оверлее — тихо английский текст; нечитаемый файл оверлея целиком —
  ошибка в журнале и английский шаблон вместо падения.
- При загрузке проверяются все условные конструкции (`#if`, `#enable`,
  `#on_change`, `for_each.filter`, плейсхолдеры тел DNS-серверов) против
  объявленных переменных. Нарушение — ошибка загрузки: это дефект
  поставки, а не данных пользователя.
- Исключение: пресет, у `for_each` которого нет `node_type` или `as`,
  снимается из перечня один, с записью в журнале; шаблон работает.
- Переменная DNS-сервера шаблона видна только его телу; глобальные
  переменные телу сервера не видны.
- Секция `internal` на экранах не появляется, но её переменные участвуют
  в подстановке и доступны пресетам по ссылке.

## Границы

- Язык конструкций внутри шаблона — [язык шаблона](template-language.ru.md).
- Содержимое конкретных пресетов, DNS-каталога, шаблонов групп — фичи-
  владельцы из таблицы выше.
- Пользовательского шаблона нет: шаблон приходит только с обновлением
  приложения.
