# Язык шаблона

| Поле | Значение |
|------|----------|
| Фича | [003-CONFIG_BUILD](../FEATURE.ru.md) |
| Обещания | P1 P2 P3 P5 P6 P7 |
| Состояние | ✅ написана по коду, 2026-09-28 |

## Что делает

Превращает декларативный шаблон с переменными и условиями в конкретный
JSON. Правило разметки одно: `#` — ключевое слово движка, `@` — ссылка на
переменную, всё остальное — данные. Норматив языка — общий с лаунчером
(`contract/docs/TEMPLATE_LANG.md`, корпус `contract/corpus/template/`).

## Параметры

**Типы переменных и приведение:**

| `type` | В конфиг | Замечание |
|---|---|---|
| `bool` | `true`, если значение после trim без учёта регистра = `true`, иначе `false` | |
| `int` | число, зажатое в 0..65535; не число — строкой + `template_int_invalid` | вне 0..65535 — `template_int_clamped` |
| `text_list` | массив строк: построчно, trim, пустые выброшены | |
| `text`, `secret`, `enum`, `outbound`, `dns_servers` | строка дословно | `options` на приведение не влияют |
| без объявления | строка дословно | legacy-значения |

Значение переменной: запись пользователя, иначе `default_value`. Пустое
при `required` и непустом умолчании → умолчание (не для `secret`).
Переменная с границами (`dns_cache_capacity` 1024..65535): вне границ —
умолчание.

**Конструкции:**

| Конструкция | Смысл |
|---|---|
| `"@name"` (вся строка) | подстановка типизированного значения; внутри строки `@` — литерал |
| `{"#tpl": "@{node}-dns"}` | составная строка; пустое или неизвестное → узел снят |
| `"#if…": {"#and"\|"#or": […], "#value": …, "#else": …}` | ключом объекта — поля ветки вливаются в объект; единственным ключом элемента массива — элемент заменяется веткой или выпадает |
| `"#enable": <условие>` | узел существует, только если условие истинно; содержимое не вычисляется |
| `"#on_change": {"#set": {"@x": …}}` | при переключении переменной разово записать производные |
| `{"ref": "<глобальная>"}` в `vars` пресета | переменная по ссылке на глобальную |
| `for_each: {node_type, as, filter}` у пресета | тело повторяется для каждого подходящего узла; `@node`, `@node.skip_presets`, `@node.body.<путь>` |

Предикаты: `"@v"` (bool), `{"@v": "литерал"}`, `{"@v": "#notEmpty"|"#isEmpty"}`,
`{"@v": {"#in"|"#notIn": […]}}`, `{"@v": {"#matches": "re"}}`,
`{"#not": …}`; вложение условий на любую глубину. Легаси-написания без `#`
(`and`, `value`, `enabled: "@var"`) читаются бессрочно.

## Входы / Выходы

**Входы:** фрагмент шаблона (каркас, тело пресета, тело шаблонного DNS-
сервера), значения переменных, для `for_each` — узлы итогового конфига.
**Выходы:** JSON-фрагмент; предупреждения движка с кодом и параметрами
(`template_var_undeclared`, `template_unknown_directive`,
`template_int_clamped`, `template_int_invalid`, `template_fragment_dropped`),
без дублей по паре «код + параметры».

## Правила и инварианты

- Ветка выбирается до обхода; отброшенная ветка не вычисляется и не даёт
  предупреждений. Несколько `#if` на одном объекте различаются суффиксом
  (`#if1`, `#if tun-only`) и применяются в отсортированном порядке.
- Ветка `#if` элемента массива, сама являющаяся массивом, вливается в
  родителя на один уровень.
- В рантайме необъявленное `@имя` остаётся литералом, неизвестная
  `#`-директива-сосед снимается — оба с предупреждением. На загрузке те же
  ошибки в поставляемом шаблоне отвергают шаблон.
- Предупреждения шаблона идут первыми в отчёте сборки, показываются снеком
  с раскрытием списка и сохранение конфига не блокируют.
- Ref-переменная не имеет своих метаданных и значения: тип, варианты и
  значение берутся у глобальной; в редакторе правила она показывается с
  метаданными глобальной, правка пишет в глобальную. Копия в записи
  пресета игнорируется и вычищается.
- В записях шаблонных DNS-серверов и пресетов значение, равное умолчанию,
  не хранится; необъявленное имя снимается (`outbound` законен у любого
  пресета как универсальная замена цели).
- `on_change` — разовый эффект в момент переключения, не замок: цель можно
  переопределить руками. Пример: `ipv6_enabled` ставит `dns_strategy` и
  `resolve_strategy` в `prefer_ipv4` / `ipv4_only`. Псевдопеременные
  пресета `@rule_enable` / `@dns_enable` пересчитывают глобальные цели при
  включении пресета и его DNS-части (FakeIP гасит `resolve_enabled`).
- `for_each` обслуживает только узлы, попавшие в итоговый конфиг, в порядке
  конфига; теги таких пресетов без префикса пресета (`<узел>-dns`).
- `@runtime.platform/arch/target` на телефоне объявлены без значения: ключ
  или элемент выпадает, в условии — ложь.
