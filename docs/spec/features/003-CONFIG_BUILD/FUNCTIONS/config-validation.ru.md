# Проверка итогового конфига — конфиг, с которым ядро не стартует, не проходит

Перед сохранением собранный конфиг проверяется на висячие ссылки, пустые группы и кольца detour;
конфиг, не прошедший проверку, не записывается на диск и не попадает в ядро.

| Поле | Значение |
|------|----------|
| Фича | [003-CONFIG_BUILD](../FEATURE.ru.md) |
| Обещания | P9 |
| Состояние | ✅ написана по коду, 2026-09-28 |

## Что делает

Последний рубеж перед сохранением: проверяет собранный JSON на ошибки,
с которыми ядро гарантированно не стартует, и не даёт такому конфигу
попасть на диск и в ядро. Стадии лечения перед ней уже сняли всё, что
можно снять деградацией; сюда доезжает только то, что пользователь должен
устранить сам.

## Параметры

Своих ручек нет. Проверки (все fatal):

| Проверка | Что ловит |
|---|---|
| Ссылка правила | `route.rules[].outbound` на тег, которого нет среди `outbounds`/`endpoints` |
| `route.final` | Цель, которой нет в конфиге |
| Ссылка detour | `detour` узла или endpoint на несуществующий тег |
| Кольцо detour | Цикл в графе «узел → detour» с учётом рёбер «группа → каждый член» (selector/urltest) |
| Пустой urltest | Группа `urltest` без членов |
| `default` селектора | Не строка или не из состава `outbounds` |
| Резолверы DNS | `dns.final`, `route.default_domain_resolver` на отсутствующий сервер; на сервер `fakeip`/`hosts` |
| DNS-группы | Пустая после фильтра группа, член `fakeip`/`hosts`, кольцо групп (по одному на кольцо) |

Правило с `action` без строкового `outbound` (например `reject`) ошибкой
не считается; пустой или отсутствующий резолвер — тоже.

## Входы / Выходы

**Входы:** собранный JSON (после всех лечений и граф-санитайзера).
**Выходы:** список проблем с серьёзностью. При любой fatal сборка
возвращает отказ вместо JSON; причины — в журнале по одной строке и в
последней ошибке сборки.

## Правила и инварианты

- Fatal-конфиг не сохраняется: на диске и в ядре остаётся предыдущий
  конфиг, флаг «конфиг устарел» остаётся поднятым, синяя плашка горит.
- Что видит пользователь:
  - кольцо detour — шторка со списком узлов-виновников (показывается не
    больше трёх: чинить первые и пересобирать); тап по виновнику открывает
    экран его владельца; старт VPN и reconnect отменяются;
  - прочие fatal — снек «Config rebuild failed: <причины>» при сборке по
    действию пользователя; при тихой сборке (фон, запуск) снека нет;
  - Start при прочих fatal продолжает старт на предыдущем сохранённом
    конфиге (снек показан, плашка горит).
- Виновники кольца — минимальный набор рёбер, снятие которых разваливает
  кольцо; структурные рёбра «группа → член» виновниками не бывают.
- Проверка работает только на собранном конфиге: JSON, записанный руками
  через экран правки или Debug API, ей не проходит.
- Висячий член DNS-группы здесь не ловится: его отсеивает сборка с
  предупреждением.

## Границы

- Лечение того, что можно деградировать, — [конвейер сборки](build-pipeline.ru.md).
- DNS-проверки по существу — [005-DNS](../../005-DNS/FEATURE.ru.md); отказ
  ядра на старте с именем узла и автоотключение узла —
  [009-NODE_HEALTH](../../009-NODE_HEALTH/FEATURE.ru.md).
- Схема тел узлов (неизвестные ключи, типы) проверяется гейтом реестра до
  этой стадии — [021-CORE_CONTRACT](../../021-CORE_CONTRACT/FEATURE.ru.md).
