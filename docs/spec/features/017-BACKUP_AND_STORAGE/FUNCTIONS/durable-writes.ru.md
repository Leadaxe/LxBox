# Надёжная запись настроек

| Поле | Значение |
|------|----------|
| Фича | [017-BACKUP_AND_STORAGE](../FEATURE.ru.md) |
| Обещания | P21–P24 |
| Состояние | ✅ написана по коду, 2026-09-28 |

## Что делает

Гарантирует, что убийство процесса, сворачивание или переключение набора
настроек не оставят полуфайла и не потеряют правку: документ настроек
пишется целиком и атомарно, битый восстанавливается из предыдущей копии,
правки редакторов видны сразу, а на диск ложатся одной записью, запись «из
прошлого» не проходит.

## Параметры

| Что | Значение |
|-----|----------|
| Немедленная запись | переключатели и одиночные действия — сразу на диск |
| Отложенная запись | редакторы (Routing, DNS, VPN Settings, Tunnel apps и др.): правка — сразу в память; на диск — при уходе с экрана или сворачивании |
| Предыдущая копия | делается перед каждой записью, только из валидного основного файла |

Пользовательских ручек нет.

## Входы / Выходы

**Входы:** правки экранов; импорт копии и переноса; Debug API; сворачивание
и уход с экрана; убийство процесса в любой момент.

**Выходы:** целый документ на диске; при повреждении — восстановленное
состояние или настройки по умолчанию с признаком повреждения в журнале.

## Правила и инварианты

- **Атомарность:** копия валидного основного → запись во временный файл со
  сбросом на носитель → атомарная замена. Убийство на любом шаге оставляет
  прежний или новый целый документ (P21). Каждая запись — свой временный
  файл; параллельные записи не мешают друг другу.
- **Чтение на старте:** основного нет — новая установка (документ сразу с
  признаком формы); основной читается — он; основной битый (в т. ч. пустой)
  — восстановление из предыдущей копии, предупреждение в журнал; копии нет —
  настройки по умолчанию, признак повреждения, ошибка в журнал один раз.
- **Битый файл не затирается** до первой правки пользователя: он остаётся
  для ручной диагностики; первая запись перезаписывает его и снимает признак
  (P22). Осиротевшие временные файлы убираются при чтении.
- **Отложенная запись (§107):** каждая правка редактора сразу уходит в
  настройки в памяти — пересборка на возврате к главному экрану, гейт на
  Start и старт видят её до дисковой записи. На диск — одной записью при
  уходе с экрана или сворачивании; без несохранённого — записи нет (P23).
- **Признак «конфиг устарел»** поднимают только конфиг-значимые записи;
  запись настроек без правки конфига выравнивает время конфига, чтобы после
  убийства не было ложного «устарел» —
  [003-CONFIG_BUILD · P11](../../003-CONFIG_BUILD/FEATURE.ru.md#обещания).
- **Запись «из прошлого» (§515):** контроллер подписок, переживший смену
  набора настроек, в новый набор не пишет — ни отложенный фетч, ни
  переключение узла; закрытый контроллер не пишет; остановленный проход
  автообновления прерывается между подписками и новых не начинает (P24).
- Импорт переноса пишет все секции в память и одним сбросом на диск.

## Границы

- Писатели вне экрана подписок (импорт копии, Debug API) барьером поколения
  намеренно не ограничены —
  [018-WORKSPACES](../../018-WORKSPACES/FEATURE.ru.md).
- Атомарность замены — свойство файловой системы внутреннего хранилища
  приложения (зависит от возможностей ОС).
- Журнала транзакций между документом и другими наборами данных нет:
  атомарен каждый файл отдельно.
