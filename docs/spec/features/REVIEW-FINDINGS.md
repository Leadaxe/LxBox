## 005-DNS — расхождения (кандидаты в задачи)
- §530: правка SNI в форме заменяет весь объект `tls`, остальные поля теряются (код не написан).
- Своё DNS-правило (JSON) со ссылкой на удалённый/выключенный сервер клиентом не проверяется; ядро падает на каждом запросе «DNS server not found».
- Своё правило по rule-set без скачанного `.srs` или без `server` молча выпадает из конфига.
- 014F: переключатель «Independent cache» — в коде нет; «шаблонные серверы не редактируются» — устарело.
- «Пресеты по региону» — в коде нет; `ru-direct` включён у всех, регион (§425) влияет только на WARP.
- Плашка «Switch to cloudflare_udp» при умолчании `dns_shield`; подсказки про системный резолвер противоречат друг другу.
- Комментарий формы «local, h3 не выражаются» устарел; `tcp`/`local`/`fakeip`/`hosts` только через JSON.
- Поле `enabled` у записи пресета в DNS-правилах — мёртвое (реальный переключатель `dns_enable`).
- §578 статус отстал: `for_each` и серверы по узлам уже в коде и тестах.
- Неясно: кто ввёл `dns_shield` как умолчание (после §206 было `cloudflare_udp`); нет проверки существования `vpn-1`.
