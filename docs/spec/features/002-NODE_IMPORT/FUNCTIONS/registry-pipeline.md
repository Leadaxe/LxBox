## Что делает

Даёт всем входам — ссылке, `.conf`, объекту Xray, объекту sing-box — один
путь до узла и одни правила значений. Правила берутся из реестра контракта,
который приложение везёт в сборке и делит с лаунчером: одинаковая ссылка в
обоих приложениях даёт одинаковое тело и одинаковые коды.

## Параметры

| Часть реестра | Что задаёт |
|---------------|-----------|
| протоколы (`scheme`, `aliases`, `kind`, `sources`) | написания схем, тип тела, outbound или endpoint, допустимые входы |
| `mappers.<вход>` (`uri`, `conf`, `xray`, `singbox`) | формы записи, как из неё собрать тело ядра, дефолты, фолбэк имени |
| `body` + `tls` / `transports` / `multiplex` / `dialer` | схема тела: поля, типы, допустимые значения, `on_invalid`, `secret`, `min_core` |
| `emit` | сборка share-ссылки ([экспорт](share-link-export.md)) |
| `source_kinds` | виды документа ([опознание тела](body-recognition.md)) |
| `warnings` | тексты и severity кодов ([предупреждения](parse-warnings.md)) |
| `limits` | лимиты длины, глубины, цепочек |

Версия реестра — `1.1.99`; реестр приезжает синком, руками не правится.

## Входы / Выходы

**Вход:** запись одного вида (строка, INI, объект) и имя маппера.
**Выход:** узел с моделью, телом, источником и кодами — или вердикт «узла
нет» с кодом.

## Правила и инварианты

- **Порядок стадий:** маппер → сырая карта в форме ядра → санитайзер по
  схеме тела → типизированная модель → второй проход санитайзера по
  итоговому телу → отбраковка по вердикту → дедуп внутри тела.
- **Санитайзер — единственный судья значений.** Модель строится из уже
  очищенной карты; рукописных правил значений в разборе нет.
- **Вердикты правила реестра:** снять узел (`drop_node`, severity `error`),
  снять поле с кодом, заменить значение с кодом, оставить с info-кодом.
- **Вход называет себя.** Правила вида «кроме тела, написанного в форме
  ядра» (`except_sources`) различают ссылку, INI, Xray и авторский
  sing-box JSON.
- **Гейты ядра (`min_core`, платформа) при разборе выключены** — узел не
  зависит от того, какое ядро запущено; их судит сборка.
- **Реестр не загружен — ссылки не разбираются.** Отката на рукописную копию
  правил нет; единственное запасное число — потолок MTU AmneziaWG.
- **Дедуп внутри одного тела** — по подписи: эмиссия узла без `tag` и
  `detour` плюс подпись пути дозвона. Выживает первая запись, повтор уходит в
  отбраковку кодом `duplicate` с именем выжившего. Группы не дедупятся.
- **Идентичность узла — его тег.** Смена движка не меняет ни хеша, ни тега,
  ни тела ни одного кейса корпуса.
- **Узел хранится текстом источника** и разбирается заново при каждой
  загрузке; модель, дельта тела и коды — производные.
- **Поля тела, которых модель не держит**, возвращаются в тело из очищенной
  карты: каждое поле схемы реестра переживает круг «тело → модель → тело».
- Разбор 2000 узлов укладывается в разумное время (тесты цены разбора).
