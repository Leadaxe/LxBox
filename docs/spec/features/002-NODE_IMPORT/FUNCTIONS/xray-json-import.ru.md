# Импорт Xray JSON — узлы, группы балансировщиков и цепочки из конфигов Xray

Конфиги Xray из подписок панелей в любой из четырёх JSON-форм становятся узлами sing-box, группами
автовыбора и цепочками `detour`.

| Поле | Значение |
|------|----------|
| Фича | [002-NODE_IMPORT](../FEATURE.ru.md) |
| Обещания | P4 P8 P9 |
| Состояние | ✅ написана по коду, 2026-09-28 |

## Что делает

Принимает конфиги Xray в любой из четырёх форм — массив автономных конфигов
(типичная подписка панелей), полный конфиг, одиночный outbound, массив
outbound'ов — и переводит их серверы в узлы sing-box. Серверов в одном
элементе может быть несколько, и все они становятся узлами.

## Параметры

| Xray `protocol` | Узел | Заметки |
|-----------------|------|---------|
| `vless`, `vmess`, `trojan`, `shadowsocks` | тот же тип | `vnext[]` / `servers[]`, `streamSettings` → `tls`/`transport` |
| `hysteria` с `version: 2` | `hysteria2` | форма форка; `finalmask.quicParams` в тело не едет |
| `hysteria` с `version: 1` | — | узла нет |
| `wireguard` | endpoint `wireguard` | |
| `http` | `http` | |
| `socks` | — самостоятельным узлом не становится | только как звено |
| `freedom`, `blackhole`, `dns`, `loopback` | — служебные | |
| `routing.balancers` + наблюдатель | группа-автовыбор | смысл группы — [006-DETOUR_AND_BALANCE](../../006-DETOUR_AND_BALANCE/FEATURE.ru.md) |

## Входы / Выходы

**Вход:** JSON, опознанный как Xray ([опознание тела](body-recognition.ru.md)).
**Выход:** узлы, группы автовыбора, отбраковка с тегом записи. Источник
узла — исходный объект Xray дословно; «расширенный источник» — элемент
целиком, с соседними секциями.

## Правила и инварианты

- **Два прохода.** Первый (черновой) идёт от одиночных элементов к
  многоузловым: право выпустить сервер и дать ему имя получает элемент с
  осмысленным `remarks`, а не пул. Второй выпускает узлы строго в порядке
  файла. Сортировка стабильна при любом числе элементов.
- **Имя.** `remarks` элемента достаётся ровно одной сущности: единственному
  узлу, либо группе, если она есть; остальные узлы получают тег; повтор тега —
  индексный суффикс.
- **Дедуп** — по содержимому узла плюс путь дозвона, на всю подписку. Разный
  SNI, транспорт, учётка или «напрямую vs через релей» — разные узлы.
- **Синонимы тегов.** Состав группы, записанный на тегах соседнего элемента
  (`selector: ["proxy"]`), резолвится по таблице «тег → сервер».
- **`dialerProxy`.** Цель — прокси: узел получает цепочку `detour`.
  Цель — `freedom` с `settings.fragment`: узел получает `tls.fragment`, а не
  цепочку. Недостижимая цель — узел отбраковывается кодом
  `dialer_proxy_unusable`.
- **`finalmask.tcp` c `type: fragment`** → `tls.fragment`.
- **Отбраковка записи:** неподдержанный `protocol` → `protocol_unsupported`
  в отбраковке (сосед по элементу чист); `network`, которого нет в ядре, и
  обфускация заголовком `header.type: http` → узла нет, код назван.
- Неизвестные ключи внутри объявленных контейнеров → info-код с полным путём;
  поддерево `sockopt` молчит.
- Отбраковка едет только в `dropped[]` источника, на соседние узлы не вешается.

## Границы

- Маршрутизация, DNS, `inbounds` Xray не переносятся.
- Дедуп не пересекает границы подписок.
- Стратегии балансировщика и их перевод в режимы группы —
  [006-DETOUR_AND_BALANCE](../../006-DETOUR_AND_BALANCE/FEATURE.ru.md).
