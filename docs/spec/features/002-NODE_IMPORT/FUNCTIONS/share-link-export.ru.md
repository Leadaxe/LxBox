# Экспорт в share-ссылку

| Поле | Значение |
|------|----------|
| Фича | [002-NODE_IMPORT](../FEATURE.ru.md) |
| Обещания | P2 P13 |
| Состояние | ✅ написана по коду, 2026-09-28 |

## Что делает

Собирает из узла share-ссылку его схемы — чтобы перенести узел на другое
устройство или в другой клиент («Copy link»). Та же ссылка служит формой
хранения своих серверов, поэтому обязана разбираться обратно в тот же узел.

## Параметры

| Узел | Что отдаётся |
|------|--------------|
| `vless`, `trojan`, `tuic`, `anytls`, `hysteria2`, `ssh` | URL-форма, параметры по алфавиту |
| `vmess` | `vmess://` + base64(JSON) без паддинга |
| `shadowsocks` | `ss://` + base64url(`method:password`) без паддинга, `@host:port#имя` |
| `socks` | схема по версии: `socks4://`, `socks4a://`, иначе `socks5://` |
| `http` | `proxy-https://` при TLS, иначе `proxy-http://` |
| `naive` | `naive+quic://` при QUIC, иначе `naive+https://`; порт пишется всегда |
| `wireguard` (+AWG), `masque` | URL-форма, порядок параметров семантический; WireGuard — один пир |
| `tailscale` | не ссылка: JSON-текст тела с `tag` |
| `openvpn-client`, тип вне реестра | исходный текст узла |
| группа | ссылки нет |

Правила сборки — секция `emit` каждого протокола в реестре.

## Входы / Выходы

**Вход:** узел. **Выход:** строка ссылки; пустая строка — ссылку собрать
нельзя.

## Правила и инварианты

- **Круг:** разбор собранной ссылки даёт то же тело; повторная сборка того
  же тела — та же строка байт в байт; старые ссылки прежнего рукописного
  эмита читаются так же.
- **Отказ вместо искажения.** Тело, которое ссылкой не выражается
  (WireGuard с несколькими `peers`), даёт пустую ссылку, а не ссылку на
  первого пира. Копирование пустой ссылки ничего не делает.
- **Приватный ключ.** Если в теле есть поле с ролью `private_key` по реестру
  (WireGuard/AWG, SSH с ключом, MASQUE), перед копированием спрашивается
  подтверждение «Link contains a private key» с кнопками «Cancel» и «Copy
  anyway». Отмена не трогает буфер. Ключ из ссылки не вырезается — иначе
  своя ссылка перестала бы восстанавливать узел. UUID VLESS и пароль SSH
  ключом не считаются.
- После копирования — «URI copied»; узел не найден — «No source URI for this
  node».
- Без загруженного реестра сборка ссылки — ошибка, а не пустая строка
  (своя ссылка — форма хранения, молчаливая потеря недопустима).

## Границы

- Где в интерфейсе копирование и QR — [007-NODE_LIST](../../007-NODE_LIST/FEATURE.ru.md).
- Форма хранения узлов и бэкап — [017-BACKUP_AND_STORAGE](../../017-BACKUP_AND_STORAGE/FEATURE.ru.md).
- Ссылка узла подписки — это её исходный текст; экспорт собирает ссылку
  заново из тела, байт в байт с исходной она не обязана совпадать.
