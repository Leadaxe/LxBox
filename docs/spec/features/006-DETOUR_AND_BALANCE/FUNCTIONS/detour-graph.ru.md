# Граф detour-зависимостей — починка колец и пометка мёртвых опор

Перед стартом сборка чинит кольца и висячие detour-ссылки; на работающем
туннеле приложение показывает живой путь узла и предупреждает о мёртвых
узлах, на которых держатся другие.

| Поле | Значение |
|------|----------|
| Фича | [006-DETOUR_AND_BALANCE](../FEATURE.ru.md) |
| Обещания | P6 P15 |
| Состояние | ✅ написана по коду, 2026-09-28 |

## Что делает

Смотрит на связи «кто через кого» целиком: `detour` узла, член группы,
позиция цепочки. Перед стартом чинит то, что ядро отвергло бы (кольца,
висячие ссылки, призраки в группах), и называет починку предупреждением;
неразрешимое кольцо показывает виновниками. На работающем туннеле
показывает живой путь узла и помечает мёртвые узлы, на которых держатся
другие.

## Параметры

Своих ручек нет. Потолок виновников в fatal — 3; потолок живого пути — 12
хопов.

## Входы / Выходы

**Входы:** собранный конфиг; выборы групп работающего ядра; замеры
задержки.
**Выходы:** исправленный конфиг + строки предупреждений; fatal
«Routing loop — VPN not started»; ⚠ у узла; баннер на главном для DNS;
вкладки Overview и Dependents в окне узла.

## Правила и инварианты

Починка сборкой (повторяется до неподвижной точки):

| Случай | Исход |
|---|---|
| `detour` в теле узла на несуществующий тег | ключ снят, узел ходит напрямую; одна строка на цель (первые пять имён + счётчик) |
| член группы не существует | исключён; опустевшее Направление → `[block, direct-out]`, прочая группа выпадает |
| `default` группы вне состава | первый участник, предупреждение |
| узел с `detour` на группу, где состоит сам | вон из состава (и из `<tag>-auto`), detour сохранён; одна строка на узел |
| прочее кольцо | рвётся замыкающее ребро: `detour` снят («the node dials directly») или член исключён |
| detour-узлы в Направление, ушедшее в block | detour сохранён, отдельное предупреждение «…which is now blocked — their traffic is blocked too» |

- Fatal (P6) — только если кольцо осталось: старт отменяется, лист
  «Routing loop — VPN not started» перечисляет до трёх узлов-виновников
  («detour → X»), «Show loop» раскрывает цикл, тап по узлу ведёт к его
  источнику; «More loops may remain — fix these and try again.». Кольцо
  из одних групп показывается без виновников.
- Кольцо в папке ловится ещё при выборе личного detour (см.
  [node-detour.md](node-detour.ru.md)); кольцо detour-ссылок пользователя
  — выпадением участников (P1).
- Живой путь (Overview): «Live path in packet order. Tap a hop to open its
  source.» — по `detour` собранного конфига и текущим выборам групп;
  обрыв на группе без выбора («connect to see the full path»); у
  `round_robin` выбранного узла нет — путь обрывается на группе.
- Мёртвые опоры (P15): узел `dead`, если все его замеры −1 (хоть один
  живой — `alive`, замеров нет — `unknown`). Болезнь идёт вверх: selector,
  где выбран мёртвый узел; `urltest` — только при полностью мёртвом
  составе; далее все, у кого `detour` на больного. ⚠ — только у корня с
  зависимыми; вкладка Dependents перечисляет «These route through this
  node:», DNS-жертвы сверху. Баннер на главном — только когда болен
  DNS-сервер. Пересчёт — на новых замерах и смене выбора.
- Никаких фоновых проб и никакой смены выбора групп ради починки.
