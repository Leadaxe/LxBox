# Detour и балансировка — detour-серверы, цепочки хопов и балансировка нагрузки для VPN-узлов

LxBox пускает трафик VPN-узла через другой сервер, многохоповую цепочку или
пул с автовыбором и балансировкой, и всё это настраивается без правки JSON.
Фича охватывает личный detour, jump-серверы провайдера (Xray `dialerProxy`,
sing-box `detour`), Направления как переключаемый upstream, цепочки хопов
ядра sing-box-lx и группы `urltest` в режиме Fastest или round-robin. Сборка
конфига проверяет каждую связь: ядро принимает результат, а сломанная ссылка
никогда не превращается в прямое соединение.

## Назначение

Отвечает на вопрос «через что узел выходит в сеть»: напрямую, через другой
сервер (detour), через переключаемую прослойку-Направление, через цепочку
из нескольких хопов, через пул узлов с автовыбором или балансировкой.
Пользователь собирает многохоповые маршруты без правки JSON, а сборка
гарантирует, что конфиг с такими связями ядро примет.

Принципы, которые фича защищает:

- **Ссылка на хоп не превращается молча в прямое соединение.** Узел,
  чья detour-ссылка не разрешилась, не попадает в конфиг; цепочка без
  хопа — другой маршрут, поэтому она выпадает целиком, а не укорачивается
  на сборке.
- **Связи не роняют весь конфиг.** Кольца и висячие ссылки чинятся
  сборкой деградацией одного элемента с предупреждением; не распутываемое
  кольцо — единственный случай, когда старт отменяется, и пользователь
  видит виновников.
- **Порядок читается однозначно.** Позиции цепочки — в порядке пакета
  (первая ближе к телефону); превью detour-пути — тоже «Phone → … → Internet».

Из коробки: detour нет ни у одного узла, Направлений с «Use as detour»
нет, цепочек нет; родные detour-цепочки подписок работают, их звенья
скрыты из выбора узлов.

## Обещания

- **P1. Неразрешившаяся detour-ссылка не даёт прямого выхода.** Ссылка
  пользователя (личный detour, detour источника) на узел, которого нет,
  выключенный, на себя или в кольцо ссылок → носитель выпадает из
  конфига с предупреждением, каскадом и те, кто шёл через него.
  Свидетель: юниты «узла нет в контейнере — носитель detour не
  эмитится», «выключенный член — тот же исход», «detour на себя —
  носитель выпадает», «каскад: цель выпала — выпадает и тот, кто ходил
  через неё». Мутация: снять ключ `detour` и оставить узел.
- **P2. Append vs Replace.** «Fill missing» (умолчание) сохраняет родную
  цепочку узла и дописывает выбранный outbound хвостом; «Replace all»
  отбрасывает родную цепочку; «Don't use detour servers» снимает detour
  и побеждает выбранный outbound. Свидетель: юниты «append (default):
  main.detour = override (1-hop)», «replace (explicit toggle)»,
  «useDetourServers=false + override → no detour». Мутация: override
  пишется в `main`, затирая родное звено.
- **P3.** перенесено в [026-DIRECTIONS · P18](../026-DIRECTIONS/FEATURE.ru.md#обещания)
- **P4.** перенесено в [026-DIRECTIONS · P19](../026-DIRECTIONS/FEATURE.ru.md#обещания)
- **P5.** перенесено в [026-DIRECTIONS · P20](../026-DIRECTIONS/FEATURE.ru.md#обещания)
- **P6. Кольца чинит сборка, fatal — последний рубеж.** Узел с detour на
  группу, в которой состоит сам, исключается из её состава (detour
  сохранён); прочее кольцо рвётся по замыкающему ребру с предупреждением.
  Нераспутанное кольцо — fatal «Routing loop — VPN not started» с не
  более чем тремя виновниками. Свидетель: юниты «прямой цикл:
  member.detour=C → член вон из состава, detour цел», «транзитивный цикл
  — рвётся ОДНО ребро», «§254 — цикл через selector: 1 culprit», «cap:
  показываем не больше … виновников». Мутация: рвать все рёбра кольца.
- **P7. Цепочка — узел `type: chain` в порядке пакета.** Позиции уходят
  ключом `outbounds` дословно; `idle_timeout`, `strip_evasion`, `strip`,
  `rewrite` пишутся только когда заданы; цепочка попадает в пул
  Направлений наравне с серверами. Свидетель: юниты «порядок хопов =
  порядок ПАКЕТА», «умолчания в конфиг не пишутся», «цепочка — узел: её
  ловит фильтр Направления». Мутация: сортировка или дедуп позиций.
- **P8. Негодная цепочка выпадает целиком, конфиг собирается.** Меньше
  двух позиций, пустая/повтор/самоссылка, позиция в никуда, ссылка на
  цепочку ниже по списку, вложенная цепочка не первой позицией, занятый
  тег, ядро старше `1.14.0-lx.27-rc.5` → цепочки нет, предупреждение,
  остальное собирается. Свидетель: юниты «позиция в никуда дропает
  ЦЕПОЧКУ», «ссылка ВПЕРЁД дропает цепочку», «вложенная цепочка позицией
  ≥1 дропает цепочку», «коллизия тега с Направлением», «старое ядро:
  цепочка не эмитится, остальное собирается». Мутация: пропустить одну
  позицию.
- **P9. Направление не берёт цепочку, идущую через него.** В т.ч.
  транзитивно через вложенную цепочку; в чужом Направлении та же
  цепочка остаётся. Свидетель: юниты «прямой случай [proxy-out, exit]»,
  «ТРАНЗИТИВНО», «в ЧУЖОЕ Направление та же цепочка входит». Мутация:
  фильтр «все узлы» без вычета.
- **P10. Удаление источника укорачивает цепочку, а не удаляет её.**
  Позиция на удалённый сервер/член/подписку/Направление/цепочку снимается,
  счётчик показывается; цепочка с <2 позициями остаётся в списке, но не
  собирается; обновление подписки позиции не трогает. Свидетель: юниты
  «3-хоповая после heal эмитится УКОРОЧЕННОЙ + счётчик», «2-хоповая после
  heal остаётся, но не эмитится», «ГРАНИЦА: обновление подписки НЕ
  вычищает позиции». Мутация: каскадное удаление цепочки.
- **P11. Редактор цепочки не даёт сохранить то, что ядро отвергнет.**
  Блокируют: <2 позиций, пустая позиция, самоссылка, повтор, вложенная не
  первой, ссылка на цепочку ниже, пустое/занятое имя. Не блокируют:
  потерянные позиции, detour у входа, WireGuard за TCP-хопом, MASQUE h3 на
  звене. Свидетель: юниты «инварианты ядра — блокирующие», «детур позиции
  0 — ПРЕДУПРЕЖДЕНИЕ, сохранять не мешает». Мутация: сохранение при
  блокирующей находке.
- **P12. Группа не бывает detour-целью и не имеет detour.** Узлы
  автовыбора не предлагаются в пикере detour; у них нет блока Detour.
  Свидетель: ручная проверка — папка с узлом автовыбора, пикер detour
  члена папки его не показывает. `без свидетеля` (юнита нет).
  Мутация: группа в секции пикера.
- **P13. Балансировка — режим автовыбора.** «Load balance» даёт
  `mode: round_robin` и `balancer{pool, pool_tolerance, sticky_hash}`;
  пустой набор sticky → `["none"]`; «Fastest» не пишет ни `mode`, ни
  `balancer`. Свидетель: юниты «leastTest → НЕТ mode/balancer»,
  «round_robin → mode + balancer», «пустой stickyHash → ["none"]».
  Мутация: `balancer` без `round_robin` — ядро не стартует.
- **P14. Узел автовыбора не ломает старт.** Пустой пул → узел не
  эмитится; в селекторе Направления он есть, в `<tag>-auto` — нет;
  другую группу в пул не берёт. Свидетель: юниты «пустой пул → группа НЕ
  эмитится», «группа попадает в selector, но не в ✨auto», «группа не
  берёт в пул другую группу». Мутация: пустой `urltest` в конфиге.
- **P15. Мёртвая опора помечается.** Узел с замерами только −1, от
  которого транзитивно зависят узлы или DNS-серверы, получает ⚠;
  `urltest` болен лишь при полностью мёртвом составе. Свидетель: юниты
  «репро инцидента», «urltest-Направление не болеет по выбору». Мутация:
  ⚠ на любой мёртвой ноде.
- **P16. Послойная проба цепочки — только при поднятом VPN.** Слой k
  с ошибкой → следующие «not reached» и не пробятся. Свидетель: юниты
  «VPN выключен → vpn_down», «слой k с ошибкой → k+1.. not reached».
  Мутация: проба синтетическим конфигом.

## Входы / Выходы

**Входы:** узлы подписок, папок, одиночных серверов (в т.ч. родные
detour-звенья из Xray `dialerProxy` и sing-box `detour`); Xray `balancers`
+ `burstObservatory`; список Направлений; список цепочек; версия ядра;
выбор групп и замеры задержки работающего ядра.

**Выходы:** `detour` у outbound'ов/endpoint'ов; `selector`/`urltest`
с `balancer{}`; outbound'ы `type: chain`; предупреждения сборки;
fatal «Routing loop»; ⚠ у мёртвых опор и баннер для DNS; превью пути
«Phone → … → Internet»; живой путь и послойная проба на экране узла;
уведомления о вылеченных ссылках.

## Data flow

```
источники ─► узлы получают финальные теги ─► словарь ссылок
   │  (родная цепочка + политика источника: Use / Fill missing / Replace all / none)
   ▼
второй проход ссылок: detour → финальный тег | носитель выпал (каскад)
   ▼
цепочки по порядку списка: гейт ядра → инварианты → тег → позиции → вложенность
   ▼
Направления: фильтр → минус цепочки через себя → selector + <tag>-auto
   ▼
граф-санитайзер: висячее / призраки / default / кольца (до фикспойнта)
   ▼
проверка перед стартом: кольцо осталось → fatal с виновниками
   ▼
ядро ─► выборы групп + замеры ─► граф зависимостей ─► ⚠ / баннер
```

## Правила и гарантии

- Ссылка на узел хранится адресом `{folder_id?, tag}` (контракт 439);
  финальный тег вычисляет только сборка. Хранение ссылок, их
  переименование и удаление — [017-BACKUP_AND_STORAGE](../017-BACKUP_AND_STORAGE/FEATURE.ru.md).
- Пикер detour: свободные серверы — всегда; члены своей папки — только
  в контексте папки; чужие папки и узлы подписок — никогда; группы — никогда.
- `detour: direct-out` не предлагается: прямой выход — это «None».
- Направление-тёзка члена папки в пикере этой папки скрыто: значение
  читается как член.
- Под detour сборки тело узла уступает: `tls.fragment` снимается (с
  осиротевшей паузой), `listen_port` WireGuard снимается.
- Цепочки ссылаются только на цепочки выше по списку — циклы между
  ними невозможны по построению.
- Detour через WireGuard/AmneziaWG не запрещён (прежний запрет снят
  вместе с защитой ядра).

- Модель Направления — теги, фильтр состава, `route.final`, лечение

- Канал DNS-сервера через Направление — [005-DNS](../005-DNS/FEATURE.ru.md).
- Фильтр главного экрана «Hide detour servers / Show only detour
  servers», выбор узла в группе, значки пула — [007-NODE_LIST](../007-NODE_LIST/FEATURE.ru.md).
- Detour-хвост в списке соединений — [012-LIVE_STATE](../012-LIVE_STATE/FEATURE.ru.md).
- Runtime-вкл/выкл позиции цепочки и состояние звеньев ядра
  (`SetChainPositionEnabled`, `GetChainCloneConfig`) приложение не использует.
- Отдельного outbound'а `loadbalance` нет; стратегии «consistent hashing»
  и «sticky sessions» выражаются составом `sticky_hash`.
- Не планируется (решение владельца 2026-09-29, аудит [591](../../tasks/591-spec-kit-revision-audit.md)): предупреждение «AWG → канал с
  WireGuard» (`248F`) — detour через WireGuard/AmneziaWG разрешён без него.

## Особенности сопровождения

- Стрелки противоположны: у `detour` «узел через кого», у цепочки
  «в каком порядке идёт пакет». Перепутанный порядок даёт работающий,
  но не тот маршрут — заметно только по стране выхода.
- Лечение ссылок на Направление обязано зеркалиться в памяти списка
  источников, иначе ближайшее сохранение воскресит вылеченную ссылку.
- Решение владельца 2026-09-29 (аудит 591 · 36): режим отказа для висячего
  detour единый — fail-closed. Сейчас `detour` в теле узла на несуществующий
  тег и разрыв кольца санитайзером ведут узел напрямую (fail-open); это
  расхождение с P1, закрывается задачей (аудит 591).
