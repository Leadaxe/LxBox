# Отключение узлов подписки — выключение отдельных узлов, которое переживает обновления

Любой узел подписки можно выключить: он остаётся в списке, но не попадает в конфиг, а отметка
переживает обновления и перезапуски.

| Поле | Значение |
|------|----------|
| Фича | [001-SUBSCRIPTIONS](../FEATURE.ru.md) |
| Обещания | P9, P10 |
| Состояние | ✅ написана по коду, 2026-09-28 |

## Что делает

Позволяет выключить отдельный узел **внутри подписки**, не трогая источник.
Выключенный узел остаётся виден в списке узлов подписки с переключателем,
но в конфиг не попадает. Отметка переживает обновления и перезапуск.

## Параметры

| Действие | Где | Эффект |
|---|---|---|
| Переключатель узла | Подписка → Nodes | вкл/выкл одного узла |
| Вкл/выкл все | Подписка → Nodes | Вкл: карта отметок очищается целиком (с вердиктами ядра); Выкл: отмечаются все узлы, старые отметки сохраняются |
| Пакетное выключение по итогам проверки | Подписка → Nodes (кнопки проверки) | отметки той же карты |
| Правила Disable/Enable | Подписка → Filters | [import-rules.md](import-rules.ru.md) |

Константы TTL: `clamp(3 × интервал, 24 ч, 30 сут)`; интервал ≤ 0 → 24 ч.

## Входы / Выходы

**Вход:** действие пользователя или итог правил.
**Выход:** отметка «имя узла → когда последний раз видели в подписке»;
счётчик «M off» в шапке подписки.

## Правила и инварианты

- **Ключ отметки — имя узла внутри источника**, тёзки нумеруются `X`, `X-2`,
  `X-3` по порядку разбора (сгенерированное имя проверяется на занятость).
  Смена адреса, портов, ключей под тем же именем отметку не снимает;
  переименование провайдером — снимает (осиротевшая отметка уходит по TTL).
- Префикс тегов подписки на ключ не влияет.
- Группы и узлы без имени отметок не имеют и не выключаются по одному.
- Выключенный узел не эмитится; его предупреждения сборки не выводятся;
  ссылки других узлов на него как на detour снимаются с предупреждением.
- **TTL-очистка — только на успешном сетевом обновлении:** узел в свежем
  ответе → время «видели» = сейчас; отсутствует дольше порога → отметка
  удаляется. Провал обновления, регидрация из кэша и файловая подписка
  отметки не чистят.
- Выключение ставит «видели» = сейчас.
- Отметки старого формата (хеш содержимого, 64 hex) при первом разборе
  переезжают на имя узла с тем же содержимым; не нашедшие узла — удаляются.
- Включение узла рукой снимает с него вердикт ядра «отвергнут».
- Изменение набора отметок меняет «состав» подписки
  ([on-update-action.md](on-update-action.ru.md)) и помечает конфиг изменённым.
- Удаление подписки уносит отметки; смена источника их сохраняет.

## Границы

- Папки и одиночные серверы имеют свой переключатель —
  [007-NODE_LIST](../../007-NODE_LIST/FEATURE.ru.md).
- Автовыключение отвергнутых ядром и проверка доступности —
  [009-NODE_HEALTH](../../009-NODE_HEALTH/FEATURE.ru.md).
- Кто выключил узел (человек или правило), не запоминается.
