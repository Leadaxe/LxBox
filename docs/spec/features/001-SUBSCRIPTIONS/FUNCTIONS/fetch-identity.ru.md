# Идентичность запроса подписки — User-Agent и HWID-заголовки для панелей провайдеров

Задаёт User-Agent и HWID-заголовки, которые приложение отправляет в запросе подписки, — глобально
или для отдельной подписки.

| Поле | Значение |
|------|----------|
| Фича | [001-SUBSCRIPTIONS](../FEATURE.ru.md) |
| Обещания | P7 |
| Состояние | ✅ написана по коду, 2026-09-28 |

## Что делает

Определяет, **кем представляется приложение** в HTTP-запросе подписки. Панели
(Remnawave, Marzban и подобные) по User-Agent выбирают формат ответа, а по
HWID-заголовкам считают устройства под лимит. Настройки влияют только на
запрос подписки — не на конфиг ядра и не помечают его изменённым.

## Параметры

Глобальные (Настройки → Subscriptions → Fetch identity):

| Параметр | Значения | Дефолт |
|---|---|---|
| Custom User-Agent | строка, пробелы по краям срезаются; свой ввод или пресет клиента | пусто = `LxBox-android/<версия>` |
| Send HWID | вкл/выкл | выкл |
| HWID · `x-hwid` | строка; Regenerate даёт новый UUIDv4 | UUIDv4, генерируется при первом показе |
| `x-device-os` | строка | `android` |
| `x-ver-os` | строка | версия ОС устройства |
| `x-device-model` | строка | модель устройства |

На подписке (Settings → Fetch identity → Custom identity): тот же набор
полей. Включение Custom копирует текущие глобальные значения (с уже
подставленными значениями устройства); выключение отбрасывает слепок.

## Входы / Выходы

**Выход — заголовки GET-запроса:**

| Заголовок | Когда |
|---|---|
| `User-Agent` | всегда |
| `x-hwid` | Send HWID вкл и HWID непуст |
| `x-device-os`, `x-ver-os`, `x-device-model` | вместе с `x-hwid`, каждый — если значение непусто |

## Правила и инварианты

- Default-режим: UA = глобальный override, иначе брендированный. Custom-режим:
  UA и HWID-заголовки **только** из слепка подписки; глобальные игнорируются;
  пустой UA слепка → брендированный (пустой заголовок не шлётся).
- Брендированный UA: `LxBox-android/<версия>`; ведущее `v`, скобки, `;` и
  пробелы из версии вырезаются; при пустой версии — `unknown`. Подстроки
  `singbox` в нём нет никогда (на ней часть панелей отдаёт JSON-конфиг).
- У поля UA — список пресетов популярных клиентов: LxBox (default, очищает
  поле), Happ, v2RayTun, Streisand, Karing, v2rayNG, Hiddify, sing-box. Пресет
  только подставляет строку в поле, её можно дописать руками; какой пресет
  выбран, не хранится, только сама строка. Пресеты нужны для панелей, которые
  отдают полный формат (например, xray-JSON с ws `path` и заголовками) только
  «своим» клиентам, а остальным — урезанные ссылки или отказ. Клиентов
  семейства Clash нет: Clash YAML не разбирается. Дефолт сам не меняется: чужой
  UA — маскировка, и панель с HWID-гейтом может ответить на него заглушкой.
- Подсказка под полем говорит, что формат зависит от User-Agent, и советует UA
  другого клиента (например, Happ), если подписка грузится, а узлы не работают.
  Не блокирует.
- Regenerate HWID = для панели новое устройство; старое может занимать слот
  лимита. Предупреждения нет.
- Живой просмотр ответа во вкладке Source подписки идёт с той же
  идентичностью, что и обновление.
- Если значения устройства недоступны, соответствующие заголовки не шлются.

## Границы

- HWID передаётся только заголовком; ни в UA, ни в query не кладётся.
- Идентификатор устройства ОС не используется — HWID случайный.
