# Сон туннеля (фоновый режим) — пауза VPN ради экономии батареи

Туннель можно ставить на паузу, пока устройство спит или экран выключен, и
возобновлять потом; по умолчанию он не засыпает.

| Поле | Значение |
|------|----------|
| Фича | [010-VPN_SERVICE](../FEATURE.ru.md) |
| Обещания | P16 |
| Состояние | ✅ написана по коду, 2026-09-28 |

## Что делает

Позволяет обменять надёжность фоновых соединений на батарею: приостанавливать
туннель целиком, когда устройство спит или гаснет экран, и будить его обратно.
По умолчанию туннель не спит никогда.

## Параметры

| Настройка | Значения | Дефолт |
|-----------|----------|--------|
| Tunnel sleep mode (Настройки VPN → System → Optimization) | `never` — «Never sleep (recommended)»; `lazy` — «Lazy sleep», пауза в глубоком сне устройства; `always` — «Aggressive battery saving», пауза при каждом гашении экрана | `never` |

Входит в резервную копию. Применяется со следующего подключения; смена при
поднятом туннеле помечает «нужен перезапуск».

## Входы / Выходы

**Входы:** вход/выход устройства из глубокого сна (`lazy`); гашение/включение
экрана (`always`).
**Выходы:** вызовы ядра `pause` и `wake`.

| Режим | Когда `pause` | Когда `wake` |
|-------|---------------|--------------|
| `never` | никогда | никогда |
| `lazy` | устройство вошло в глубокий сон | устройство вышло из глубокого сна |
| `always` | экран погас | экран включился |

## Правила и инварианты

- Режим читается один раз при старте туннеля; смена на лету не подхватывается.
- В `never` ни пауза, ни пробуждение не вызываются вовсе — нулевые издержки.
- `pause` закрывает все соединения ядра: приложения получают обрыв, push- и
  keep-alive-каналы рвутся. Поэтому `always` рвёт их при каждом гашении экрана,
  а дефолт — `never`.
- На паузе туннельный интерфейс остаётся поднятым: трафик не уходит мимо
  туннеля, реальный адрес не светится. Пакеты на паузе не копятся —
  отбрасываются; после `wake` приложения сами переоткрывают соединения (отсюда
  «пачка пушей при разблокировке»).
- Независимо от режима, включение экрана запускает перепривязку стухших
  WG/AWG-сессий (см. [network-changes](network-changes.ru.md)).

## Границы

- Выборочный сон отдельных WG/AWG-туннелей — [core-resources](core-resources.ru.md);
  он ортогонален сну туннеля целиком.
- Сон потоков данных для экрана приложения в фоне —
  [012-LIVE_STATE](../../012-LIVE_STATE/FEATURE.ru.md).
- Зависит от возможностей ОС: наличие и момент глубокого сна (обычно десятки
  минут неподвижности с погашенным экраном), доставка событий экрана.
