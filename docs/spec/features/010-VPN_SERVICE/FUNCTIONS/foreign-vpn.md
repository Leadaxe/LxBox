# Сосуществование с чужим VPN

| Поле | Значение |
|------|----------|
| Фича | [010-VPN_SERVICE](../FEATURE.md) |
| Обещания | P7, P8, P9 |
| Состояние | ✅ написана по коду, 2026-09-28 |

## Что делает

Системный VPN-слот на устройстве один. Функция не даёт L×Box молча вытеснить
чужой VPN при старте и честно сообщает, когда чужой VPN вытеснил L×Box.

## Параметры

Своих настроек нет. Поведение зависит от режима работы: вопрос и запрос
системного разрешения есть только в режимах с туннелем (`vpn`, `vpn_proxy`),
см. [operating-modes](operating-modes.md).

## Входы / Выходы

**Входы:** ручной старт из приложения; наличие активной VPN-сети другого
приложения; сигнал ОС о перехвате слота.
**Выходы:** диалог «Another VPN is active» с кнопками Switch / Cancel / VPN
settings; статус `revoked` и сообщение «Another VPN app took the system VPN slot
(e.g. an always-on VPN). Start again to reconnect.»

## Правила и инварианты

- Перед ручным стартом в режиме с туннелем приложение спрашивает, активен ли
  чужой VPN. Активен — диалог: Switch продолжает старт, Cancel отменяет,
  VPN settings открывает системный список VPN (там активный помечен, имя
  перехватчика приложению ОС не сообщает) и тоже не стартует.
- Чужим считается VPN, который сейчас обслуживает активную сеть; собственная
  «осиротевшая» VPN-сеть L×Box чужой не считается. Пока наш туннель не
  остановлен, вопрос не задаётся. Сбой проверки = «чужого нет»: старт не
  блокируется.
- В режиме Proxy не задаётся ни вопрос, ни запрос системного VPN-разрешения:
  старт порта не должен отзывать чужой VPN.
- Старт без экрана (плитка, автоматизация, Debug API) вопроса не задаёт; если
  разрешение ещё не выдано, он отвечает «нужно согласие» и не стартует.
- Перехват слота: туннель останавливается штатно (все ожидания остановки
  разрешаются), статус — `revoked`, причина показывается всплывающим
  сообщением и сохраняется как последняя ошибка старта. Отдельного пятого
  статуса службы нет: это признак поверх «Stopped».
- Признак перехвата отдаётся и при запросе статуса, поэтому приложение,
  открытое после перехвата, показывает его, а не «Disconnected».
- Текст причины перехвата во внешних интерфейсах (Debug API, последняя ошибка
  старта) — всегда английский.

## Границы

- Определить, какое именно приложение забрало слот, нельзя — ОС не сообщает.
- Автоматически отбирать слот обратно не делается.
- Зависит от возможностей ОС: единственность VPN-слота, always-on VPN других
  приложений, видимость владельца VPN-сети (на старых версиях ОС своя
  осиротевшая сеть может считаться чужой).
