# Здоровье Направления — пинг, URLTest и настройки проверки на Направление

Направление измеряется двумя способами: приложение пингует его узлы с главного экрана, а
двойник ядра `<tag>-auto` проверяет их URLTest'ом по своему расписанию с параметрами,
заданными в редакторе Направления.

| Поле | Значение |
|------|----------|
| Фича | [026-DIRECTIONS](../FEATURE.ru.md) |
| Обещания | P21 |
| Состояние | ✅ написана по коду, 2026-09-29 |

## Что делает

Даёт каждому Направлению свой взгляд на здоровье узлов. Массовый пинг на главном экране
меряет узлы выбранного Направления и держит карту на каждое Направление; Направление может
переопределить глобальные URL и таймаут проверки. Auto-двойник — собственный замер ядра: он
перепроверяет пул по `interval`, переключается, когда узел лучше более чем на `tolerance`,
засыпает после `idle_timeout` без трафика и с Passive health check пропускает пробу, пока
идёт трафик. Функция только называет то, что принадлежит Направлению; сам замер — во владении
[009-NODE_HEALTH](../../009-NODE_HEALTH/FEATURE.ru.md).

## Параметры

| Ручка | Где | Значения | Умолчание | Владелец |
|---|---|---|---|---|
| Переопределение URL / таймаута пинга | шторка настроек пинга, область «current Direction» | URL, мс | глобальные | [009 настройки пинга](../../009-NODE_HEALTH/FUNCTIONS/ping-settings.ru.md) |
| Test URL, Interval, Tolerance (ms), Idle timeout, Interrupt connections | редактор Направления, «Include auto» | — | `generate_204` / `15m` / 50 / `30m` / выкл | здесь → двойник |
| Mode, Pool size, Pool tolerance, Sticky session by | там же | Fastest · Load balance | Fastest / 3 / 0 / process + domain | [006 балансировка](../../006-DETOUR_AND_BALANCE/FUNCTIONS/balancing.ru.md) |
| Passive health check | Settings → Optimization | вкл/выкл | вкл | одно значение для всех двойников |

## Входы / Выходы

**Входы:** поля двойника из редактора; глобальные и per-Direction настройки пинга; Passive
health check.
**Выходы:** `url`, `interval`, `tolerance`, `idle_timeout`, `interrupt_exist_connections` и
`passive_check` в группе `<tag>-auto`; карта пинга выбранного Направления; выбранный
группой узел в строке главного экрана («→ узел»).

## Правила и инварианты

- Поля двойника идут в конфиг как введены (после клэмпа); «Fastest» не пишет ни `mode`, ни
  `balancer`, и двойник байт-в-байт совпадает с апстримным `urltest`.
- Карты пинга — на Направление: массовый пинг пишет и сбрасывает только карту текущего
  Направления; узел без замера здесь показывает значение другого Направления с пометкой `~`
  ([009-NODE_HEALTH · P2](../../009-NODE_HEALTH/FEATURE.ru.md#обещания)).
- Переопределение на Направление ищется по его тегу; удаление Направления снимает
  переопределение, выключение оставляет; сирота от старого удаления или восстановленного
  бэкапа снимается при загрузке ([009-NODE_HEALTH · P5](../../009-NODE_HEALTH/FEATURE.ru.md#обещания),
  408); переопределения едут в бэкап вместе с Направлениями (409).
- Принудительная перепроверка двойника заставляет ядро переселектить сразу, не дожидаясь
  `interval` ([009-NODE_HEALTH · P6](../../009-NODE_HEALTH/FEATURE.ru.md#обещания)).
- `interval` больше `idle_timeout` поднимается сборкой с подсказкой в редакторе
  ([009-NODE_HEALTH · P7](../../009-NODE_HEALTH/FEATURE.ru.md#обещания)).
- Двойник помечается мёртвой опорой, только когда мёртв весь его состав
  ([006-DETOUR_AND_BALANCE · P15](../../006-DETOUR_AND_BALANCE/FEATURE.ru.md#обещания)).

## Границы

- Массовый пинг, его отмена и жизненный цикл, автопинг после подключения, проверка папок,
  спидтест и автоотключение по отказу ядра — [009-NODE_HEALTH](../../009-NODE_HEALTH/FEATURE.ru.md).
- Round-robin-балансировка и просмотр пула — [006-DETOUR_AND_BALANCE](../../006-DETOUR_AND_BALANCE/FEATURE.ru.md).
- Проверка серверов папки и подписки переопределений Направления не видит.
- Подпись шторки настроек пинга «Shared with the home screen ping» остаётся и при активном
  переопределении Направления (591).
