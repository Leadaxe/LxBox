# Редактор узлов — добавление и правка своих VPN-серверов: SOCKS5, HTTP, Tailscale, ссылки и JSON

LxBox добавляет VPN-серверы, которых нет ни в одной подписке (SOCKS5, HTTP,
Tailscale, ссылка, WireGuard INI или sing-box JSON), и позволяет потом их
править. Узел хранится тем текстом, который вы ввели, поэтому написанное
вручную sing-box-тело доходит до ядра без изменений, пройдя проверку ядром.
Узлы подписок показываются только для чтения; меняются они лишь правилами
импорта подписки.

## Назначение

Пользователь заводит **свой узел** — сервер, которого нет ни в одной подписке:
локальный SOCKS5/HTTP-прокси, узел Tailscale, ссылку или sing-box JSON от
знакомого — и потом правит его сам. Фича отвечает за мастер добавления, экран
настроек узла и правку его **источника** — текста, из которого узел
получается.

Принципы, которые фича защищает:

1. **Истина узла — его источник.** Хранится то, что человек ввёл (ссылка,
   WireGuard INI или тело sing-box), а не копия, собранная моделью. Правится
   только источник; вкладка JSON показывает, что уйдёт в ядро, и только для
   чтения.
2. **Написанное руками уходит в ядро как написано.** Своё JSON-тело не
   переписывается гейтами приложения, проверяет его ядро при сохранении.
   Ключи, которых приложение не знает, не теряются.
3. **Имя — это тег.** Заголовок своего сервера в списке — тег его узла;
   отдельного «отображаемого имени» нет. Переименование переписывает все
   ссылки на узел.
4. **Узел подписки — чужой.** Поштучно он не правится: следующее обновление
   всё равно заменит его. Менять узлы подписки можно только правилами
   импорта подписки ([001-SUBSCRIPTIONS](../001-SUBSCRIPTIONS/FEATURE.ru.md)).

Разбор ссылок и форматов — [002-NODE_IMPORT](../002-NODE_IMPORT/FEATURE.ru.md);
detour и цепочки — [006-DETOUR_AND_BALANCE](../006-DETOUR_AND_BALANCE/FEATURE.ru.md);
список узлов, папки и порядок — [007-NODE_LIST](../007-NODE_LIST/FEATURE.ru.md).

## Обещания

- **P1. Тег из формы мастера переживает перезапуск.** SOCKS5, HTTP и Tailscale
  хранятся телом sing-box с полем `tag`, поэтому тег после перечитывания
  записи тот же, что ввёл человек. Свидетель: юниты «SOCKS5-узел мастера →
  тело JSON → перечитанная запись сохраняет тег», «HTTP-узел с логином и TLS
  → круг сохраняет логин, пароль, tls», виджет «введённый tag переживает
  persist round-trip». Мутация: хранить SOCKS5 ссылкой `socks5://…#label`.
- **P2. Пустой тег формы — дефолт с эмодзи.** Пусто → `local-socks5-out`,
  `local-http-out`, `tailscale`; у созданного узла без эмодзи в теге появляется
  эмодзи по виду узла. Свидетель: виджеты «пустое поле Tag → дефолтный tag»,
  «пустой Tag → «tailscale» с эмодзи по умолчанию». Мутация: требовать Tag.
- **P3. Заголовок своего сервера — тег узла.** Имя записи не пишется и не
  показывается, даже если осталось от старой версии; пересохранение его
  стирает. Свидетель: виджет «заполненный Tag → tag узла = введённое, name
  пуст», юнит «legacy-запись v2.11.0 с непустым name: displayName игнорирует
  name». Мутация: показывать имя записи первым.
- **P4. Эмодзи ставится один раз.** Тег без эмодзи при создании получает
  эмодзи по виду узла (локальный → 🔁, WARP → 🔥☁️, WireGuard → 🏠,
  Tailscale → 🕸️, MASQUE → 🎭, Hysteria2/TUIC → 🚀, прочее → ⚡); тег с
  эмодзи не трогается; повтор не дублирует. Свидетель: юниты групп
  «defaultEmojiFor» и «withDefaultEmoji — round-trip через парсер». Мутация:
  проверять эмодзи только в начале тега.
- **P5. В источник пишется только тело узла.** Документ (`outbounds`/
  `endpoints` в корне) → первый узел не служебного типа и не группа,
  `endpoints` раньше `outbounds`; массив → первый элемент; всё прочее не
  сохраняется, пользователь видит одно сообщение. Свидетель: юниты групп
  «документ» и «массив тел». Мутация: писать в источник текст целиком.
- **P6. Нетронутый JSON сохраняется байт в байт.** Если тег не менялся, текст
  тела уходит в источник как набран; пустое поле Tag тег тела не трогает.
  Свидетель: юниты «тег не менялся → исходный текст байт в байт», «пустой Tag →
  тег тела не трогается». Мутация: всегда перекодировать JSON.
- **P7. Своё JSON-тело проверяет ядро до записи.** Ядру отдаётся конфиг из
  одного узла без `detour`, WireGuard — под `endpoints`; отказ ядра —
  источник не меняется, текст ошибки — словами ядра. Свидетель: юниты
  «голое тело → outbounds без detour», «wireguard → endpoints»; отказ ядра —
  ручная проверка: вписать в тело незнакомый ядру ключ `"foo": 1`, Save →
  «The core rejected the node: …», источник прежний. Мутация: писать до ответа ядра.
- **P8. Своё JSON-тело уходит в конфиг дословно.** Ключи вне модели живы; ключ
  `detour` тела снимается, detour решает запись
  ([006-DETOUR_AND_BALANCE](../006-DETOUR_AND_BALANCE/FEATURE.ru.md)). Узел
  подписки и ссылка — через модель. Свидетель: юниты «одиночный сервер из
  JSON: тело дословно, ключи вне модели живы», «JSON-источник → объект без
  detour», «личный detour члена применяется поверх дословного тела»,
  «контейнер: узел подписки идёт через модель». Мутация: эмитить модель для
  всех.
- **P9. Правка тела снимает вердикт ядра.** Узел, выключенный за отказ ядра,
  после изменения тела включается обратно; пересохранение без изменения
  вердикт держит; выключенный человеком узел правкой не оживает. Свидетель:
  юниты «тело изменилось → вердикт снят…», «пересохранение без правки…»,
  «сервер, выключенный человеком (без вердикта), правкой не оживает».
  Мутация: снимать вердикт на любом Save.
- **P10. Битый источник члена папки не записывается.** «Could not parse server
  config — keeping current», член не тронут. Свидетель: юнит «updateMemberAt:
  битый raw → откат с ошибкой, член не тронут». Мутация: записать, потом
  разобрать. (У одиночного сервера такой защиты нет — см. сопровождение.)
- **P11. Переименование переписывает ссылки.** Новый тег узла подхватывают
  detour других узлов, члены групп и позиции цепочек. Свидетель: юниты
  «переименование корневого узла переписывает корневые ссылки», «правка тела
  члена (переименование) переписывает хранение». Мутация: сопоставлять узлы
  до и после по тегу, а не по месту в теле.
- **P12. Комментарии и незнакомый тип не мешают.** JSON с `//` и `/* */`
  принимается, в источник уходит без комментариев с сообщением «Comments were
  removed.»; своё тело типа, которого приложение не знает, принимается с
  предупреждением; тело без `type` — отказ. Свидетель: юниты «вход с
  комментариями принимается, источник без комментариев», «вставка тела
  незнакомого типа…», «тело без type по-прежнему отклоняется». Мутация:
  строгий разбор JSON до снятия комментариев.
- **P13. Форма Tailscale пишет только заполненное.** Auth key обязателен;
  пустые поля в тело не попадают, булевы — только `true`; Hostname
  предзаполнен `LxBox-<модель>`, стёртый — ключа нет. Свидетель: виджеты
  «пустой Auth key → валидатор не пускает», «необязательные поля и тумблеры
  попадают в тело как есть», «§449 Hostname с дефолтом LxBox…». Мутация:
  писать `false` и пустые строки. Подробно —
  [030-TAILSCALE](../030-TAILSCALE/FEATURE.ru.md).
- **P14. Узел подписки поштучно не правится.** Экран узла подписки — только
  осмотр: нет Save, нет Edit JSON, у Tailscale нет Save choice. Свидетель —
  ручная проверка: подписка → узел → «Inspect node»: вкладки JSON/Source
  только для чтения, кнопок записи нет. Мутация: открыть узлу подписки
  экран своего узла.
- **P15. Формы прокси не пускают негодный адрес.** Host непустой, Port 1..65535,
  иначе Add не срабатывает. `без свидетеля` (тестов на валидатор
  SOCKS5/HTTP нет).
- **P16. Секция Masquerade пишет `ip`/`id`/`ib` в источник, явный `i1`
  приоритетнее.** На вкладке Settings узла WireGuard/AmneziaWG — секция
  Masquerade (протокол, домен, браузер). Save кладёт ключи в текст источника
  в его же форме (query ссылки, `[Interface]` INI, тело sing-box), прочие
  байты не трогает; ключи, которых форма не показывает, убирает. QUIC без
  домена или негодный домен Save не пропускают. У узла с явным `i1`, у
  упакованной ссылки (`awg://` base64, `vpn://`) и у Xray-источника секция
  выключена, причина написана. Свидетель:
  `test/services/masquerade_source_test.dart` (три формы, сырой `+` и `\r\n`
  целы, круг через разбор на образцах корпуса),
  `test/widgets/masquerade_section_test.dart` (`i1` → нет Save, `i2` → `sip`
  выключен, QUIC без домена → Save выключен). Мутация: пересобрать ссылку
  через `Uri.queryParameters`; убрать проверку `i1`.

Ключи конфига ядра, которые фича создаёт: outbound `socks` (`server`,
`server_port`, `username`, `password`), outbound `http` (то же + `tls.enabled`,
`tls.server_name` = Host), endpoint `tailscale` (`auth_key`, `control_url`,
`hostname`, `ephemeral`, `accept_routes`, `exit_node`), `tag`. Своё JSON-тело
отдаётся ядру целиком, кроме `detour`.

## Входы / Выходы

**Входы:** поля форм мастера; ссылка или JSON во вкладках мастера; текст
источника на вкладке Source; выбор эмодзи; ответ ядра `CheckConfig` на
сохранение JSON-тела.

**Выходы:** новая запись «свой сервер» (одиночный) с одним узлом; изменённый
источник своего сервера или члена папки; пересборка конфига; сообщения
«Added: <тег>», «Saved», «Only the node is saved. The rest of the input is not
kept.», «Comments were removed.», «The core rejected the node: …».

## Data flow

```
мастер: форма ─► тело sing-box с tag ──┐
        ссылка/JSON ─► разбор (002) ───┼─► авто-эмодзи ─► запись «свой сервер» ─► пересборка
экран узла: Source ─► вид текста?
   JSON  ─► только тело + тег из Tag ─► CheckConfig ядра ─► запись
   ссылка ─► тег во фрагмент ─────────────────────────────► запись
   INI    ─► как есть, тег полем записи ──────────────────► запись
   запись ─► перечитать: модель для формы, списка, диагностики
            ─► вердикт ядра снят, если тело изменилось; ссылки переписаны
сборка: свой JSON-источник ─► тело дословно (без detour) ; иначе ─► модель
```

## Правила и гарантии

- Вид источника выводится из текста: JSON-объект → `json`, WireGuard INI →
  `wg_ini`, прочее → ссылка. Флага режима нет.
- Tag и Source применяются только кнопкой Save; Edit JSON — сразу после
  подтверждения; Detour и Skip presets записываются сразу при выборе.
- «Edit JSON» у ссылки или INI после предупреждения заменяет источник телом
  модели — необратимо, обратно в ссылку дороги нет; у JSON-источника просто
  открывает Source.
- Тег в мастере не проверяется на уникальность: при совпадении сборка даёт
  узлу суффикс `-1`, `-2`…; сообщение показывает введённый тег.
- Эмодзи ставится только при создании записи; при правке тега не
  подставляется.
- У узла автовыбора (группы) блока Detour нет.

## Границы

- Разбор ссылок, форм JSON, INI и `vpn://` —
  [002-NODE_IMPORT](../002-NODE_IMPORT/FEATURE.ru.md); добавление по ссылке,
  QR, файлу, публичные тест-серверы — функция «Добавление источника» в
  [001-SUBSCRIPTIONS](../001-SUBSCRIPTIONS/FEATURE.ru.md).
- Выбор detour, политика папки, цепочки —
  [006-DETOUR_AND_BALANCE](../006-DETOUR_AND_BALANCE/FEATURE.ru.md); здесь
  только место на экране.
- Папки, перенос в папку, порядок, главный экран — [007-NODE_LIST](../007-NODE_LIST/FEATURE.ru.md).
- Диагностика узла и уведомления — [009-NODE_HEALTH](../009-NODE_HEALTH/FEATURE.ru.md);
  Cloudflare WARP — [015-WARP](../015-WARP/FEATURE.ru.md); пресет Tailscale —
  [004-ROUTING](../004-ROUTING/FEATURE.ru.md); сам узел Tailscale, его
  личность и вкладка Network — [030-TAILSCALE](../030-TAILSCALE/FEATURE.ru.md).
- Не делает: переопределения (overrides) узла подписки, форму по схеме
  протокола, форму TLS.
- Не планируется (решение владельца 2026-09-29, аудит [591](../../tasks/591-spec-kit-revision-audit.md)): дублирование узла; отдельная
  форма WireGuard/AmneziaWG (`097F` Phase 2b) — такие узлы правятся текстом.
  Единственное исключение — секция Masquerade (`ip`/`id`/`ib`, задача
  [623](../../tasks/623-node-masquerade-section.md), P16); `jc`, `h1`–`h4`,
  `i1`–`i5` и поля AWG 3.x — по-прежнему только текстом.
- Камера и выбор файла — зависят от возможностей ОС
  ([001-SUBSCRIPTIONS](../001-SUBSCRIPTIONS/FEATURE.ru.md)).

## Особенности сопровождения

- **Битый источник одиночного сервера записывается.** У члена папки есть
  откат (P10), у одиночного — нет: ссылка, из которой не вышло узла,
  сохраняется, запись остаётся без узла. Любая новая точка записи обязана
  решать это явно.
- **Save пишет текст вкладки Source.** Правка одного Tag пересохраняет
  источник; для ссылки тег уходит во фрагмент `#…`, для JSON — в `tag`, для
  INI — в поле записи. Уход с экрана без Save молча теряет правку.
- **Проверка ядром — только для JSON.** Ссылка и INI идут через модель и её
  гейты; если мост к ядру недоступен, сохранение не блокируется.
- **SNI HTTP-прокси = Host.** HTTPS-переключатель кладёт в `tls.server_name`
  значение Host; тонкая настройка TLS — только текстом тела.
- **Узел подписки правится только правилами импорта**
  ([001-SUBSCRIPTIONS](../001-SUBSCRIPTIONS/FEATURE.ru.md)): правка поштучно
  была бы стёрта следующим обновлением — поэтому её нет.
