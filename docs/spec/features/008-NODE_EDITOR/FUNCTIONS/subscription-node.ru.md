# Узел подписки

| Поле | Значение |
|------|----------|
| Фича | [008-NODE_EDITOR](../FEATURE.ru.md) |
| Обещания | P14 |
| Состояние | ✅ написана по коду, 2026-09-28 |

## Что делает

Показывает узел, пришедший из подписки, так же подробно, как свой, но не
даёт править его поштучно. Узел подписки — чужой текст: следующее
обновление заменит его, и любая ручная правка была бы молча стёрта. Поэтому
**переопределений (overrides) над узлом подписки нет**; менять узлы подписки
можно только правилами импорта на уровне подписки.

## Параметры

Меню узла в списке узлов подписки: «Copy node info», «Copy tag», «Inspect
node». Экран осмотра, только чтение:

| Вкладка | Содержимое |
|---|---|
| JSON | тело, в которое узел превратится в конфиге |
| Source | исходный фрагмент подписки; у JSON-тел — Compact (сам outbound) / Extended (весь элемент, как прислал провайдер) |
| Replacements | что поменяли правила импорта; есть, только если поменяли |
| Network | у Tailscale — просмотр, без Save choice |
| Diagnostics | диагностика и уведомления (009) |

## Входы / Выходы

**Вход:** узел из последнего успешного разбора подписки.
**Выход:** просмотр и копирование; изменений не производит.

## Правила и инварианты

- Нет Save, нет Edit JSON, нет правки Source; у Tailscale — нет выбора Exit
  node с записью (P14, ручная проверка).
- Узел подписки идёт в конфиг через модель и её гейты, не дословно — даже
  если провайдер прислал sing-box JSON.
- **Что переживает обновление подписки** (всё — на уровне подписки, не узла,
  см. [001-SUBSCRIPTIONS](../../001-SUBSCRIPTIONS/FEATURE.ru.md)):

| Что | Переживает? |
|---|---|
| отметка «узел выключен» | да, по имени узла; теряется при переименовании провайдером |
| правила импорта (Replace / Disable / Enable) | да, применяются к каждому новому разбору |
| префикс тегов, detour-политика подписки | да (006) |
| выбор члена ручной группы подписки | да (006/007) |
| любая поштучная правка тела | не существует |

- Чтобы править узел подписки как свой, его переносят руками: копируют ссылку
  (007) и добавляют как свой сервер — дальше это независимая запись, которую
  обновления не трогают.
