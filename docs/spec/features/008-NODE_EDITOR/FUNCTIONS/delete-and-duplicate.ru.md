# Удаление и дублирование узла — удаление своего узла без висячих ссылок

Удаление своего узла очищает все ссылки на него и сообщает, кого это
затронуло; дублирования нет.

| Поле | Значение |
|------|----------|
| Фича | [008-NODE_EDITOR](../FEATURE.ru.md) |
| Обещания | P11 |
| Состояние | ✅ написана по коду, 2026-09-28 |

## Что делает

Убирает свой узел из приложения так, чтобы ничто не осталось ссылаться на
пустоту, и сообщает, кого это задело. Дублирования узла («сделать копию для
правки») в приложении нет.

## Параметры

| Что удаляется | Где | Подтверждение |
|---|---|---|
| свой одиночный сервер | долгое нажатие на запись в списке источников → «Delete» | диалог «Delete subscription?» / «Remove "<тег>"?» |
| член папки | экран папки ([007-NODE_LIST](../../007-NODE_LIST/FEATURE.ru.md)) | см. [007-NODE_LIST](../../007-NODE_LIST/FEATURE.ru.md) |
| папка | долгое нажатие на папку → «Delete…» | выбор: удалить папку с серверами или оставить серверы |

## Входы / Выходы

**Вход:** подтверждение пользователя.
**Выход:** запись удалена; ссылки на её узел погашены; уведомление с
подсчётом задетых; пересборка конфига.

## Правила и инварианты

- При удалении узла гаснут все ссылки на него:
  - detour других узлов становится «None (direct)»;
  - узел уходит из членов групп автовыбора;
  - позиция уходит из цепочки, сама цепочка остаётся.
- Уведомление считает задетых порознь: носителей detour, группы и их
  членов, позиции цепочек; член группы автовыбора detour-носителем не
  считается. Свидетель: юниты «удаление гасит ссылки и называет задетых
  порознь…», «удаление члена: уведомление считает detour, члены групп и
  позиции порознь».
- Переименование, в отличие от удаления, ссылки не гасит, а переписывает и
  не уведомляет (P11, [name-is-tag.md](name-is-tag.ru.md)).
- Удаление необратимо: корзины и отмены нет.
- **Дублирования нет.** Копию узла можно получить только вручную: взять
  источник со вкладки Source (или скопировать ссылку,
  [007-NODE_LIST](../../007-NODE_LIST/FEATURE.ru.md)) и добавить через мастер
  или поле ввода как новый сервер. Новая запись получит свой тег; при
  совпадении тегов сборка суффиксует `-1`.

## Границы

- Удаление подписки целиком, узлов папки и перенос между папками —
  [001-SUBSCRIPTIONS](../../001-SUBSCRIPTIONS/FEATURE.ru.md) /
  [007-NODE_LIST](../../007-NODE_LIST/FEATURE.ru.md).
- Выключение узла вместо удаления —
  [001-SUBSCRIPTIONS](../../001-SUBSCRIPTIONS/FEATURE.ru.md) (узлы подписки) и
  [007-NODE_LIST](../../007-NODE_LIST/FEATURE.ru.md) (свои).
- Реестр ссылок и хранение — [017-BACKUP_AND_STORAGE](../../017-BACKUP_AND_STORAGE/FEATURE.ru.md).
- Смысл detour и цепочек после удаления цели — [006-DETOUR_AND_BALANCE](../../006-DETOUR_AND_BALANCE/FEATURE.ru.md).
- Дублирование узла не планируется (решение владельца 2026-09-29, аудит [588](../../../tasks/588-spec-kit-revision-audit.md)).
