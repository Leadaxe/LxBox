# Имя равно тегу — одно имя своего сервера, согласованное везде

У своего сервера одно имя — тег его узла: при создании он получает умолчание
и эмодзи, а переименование переписывает все ссылки на узел.

| Поле | Значение |
|------|----------|
| Фича | [008-NODE_EDITOR](../FEATURE.ru.md) |
| Обещания | P2 P3 P4 P11 |
| Состояние | ✅ написана по коду, 2026-09-28 |

## Что делает

У своего сервера одно имя — тег его узла. Его видно заголовком в списке
источников, строкой на главном экране, в пикере detour и в правилах. Фича
гарантирует, что это имя задаётся в одном месте, переживает перезапуск и
при смене не рвёт ссылки на узел.

## Параметры

| Откуда тег | Правило |
|---|---|
| форма мастера | поле Tag; пусто → `local-socks5-out` / `local-http-out` / `tailscale` |
| ссылка | фрагмент `#…`; разбор — [002-NODE_IMPORT](../../002-NODE_IMPORT/FEATURE.ru.md) |
| sing-box JSON | поле `tag` |
| WireGuard `.conf` из файла | имя файла без расширения, если в INI нет своего имени ([002-NODE_IMPORT](../../002-NODE_IMPORT/FEATURE.ru.md)) |
| поле Tag экрана узла | при Save пишется в источник по его виду |

Авто-эмодзи при создании записи, если в теге эмодзи нет:

| Узел | Эмодзи |
|---|---|
| тег `WARP` / `WARP+` | 🔥☁️ |
| сервер `127.0.0.1`, `localhost`, `::1` | 🔁 |
| WireGuard / AmneziaWG | 🏠 |
| Tailscale | 🕸️ |
| MASQUE | 🎭 |
| Hysteria2, TUIC | 🚀 |
| прочее | ⚡ |

Эмодзи — пиктограмма Unicode или пара региональных индикаторов (флаг).

## Входы / Выходы

**Вход:** тег из формы, ссылки, JSON, имени файла или поля Tag.
**Выход:** тег узла в источнике; заголовок записи; при переименовании —
переписанные ссылки на узел.

## Правила и инварианты

- Имя записи своего сервера не пишется и не показывается; старое имя от
  версии v2.11.0 игнорируется и стирается при первом пересохранении (P3).
  Для подписок и папок имя записи работает как раньше.
- Эмодзи ставится только при создании записи (мастер, вставка, файл) и
  префиксом через пробел: `⚡ my-node`. Тег, где эмодзи уже есть в любом
  месте, не трогается; повтор не дублирует (P4).
- Тег в мастере на уникальность не проверяется. При совпадении сборка даёт
  следующему узлу суффикс `-1`, `-2`… — итоговый тег видно в списке узлов,
  сообщение мастера показывает введённый.
- Переименование правкой источника переписывает все ссылки на узел: detour
  других узлов, членов групп, позиции цепочек. Узлы до
  и после сопоставляются по месту в теле, а не по тегу (P11).
- Префикс тегов папки или подписки к тегу добавляется на сборке; в источнике
  и в поле Tag его нет.
- Тег INI-узла хранится полем записи: сам INI остаётся байт в байт.
