# Поделиться текстом — текст или ссылка файлом-заметкой

Текст или ссылка, которыми поделились с LxBox из любого приложения,
становятся маленьким текстовым файлом и едут обычным файлом Taildrop, так что
любой получатель Taildrop, включая официальные клиенты Tailscale, получает
обычный файл.

| Поле | Значение |
|------|----------|
| Фича | [032-TAILDROP](../FEATURE.ru.md) |
| Обещания | P8 |
| Состояние | ✍ Черновик, 2026-11-01 — не реализована |

## Что делает

Когда меню «Поделиться» передаёт LxBox текст без файлов, текст записывается в
файл `note-YYYY-MM-DD-HHMM.txt` (местные дата и время телефона в момент
отправки) и идёт тем же путём, что [отправка файлов](send-files.ru.md): выбор
узла при необходимости, выбор пира, прогресс в уведомлении.

## Параметры

| Что | Значение |
|-----|----------|
| Имя файла | `note-YYYY-MM-DD-HHMM.txt`, местное время отправки |
| Содержимое | текст как есть, UTF-8 |
| Доставка | путь отправки файлов: узел, своё устройство в сети, уведомление |

## Входы / Выходы

**Входы:** intent «Поделиться» с текстом (простой текст или ссылка) без
файлов.

**Выходы:** один файл `.txt`, отправленный через Taildrop.

## Правила и инварианты

- На стороне получателя заметка — обычный файл; ничто в ней не помечает её
  как файл LxBox.
- «Поделиться» с файлами отправляется файлами; эта функция обрабатывает
  только текст.
- Заметка создаётся только для передачи и на телефоне не хранится.

## Границы

- Никакой семантики буфера: заметка попадает во входящие файлы получателя, а
  не в его буфер. Текст буфера идёт через
  [синхронизацию буфера](clipboard-sync.ru.md).
- На устройстве не проверено.
