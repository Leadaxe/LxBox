# Поделиться текстом — текст из «Поделиться» и выделенный в окно Send clipboard

Текст или ссылка, которыми поделились с LxBox из любого приложения, а также
текст, выделенный в любом приложении и отправленный пунктом «Send to device»,
открывают окно Send clipboard с этим текстом в поле. Оттуда он уходит
служебным файлом на своё устройство.

| Поле | Значение |
|------|----------|
| Фича | [032-TAILDROP](../FEATURE.ru.md) |
| Обещания | P8 |
| Состояние | ✅ реализована, 2026-11-03 ([707](../../../tasks/707-taildrop-send-receive-files.md), итерация 7); на устройстве не проверена |

## Что делает

Два входа, одно окно:

1. **«Поделиться».** Когда меню «Поделиться» передаёт LxBox текст без файлов,
   открывается окно Send clipboard из [служебных файлов](clipboard-sync.ru.md)
   с этим текстом в поле вместо буфера.
2. **Меню выделения.** Пункт «Send to device» в меню выделения текста любого
   приложения (в панели выделения или под ⋮) открывает то же окно с
   выделенным текстом. Текст в исходном приложении не меняется.

Текст в поле можно править. ➤ отправляет его командой `clipboard`; «Open on
<device>» (только для ровно одной ссылки `http(s)`) — командой `open_url`.
Получатель, лента и отказы — как у окна.

## Параметры

| Что | Значение |
|-----|----------|
| Входы | LxBox в «Поделиться» (текст без файлов); «Send to device» в меню выделения текста |
| Когда они есть | только пока VPN поднят и в работающем конфиге есть узел Tailscale с Allow Taildrop |
| Доставка | служебный файл через окно Send clipboard: `clipboard` или `open_url` |

## Входы / Выходы

**Входы:** intent «Поделиться» с текстом (простой текст или ссылка) без
файлов; текст из «Send to device».

**Выходы:** окно Send clipboard с текстом в поле; после ➤ или «Open on
<device>» — служебный файл выбранному устройству.

## Правила и инварианты

- «Поделиться» с файлами отправляется файлами ([отправка файлов](send-files.ru.md));
  эта функция обрабатывает только текст.
- До ➤ или «Open on <device>» ничего не уходит: окно сначала показывает
  текст.
- Оба входа включаются при старте VPN или перезагрузке конфига, где есть узел
  Tailscale с Allow Taildrop, и выключаются при остановке VPN, перезагрузке
  без такого узла и перезапуске процесса. Если вход всё же сработал без
  такого узла (гонка), окно показывает причину отказа (`Start VPN to send`
  при выключенном VPN).
- Текст из «Поделиться» больше не становится файлом-заметкой. Файл
  `note-YYYY-MM-DD-HHMM.txt` (местное время телефона, UTF-8) делает только
  Debug API (`POST /taildrop/send` с `text`), и он едет обычным файлом
  Taildrop.

## Границы

- Получатель получает команду, а не файл: официальный клиент Tailscale
  показывает её обычным `.json`. Заметка для официального клиента — только
  путь Debug API.
- На устройстве не проверено.
