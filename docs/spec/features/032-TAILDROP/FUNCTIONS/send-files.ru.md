# Отправка файлов — из «Поделиться» или строки пира на своё устройство tailnet

Файлы уходят с телефона через Taildrop на одно из своих устройств
пользователя в сети — из системного меню «Поделиться» любого приложения или
из строки пира на вкладке Network узла Tailscale.

| Поле | Значение |
|------|----------|
| Фича | [032-TAILDROP](../FEATURE.ru.md) |
| Обещания | P1–P3, P7 |
| Состояние | ✍ Черновик, 2026-11-01 — не реализована |

## Что делает

Два входа, одна передача:

1. **«Поделиться».** LxBox — цель системного меню «Поделиться». Экран отправки
   спрашивает узел Tailscale, если в работающем конфиге их несколько, затем
   пира, запускает передачу и закрывается; прогресс идёт дальше в
   уведомлении.
2. **Вкладка Network.** У строки пира на вкладке Network узла есть «Send
   file…». Пункт открывает системный выбор файла; выбранные файлы уходят
   этому пиру.

За одну отправку или один выбор можно передать несколько файлов.

## Параметры

| Что | Значение |
|-----|----------|
| Выбор узла | только работающие узлы Tailscale из работающего конфига; спрашивается, только если их несколько |
| Список пиров | устройства в сети того же владельца, что и это устройство; расшаренные машины и устройства других пользователей в списке нет |
| «Send file…» | у строк пиров, которые проходят в список пиров |
| Файлов за передачу | один или несколько |
| Прогресс | уведомление на передачу: имя пира, прогресс, затем «готово» или «ошибка» |

## Входы / Выходы

**Входы:** intent «Поделиться» с одним или несколькими файлами (любого
типа); результат системного выбора файла; состояние tailnet от ядра (пиры, в
сети ли, владелец); состояние VPN и узла.

**Выходы:** передача Taildrop пиру; уведомление о прогрессе; результат в
этом уведомлении.

## Правила и инварианты

- Список пиров и «Send file…» подчиняются одному правилу: своё и в сети. На
  пира, ушедшего из сети во время выбора, ничего не отправляется; передача
  падает с уведомлением.
- При выключенном VPN или без работающего узла Tailscale (P7) экран отправки
  не предлагает пира и объясняет, что нужны VPN и узел Tailscale; ничего не
  откладывается на потом.
- Содержимое читается прямо из присланного источника и стримится в ядро;
  на телефоне ничего не копируется.
- Если Taildrop не включён в админке tailnet, экран говорит об этом вместо
  списка пиров.
- «Поделиться» с текстом и без файлов здесь не обрабатывается — см.
  [поделиться текстом](share-text.ru.md).

## Границы

- Отправки расшаренным машинам и устройствам других пользователей нет (сам
  Taildrop этого не позволяет).
- Очереди при выключенном VPN нет; сам повтор не делается.
- Отправке нужен поднятый сервис с этим узлом, то есть включённый VPN
  ([особенности сопровождения](../FEATURE.ru.md#особенности-сопровождения)).
- На устройстве не проверено.
