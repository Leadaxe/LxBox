# Каталог DNS-серверов — серверы шаблона, пресетов и свои по UDP, DoT, DoH и DoQ

Все DNS-серверы, которые могут попасть в конфиг, собраны в одном списке: здесь их включают, выбирают
канал, добавляют свои формой или JSON и переопределяют шаблонные.

| Поле | Значение |
|------|----------|
| Фича | [005-DNS](../FEATURE.ru.md) |
| Обещания | P1 P2 P3 P4 P10 |
| Состояние | ✅ написана по коду, 2026-09-28 |

## Что делает

Показывает все DNS-серверы, которые могут попасть в конфиг, одним списком
и даёт ими управлять: включать и выключать, выбирать канал (`detour`) и
адрес из вариантов шаблона, добавлять свои серверы формой или JSON'ом,
переопределять шаблонные, переименовывать без разрыва ссылок.

## Параметры

| Вид | Откуда | Что правит пользователь |
|---|---|---|
| Шаблонный (бейдж «Template») | каталог шаблона | вкл/выкл, описание, переменные сервера (`outbound`, IP из списка, резолвер имени) |
| Пресетный («Preset») | активный пресет | ничего здесь; параметры — в правиле пресета |
| Свой («User») | пользователь | всё: тег, описание, вкл/выкл, форма и JSON |
| Переопределение («Overridden») | свой с тегом шаблонного/пресетного | всё + «Reset to default» |

Форма своего сервера — тип: `udp` (53), `tls` (853), `https` (443),
`quic` (853), `h3` (443), `group`, `tailscale`. Поля: адрес, порт (пусто —
порт типа по умолчанию, ключ не пишется), путь (`https`/`h3`), SNI,
резолвер имени (для адреса-имени), канал «Outbound (detour)» — Direct или
активное Направление. Прочие типы ядра (`local`, `tcp`, `fakeip`, `hosts`,
…) — только JSON-вкладкой; форма для них не рисуется.

Каталог шаблона: `local_dns_resolver` (System DNS), `google_udp`,
`google_dot` (через `vpn-1`), `google_doh`, `cloudflare_udp`,
`cloudflare_dot` (через `vpn-1`), `safe_dns_dot` (выкл; Quad9 / AdGuard /
AdGuard Family), `opendns_udp`, `opendns_doh`, `quad9_doh` (через `vpn-1`),
`yandex_dot`, группа `dns_shield`.

## Входы / Выходы

**Входы:** записи серверов, каталог шаблона, серверы активных пресетов,
активные Направления, узлы Tailscale, ссылки правил маршрутизации.
**Выходы:** `dns.servers[]` с синтезированным `tag`, без служебных полей
(`description`, `enabled`); предупреждения сборки.

## Правила и инварианты

- Досбор: новый шаблонный сервер появляется с `enabled` шаблона, новый
  пресетный — включённым; запись, чей шаблон или пресет исчез, удаляется;
  свои — никогда. Порядок пользователя сохраняется; на экране — шаблонные,
  затем пресетные, затем свои.
- Переменные: значение пользователя (после обрезки пробелов) →
  `default_value` → ключ выпадает. Имя, не объявленное ни сервером, ни
  шаблоном, — ключ выпадает с предупреждением. Адресный тип без адреса после
  подстановки не эмитится.
- `detour`: Direct / `direct-out` / пусто — ключа нет. Канал, которого нет в
  конфиге, — сервер не эмитится, предупреждение «dropped: its detour … is
  not in the config», ссылки лечатся политикой отказа (P2). У `group` и
  `tailscale` `detour` снимается всегда.
- Адрес-имя в форме автоматически получает резолвер имени (`google_udp`,
  иначе первый доступный); IP-адрес его теряет. Вставка `https://host/path`
  раскладывается на адрес, путь и режим DoH (DoH3 сохраняется).
- Сервер, на который ссылается активный пресет или правило маршрутизации с
  DNS-опцией, эмитится независимо от выключателя; в UI — замок «used by …»,
  удаления нет (P3). Выключенный пресет не даёт серверов (P4).
- Сохранение: пустой тег, невалидный JSON, пустой адрес (кроме группы и
  `tailscale`), `tailscale` без узла — снекбар, сохранения нет.
  Переименование в занятый тег — запрет; новый сервер с занятым тегом —
  диалог «Replace?».
- Переименование каскадит тег в ссылки (P10). Удаление — с подтверждением.
- Переопределение сбрасывается к исходному виду с тем же `enabled`.
- `tailscale`: висячий `endpoint` или второй сервер на тот же узел — сервер
  выпадает с предупреждением.
- JSON-вкладка у шаблонного/пресетного — только просмотр итогового тела и
  записи хранения.

## Границы

- Переменные пресетных серверов и сам пресет — [004-ROUTING](../../004-ROUTING/FEATURE.ru.md).
- Узлы Tailscale — вне фичи; здесь только тип сервера.
- Поля `tls`, кроме SNI (ALPN, сертификаты, `insecure`), — только JSON; SNI
  из формы перезаписывает весь `tls` (дефект §530).
- Разового теста латентности серверов нет (§365).
