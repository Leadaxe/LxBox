# Кэш DNS — размер, устаревшие ответы, хранение и сброс

Пользователь задаёт, сколько DNS-ответов держит ядро, отдаёт ли оно устаревшие ответы с фоновым
обновлением и переживает ли кэш перезапуск, и может очистить кэш.

| Поле | Значение |
|------|----------|
| Фича | [005-DNS](../FEATURE.ru.md) |
| Обещания | P13 P14 |
| Состояние | ✅ написана по коду, 2026-09-28 |

## Что делает

Управляет кэшем ответов ядра: сколько ответов держать, отвечать ли из
кэша сразу с фоновым обновлением, переживает ли кэш перезапуск. Даёт
разовое действие — сбросить кэш целиком, когда он «застрял».

## Параметры

| Настройка | Переменная шаблона | Значения | Умолчание | Ключ ядра |
|---|---|---|---|---|
| DNS cache size | `dns_cache_capacity` | 1024..65535 | 4000 | `dns.cache_capacity` |
| Serve stale answers | `dns_optimistic` | вкл/выкл | вкл | `dns.optimistic` |
| Keep DNS cache after restart | `dns_store_cache` | вкл/выкл | вкл | `experimental.cache_file.store_dns` |
| Clear DNS cache | — | действие с подтверждением | — | удаляет `cache.db` |

Кэш-файл (`experimental.cache_file`, `path: cache.db`) включён всегда;
`store_fakeip: true` — всегда.

## Входы / Выходы

**Входы:** ввод на экране DNS, сохранённые переменные, состояние туннеля.
**Выходы:** три ключа конфига; удалённый `cache.db`; перезагрузка ядра
при поднятом туннеле; снекбар с результатом.

## Правила и инварианты

- Переменная не задана или сохранена вне границ — действует умолчание
  шаблона (4000, вкл, вкл); экран показывает то же.
- Ввод размера вне 1024..65535 — ошибка «Range 1024..65535» под полем,
  значение не сохраняется и в конфиг не попадает. Границы включительны.
- Любое изменение трёх настроек помечает конфиг к пересборке.
- Clear DNS cache:
  - диалог объясняет последствие: при поднятом туннеле — «The VPN will
    briefly reload to apply», иначе — «It will be rebuilt clean on the next
    connect»;
  - удаляется весь `cache.db`: выдачи FakeIP, сохранённые записи DNS и
    прочее, что ядро в нём держит;
  - туннель поднят — ядро перезагружается (связь прерывается на несколько
    секунд); туннель опущен — только удаление файла;
  - результат: «DNS cache cleared — reloading» / «DNS cache cleared» /
    «Could not clear DNS cache».
- Сброс — действие, а не настройка: пересборку конфига не вызывает.

## Границы

- Время жизни записей, стратегия устаревших ответов — поведение ядра.
- Удаление файла и перезагрузка ядра зависят от возможностей ОС.
- Сброс кэша ядра при сбое приложения — [013-DIAGNOSTICS](../../013-DIAGNOSTICS/FEATURE.ru.md).
