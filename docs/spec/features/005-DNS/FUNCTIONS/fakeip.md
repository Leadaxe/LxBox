# FakeIP

| Поле | Значение |
|------|----------|
| Фича | [005-DNS](../FEATURE.md) |
| Обещания | P6 P11 P12 |
| Состояние | ✅ написана по коду, 2026-09-28 |

## Что делает

Отвечает приложению на запрос имени мгновенно — подставным адресом из
служебного пула, не ходя в сеть; реальное имя ядро вспоминает по этому
адресу и резолвит уже внутри туннеля по маршруту. Даёт скорость DNS и
убирает DNS-запросы до туннеля. Обходом DPI не является — это сказано в
описании пресета.

## Параметры

Пресет «FakeIP» (выключен по умолчанию):

| Переменная | Видна | Смысл | Умолчание |
|---|---|---|---|
| `dns_enable` («DNS») | да | FakeIP-обработка вкл/выкл без удаления пресета | вкл |
| `force` («Block HTTPS records») | да | на `HTTPS`/`SVCB` отвечать пусто, чтобы приложение взяло A/AAAA | вкл |
| `dns_server` | нет | сервер-выдатчик | `fakeip` |

Отдаёт ядру:

- сервер `{type: fakeip, tag: fakeip, inet4_range: 198.18.0.0/15, inet6_range: fc00::/18}`
  (в конфиге — в пространстве пресета);
- правила: при `force` — `{query_type: [HTTPS, SVCB], action: predefined, rcode: NOERROR}`,
  затем `{query_type: [A, AAAA], server: <fakeip>}`;
- `experimental.cache_file.store_fakeip: true` (всегда, в шаблоне) —
  выдачи переживают перезапуск.

## Входы / Выходы

**Входы:** включение пресета, его переменные.
**Выходы:** сервер и правила в конфиге; переменная `resolve_enabled`
глобального «Resolve destination IP».

## Правила и инварианты

- Включение пресета при включённом `dns_enable` ставит
  `resolve_enabled=false`: реальный резолв назначения обошёл бы FakeIP и
  мог упасть на сломанном резолвере. Выключение пресета или его DNS —
  `resolve_enabled=true` (P12).
- Сервер `fakeip` не допускается под `dns.final`, резолвером ядра и членом
  группы: пикеры его не предлагают, иначе — fatal до старта (P6). В
  DNS-правиле он законен.
- `query_type` в правилах FakeIP переводит ядро в не-легаси DNS-режим;
  `strategy` в любых DNS-правилах снимается (P11).
- Место FakeIP относительно других DNS-правил — место пресета в порядке
  маршрутизации (атомарная группа зеркал); описание пресета советует
  ставить его ниже особых доменов, чтобы прямая маршрутизация по GeoIP
  продолжала работать.
- «Clear DNS cache» сбрасывает и выдачи FakeIP.

## Границы

- Тумблер «Resolve destination IP» и «Hijack DNS» — пресет Traffic
  Processing, [004-ROUTING](../../004-ROUTING/FEATURE.md); без Hijack DNS
  FakeIP не работает (подсказка тумблера это говорит).
- Отображение подставных адресов в соединениях — [012-LIVE_STATE](../../012-LIVE_STATE/FEATURE.md).
