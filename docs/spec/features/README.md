# FEATURES — фичи L×Box

Каталог фич пишется заново по образцу Spec Kit ядра
([sing-box-lx/SPECS/FEATURES](https://github.com/Leadaxe/sing-box-lx/tree/lx/SPECS/FEATURES)).

Фича здесь — **чёрный ящик**: зачем существует, что обещает пользователю, какие
принципы защищает, где границы. Кода, имён файлов, классов и платформенных
механизмов в этой папке нет: если приложение переписать на другой платформе, папка
переносится целиком и меняется только тогда, когда меняется поведение для
пользователя. Реализация живёт в задачах — [`../tasks/`](../tasks/README.md).

## Раскладка

```
features/
├── README.md                 # индекс фич, шаблон, соглашения
└── NNN-NAME/
    ├── FEATURE.md            # фича: назначение, обещания, параметры, входы/выходы, границы, функции
    └── FUNCTIONS/
        └── <function>.md     # одна функция: что делает, параметры, инварианты, таблица ревизий
```

Старые спеки фич (до Spec Kit) — задачи с индексом `F`:
[`../tasks/F-INDEX.md`](../tasks/F-INDEX.md).
