# Изоляция переключения — без хвостов прежнего набора

После переключения набора незавершённые операции прежнего не могут писать в
новый, а каждый набор сохраняет свои личности Tailscale.

| Поле | Значение |
|------|----------|
| Фича | [018-WORKSPACES](../FEATURE.ru.md) |
| Обещания | P8, P12 |
| Состояние | ✅ написана по коду, 2026-09-28 |

## Что делает

Гарантирует, что после переключения на сцене живёт ровно один набор:
незавершённые операции прежнего набора не записывают его состав в новый, а
узлы Tailscale каждого набора сохраняют свою личность.

## Параметры

Ручек нет.

## Входы / Выходы

**Входы:** переключение набора в момент, когда идёт автообновление подписок,
летит ответ сервера подписки, выполняется правка списка (вкл/выкл узла,
перенос, переименование) или восстановление узлов из кэша тел.

**Выходы:** запись прежнего набора отброшена, в журнале
`workspaces: persist skipped …` / `workspaces: fetch result dropped …`;
новый набор не поднимает «конфиг устарел» из-за чужого хвоста.

## Правила и инварианты

- **Гонка 515.** Список источников записывается целиком; без барьера
  опоздавшая запись прежнего набора заменяла им состав нового, а ближайшая
  загрузка закрепляла подмену в слоте — одна подписка расходилась по всем
  наборам.
- **Барьер у владельца списка источников.** Экземпляр, переживший смену
  набора или уже закрытый, не пишет ничего и не поднимает признак «конфиг
  устарел». Экземпляр текущего набора пишет как обычно.
- **Ранний выход после сети.** Ответ подписки, пришедший после
  переключения, отбрасывается до разбора — ни узлов, ни статуса «обновлено».
- **Автообновление прерывается до копирования.** Идущий проход выходит на
  ближайшей проверке (пауза между подписками прерывается за четверть
  секунды); новых проходов прерванный экземпляр не начинает.
- **Писатели вне экрана не ограничены** — импорт бэкапа, Debug API, шаги
  перечитывания пишут в сцену штатно.
- **Tailscale.** Каталоги состояния узлов в слот не копируются: у каждого
  слота свой набор записей «узел → каталог». «Save as» копирует записи
  текущего в новый слот, Rename переносит, Delete снимает только каталоги без
  ссылок других слотов. Сбой индекса операцию набора не останавливает.
  Подробно — [030-TAILSCALE](../../030-TAILSCALE/FUNCTIONS/device-identity-and-state.ru.md).

## Границы

- Слоты, уже испорченные до исправления, не лечатся — только из бэкапа.
- Барьер на уровне хранения (эпоха набора у каждого писателя) не сделан —
  follow-up 515.
- Выдача каталогов состояния Tailscale узлам при сборке — [003-CONFIG_BUILD](../../003-CONFIG_BUILD/FEATURE.ru.md);
  фича ведёт только наборы записей по слотам.
