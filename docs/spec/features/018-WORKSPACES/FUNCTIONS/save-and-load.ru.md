# Сохранение и загрузка набора — Save as и Load без потери положения туннеля

LxBox сохраняет текущее состояние под именем через «Save as…»; загрузка другого
слота сначала сохраняет текущий, затем пересобирает конфиг и возвращает туннель
в прежнее положение.

| Поле | Значение |
|------|----------|
| Фича | [018-WORKSPACES](../FEATURE.ru.md) |
| Обещания | P1–P7, P11, P13, P14 |
| Состояние | ✅ написана по коду, 2026-09-28 |

## Что делает

«Save as…» кладёт копию текущего состояния под имя и делает этот слот
текущим. Тап по другому слоту в разделе Load сохраняет сцену в текущий слот
и выкладывает выбранный на сцену; конфиг пересобирается из нового набора,
туннель возвращается в прежнее положение. Отдельной кнопки «Save» нет.

## Параметры

| Что | Значение |
|-----|----------|
| Состав слота | файл настроек · скачанные rule-set · кэш тел подписок |
| Не в слоте | собранный конфиг · база кэша ядра · тема · журналы · отчёты о сбоях · служебные копии и временные файлы · каталоги состояния Tailscale |
| Предложенное имя в «Save as» | имя текущего, если у него ещё нет копии; иначе пусто |

## Входы / Выходы

**Входы:** выбор слота или имени в попапе; положение туннеля; журнал
незавершённой загрузки на старте.

**Выходы:** сцена выбранного слота; пересобранный конфиг; туннель поднят
снова, если был поднят; снек «Workspace “X” loaded» / «Saved as “X”»;
модальный индикатор «Loading workspace…».

## Правила и инварианты

- **Порядок загрузки:** стоп автообновления подписок и проб → стоп туннеля
  → сброс настроек на диск → журнал → сцена в текущий слот → цель на сцену →
  текущий = цель, журнал снят → признак «конфиг устарел» → перечитать
  состояние (язык, зеркало тумблеров, миграции Направлений, события
  автоматизации) → новый главный экран → пересборка → старт, если был поднят.
- **Копия зеркальна.** Слот после сохранения равен сцене: позиции, которых
  на сцене нет, из слота удаляются; папки копируются заново целиком; файл
  на сцене никогда не бывает полузаписанным.
- **Запасная копия настроек снимается** после загрузки — это снимок прежнего
  слота.
- **Старт после загрузки — только на своём конфиге.** Если пересборка не
  удалась и конфиг остался «устаревшим», туннель не поднимается; в журнале
  «auto-connect skipped». Старт идёт тем же путём, что кнопка Start, — через
  страховку отвергнутых ядром узлов.
- **Доводка.** Журнал `load` на старте повторяет шаги целиком (они
  идемпотентны) до первого чтения настроек и поднимает признак «конфиг
  устарел». Цели нет — журнал снимается, сцена остаётся.
- **Save as** не трогает туннель и ничего не перечитывает. Имя уже есть —
  диалог «Overwrite “Y”?»; согласие заменяет слот целиком.
- **Старая форма хранения.** Слот, сохранённый до контракта хранения 1.0,
  при загрузке получает копию исходного файла настроек рядом (если её нет);
  сцена мигрирует при чтении; «Save as» пишет уже новую форму. Спящие слоты
  не мигрируют.
- Ошибки: слот исчез — «Workspace not found»; иное — «Failed to load
  workspace: …». Индикатор снимается в любом случае.
