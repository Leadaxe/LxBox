# Управление слотами

| Поле | Значение |
|------|----------|
| Фича | [018-WORKSPACES](../FEATURE.ru.md) |
| Обещания | P9, P10 |
| Состояние | ✅ написана по коду, 2026-09-28 |

## Что делает

Показывает, какие наборы есть и какой сейчас на сцене, и даёт их
переименовать или удалить. Отдельного экрана управления нет — всё в попапе
кнопки набора на главном экране.

## Параметры

| Параметр | Правило |
|----------|---------|
| Имя | обрезаются пробелы; не пустое; ≤ 64 символов; без `/`, `\`, управляющих символов и DEL; не начинается с точки (в т. ч. `.` и `..`) |
| Регистр | имена различаются с учётом регистра |
| «Default» | имя текущего до первого «Save as»; показывается локализованно, имена пользователя — как есть |

## Входы / Выходы

**Входы:** попап «Workspaces»; меню «⋮» строки слота: Rename, Delete; диалог
имени с проверкой на лету.

**Выходы:** справочник наборов; в разделе Load — слоты по алфавиту без
учёта регистра, отметка текущего, у каждого относительная дата сохранения и
размер на диске; имя текущего на кнопке.

## Правила и инварианты

- **Проверка имени на лету.** Кнопка «Save» диалога недоступна при
  невалидном имени; текст причины: «Name is empty», «Name is too long»,
  «Name must not contain / or \», «Name must not start with a dot».
- **Rename** переименовывает слот вместе с его копией; если это текущий —
  текущий получает новое имя. Занятое имя — «A workspace with this name
  already exists». Личности Tailscale слота переезжают вместе с ним.
- **Delete** — после подтверждения «Delete workspace “X”?» («This cannot be
  undone»); удаляет копию и запись. Текущий удалить нельзя: пункт недоступен,
  попытка в обход — «The current workspace cannot be deleted».
- **Текущий без копии** (до первого «Save as») показан первым, без даты и без
  меню «⋮» — переименовывать и удалять нечего.
- **Тап по текущему** закрывает попап без действия.
- Справочник нечитаем — считается отсутствующим: «Default», слотов нет.

## Границы

- Удалённый слот не восстанавливается; корзины нет.
- Переименовать «Default» до первого «Save as» нельзя — у него нет копии.
