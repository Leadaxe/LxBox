# Workspaces — именованные наборы настроек VPN с переключением в один тап

Workspaces в LxBox хранят несколько именованных наборов настроек VPN — например,
«дом», «работа» и «эксперимент» — и переключают их одним тапом. Набор содержит
всё, из чего собирается конфиг sing-box: подписки, Направления, правила
маршрутизации, DNS, приложения туннеля, режим VPN и язык. При переключении
приложение сохраняет текущий набор, пересобирает конфиг и снова поднимает
туннель, если он был поднят.

| Поле | Значение |
|------|----------|
| Фича | 018-WORKSPACES |
| Тип | Продуктовая фича |
| Поглотила | `§417F` |
| Состояние | ✅ написана по коду, 2026-09-28 |

## Назначение

Несколько миров — «дом», «работа», «эксперимент» — с переключением без
ручного разбора конфигурации. Набор (workspace) — именованная копия **всего
состояния, из которого собирается конфиг**: подписки и их тела, Направления,
правила, DNS, переменные, приложения туннеля, режим VPN, язык, Debug API.

Модель — слоты сохранения. **Сцена** — рабочее состояние приложения, одно.
**Слот** — сохранённая копия сцены под именем. **Текущий** — имя слота,
который сейчас на сцене; до первого использования это «Default» без копии.
Кнопки «Save» нет: загрузка другого слота сама сохраняет сцену в текущий.

Принципы: **терять нечего** — переключение сначала сохраняет сцену,
подтверждение только при перезаписи слота через «Save as»; **один мир на
сцене** — хвосты прежнего набора не пишут в новый; **кто не пользуется — не
платит** — без первого «Save as» на диск ничего не пишется.

## Обещания

- **P1. Состав слота фиксирован.** В слот входят файл настроек, скачанные
  rule-set и кэш тел подписок; не входят собранный конфиг, база кэша ядра,
  тема, журналы, отчёты о сбоях, служебные копии. Свидетель: юнит «saveAs
  копирует все три позиции, current = имя, дата записана». Мутация: конфиг
  ядра в слоте (подменённый на диске конфиг ядро не увидит).
- **P2. Без использования — без следов.** Нет справочника — текущий
  «Default», слотов нет, диск не трогается. Свидетель: юнит «дефолт:
  current=Default, слотов нет, диск не трогается». Мутация: справочник
  создаётся при старте.
- **P3. Загрузка сохраняет сцену перед заменой.** Сцена уходит в текущий
  слот (у «Default» копия появляется при первой загрузке), затем цель
  приходит на сцену целиком. Свидетель: юниты «сцена уходит в current, цель
  приходит на сцену, .bak снят», «первая загрузка без папки у current
  создаёт «Default»». Мутация: загрузка без сохранения текущего.
- **P4. Загрузка текущего — ничего не делает** (туннель не трогается).
  Свидетель: юниты «load current → alreadyCurrent: стоп не зовётся»,
  «load current → no-op, файлы не трогаются». Мутация: стоп туннеля.
- **P5. Туннель переживает переключение.** Был поднят — опускается, конфиг
  пересобирается из нового набора, туннель поднимается снова; не был — не
  поднимается. Свидетель: юниты «load другого: стоп → файлы → … флаг
  автозапуска один раз», «VPN был опущен → автозапуска нет». Мутация:
  автозапуск при опущенном туннеле.
- **P6. После загрузки конфиг — от нового набора.** Свидетель: юниты
  «загрузка слота → configDirty → сборка из настроек нового слота», «init не
  опускает флаг процесса при выровненном mtime». Мутация: признак «конфиг
  устарел» только по времени изменения файлов.
- **P7. Прерванная загрузка доводится.** Убийство процесса посреди
  копирования → на следующем старте, до любого чтения настроек, шаги
  повторяются; исчезнувшая цель — журнал снимается, сцена как есть.
  Свидетель: юниты «pending load → повтор шагов», «pending с исчезнувшей
  целью → журнал снят», контракт «recover before any settings read».
  Мутация: доводка после первого чтения настроек.
- **P8. Хвост прежнего набора не пишет в новый.** Свидетель: юниты
  «РЕГРЕСС (а)…(в)», «контроллер ТЕКУЩЕГО поколения пишет как обычно».
  Мутация: снять барьер записи — подписки одного набора во всех.
- **P9. Имя слота — безопасное имя папки.** Свидетель: юниты «правила
  имени = имени папки», «saveAs с плохим именем → invalidName, ничего не
  создано». Мутация: имя `..` проходит.
- **P10. Текущий не удаляется; имя не занимается дважды.** Свидетель: юниты
  «delete current → isCurrent…», «rename в занятое имя → exists», «rename
  current переименовывает папку и current». Мутация: удаление текущего.
- **P11. «Save as» в существующее имя заменяет слот целиком** — после
  подтверждения «Overwrite». Свидетель: юнит «повторный saveAs в то же имя
  перезаписывает слот целиком»; диалог — ручная проверка. Мутация: слияние.
- **P12. Личности Tailscale у каждого слота свои.** Свидетель: юниты «Save
  as → сборка другого слота → Load → Rename → Delete», «без индекса Tailscale
  операции Workspaces файлов не создают». Мутация: каталоги состояния
  копируются в слот.
- **P13. Слот старой формы хранения грузится.** Свидетель: юниты «загрузка
  слота 2.23.2: сцена мигрирует, исходник слота — копией…», «слот текущей
  формы копии не получает». Мутация: исходник теряется.
- **P14. Битый справочник = отсутствующий.** Свидетель: юнит «битый
  справочник читается как отсутствующий». Мутация: падение старта.

## Контролируемые параметры

| Ручка | Значения | Дефолт |
|-------|----------|--------|
| Имя слота | 1–64 символа после обрезки пробелов; без `/`, `\`, управляющих символов, без ведущей точки; сравнение с учётом регистра | предложено «Default», пока у текущего нет копии; иначе пусто |

Ключей конфига ядра фича не отдаёт: конфиг собирается из сцены штатно
([003-CONFIG_BUILD](../003-CONFIG_BUILD/FEATURE.ru.md)).

## Входы / Выходы

**Входы:** кнопка с именем текущего набора справа от «L×Box» на главном
экране; попап «Workspaces»: раздел Load (слоты по алфавиту, отметка
текущего, дата сохранения и размер, меню «⋮» — Rename / Delete) и раздел
Save («Save as…»); старт приложения (доводка журнала).

**Выходы:** сцена нового набора; пересобранный конфиг; туннель в прежнем
положении; снеки «Workspace “X” loaded», «Saved as “X”», тексты ошибок;
модальный индикатор «Loading workspace…» на время загрузки.

## Data flow

```
Load X:  стоп пробы и автообновления → стоп туннеля (запомнить «был поднят»)
         → сброс настроек на диск → журнал {load X}
         → сцена → слот текущего → слот X → сцена → текущий = X, журнал снят
         → признак «конфиг устарел» → перечитать состояние, пересоздать главный экран
         → пересборка конфига → если туннель был поднят и сборка удалась — старт
Save as Y: сброс на диск → сцена → слот Y → текущий = Y (туннель не трогается)
```

## Правила и гарантии

- Операции над слотами — строго по одной; кнопка набора недоступна, пока
  идёт загрузка. Перезапуск процесса не нужен: состояние перечитывается,
  главный экран создаётся заново.
- Запасная копия настроек после загрузки удаляется — это снимок прежнего
  слота, и восстановление из неё подменило бы набор.
- Туннель поднимается снова только если пересборка удалась; иначе старт
  пропускается (в журнале — причина).
- Обновления подписок, начатые до переключения, отбрасываются целиком; новый
  набор обновит свои подписки сам по своим триггерам.

## Границы

- Переключение из Intent API и автоматизаторов не поддержано; имени набора
  в уведомлении нет.
- Общих подписок между наборами нет (overlay-модель отвергнута).
- Резервная копия охватывает только сцену, не слоты; экспорт слота — загрузить
  его и сделать бэкап. Импорт бэкапа прямо в слот не поддержан —
  [017-BACKUP_AND_STORAGE](../017-BACKUP_AND_STORAGE/FEATURE.ru.md).
- Разрыв соединений на время переключения ожидаем: хот-свопа нет по
  построению (база кэша ядра, inbound'ы, приложения туннеля).
- Слоты, перезаписанные до исправления гонки 515, фича не восстанавливает.

## Связанные фичи

- [003-CONFIG_BUILD](../003-CONFIG_BUILD/FEATURE.ru.md) — после загрузки конфиг
  пересобирается из новой сцены штатной сборкой с её гейтами; сборка же выдаёт
  узлам каталоги состояния Tailscale.
- [010-VPN_SERVICE](../010-VPN_SERVICE/FEATURE.ru.md) — стоп и старт туннеля
  вокруг переключения.
- [017-BACKUP_AND_STORAGE](../017-BACKUP_AND_STORAGE/FEATURE.ru.md) — бэкап
  видит только сцену, не слоты; слоты старой формы хранения грузятся его
  миграцией.

## Особенности сопровождения

- **Новый файл состояния обязан быть классифицирован:** либо в состав слота,
  либо явно «свойство устройства». Иначе он молча станет общим для всех
  наборов.
- **Время изменения файлов — не признак.** Сброс на диск выравнивает его в ту
  же секунду; признак «конфиг устарел» после загрузки ставится явно (447).
- **Любой асинхронный писатель настроек, живущий дольше экрана, — кандидат
  на гонку 515.** Барьер стоит на уровне владельца подписок; писатели вне
  экрана (импорт бэкапа, Debug API) им намеренно не ограничены.
- **Доводка журнала — до первого чтения настроек**, иначе старая сцена из
  кэша ляжет поверх доведённого слота.
