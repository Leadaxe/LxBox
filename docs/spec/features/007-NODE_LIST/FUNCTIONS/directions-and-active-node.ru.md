# Направление и активный узел — какой узел несёт трафик и как его сменить

Главный экран показывает выбранное Направление и его активный узел и
переключает их в работающем ядре без перезапуска VPN-туннеля.

| Поле | Значение |
|------|----------|
| Фича | [007-NODE_LIST](../FEATURE.ru.md) |
| Обещания | P1, P2, P3, P17 |
| Состояние | ✅ написана по коду, 2026-09-28 |

## Что делает

Показывает, через какое **Направление** (selector-группу ядра) и какой узел
сейчас идёт трафик, и даёт переключить то и другое в работающем ядре.
Активный узел выделен и закреплён в верхней части списка.

## Параметры

| Параметр | Значения | Дефолт |
|---|---|---|
| Direction (выпадающий список) | все selector-группы снимка ядра, кроме `GLOBAL`; последним — псевдо-направление `NETWORKS`, если в конфиге есть такие узлы | `route.final`, если это selector; иначе первая |
| Interrupt connections on switch (Settings) | вкл/выкл | выкл |

Список Направлений включает не только Направления приложения, но и любые
выбираемые selector-группы конфига: провайдерский `selector` из подписки и
selector свёртки источника ([род и свёртка](selector-genus-and-fold.ru.md)).

## Входы / Выходы

**Вход:** поток и снимок групп ядра (тег, тип, члены, текущий выбор);
жесты — выбор в списке Направлений, кнопка ▷ у строки, «Use this node» в
меню, свайп вниз.
**Выход:** `SelectOutbound(группа, узел)` в ядре; при включённом тумблере —
`CloseConnection` для живых соединений, в цепочке которых есть это
Направление; для группы подписки или папки — сохранённый выбор члена.

## Правила и инварианты

- Выбирать узел и Направление можно только при поднятом туннеле: список
  Направлений и кнопки ▷ неактивны, пока VPN выключен или идёт операция.
- **Тап по строке только подсвечивает узел** (полоса слева, фон) — выбора
  не происходит. Выбор — кнопка ▷ или «Use this node».
- Выбор активного узла — пустая операция: ядро не вызывается, соединения не
  рвутся; внешнему автоматизатору уходит «уже активен».
- После выбора список сразу подсвечивает новый узел, затем тянет свежий
  снимок групп и ставит ACTIVE по ответу ядра. Если снимок не пришёл —
  ACTIVE ставится по выбору.
- Отказ ядра — ошибка «Switch failed: …»; прежний узел
  остаётся активным.
- Обрыв соединений при переключении — не дольше 5 с, соединение, уже
  закрывшееся, пропускается.
- **Закрепление:** активный узел стоит сразу после direct / двойников
  автовыбора / block при любой сортировке; если активен сам служебный узел,
  он не дублируется.
- Пустой снимок групп поверх непустого при живом туннеле — шум гонки,
  игнорируется. Свайп вниз тянет снимок заново; без ответа ядра остаётся
  текущий.
- Если выбранное Направление пропало из снимка (переименовано, выключено) —
  выбирается `route.final`, иначе первое.
- Смена Направления сбрасывает «замороженный» порядок сортировки
  ([сортировка](node-sorting.ru.md)) и переключает память фильтра
  ([фильтры](node-filters.ru.md)).
- `NETWORKS` — вид, а не выход трафика: показывает узлы вне списков выбора
  (например, Tailscale) в порядке конфига, без фильтра, сортировки и пинга;
  на месте задержки — состояние узла от ядра; нажатие открывает экран узла.
  Выбранное настоящее Направление при этом не меняется.
- Для группы автовыбора в строке видно «→ выбранный узел»; пункт меню
  «Select server» подсвечивает и прокручивает список к нему.

## Границы

- Выбор члена группы, не являющейся Направлением, с экрана узла — там же ([род
  группы](selector-genus-and-fold.ru.md)); сам экран узла —
  [008-NODE_EDITOR](../../008-NODE_EDITOR/FEATURE.ru.md).
- Автоматизаторы (переключить узел/Направление извне) —
  [014-AUTOMATION](../../014-AUTOMATION/FEATURE.ru.md).
- Выбор в селекторе Направления приложение между запусками VPN не хранит.
- Полоса трафика над списком — [012-LIVE_STATE](../../012-LIVE_STATE/FEATURE.ru.md).
