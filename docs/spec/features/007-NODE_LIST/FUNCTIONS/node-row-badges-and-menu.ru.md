# Строка узла: бейджи и контекстное меню

| Поле | Значение |
|------|----------|
| Фича | [007-NODE_LIST](../FEATURE.ru.md) |
| Обещания | P2 (кнопка ▷ у активного узла неактивна) |
| Состояние | ✅ написана по коду, 2026-09-28 |

## Что делает

Одна строка списка сообщает всё, что нужно для выбора: имя, активен ли
узел, протокол с транспортом и безопасностью, последний пинг с цветом,
состояние WireGuard-узла, уведомления о разборе. Долгое нажатие открывает
меню действий над узлом.

## Параметры

Своих настроек нет. Регекс значков пула задаётся на группе автовыбора
(по умолчанию — первый эмодзи-флаг имени), см. 006.

## Входы / Выходы

**Вход:** тег и тип узла из собранного конфига, транспорт и безопасность,
замер задержки, состояние endpoint-узла от ядра, уведомления источника и
сборки, выбранный член группы автовыбора.
**Выход:** строка высотой 56 и меню.

## Правила и инварианты

**Первая строка** — имя узла как есть (эмодзи-теги — часть имени). У
служебных узлов имя подменяется названием из шаблона с иконкой: Direct 🌐,
Auto ✨ (только двойник автовыбора Направления), Block ⛔; такие строки
слегка подкрашены. ⚠ после имени — узел, от которого зависят другие
(DNS, detour), а сам он мёртв; тап открывает список пострадавших.

**Вторая строка**, слева направо:

| Элемент | Когда | Вид |
|---|---|---|
| `ACTIVE` | узел выбран в Направлении | зелёная плашка; имя жирнее, полоса слева |
| Значок уведомлений | у узла есть уведомления | ⓘ / ⚠ / ⊗ по старшему уровню; тап — шторка уведомлений |
| Режим и выбор автовыбора | группа автовыбора | `🎯 [N] → узел` или `🔀 [N/M]` + значки пула (`🇩🇪, 🇳🇱[2]`) |
| Протокол·транспорт·безопасность | узел с протоколом | `VLESS·xhttp·Reality+Vision`, `WG·awg2`, `Hy2·TLS`; для автовыбора не показывается |
| Состояние WG/AWG | ядро отдало состояние endpoint | `up` / `sleep` / `down` / `off` (оранжевый) |
| Пинг | справа, всегда у края | `NNMS`, `ERR`, `PING…`; `~` — замер другого Направления, приглушён |

- Цвет пинга: < 200 мс — зелёный, < 500 — оранжевый, иначе и `ERR` —
  красный. У block пинга нет; у выключенного endpoint — «—».
- При нехватке ширины первым уступает протокол, выбранный член держится.
- Несовпавший с фильтром узел — прозрачность 0,4.

**Меню** (долгое нажатие):

| Пункт | Доступен |
|---|---|
| Ping | туннель поднят, не занят, не block |
| Use this node | туннель поднят, узел не активен |
| Run URLTest | группа автовыбора |
| Select server | у группы автовыбора есть выбранный — подсветить и прокрутить к нему |
| View pool | двойник автовыбора Направления в режиме round-robin |
| Turn off / Turn on | WG/AWG-узел, ядро отдало его состояние, туннель поднят |
| View details | всегда — экран узла |
| Copy URI | обычный узел; у служебных и групп автовыбора пункта нет |

- Нажатие по строке только подсвечивает её. Кнопка ▷ справа выбирает узел;
  у активного это ✓ и нажать нельзя.
- В `NETWORKS` нет Ping, Use this node и кнопки ▷.
- Copy JSON / detour перенесены в View details.

## Границы

- Замер, URLTest группы, ⚠ зависимостей, выключатель endpoint как
  механизм — 009-NODE_HEALTH; уведомления узла как данные — 001/002.
- Экран View details, Copy URI с подтверждением для ссылок с ключом — 008.
