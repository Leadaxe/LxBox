# Пустые состояния главного экрана

| Поле | Значение |
|------|----------|
| Фича | [007-NODE_LIST](../FEATURE.md) |
| Обещания | P11 |
| Состояние | ✅ написана по коду, 2026-09-28 |

## Что делает

Когда показать нечего, место списка занимает не пустота, а следующий шаг:
добавить сервер, подключиться или выбрать другое Направление.

## Параметры

Своих настроек нет.

## Входы / Выходы

**Вход:** состояние туннеля, сохранённый конфиг (число реальных узлов, без
служебных типов), наличие узлов в источниках, члены выбранного Направления.
**Выход:** один из экранов ниже на месте списка.

| Состояние | Что видно | Действие |
|---|---|---|
| VPN выключен, **реальных серверов нет** (ни в конфиге, ни в источниках) или конфига нет | «Add a server» + «Connect a subscription or add a node manually to get started.»; кнопка «+»; «Restore from backup» | «+» — экран источников; восстановление из бэкапа |
| VPN выключен, серверы есть | крупная зона «Tap to connect» | тап = та же кнопка Start (неактивна во время запуска/остановки) |
| VPN поднят, в выбранном Направлении нет узлов | «No nodes in this direction. Try another one.» | — |
| VPN поднят, конфиг пуст (сбой загрузки) | «Add a server» | как в первой строке |

## Правила и инварианты

- «Нет серверов» считается по реальным узлам, а не по файлу конфига:
  конфиг из шаблона несёт служебные узлы (direct, Направления), и по ним
  экран выглядел бы непустым.
- Узел, только что добавленный в источник, но ещё не попавший в
  пересобранный конфиг, подсказку уже снимает.
- Сырой импорт конфига без записей источников подсказку тоже снимает — его
  узлы видны в конфиге.
- При поднятом туннеле подсказка «Add a server» не показывается никогда,
  кроме аварийного «конфиг не загрузился» — у остальных состояний «up»
  свои плашки.
- При выключенном VPN заголовка «Nodes», сортировки, фильтра и полосы
  трафика нет — фильтровать нечего.
- VPN поднят, настоящих Направлений нет, но есть узлы вне списков выбора —
  вместо пустоты показывается `NETWORKS`.
- Для проверки вида пустого экрана без потери данных есть режим
  предпросмотра пустого состояния в Debug API; он подменяет только вид.

## Границы

- Экран источников и добавление — [001-SUBSCRIPTIONS](../../001-SUBSCRIPTIONS/FUNCTIONS/add-source.md).
- Восстановление из бэкапа — 017; первый запуск и мастер — 020.
- Плашки ошибок старта и «Config changed — restart VPN» — 010/003.
