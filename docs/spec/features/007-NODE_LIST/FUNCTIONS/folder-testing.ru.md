# Тест папки

| Поле | Значение |
|------|----------|
| Фича | [007-NODE_LIST](../FEATURE.ru.md) |
| Обещания | P15, P16 |
| Состояние | ✅ написана по коду, 2026-09-28 |

## Что делает

Проверяет пачку серверов папки **без запуска VPN**: поднимает временную
сессию ядра только с узлами папки, меряет каждый и показывает задержку с
цветом по порогам. По результату можно разом выключить медленные, выключить
или удалить недоступные, упорядочить по пингу. Тот же тест, без удаления и
сортировки, есть на экране подписки.

## Параметры

| Параметр | Где | Значения | Дефолт |
|---|---|---|---|
| Ping URL & timeout… | long-press кнопки теста; «Shared with the home screen ping» | URL (пусто = умолчание ядра), мс | глобальные; timeout 3000 мс |
| Ping color thresholds… | там же | «Green up to», «Yellow up to», «Orange up to», мс; выше — красный | 250 / 500 / 700 |
| Disable slower than… | меню «Test actions» | мс | оранжевый порог |

Пороги хранятся как настройки приложения и едут в бэкапе; в конфиг ядра не
идут.

## Входы / Выходы

**Вход:** члены папки — все, включая выключенных; для подписки — её узлы.
**Выход:** бейдж у каждого члена и сводка над списком («Testing… N done»,
«N ok», «N off»); массовые правки папки (выключение, удаление, порядок) —
это обычные правки источника с пересборкой конфига.

| Бейдж | Смысл |
|---|---|
| `123 ms` | ответил; цвет по порогам (включительно) |
| `err` | замер не удался; тап — текст ошибки |
| `broken` | член не разбирается — вердикт до ядра |
| `invalid` | узел не собрался в запись ядра |
| `auto` | группа автовыбора — не тестируется |

## Правила и инварианты

- **VPN поднят — тест не стартует.** Диалог «VPN is running» с «Stop VPN»
  (остановка, затем прогон) и «Cancel». Если VPN запустился между проверкой
  и стартом сессии — тот же диалог. Одновременно работает одна сессия ядра.
- Тестовая сессия — без tun и без маршрутов: только узлы папки с голыми
  тегами (без префикса), их собственные detour-цепочки и локальный DNS.
  Detour-политика папки не применяется — меряется узел, а не маршрут
  Направления.
- Меряется до 6 узлов параллельно. Узлы, тяжёлые по памяти, разбиваются на
  последовательные запуски: не больше 1 naive и 4 WireGuard/AWG-записей на
  запуск (цепочка узла неделима).
- Группы автовыбора не тестируются; папка из одних групп — теста нет.
- Результаты привязаны к узлу (по его тегу), а не к строке: перестановка и
  удаление соседей их не сдвигают; переименование — новый узел.
- Результаты живут только на экране и не сохраняются.
- Тест прерывается при сворачивании приложения и при остановке туннеля
  (массовый пинг главного экрана сворачивание переживает).
- **Test actions** (меню всегда на месте, пункты серые до первого
  результата):
  - «Disable slower than…» — выключить ответивших медленнее порога;
  - «Disable unreachable» — выключить `err`/`broken`/`invalid`;
  - «Delete unreachable» (только папка) — удалить их, с подтверждением;
  - «Sort by ping» (только папка) — ответившие по возрастанию, затем
    непроверенные и группы, затем ошибки; равные — в прежнем порядке.
- На экране подписки — общий переключатель всех узлов в одном столбце с
  переключателями строк.
- Кнопка фильтра в полосе теста: регекс + протоколы; при активном фильтре
  перетаскивание членов выключено.

## Границы

- Пинг через работающее ядро на главном экране, URLTest групп — 009.
- Выключение узлов подписки как отметка — [001](../../001-SUBSCRIPTIONS/FUNCTIONS/node-disable.ru.md).
- Способность ОС держать вторую сессию ядра рядом с VPN — не поддерживается.
