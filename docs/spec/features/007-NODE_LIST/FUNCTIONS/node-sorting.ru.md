# Сортировка и ручной порядок — как упорядочить список узлов

Список узлов идёт в порядке конфига, по пингу, по имени или в своём порядке
перетаскиванием, а на широком экране раскладывается в две колонки.

| Поле | Значение |
|------|----------|
| Фича | [007-NODE_LIST](../FEATURE.ru.md) |
| Обещания | P3, P4, P9, P10 |
| Состояние | ✅ написана по коду, 2026-09-28 |

## Что делает

Упорядочивает список Направления: как в конфиге, по пингу, по имени или в
своём порядке, заданном перетаскиванием. Служебные узлы и активный узел
держатся сверху отдельной секцией. На широком экране список раскладывается в
две колонки.

## Параметры

| Параметр | Где | Значения | Дефолт | Живёт |
|---|---|---|---|---|
| Режим | тап по кнопке сортировки — по кругу; шторка «Sort options» (long-press) — выбор | Default → Ping → A–Z → Custom → Default | Ping | сохраняется |
| Ручной порядок | перетаскивание строки | список тегов | пусто | сохраняется |
| Pin DIRECT to top | «Sort options» | вкл/выкл | вкл | сессия |
| Pin AUTO to top | «Sort options» | вкл/выкл | вкл | сессия |
| Re-sort on manual ping | «Sort options» | вкл/выкл | вкл | сессия |
| Two columns on wide screens | App Settings → Appearance | вкл/выкл | вкл | сохраняется |

Иконка кнопки показывает режим; жёлтая точка — когда хотя бы один из трёх
тумблеров не в значении по умолчанию. Без узлов кнопка неактивна.

## Входы / Выходы

**Вход:** члены Направления в порядке конфига, типы узлов, активный узел,
замеры (свои и из других Направлений), жест перетаскивания.
**Выход:** порядок строк на экране и порядок массового пинга; сохранённые
режим и ручной порядок (конфиг изменённым не помечают).

## Правила и инварианты

- **Закреплённая секция** сверху, в порядке: direct (если «Pin DIRECT»),
  двойники автовыбора Направлений (если «Pin AUTO»), block (всегда), затем
  активный узел (всегда). Закрепление — по типу узла. Узел автовыбора
  подписки/папки не закрепляется. Режим Default с выключенными тумблерами
  даёт чистый порядок конфига (block и активный узел — всё равно сверху).
- **Ping:** по возрастанию той задержки, что видна в строке (включая
  приглушённую «~» из другого Направления); затем ошибки; неизмеренные — в
  конце.
- **A–Z:** по имени без учёта регистра.
- **Custom:** сохранённый порядок, отфильтрованный по текущему составу;
  узлы, которых в нём нет (новые), — в конец в порядке конфига. Порядок один
  на все Направления.
- **Перетаскивание** в режиме Custom — за видимую полосу слева, сразу; в
  других режимах — долгим нажатием у левого края строки; любое завершённое
  перетаскивание переводит режим в Custom и сохраняет видимый порядок.
  Закреплённые строки не двигаются, бросить строку в закреплённую секцию
  нельзя.
- Уход из Custom (тапом или выбором) порядок **не стирает**: возврат в
  Custom восстанавливает его.
- **Re-sort on manual ping выключен:** одиночный пинг не двигает строки;
  порядок пересчитывается после массового пинга, смены Направления,
  пересборки конфига или изменения числа узлов.
- **Колонки:** при ширине ≥ 600 dp и включённом тумблере — две колонки,
  порядок построчный (1-2 / 3-4); в режиме Custom всегда одна колонка;
  смена числа колонок на лету сохраняет положение прокрутки.
- Под последней строкой — запас высотой в строку, чтобы её можно было
  докрутить из-под нижних элементов.
