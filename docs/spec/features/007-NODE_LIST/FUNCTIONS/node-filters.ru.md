# Фильтры узлов — поиск нужного сервера среди сотен

Панель фильтров сужает список узлов Направления по имени, эмодзи-флагу,
протоколу, транспорту, источнику, пингу и роли detour, не трогая конфиг.

| Поле | Значение |
|------|----------|
| Фича | [007-NODE_LIST](../FEATURE.ru.md) |
| Обещания | P5, P6, P7, P8 |
| Состояние | ✅ написана по коду, 2026-09-28 |

## Что делает

Помогает найти нужные узлы в большом Направлении: по имени (регекс, эмодзи-
флаг), протоколу, транспорту/безопасности, источнику, порогу пинга и роли
detour. Несовпавшие узлы либо приглушаются и уходят вниз, либо скрываются.
Фильтр — только вид: маршрут и конфиг он не меняет.

## Параметры

Панель открывается кнопкой фильтра в заголовке «Nodes»; на время работы с
панелью полоса трафика и заголовок прячутся. Вкладки с точкой при активном
фильтре; над содержимым — сводка активных фильтров чипами (тап — к вкладке,
✕ — снять).

| Вкладка | Что | Дефолт |
|---|---|---|
| Regex | поле регекса + `!`; чипы эмодзи из имён узлов (по частоте); 💾 — сохранить в Направление | пусто |
| Protocol | чипы протоколов пула + `!`; второй ряд — транспорт/безопасность (`tcp` `ws` `grpc` `h2` `h3` `httpupgrade` `quic` `xhttp`, `TLS` `TLS+Vision` `Reality` `Reality+Vision`, `awg` … `awg3.1`, режимы `Fastest`/`Pool`) + `!` | ничего |
| Sources | чипы подписок и папок + `!` | ничего |
| Settings | «Test ≤ N ms» (чекбокс + число); detour: выкл / скрыть detour / только detour; «Show non-matching (dimmed)» | порог 200 не активен; detour выкл; показывать |

## Входы / Выходы

**Вход:** список Направления после закрепления и сортировки; тип узла,
транспорт и безопасность из собранного конфига; префиксы источников;
последние замеры (включая чужие Направления, как в строке).
**Выход:** видимый список — совпавшие, затем (если разрешено) несовпавшие с
прозрачностью 0,4; тот же порядок получает массовый пинг.

## Правила и инварианты

- Две фазы: сначала **detour-пул** (скрыть или оставить только узлы, на
  которые ссылаются как на detour-хоп), затем **совпадение**. Detour
  определяется по связям в конфиге, а не по значку ⚙.
- **Шасси всегда видно и считается совпавшим:** Направления, их двойники
  автовыбора, direct/block/dns — по типу. Узел автовыбора подписки/папки —
  обычный узел: его протокол «Auto», транспорт — режим (`Fastest`/`Pool`).
- Между категориями — И, внутри категории — ИЛИ; `!` инвертирует только
  свою категорию и не действует при пустом выборе.
- Регекс — без учёта регистра, с задержкой 300 мс; неверный регекс
  подсвечивается и фильтр не применяет. Тап по эмодзи-чипу добавляет или
  убирает эмодзи как ИЛИ-терм регекса.
- Протокол/транспорт узла неизвестен — при активном фильтре не совпадает
  (при `!` — совпадает). У группы ручного рода из источника протокола нет:
  любой чип протокола её прячет.
- **Источник — по префиксу тега** «префикс + пробел». Чип есть только у
  включённой подписки/папки с непустым префиксом и хотя бы одним узлом.
  Узел без префикса (одиночный сервер, импорт, источник без префикса) ни к
  одному чипу не относится: выбор чипа его прячет, `!` — оставляет. Общий
  префикс у двух источников — узел виден в обоих. Цепочки источниками
  фильтра не являются.
- Порог пинга: узел с задержкой больше порога не совпадает; неизмеренный
  совпадает всегда; ввод числа включает порог сам.
- **Память:** регекс, протоколы, варианты, источники (с `!`) и порог
  запоминаются за каждым Направлением и восстанавливаются при возврате к
  нему; пустой фильтр запись не заводит. Detour-фильтр и «Show non-matching»
  общие для всех. Память — на время работы приложения.
- 💾 доступна, только если выбрано существующее Направление: спрашивает,
  в какое поле Направления положить регекс (фильтр узлов или фильтр по
  умолчанию), и открывает редактор Направления с заполненным полем — тихой
  записи нет.
- У `NETWORKS` фильтра нет.
