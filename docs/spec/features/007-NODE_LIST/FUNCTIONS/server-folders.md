# Папки серверов и единый список источников

| Поле | Значение |
|------|----------|
| Фича | [007-NODE_LIST](../FEATURE.md) |
| Обещания | P14 |
| Состояние | ✅ написана по коду, 2026-09-28 |

## Что делает

**Папка** собирает одиночные серверы в один контейнер с общим именем,
выключателем, префиксом тегов и detour-политикой — вместо россыпи десятка
импортированных файлов. Папки, подписки, одиночные серверы и цепочки живут
**одним списком** на экране Servers, в порядке, который задаёт человек.

## Параметры

| Параметр | Где | Значения | Дефолт |
|---|---|---|---|
| Имя папки | заголовок папки (Rename) | строка | задаётся при создании |
| Папка вкл/выкл | переключатель в списке Servers | вкл/выкл | вкл |
| Член вкл/выкл | переключатель у члена | вкл/выкл | вкл |
| Tag prefix, detour-политика, Replace with a group | папка → Settings (та же форма, что у подписки) | как у подписки | префикс пуст |
| Личный detour члена | тап по члену → настройки узла | узел / нет | нет |

## Входы / Выходы

**Вход в папку:** «Paste from clipboard», «Import from files…» (несколько
файлов), «Add by URL…» (снимок один раз), «Add auto node…» (группа
автовыбора среди членов этой папки); «Move to folder…» у одиночного сервера
или члена другой папки.
**Выход:** узлы включённых членов с префиксом папки → сборка конфига;
запись папки в едином списке источников.

## Правила и инварианты

- **Член ↔ узел строго 1:1.** Фрагмент на несколько узлов при добавлении
  делится на несколько членов. Член хранит свой исходный текст (ссылка или
  целый WG/AWG-конфиг), узел выводится из него заново.
- Безымянный узел из файла получает имя файла без расширения; коллизии —
  с суффиксом.
- Выключенная папка не даёт ни одного узла; выключенный член не попадает в
  конфиг. Битый член живёт в папке («Unreadable entry») и в конфиг не идёт.
- Правка члена с неразбираемым текстом — откат с ошибкой, член не тронут.
- **«Add by URL…» — снимок:** запрос один раз, узлы становятся статичными
  членами, подписка не создаётся, адрес не хранится («Fetched once …»).
- **Удаление папки:** «Delete folder & servers» или «Keep servers» — члены
  выносятся одиночными серверами; группы автовыбора при этом удаляются и
  названы в диалоге; если в папке одни группы — «Keep servers» нет.
- **Move out of folder** — член становится одиночным сервером сразу после
  папки; у группы автовыбора такого пункта нет.
- **Одиночный сервер → папка:** его личные префикс и detour-политика
  отбрасываются, действуют папочные. Личный detour члена переживает
  переносы между папками и вынос.
- Члены упорядочиваются перетаскиванием; при активном фильтре внутри папки
  перетаскивание выключено.
- Подписка в папку не кладётся; вложенных папок нет; дедупликации членов нет.
- Экран закрывается сам, если папку удалили или она пропала.
- **Единый список источников:** подписки, серверы, папки и цепочки — одна
  последовательность; перетаскивание пишет перестановку целиком одной
  записью; цепочка может стоять между сервером и подпиской; удаление записи
  из середины соседей не двигает; нечитаемая запись держит своё место.
- Принадлежность узла папке для фильтра главного экрана — по префиксу
  тегов папки ([фильтры](node-filters.md)).

## Границы

- Подписки и их обновление, добавление источника — 001.
- Редактирование узла члена — 008; цепочки и detour-политика — 006.
- Свёртка папки в группу — [род и свёртка](selector-genus-and-fold.md).
- Цепочки на главном экране источником фильтра не являются.
