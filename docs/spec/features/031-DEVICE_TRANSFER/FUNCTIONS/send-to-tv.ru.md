# Отправка на TV — телефон сканирует код телевизора и отправляет настройки

Телефон собирает бэкап отмеченных для экспорта категорий, шифрует его ключом
из отсканированного кода и доставляет на TV по локальной сети мимо
собственного туннеля.

| Поле | Значение |
|------|----------|
| Фича | [031-DEVICE_TRANSFER](../FEATURE.ru.md) |
| Обещания | P5–P7, P10 |
| Состояние | ✅ реализована, 2026-10-16 (§622); ручная проверка с поднятым туннелем не проведена |

## Что делает

На устройстве, которое не TV и у которого есть камера, в Backup & restore
под карточкой Export есть карточка «Send to TV». «Scan code» открывает
сканер QR; после скана телефон спрашивает «Send to <имя устройства>?»,
затем собирает бэкап категорий, отмеченных в карточке Export, шифрует и
отправляет. Итог — одна строка внизу экрана.

## Параметры

| Настройка | Значения | По умолчанию |
|-----------|----------|--------------|
| Категории | те же, что в карточке Export: Server lists, Routing, App settings, VPN system toggles, Debug API config | все, кроме Debug API config |

Фиксировано: таймаут соединения 5 с на адрес, ожидание ответа 60 с.

## Входы / Выходы

**Входы:** отсканированный текст; отмеченные категории.

**Выходы:** один `POST /transfer` с конвертом на каждый адрес кода по
очереди, пока какой-то не ответит; строка итога.

## Правила и инварианты

- Ни одной категории — «Nothing to export — pick at least one category.»
  до открытия сканера.
- QR-код, который не код передачи версии 1, — «This is not a LxBox transfer
  code»; ничего не отправляется.
- Соединение идёт по физической сети Wi-Fi или Ethernet, а не через
  собственный VPN телефона, что бы ни говорили его правила маршрутизации и
  раздельное туннелирование. Без такой сети телефон идёт обычным
  соединением.
- Строки итога:
  - принято — «Sent. Confirm the restore on the TV.»;
  - ни один адрес не ответил — «Cannot reach the TV. Both devices must be on
    the same network; guest Wi-Fi often keeps devices from seeing each
    other.»;
  - порт закрыт или 409 — «The code has expired or was already used. Show a
    new code on the TV.»;
  - 403 — «The TV did not accept the code. Show a new code on the TV and
    scan it again.»;
  - 413 — «The settings are too large to send.»;
  - 422 — «The TV cannot restore these settings: <причина>»;
  - 503 — «The TV is busy with another request. Try again in a moment.»;
  - другой ответ — «Sending failed: HTTP <код>».

## Границы

- На TV и без камеры не показывается; ручного ввода кода нет.
- Отправляет разово; последующие изменения сами не уезжают.
- Не узнаёт, применил ли телевизор бэкап.
