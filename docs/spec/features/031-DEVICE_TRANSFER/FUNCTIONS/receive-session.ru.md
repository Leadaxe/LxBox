# Сессия приёма — телевизор показывает код и принимает один бэкап с телефона

Пока открыт экран «Receive settings», телевизор слушает локальную сеть и
ждёт один зашифрованный бэкап с ключом из своего QR-кода, а пришедшее
передаёт в обычный предпросмотр восстановления.

| Поле | Значение |
|------|----------|
| Фича | [031-DEVICE_TRANSFER](../FEATURE.ru.md) |
| Обещания | P1–P4, P6–P10 |
| Состояние | ✅ реализована, 2026-10-16 (§622); ручная проверка на эмуляторе TV не проведена |

## Что делает

На TV пункт «Receive from phone» (первая карточка Backup & restore; на
пустом главном экране — над «Restore from backup») открывает «Receive
settings». Экран открывает сессию и показывает QR-код на белом поле, имя
устройства, локальный адрес, оставшееся время и состояние. Телефон
сканирует код и отправляет; как только содержимое расшифровалось и
разобралось как бэкап, экран закрывается и открывается предпросмотр
восстановления — тот же, что у файла бэкапа: категории, Merge или Replace,
затем «Restart now» в строке итога. С главного экрана подписки сразу после
применения перечитываются и скачиваются, как у «Restore from backup».

## Параметры

Пользовательских настроек нет.

| Величина | Значение |
|----------|----------|
| Время жизни сессии | 10 минут, обратный отсчёт на экране |
| Порт | выбирает система на каждую сессию |
| Предел содержимого | 32 МиБ |
| Отвергнутых попыток (конверт не разобран или не расшифрован) до закрытия | 5 |
| Запросов в обработке одновременно | 1 |

## Входы / Выходы

**Входы:** открытие экрана; локальные IPv4-адреса устройства (Wi-Fi и
Ethernet первыми; loopback, link-local и интерфейсы туннелей отброшены);
один `POST /transfer` с конвертом.

**Выходы:** QR-код (`lxbox-transfer:1?a=…&k=…&n=…`); строка состояния;
ответ отправителю — 200 принято, 400 конверт не разобран, 403 чужой ключ,
404 другой маршрут, 409 сессия уже закрыта, 413 слишком большое, 422 не
годный бэкап (с причиной), 503 занят другим запросом; разобранный бэкап — в предпросмотр.

## Правила и инварианты

- Порядок проверок: размер → конверт → расшифровка → разбор бэкапа. До
  аутентификации ничего не разбирается.
- Один запрос за раз: пока один читается, расшифровывается или
  разбирается, другой `POST /transfer` получает 503 до чтения содержимого.
- Неразобранный конверт (400) и чужой ключ (403) увеличивают счётчик —
  «Rejected attempts with a wrong code: N of 5»; пятый закрывает сессию — «Too many attempts with a wrong code. The
  code is closed; press New code to get another one.»
- Содержимое, которое расшифровалось, но не бэкап, сессию не закрывает и
  показывает «The phone sent settings that cannot be restored: <причина>».
- Нет пригодного адреса — «No local network» и «Connect this TV to Wi-Fi or
  Ethernet, then press New code.»
- Таймаут — «The code has expired. Press New code to get another one.»
- «New code» закрывает сессию и открывает новую с новыми ключом и портом.
  «Cancel» (в фокусе при открытии экрана) и уход с экрана закрывают
  сессию; порт после этого отказывает.
- Пока экран открыт, экран устройства не гаснет.
- В журнал пишутся открытие сессии, порт, число адресов и исход каждого
  запроса; ключ и текст кода — никогда.
- Уход из предпросмотра без применения выбрасывает принятое; на диск оно не
  пишется.

## Границы

- Показывается только на устройстве в режиме телевизора.
- Только IPv4; ни обнаружения, ни ручного ввода кода.
- Применил ли пользователь бэкап, получатель отправителю не сообщает.
