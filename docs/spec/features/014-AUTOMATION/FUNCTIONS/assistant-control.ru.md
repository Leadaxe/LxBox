# Управление ассистентом — ИИ-ассистент диагностирует сеть и управляет ею

По умолчанию выключено; включает пользователь.

| Поле | Значение |
|------|----------|
| Фича | [014-AUTOMATION](../FEATURE.ru.md) |
| Обещания | P15 |
| Состояние | ✅ написана по спеке задачи 750, 2026-11-17; на устройстве не проверена |

## Что делает

Даёт ИИ-ассистенту набор функций, чтобы просьбу обычными словами исполняло
приложение: выяснить, почему адрес не открывается, пустить приложение через
выбранный выход, подключить или отключить рабочую сеть. Какие функции вызвать
и в каком порядке, решает ассистент; приложение только исполняет их и
отвечает данными.

## Параметры

| Параметр | Значения / поведение |
|----------|----------------------|
| App Settings → Automation → AI assistants → **AI assistant control** | вкл/выкл, по умолчанию выкл; открывает все функции |
| App Settings → Automation → AI assistants → **Let assistants change settings** | вкл/выкл, по умолчанию выкл; действует только с первым; открывает изменения сохранённых настроек |

Оба видны на Android 16 и новее и едут в бэкапе.

## Входы / Выходы

**Входы:** вызов функции ассистентом; два тумблера; статус туннеля;
сохранённые настройки; разрешение на VPN.

**Выходы:** старт или остановка туннеля; результат проверки адреса (стадия
сбоя, ошибка, код HTTP, Направление и выход, совет); внешний адрес и страна
выхода; имена выходов Направления; выбранный выход; установленные приложения
по поиску; правила, Направления, источники и подключения с их состоянием;
изменённые правила, Направления и переключатели источников.

| Группа | Примеры | Тумблер |
|--------|---------|---------|
| Туннель | старт, стоп, статус | AI assistant control |
| Проверки | проверка адреса, проверка выхода | AI assistant control |
| Чтение | выходы, приложения, правила, Направления, источники, подключения | AI assistant control |
| Выбор в работающем туннеле | смена выхода Направления | AI assistant control |
| Изменения сохранённых настроек | добавить или изменить правило или Направление, включить или выключить источник или подключение, маршрут по умолчанию, приложения туннеля | Let assistants change settings |

## Правила и инварианты

- При выключенном «AI assistant control» ни одна функция не исполняется;
  ассистент получает ошибку.
- При выключенном «Let assistants change settings» изменение отклоняется с
  текстом, где назван тумблер; ничего не меняется.
- Изменение применяется сразу, без подтверждения каждого.
- Имена выходов приложение не разбирает: о стране выхода ассистент судит по
  имени, подтверждает её проверка выхода.
- Проверка адреса и проверка выхода идут, только пока туннель поднят; сами
  туннель не включают.
- Для старта туннеля нужно выданное ранее разрешение на VPN; ассистент
  выдать его не может.
- Функции туннеля, проверки, список выходов, смена выхода и поиск приложения
  работают без окна приложения. Чтение и изменение настроек требуют окна:
  приложение пробует открыть его; если ОС отказывает, ассистент получает
  ошибку, а пользователь — уведомление.
- Для ассистента ничего не считается заранее: пока функцию не вызвали,
  приложение не делает лишней работы ни на старте, ни при изменении настроек.
- Тексты советов и ошибок — из таблиц самого приложения.

## Границы

- Ассистенту не отдаются никогда: конфиг, адреса и ключи серверов, ссылки
  подписок, бэкапы, логи, файлы.
- Ассистент не может добавлять и удалять серверы, подписки и папки, менять
  настройки DNS, миксины, конфиг, переключатели безопасности туннеля,
  настройки Debug API и два собственных тумблера.
- Вход в подключение остаётся в приложении.
- Состояние подключения OpenVPN не сообщается.
- Зависит от ОС: функции для ассистентов есть на Android 16 и новее, и ОС
  решает, каким ассистентам можно их вызывать.
- Те же функции для агента на компьютере —
  [027-DEBUG_API](../../027-DEBUG_API/FEATURE.ru.md).
