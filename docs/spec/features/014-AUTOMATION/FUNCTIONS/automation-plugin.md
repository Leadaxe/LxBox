# Плагин автоматизаторов

| Поле | Значение |
|------|----------|
| Фича | [014-AUTOMATION](../FEATURE.md) |
| Обещания | P5, P12 |
| Состояние | ✅ написана по коду, 2026-09-28 |

## Что делает

L×Box виден в списке плагинов автоматизаторов, поддерживающих стандарт
Locale/Tasker (Tasker, MacroDroid, Llama, Automate с премиум-блоком):
**действия** — выбрать команду из списка вместо ручного ввода строки;
**условия** — профиль активен, пока туннель поднят или активен нужный узел
или группа.

## Параметры

Своих настроек нет; исполнение действий и ответы условий включаются тем же
«Accept automation commands». Экраны настройки плагина доступны всегда.

Действия (строки в списке плагинов):

| Строка | Поведение |
|--------|-----------|
| L×Box: Start VPN / Stop VPN / Toggle VPN | выбор без экрана, сразу готово |
| L×Box: Custom… | экран выбора: Switch node, Set group, URL-test group, Refresh subscriptions, Rebuild config, Reset network |

Условия: **VPN is up**; **Active node =** значение; **Active group =** значение.

Формат сохранённой настройки (хранится у автоматизатора, публичный контракт):
одна строка JSON под ключом `com.leadaxe.lxbox.plugin.CONFIG` —
действие `{"v":1,"cmd":"<команда>","args":{…}}`, где команда — `start-vpn`,
`stop-vpn`, `toggle-vpn`, `switch-node` (`tag`), `set-group` (`group`),
`urltest-group` (`group`), `refresh-subs`, `rebuild-config`, `reset-network`;
условие `{"v":1,"check":"vpn-up|active-node|active-group","equals":"…"}`.

## Входы / Выходы

**Входы:** выбор в экранах плагина; исполнение действия и опрос условия
автоматизатором; кеш активного узла, группы, списка узлов активной группы и
списка групп, который приложение обновляет при каждой смене.

**Выходы:** сохранённая настройка и её подпись (на языке приложения,
например «Switch node → <узел>»); исполнение команды; ответ условия
«выполнено / не выполнено / неизвестно».

## Правила и инварианты

- Действия исполняются теми же путями, что команды из «Приёма команд»: старт,
  стоп, переключение — без интерфейса (переключение без разрешения VPN
  открывает приложение); остальное — общими обработчиками с `VPN_ERROR` на
  провал. `refresh-subs` из плагина — без принудительного обновления.
- «Custom…» для Switch node предлагает выпадающий список реальных узлов
  активной группы, для Set group / URL-test group — список групп; пустой кеш
  (приложение не открывалось после установки или смены подписки) → ручной
  ввод.
- Повторное открытие экрана подставляет сохранённую команду и значение.
- Условие отвечает сразу, без запуска интерфейса: «VPN is up» — по статусу
  службы туннеля; узел и группа — по кешу. Нет кеша, пустое ожидаемое значение,
  испорченная настройка или неизвестная проверка → «неизвестно».
- Испорченная или чужая настройка действия игнорируется.
- Строки команд и проверок в настройке — английские навсегда; подписи —
  локализуются.

## Границы

- Условие «Active node =» задаётся вводом текста, списка узлов в нём нет.
- Условие опрашивается автоматизатором периодически; мгновенного
  уведомления хосту о смене нет (для этого — события).
- Отдельного приложения-плагина и UI за пределами этих экранов нет.
- Зависит от возможностей ОС и хоста: наличие блока плагинов, частота опроса
  условий, ограничение размера настройки стандартом (25 КБ).
