# Выбор приложений — отбор приложений в список туннеля

Пикер открывается кнопкой «Add app» на вкладке «Tunnel apps» и из условия «по
приложению» в правиле маршрутизации.

| Поле | Значение |
|------|----------|
| Фича | [011-SPLIT_TUNNELING](../FEATURE.ru.md) |
| Обещания | P8, P9 |
| Состояние | ✅ написана по коду, 2026-09-28 |

## Что делает

Экран «Select apps»: показывает установленные приложения с галочками,
позволяет найти нужные, отметить или снять пачкой, перенести выбор через
буфер обмена и вернуть результат на вкладку. Тот же пикер используется для
условия «по приложению» в пользовательских правилах (004-ROUTING).

## Параметры

| Ручка | Значения | Дефолт |
|-------|----------|--------|
| Show / Hide system apps | показывать системные приложения | скрыты |
| Поиск «Search apps…» | подстрока имени или пакета, без учёта регистра | пусто |

Меню: Select all, Deselect all, Invert, Import from clipboard, Export to
clipboard, Show/Hide system apps.

## Входы / Выходы

**Вход:** текущий список вкладки (становится начальным выбором); список
установленных приложений (грузится один раз за сессию, общий для всех
пикеров).

**Выход:** полный новый список пакетов — возвращается и стрелкой, и
системным «назад»; вкладка заменяет им свой список.

## Правила и инварианты

- Отмеченные приложения — вверху, затем по имени; строка — иконка, имя, пакет.
- Выбор переключается только тапом по галочке; тап по строке ничего не
  меняет (прокрутка не снимает выбор).
- Системный «назад» возвращает выбор так же, как стрелка; двойной возврат
  исключён.
- Select all и Invert действуют на видимые (с учётом поиска и фильтра
  системных); Deselect all снимает весь выбор, включая невидимые.
- Import from clipboard: по строке на пакет; добавляются только пакеты,
  установленные на устройстве; снэкбар «N packages imported».
- Export to clipboard: выбранные пакеты по строке; доступен и во время
  загрузки; снэкбар «N packages copied».
- Пока список грузится — индикатор, массовые действия и импорт недоступны;
  счётчик «N selected · M shown».
- Уже выбранные, но не установленные пакеты в выборе остаются (их нет в
  списке, но они возвращаются вкладке).

## Границы

- Своё приложение отдельно не подсвечивается и не блокируется.
- Зависит от возможностей ОС: видимость полного списка установленных
  приложений (без него пикер покажет неполный список).
