# Своё приложение в Allow-list — LxBox внутри собственного туннеля

Это автоматическая докрутка при подъёме туннеля: пользователь её не видит, в
сохранённый конфиг она не попадает.

| Поле | Значение |
|------|----------|
| Фича | [011-SPLIT_TUNNELING](../FEATURE.ru.md) |
| Обещания | P7 |
| Состояние | ✅ написана по коду, 2026-09-28 |

## Что делает

В Allow-list всё, что не в списке, идёт мимо туннеля — в том числе само
приложение. Чтобы собственный трафик ядра гарантированно шёл предсказуемо
(паритет с эталонным клиентом sing-box), приложение при каждом поднятии
туннеля в Allow-list само добавляет себя в разрешённые — без участия
пользователя и без записи в сохранённый конфиг.

## Параметры

Нет: решение выводится из конфига — есть `include_package` у первого
туннельного входа значит Allow-list.

## Входы / Выходы

**Вход:** сохранённый конфиг на старте и перезапуске ядра.

**Выход:** параметр запуска ядра `includePackage` = свой пакет (только
Allow-list); ядро дописывает его в конец списка первого туннельного входа
работающего конфига. Сохранённый конфиг и `GET /config` его не содержат.

## Правила и инварианты

- Allow-list — дописывается; Deny-list и Off — нет: разрешённые и
  запрещённые приложения в одном туннеле ОС отвергает целиком.
- Дописывание — append без сортировки и дедупликации: если пользователь сам
  добавил приложение в список, оно окажется там дважды, это норма.
- Сравнение «работающий конфиг устарел?» воспроизводит то же дописывание,
  иначе плашка «restart» висела бы всегда в Allow-list.
- Трафик ядра к узлам дополнительно защищён от попадания в свой же туннель
  независимо от режима; самодописывание — страховка, а не единственная
  защита.
- «Allow VPN bypass» (010-VPN_SERVICE) с этим не связан: одно не заменяет и не
  отменяет другое.

## Границы

- Пользователю самодописывание не показывается; вручную добавить себя в
  список можно, в Deny-list это без эффекта для туннеля ядра.
- Зависит от возможностей ОС: правило «разрешённые и запрещённые приложения
  взаимоисключающи», поведение своего трафика при Allow-list.
