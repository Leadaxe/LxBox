# Локализация — языки интерфейса, файлы переводов и модель «английский текст как ключ»

LxBox показывает интерфейс, уведомление, плитку и ярлыки на английском, русском
или упрощённом китайском и меняет язык на лету, не останавливая VPN-туннель.
Английский — базовый язык: английский текст в коде и есть ключ перевода,
каждый другой язык — файл словаря. Журналы, Debug API, события автоматизации
и конфиг sing-box остаются английскими при любом языке.

| Поле | Значение |
|------|----------|
| Фича | 029-LOCALIZATION |
| Тип | Продуктовая фича |
| Поглотила | `§279F` |
| Состояние | ✅ написана по коду, 2026-09-29 |

## Назначение

Пользователь читает приложение на своём языке, а всё, что читает машина или
другой человек — журналы, ответы API, нагрузка автоматизации, значения
конфига, — остаётся английским, чтобы отчёты об ошибке из России и из Китая
выглядели одинаково. Фича описывает, как язык выбирается и применяется, как
устроены файлы переводов, как добавить строку или язык и какие нативные строки
и строки ядра следуют выбору.

Принципы: **английский — ключ** — ни отдельного английского словаря, ни
искусственных идентификаторов, промах в словаре деградирует в английский
текст. **Язык — для человека, английский — для машин** — интерфейс, тексты
шаблона и системные поверхности переводятся, машинные поверхности прибиты к
английскому. **Смена не останавливает туннель** — переключение перерисовывает
интерфейс, переименовывает системные поверхности и заново выводит подписи из
шаблона без перезапуска и пересборки конфига. **Непереведённое не доходит до
релиза незамеченным** — CI отклоняет захардкоженную строку экрана,
непереведённый или осиротевший ключ, несовпадающий набор подстановок и
нативную строку, которой нет в одном языке.

## Обещания

- **P1. Язык выбирается из System default / English / Русский / 中文,
  неизвестное значение — System default.** System default берёт язык
  устройства, иначе английский. Свидетель: юниты «set() with unknown value
  falls back to system», «invalid stored value resolves to system». Мутация:
  неизвестный язык устройства даёт пустую локаль.
- **P2. Смена языка — без перезапуска; первый кадр после запуска уже на
  сохранённом языке.** Свидетель: юниты «set() сохраняет выбор, прогревает кэш
  шаблона, обновляет локализатор и уведомляет», «bootstrap() прогревает
  словарь — холодный старт локализован». Мутация: словарь грузится после
  первого кадра.
- **P3. Язык из системных настроек Android и язык в приложении не спорят.**
  Изменение в системных настройках приложения побеждает; изменение хранилища
  (восстановление копии, Debug API) — тоже, если система не менялась; System
  default очищает выбор per-app. Свидетель: юниты сверки «системные Settings
  поменяли язык → система побеждает», «restore/Debug API поменял сторадж →
  сторадж побеждает», «сторадж стал system при запушенном ru → пере-пуш
  пустого». Мутация: одностороннее «система всегда права».
- **P4. Язык переживает резервную копию и набор настроек.** Свидетель: юниты
  «app_language export → import round-trip preserves value», «reloadFromStorage
  применяет восстановленное значение и идемпотентен». Мутация: ключ языка
  выпал из списка разрешённых при импорте.
- **P5. Ссылка на руководство в About следует языку интерфейса; неподдержанный
  язык открывает английское руководство.** Свидетель: юниты «ru → русский
  гайд, en → английский», «незнакомый язык → английский (fallback, не 404)».
  Мутация: ссылка всегда ведёт на русское руководство.
- **P6. Системные поверхности переименовываются при смене языка и при
  неработающем интерфейсе.** Канал и текст уведомления, плитка, ярлыки и их
  закреплённые копии, окна автоматизации; при System default то же делает
  смена языка устройства. Свидетель: ручная проверка — туннель поднят,
  переключить на русский: уведомление и плитка русские без переподключения.
  Мутация: текст уведомления кэшируется при старте службы.
- **P7. Непереведённое — по-английски, а не пусто и не форматом.** Нет словаря,
  ключа, формы или форма не того вида — английский текст с подставленными
  значениями; недостающий аргумент — пустое место, а не `%s`. Свидетель: юниты
  «missing key → key itself substituted», «missing arg → empty placeholder»,
  «.s never throws on plural-object value → key fallback», «dict null → English
  key substituted with %d». Мутация: пропущенный аргумент печатает `%s`.
- **P8. Множественное число — по правилам языка.** Русский one/few/many по
  CLDR, дроби уходят в `other`; английский one/other; китайский — одна форма.
  Свидетель: юниты «one: 1, 21», «few: 2, 3, 4, 22», «many: 5, 11, 12, 13, 14,
  25», «non-integer 1.5 → other», виджет «ru: счётчики карточки sing-box
  склоняются»; для единственной китайской формы — `без свидетеля`. Мутация:
  21 → many.
- **P9. Отображаемые тексты шаблона переводятся, конфиг из шаблона —
  байт-в-байт тот же.** Названия пресетов, подсказки, подписи опций и описания
  правил берутся из оверлея языка; значение с `@` в начале или `{`
  игнорируется. Свидетель: юниты «ru overlay localizes display fields, config
  subtree untouched», «localizes display fields, leaves machine subtrees
  byte-identical», «skips values starting with @ or containing {», «unknown
  english keys are a silent no-op». Мутация: оверлей применён к конфигу.
- **P10. Подписи, выведенные из шаблона, меняют язык без пересборки конфига.**
  Живые имена правил из пресетов выводятся заново при переключении; условия
  inline-правил не трогаются. Свидетель: юниты «relocalize: смена label в
  шаблоне отражается в выводе резолвера», «relocalize не трогает условия
  inline-правил (только титулы)». Мутация: снимок, снятый при сборке.
- **P11. Машинные поверхности английские при любом языке.** Сохранённая
  ошибка или предупреждение на экране отрисовывается на языке интерфейса, а
  для журнала, Debug API и автоматизации — по-английски: один объект, два
  рендера. Свидетель: юнит «renderWith(ru) русеет, renderEn() неизменен».
  Мутация: журнал пишет сообщение на языке интерфейса.
- **P12. Тексты предупреждений ядра есть на английском и русском; любой другой
  язык читает английский.** Свидетель: виджет «zh получает английский текст
  реестра». Мутация: zh падает в русский.
- **P13. Каждый поставляемый словарь загружается и разбирается.** Объявленный,
  но битый файл перевода до релиза не доходит. Свидетель: юнит «every declared
  template overlay asset loads and parses»; словари интерфейса ru и zh целиком
  загружает юнит ««Info» подзаголовка — своя форма словаря, не
  «Информация»». Мутация: ключ-комментарий в словаре.
- **P14. CI отклоняет захардкоженную строку экрана, непереведённый или
  осиротевший ключ, несовпадающий набор подстановок и неиспользуемую особую
  форму.** Свидетель: самотесты чекеров «Text positional literal is a site»,
  «both ternary branches in Text are sites», «key used in code but absent from
  dict = missing», «dict key never referenced = orphan», «arity mismatch (key
  vs value) fails», «special defined but never used with that index =
  orphan-special». Мутация: базовой линии разрешено расти.
- **P15. Нативные строки полны на каждом языке.** Наборы ключей и подстановок
  `%n$s` в Android-строках каждого языка совпадают с английским набором.
  Свидетель: ручная проверка — удалить один ключ из русских строк, запустить
  нативную проверку в строгом режиме: она падает. Мутация: отсутствующий ключ
  молча падает в английский.

## Контролируемые параметры

| Настройка | Где | Значения | Дефолт | Когда действует |
|-----------|-----|----------|--------|-----------------|
| Language | App Settings → Appearance | System default / English / Русский / 中文（简体） | System default | сразу |

Названия языков — эндонимы. Тот же выбор доступен в системных настройках
языка приложения (Android 13+) и в Debug API (`app_language`: `system` \|
`en` \| `ru` \| `zh`).

Ключей конфига ядра фича не отдаёт.

Форматы (контракты): словарь интерфейса `assets/l10n/<tag>/ui.json`
(английский текст → `{"value": …}`, объект множественного числа или вариант
`special`; подстановки `%s`, `%d`, `%1$s`, `%%`); оверлей шаблона
`assets/l10n/<tag>/template.json`; нативные строки Android, по файлу на язык;
пометка `// l10n-exempt: <причина>`.

## Входы / Выходы

**Входы:** выбор в приложении; язык устройства; язык приложения из системных
настроек (Android 13+); значение из резервной копии, набора настроек или Debug
API; словари и шаблон, поставляемые с приложением.

**Выходы:** текст интерфейса, отображаемые тексты шаблона, форматы даты и
времени, уведомление, плитка, ярлыки и окна автоматизации на выбранном языке;
язык сообщений ядра; английский на машинных поверхностях.

## Data flow

```
настройка | язык устройства | системные настройки (13+) → сверка → тег языка
тег языка → словарь интерфейса → каждый вызов строки → текст или английский fallback
          → оверлей шаблона → пресеты, подсказки, имена правил
          → нативные строки → уведомление · плитка · ярлыки · окна автоматизации
          → локаль ядра (при смене)
сохранённая ошибка / предупреждение → экран: язык интерфейса · журнал, Debug API, автоматизация: английский
CI: код + словари + нативные строки → четыре проверки в строгом режиме → сборка
```

## Правила и гарантии

- System default — язык устройства, если он поддержан, иначе английский; смена
  языка устройства при System default подхватывается на лету.
- Неизвестное сохранённое значение читается как System default; Debug API его
  отклоняет.
- Словарь нового языка загружается и кэш шаблона прогревается до перерисовки
  интерфейса; сбой загрузки словаря оставляет всё по-английски, язык всё равно
  переключается.
- Форматы даты и времени следуют выбранному языку.
- Сверка с per-app выбором (Android 13+) при старте: система изменилась с
  нашего последнего пуша — побеждает система; изменилось только хранилище —
  сохранённый выбор отправляется в систему; System default очищает системный
  выбор; на первом старте после обновления непустой системный выбор побеждает.
- Язык входит в резервную копию и наборы настроек; загрузка набора сразу
  применяет его язык.
- Английскими остаются всегда: журналы, ответы Debug API, события
  автоматизации, значения и теги конфига, имена файлов, данные пользователя,
  сквозная нагрузка ОС и ядра, название «L×Box», единицы (полный список —
  [native-and-core-strings](FUNCTIONS/native-and-core-strings.ru.md)).
- Сохранённые ранее снимки текста (подписи каналов, запасные имена правил из
  пресетов) задним числом не переводятся.

## Границы

- Место строки Language на экране настроек и лента поддержки со своими
  текстами по языкам — [020-APP_SHELL](../020-APP_SHELL/FEATURE.ru.md); эта
  фича владеет механизмом.
- RTL-языки не поддерживаются; ни правки переводов в приложении, ни языковых
  пакетов — языки поставляются с приложением; руководство пользователя есть
  только на английском и русском.
- Язык собственных сообщений ядра задаётся от устройства при старте процесса
  и следует выбору приложения только после смены языка (см. Особенности
  сопровождения).
- Зависит от возможностей ОС: язык приложения в системных настройках и
  per-app локаль (Android 13+); широковещательное событие смены языка
  устройства.

## Особенности сопровождения

- Известные непереведённые места (аудит
  [591](../../tasks/591-spec-kit-revision-audit.md)): подписи вариантов темы
  System/Light/Dark, строки результата проверки обновлений в About, сообщения
  «Add tile», подписи режимов и подсказка на вкладке Tunnel apps, строки ошибок
  JSON и секция APPS в редакторе правил, «Copy server + detour(s)» / «Server
  copied» / «Detour copied» в редакторе конфига, итоговые строки
  восстановления. Они проходят CI: текст попадает в виджет через переменную
  или незарегистрированный хелпер.
- Семнадцать русских записей (строки DNS-групп вроде «Error TTL», «Win TTL»,
  «Selection mode») записаны простыми строками вместо объектов `{"value": …}`:
  рантайм считает их отсутствующими и печатает английский, проверка словаря —
  присутствующими. Проверки формы для плоских записей нет (→ 591).
- Текст ошибки Debug API для `app_language` всё ещё перечисляет только
  `system`, `en` и `ru`; `zh` принимается (→ 591).
- Язык сообщений ядра задаётся от устройства при старте процесса и от выбора
  приложения только при смене языка: сохранённый русский на английском
  устройстве даёт английские ошибки ядра, пока язык не тронут (→ 591).
- Новый хелпер снэкбара или диалога с отображаемым параметром нужно
  зарегистрировать для проверки захардкоженных строк, иначе его литералы
  проскакивают.
- Список поддержанных языков зеркалится в четырёх местах плюс объявление
  локалей Android и таблица форм множественного числа в чекере; язык,
  пропущенный в одном из них, молча сбрасывает настройку в System default
  (`docs/l10n.md`).
