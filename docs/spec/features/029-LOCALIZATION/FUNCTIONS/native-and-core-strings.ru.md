# Нативные строки и строки ядра — уведомление, плитка, плагин автоматизации, предупреждения ядра и что остаётся английским

LxBox переводит тексты, живущие вне Flutter-интерфейса, — уведомление службы
VPN, плитку быстрых настроек, ярлыки, окна плагина автоматизации и реестр
предупреждений ядра — и намеренно оставляет каждую машинную строку
английской.

| Поле | Значение |
|------|----------|
| Фича | [029-LOCALIZATION](../FEATURE.ru.md) |
| Обещания | P6, P11, P12 |
| Состояние | ✅ написана по коду, 2026-09-29 |

## Что делает

Отрисовывает нативные поверхности Android на выбранном языке даже при
неработающем интерфейсе, переименовывает их при смене языка, передаёт ядру
язык его сообщений и держит фиксированный английский рендер для журналов,
Debug API и полезной нагрузки автоматизации.

## Параметры

Своих настроек нет: следует языку из
[language-selection](language-selection.ru.md). Контракт: нативные строки —
по файлу на язык с теми же ключами, что в английском; текст с полезной
нагрузкой использует `%1$s` и передаёт её как есть.

Нативные тексты по поверхностям:

| Поверхность | Тексты |
|-------------|--------|
| Уведомление службы | имя и описание канала, «Starting…», «Connected», Stop, Reconnect, заголовок ошибки, имя канала уведомлений ядра |
| Сообщения об остановке | неизвестная ошибка, сбой инициализации ядра, пустая конфигурация, командный сервер не инициализирован, не удалось запустить службу, «VPN stopped» после шторма перезапусков |
| Плитка быстрых настроек | Connecting…, Stopping…, Disconnected |
| Ярлыки быстрого подключения | Connect, Disconnect, одноразовый запрос разрешения, разрешение отклонено |
| Плагин автоматизации | четыре подписи плагина, описания Start / Stop / Toggle, приглашения команды и условия, имена команд, имена условий, подписи значения, Save |

## Входы / Выходы

**Входы:** зеркало сохранённого языка на нативной стороне; событие смены языка
устройства; смена языка из интерфейса; реестр предупреждений ядра с
английскими и русскими текстами.
**Выходы:** нативные поверхности на выбранном языке; локаль ядра; английский
рендер сохранённых ошибок и предупреждений для машинных поверхностей.

## Правила и инварианты

- Нативные поверхности берут строки в момент отрисовки под выбранным языком:
  явный выбор оборачивает контекст в этот язык, System default берёт
  собственное разрешение системы (включая per-app выбор на Android 13+).
  Ничего не кэшируется, поэтому каждая перерисовка на текущем языке.
- Нативная сторона держит зеркало настройки языка, чтобы отрисовывать без
  интерфейса; зеркало пишется только через путь смены языка, неизвестное
  значение зеркала — System default.
- Смена языка обновляет по порядку: канал уведомления (идемпотентная повторная
  регистрация переименовывает его), текст уведомления работающей службы
  (остановленной нечего переименовывать), оба ярлыка вместе с закреплёнными
  копиями, плитку и локаль ядра. Каждый шаг best-effort: сбой пишется в
  журнал, следующий шаг всё равно выполняется.
- При System default смена языка устройства запускает то же обновление даже
  при неработающем интерфейсе; при явном выборе — ничего не делает.
- Язык сообщений ядра: задаётся от устройства при старте процесса (тег
  язык-и-регион с откатом на голый язык, затем на дефолт ядра — отвергнутый
  тег никогда не блокирует запуск) и от выбора приложения внутри обновления
  выше.
- Тексты предупреждений ядра (заголовок, текст, причина, исправление) есть в
  реестре на английском и русском; русский читает русский, любой другой язык
  читает английский.
- Английскими остаются всегда: журналы, ответы Debug API, события
  автоматизации и строки команд плагина, предупреждения о конфиге в машинном
  виде, значения и теги конфига, имена файлов, данные пользователя, сквозная
  полезная нагрузка ОС, библиотек и ядра, название «L×Box», единицы и
  суффиксы длительности, названия сетей в списке пожертвований. У сохранённой
  ошибки или предупреждения два рендера — активный язык для экрана и
  английский для машинных поверхностей, — и английский от языка не меняется.
- Название «L×Box» помечено непереводимым в нативных строках; wire-префикс
  `alert:` сообщений об остановке — не отображаемая строка.

## Границы

- Сама служба, её состояния и сообщения об остановке —
  [010-VPN_SERVICE](../../010-VPN_SERVICE/FEATURE.ru.md); поведение плитки,
  ярлыков и плагина — [014-AUTOMATION](../../014-AUTOMATION/FEATURE.ru.md);
  содержимое реестра — [021-CORE_CONTRACT](../../021-CORE_CONTRACT/FEATURE.ru.md).
- Строки журнала ядра и сквозная полезная нагрузка ошибок приложением не
  переводятся; на них влияет только собственный вызов локали ядра.
- Зависит от возможностей ОС: per-app локаль и широковещательное событие
  смены языка устройства; переименование ярлыков система может ограничить по
  частоте, пока приложение в фоне.
