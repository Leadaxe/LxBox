# Выбор языка — настройка, язык устройства и per-app язык Android 13+

LxBox берёт язык интерфейса из настройки в приложении, языка устройства или
языка приложения в системных настройках Android, применяет его без
перезапуска и держит все три источника согласованными.

| Поле | Значение |
|------|----------|
| Фича | [029-LOCALIZATION](../FEATURE.ru.md) |
| Обещания | P1, P2, P3, P4, P5, P6 |
| Состояние | ✅ написана по коду, 2026-09-29 |

## Что делает

Решает, на каком из трёх языков приложение говорит сейчас, и применяет его
везде сразу: интерфейс, тексты шаблона, форматы дат, уведомление, плитка,
ярлыки и окна автоматизации. Выбор берётся из настройки, а при System
default — от устройства; на Android 13+ тот же выбор можно сделать в
системных настройках языка приложения.

## Параметры

| Настройка | Где | Значения | Дефолт |
|-----------|-----|----------|--------|
| Language | App Settings → Appearance | System default · English · Русский · 中文（简体） | System default |

Названия языков — эндонимы: каждое на своём языке при любом текущем. Та же
настройка видна как `app_language` в Debug API (`system` \| `en` \| `ru` \|
`zh`), в резервной копии и в наборах настроек.

## Входы / Выходы

**Входы:** выбор в приложении; язык устройства и событие его смены; язык
приложения из системных настроек (Android 13+); значение из резервной копии,
набора настроек или Debug API.
**Выходы:** действующий тег языка; перерисованный интерфейс; переименованные
системные поверхности; per-app язык, отправленный в систему (Android 13+);
ссылка на руководство в About.

## Правила и инварианты

- System default — язык устройства, если он среди поддержанных, иначе
  английский. Неизвестное сохранённое значение читается как System default;
  Debug API отклоняет неизвестное значение.
- Применение языка по порядку: сохранить настройку; выставить локаль даты и
  времени; загрузить словарь языка; прогреть кэш шаблона; заново вывести
  подписи из шаблона; сбросить отложенные настройки на диск; перерисовать
  интерфейс. Словарь и шаблон готовы до первой перерисовки, поэтому ни один
  кадр не смешивает языки. Сбой загрузки словаря или шаблона не блокирует
  переключение: интерфейс остаётся английским и всё равно перерисовывается.
- Первый кадр после запуска уже на сохранённом языке: словарь загружается до
  старта интерфейса.
- При System default смена языка устройства перерисовывает интерфейс и
  переименовывает системные поверхности на лету; при явном выборе смена языка
  устройства игнорируется.
- Что остаётся английским при переключении: все машинные поверхности, данные
  пользователя, сохранённые ранее снимки текста, языки ленты поддержки,
  которых у неё нет, и известные непереведённые места из Особенностей
  сопровождения фичи.
- Per-app язык Android 13+: явный выбор отправляется в систему; System default
  отправляет пустой список (иначе система возвращала бы последний явный выбор
  и System default была бы мёртвой). При старте три стороны сверяются:
  системный выбор отличается от последнего отправленного приложением —
  пользователь менял его в системных настройках, побеждает система и
  настройка переписывается; система совпадает с последней отправкой, но
  сохранённая настройка другая — хранилище изменилось под ногами
  (восстановление, Debug API, правка руками), сохранённое значение
  отправляется снова; всё совпадает — ничего не происходит. При первом старте
  после обновления непустой системный выбор побеждает, пустой выравнивается по
  хранилищу. Суффикс региона из системы (`ru-RU`) читается как голый язык.
- Ниже Android 13 per-app часть не делает ничего; решает одна настройка.
- Восстановление копии или загрузка набора настроек перечитывает язык и
  запускает тот же конвейер; если значение не изменилось, ничего не происходит.
- Ссылка на руководство в About открывает русское руководство для русского и
  английское для любого другого языка.
- Экраны, держащие тексты из шаблона, перечитывают их при смене языка, не
  теряя ввод пользователя.

## Границы

- RTL-языки не поддерживаются.
- Поставляются только три языка; добавить язык — задача разработчика
  ([translation-workflow](translation-workflow.ru.md)).
- Правила поиска текста и fallback — [english-as-key](english-as-key.ru.md);
  что переименовывает нативная сторона —
  [native-and-core-strings](native-and-core-strings.ru.md).
- Место строки на экране настроек —
  [020-APP_SHELL](../../020-APP_SHELL/FEATURE.ru.md).
- Зависит от возможностей ОС: язык приложения в системных настройках и
  per-app локаль (Android 13+); широковещательное событие смены языка
  устройства.
