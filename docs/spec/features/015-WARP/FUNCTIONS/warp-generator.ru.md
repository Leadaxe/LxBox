# Эксперимент: генератор WARP-узлов — поиск узлов WARP, которые проходят в вашей сети

Эксперимент только создаёт кандидатов; проверяют их штатные проверки узлов.

| Поле | Значение |
|------|----------|
| Фича | [015-WARP](../FEATURE.ru.md) |
| Обещания | P15 |
| Состояние | ✅ написана по коду, 2026-09-28 |

## Что делает

Кнопка «Make experiment» в мастере открывает экран с числом узлов и JSON
пула; «Create» собирает папку «WARP GENERATOR» из случайных WARP-узлов —
AWG, MASQUE h3 и MASQUE h2 на разных адресах, портах, SNI и приманках — по
одной регистрации на транспорт. Дальше пользователь тестирует папку штатной
кнопкой Test и оставляет то, что пролезает в его сети.

## Параметры

| Параметр | Значение | Дефолт |
|----------|----------|--------|
| Number of nodes | 1–200 (вне диапазона — прижимается) | 20 |
| JSON пула | формат файла пула, с `loc.<cc>` | встроенный пул |
| Reset | вернуть встроенный JSON | — |
| Ping URL папки | `https://1.1.1.1/cdn-cgi/trace` (без DNS) | — |
| Таймаут пинга папки | 3000 мс | — |

## Входы / Выходы

**Входы:** число узлов, JSON пула, регион, флаг IPv6; кэш регистраций WG и
MASQUE.

**Выходы:** папка «WARP GENERATOR» (пересоздаётся при каждом запуске)
открывается вместо мастера; «назад» ведёт на Servers. Теги узлов:
`🔥⛈️ WARP AWG (<приманка> <домен>)`, `🔥🎭 WARP MASQUE (h3: <домен>)`,
`🔥🎭 WARP MASQUE (h2: <домен>)`. Снек с замечанием при частичном успехе.

## Правила и инварианты

- **Регистрации.** Берётся кэш каждого транспорта; нет кэша — одна
  регистрация (WG — с дефолтным endpoint, без лицензии), результат
  кэшируется. Не удалась одна — генерация идёт на другой с замечанием
  «MASQUE (h3/h2) unavailable: registration failed — …». Не удались обе или
  пул битый — «Generation failed — no WARP account.»
- **Равноправие.** Протокол кандидата равновероятен среди доступных: AWG —
  если есть WG-блок и WG-порты; h3 — если есть h3-хосты; h2 — если есть
  h2-блок.
- **Кандидат AWG.** Адрес из v4 (v6 только при IPv6) блока; порт — с
  вероятностью 0.3 из эмпирических, иначе из надёжных; домен из SNI-пула WG;
  приманка `quic` (чаще), `dns` или `stun`; junk 4/40/70; без `reserved`;
  keepalive из `wireguard.keepalive` пула (0 — не писать).
- **Кандидат MASQUE.** Адрес и порт из источников своего транспорта (см. пул),
  SNI из MASQUE-пула; таймауты — из кэша регистрации.
- **Неправильный JSON** — «Invalid pool JSON — check the structure.», экран
  не закрывается.
- Эксперимент ничего не пробует и не удаляет мёртвые узлы.

## Границы

- Тест и отбор узлов — 009-NODE_HEALTH (проверка папки).
- «Вариаций вокруг живого IP» (вторая фаза сканера из исследования 132) нет
  и не планируется (решение владельца 2026-09-29, аудит [591](../../../tasks/591-spec-kit-revision-audit.md)).
- Re-register на эксперимент не влияет: он всегда берёт кэш.
