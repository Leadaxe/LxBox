# Обфускация AmneziaWG

| Поле | Значение |
|------|----------|
| Фича | [015-WARP](../FEATURE.ru.md) |
| Обещания | P8 |
| Состояние | ✅ написана по коду, 2026-09-28 |

## Что делает

Галка «Add Amnezia obfuscation» делает WG-узел WARP неузнаваемым для DPI:
перед рукопожатием идут мусорные пакеты, замаскированные под настоящий
протокол (QUIC, DNS, STUN или SIP), а само рукопожатие остаётся побитно
обычным WireGuard — Cloudflare его принимает. Служебный пакет-приманку
`i1` строит ядро по ключам `id`/`ip`/`ib`; приложение его не генерирует.

## Параметры

| Параметр | Ключ ядра | Значения | Дефолт |
|----------|-----------|----------|--------|
| Masquerade protocol | `ip` | `quic` · `dns` · `stun` · `sip` | `quic` |
| Masquerade domain | `id` | домен | случайный из SNI-пула WG; пусто → случайный, иначе `www.google.com` |
| Browser | `ib` | `chrome` · `firefox` · `curl` | `chrome`; пишется только при `ip=quic` |
| Jc / Jmin / Jmax | `jc`/`jmin`/`jmax` | числа | 4 / 40 / 70 |
| Фиксировано | `s1`,`s2` = 0; `h1..h4` = 1,2,3,4 | — | — |

## Входы / Выходы

**Входы:** галка и поля Advanced; SNI-пул WG (с региональной поправкой);
блоки и порты WG пула.

**Выходы:** endpoint `wireguard` с полями AmneziaWG в корне; тег
`🔥⛈️ WARP (AWG 1.5)`.

## Правила и инварианты

- **Рукопожатие не трогается.** `s1=s2=0` и `h1..h4=1..4` — пакеты
  рукопожатия как у plain WG; DPI-сигнатуру сбивают только junk и приманка.
- **`i1` не пишется.** `id`/`ip`/`ib` и явный `i1` взаимоисключающи — ядро
  отвергло бы оба.
- **Домен на проводе** только для `dns` (QNAME) и `sip` (host); для `quic` и
  `stun` он декоративен — мастер об этом подсказывает под выбором протокола.
- **Случайный endpoint.** Включение галки при дефолтном/пустом/ранее
  случайном endpoint ставит случайный `ip:port` из блоков WG пула (порт из
  основных и расширенных портов); 🎲 перебрасывает. Вписанный руками endpoint
  не трогается.
- **Выключение** возвращает все поля к умолчаниям: случайный endpoint →
  дефолт, `reserved` → по галке, протокол `quic`, браузер `chrome`,
  junk 4/40/70, свежий случайный домен.
- **Без новой регистрации.** Обфускация клиентская: включение и выключение
  на кэшированной регистрации пересобирают только поля узла.
- `reserved` по умолчанию снят (см. WireGuard-узел).

## Границы

- Для MASQUE обфускация AWG не применяется — галка скрыта.
- Порядок и фрагментация QUIC Initial внутри `i1` — забота ядра.
- Проверка, пролезает ли конкретная приманка в сети, — пинг узла
  (009-NODE_HEALTH) или эксперимент.
