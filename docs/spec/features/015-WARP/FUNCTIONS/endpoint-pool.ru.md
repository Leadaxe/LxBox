# Пул endpoint'ов и регион

| Поле | Значение |
|------|----------|
| Фича | [015-WARP](../FEATURE.ru.md) |
| Обещания | P12, P13, P14 |
| Состояние | ✅ написана по коду, 2026-09-28 |

## Что делает

Держит в одном встроенном файле всё, что WARP знает о сети Cloudflare:
хосты API регистрации, блоки и порты WireGuard, пресеты endpoint'ов, хосты
и порты MASQUE по транспортам, SNI-пулы и региональные поправки. Мастер и
эксперимент берут из него пресеты, рандом и подсказки; правка пула не
требует правки логики.

## Параметры

Секции файла пула:

| Секция | Ключи | Смысл |
|--------|-------|-------|
| `api` | `hosts` | Хосты регистрации по порядку предпочтения |
| `wireguard` | `v4_cidr`, `v6_cidr` | Блоки для случайного endpoint |
| | `ports`, `ports_extra` | Надёжные порты (2408/500/1701/4500) и эмпирические |
| | `endpoints_preset`, `recommended_endpoint` | Список поля Endpoint и помеченный пункт |
| | `keepalive` | Keepalive узлов эксперимента, с; 0/нет — не писать |
| | `sni_pool` | Домены маскировки AWG (без доменов Cloudflare) |
| `masque` | `hosts_preset`, `recommended_host` | Хосты, где живут и h3, и h2 |
| | `h3.hosts_extra`, `h3.ports` | Хосты только для h3, порты h3 |
| | `h2.v4_cidr`, `h2.exclude`, `h2.ports` | Блок h2 и исключённые из него адреса |
| | `sni_pool`, `recommended_sni` | SNI MASQUE (домены Cloudflare допустимы) |
| `loc.<cc>` | любые ключи выше или `alias` | Поправки для региона |

Настройка «Usage region» (App Settings → General): Auto (страна сети
оператора, затем локали) · Not set · явный код страны.

## Входы / Выходы

**Входы:** встроенный файл пула; настройка региона; флаг IPv6 системы;
JSON-окно эксперимента (тот же формат).

**Выходы:** пресеты и помеченные «(recommended)» пункты мастера; случайные
`ip:port` WG, IP и порт MASQUE, SNI; хосты API для регистрации.

## Правила и инварианты

- **Регион.** Секция `loc.<cc>` накладывается на корень: объекты сливаются
  по ключам, списки и значения заменяются целиком (иначе «убрать домен для
  региона» невозможно). `{"alias": "ru"}` — один переход, без цепочек.
  Неизвестный, пустой или битый регион — корень как есть. Смена региона
  перечитывает пул.
- **Пометка «(recommended)»** — только у пункта, равного явному
  recommended-ключу, на любой позиции, и только в меню: в поле и в конфиг
  уходит чистое значение.
- **MASQUE по транспорту.** h3 — только `hosts_preset` ∪ `h3.hosts_extra`
  (рандом по блоку дал бы мёртвые адреса); h2 — случайный адрес
  `h2.v4_cidr` вне `h2.exclude`. Старый плоский формат (`v4_cidr`,
  `h3_v4_cidr`, `ports_h3`/`ports_h2`) читается как запасной.
- **WG-рандом.** Адрес — полный рандом по хостовой части блока; v6-блоки —
  только при включённом IPv6.
- **Хосты API.** Хвостовой `/` и пустые строки срезаются. Пусто или файл
  битый — встроенный запасной список (совпадает с файлом).
- **Битый пул** — мастер работает на дефолтах (endpoint регистрации, пустые
  пресеты), кнопка эксперимента скрыта.
- **Живые данные (на 2026-09).** WG: `162.159.192/193/195.0/24`,
  `188.114.96.0/22`. MASQUE: `.198.2`, `.199.2` — оба транспорта; `.198.1`,
  `.199.1` — только h3; прочее в `162.159.198/199.0/24` — только h2; порты
  обоих — 443/500/1701/4500/4443/8443/8095. Регион `ru` добавляет
  российские домены в оба SNI-пула.

## Границы

- Пул описывает адреса, а не их живость: измерять — пингом (009-NODE_HEALTH)
  через боевое ядро.
- Регион сегодня влияет только на пулы WARP.
- Автоопределение страны зависит от возможностей ОС.
