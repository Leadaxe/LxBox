## Что это

Группа-узел в подписке бывает двух родов, и род — это сам `entry.type`:
`selector` (человек выбирает члена, поле `default`) и `urltest` (автовыбор
по пингу). Сегодня LxBox знает один род: `AutoSelectSpec` с зашитым
`protocol = 'urltest'`; `selector` при импорте сворачивается в `urltest` с
предупреждением `SelectorAsAutoWarning`, поле `default` только проносится
сквозь бэкап (`manualDefault`), кодек пишет всегда `group_type: urltest`.

Норма контракта (`group.json` → `genus`): sing-box несёт род как есть;
Xray-балансировщик и `autogroup://` — всегда `urltest`. Сторона, не
исполняющая род, обязана пронести `default` (`preserve_unexecuted`). После
этой фичи LxBox род исполняет, и `preserve_unexecuted` остаётся только как
чтение старых записей.

## Как работает после фичи

### Фаза A — род в модели, разборе, эмите, хранении и UI группы

1. **Модель.** У `AutoSelectSpec` появляется род `genus: selector | urltest`
   (значения — из `group.json` `genus.values`, не литералы Dart; читать при
   загрузке реестра). `protocol` = род. `manualDefault` становится активным
   полем рода `selector`: тег выбранного члена.
2. **Разбор.** sing-box `selector` сохраняет род, предупреждение
   `SelectorAsAutoWarning` снимается вместе с тестами на него. Xray
   `balancers[]` и `autogroup://` — `urltest`, как велит `genus.by_source`.
3. **Эмит тела.** `emitRaw`: `type` = род; для `selector` в тело идут
   `outbounds` (состав) и `default`. **Состав в теле результата разбора:**
   группа, чей состав задан источником явно (список тегов в `selector`/
   `urltest` sing-box, `selector` Xray-балансировщика), эмитит эти теги сразу
   при разборе — так ждут оба кейса корпуса; группа папки LxBox с правилом
   набора (`membership`) — как сейчас, состав на сборке. Признак — есть ли у
   группы явный список членов из источника.
4. **Сборка.** `resolveAutoSelectMembers`: для `selector` — состав из явного
   списка, `default` уходит в конфиг ядра; переключение члена в рантайме через
   существующий канал selector-outbound'а ядра (`selectorGroupTags`,
   `home_state.dart`) — проверить, что группа подписки попадает в этот список.
5. **Хранение.** Кодек `auto_group_record.dart` пишет `group_type` по роду и
   `default` для `selector`; чтение старых записей без рода — `urltest`.
   Бэкап — по `backup.schema.json` (`kind: auto` членом папки, `group_type`,
   `default` как NodeLink). Миграции нет: старые записи читаются как прежде.
6. **UI группы** (там, где группы показываются сегодня: `folder_detail_screen`,
   `auto_group_edit_screen`, `outbound_view_screen`): у группы рода `selector`
   вместо параметров urltest — список членов с отметкой текущего `default`,
   выбор члена меняет `default` и пересобирает конфиг. Строки только
   английские. Род показывается меткой рядом с именем группы.
7. **Корпус.** `body/singbox/group_member_missing` и `body/xray/balancer_group`
   зелёные без override. `body_contract_test` — 0 красных.

### Фаза B — группа как канал и «заменить подписку селектором»

Требует нормы контракта: сегодня `backup.schema.json` не допускает
`kind: auto` в корне `sources[]` («не едет»). Нужно согласовать с лаунчером:
корневая группа-источник (провайдерский `selector`/`urltest` как отдельный
канал рядом с подписками) и пользовательский селектор поверх подписки
(состав = все узлы подписки, ручной `default`). Запрос лаунчеру — после фазы A,
отдельной задачей; UI списка каналов — там же.

## Риски

- Identity узлов-членов не меняется; тег группы — по прежним правилам.
- Группы, уже сохранённые как `urltest` из бывшего `selector`, родом назад не
  станут: истина потеряна при старом импорте; при обновлении подписки род
  придёт заново из источника.
- `default` указывает на тег члена; если член выпал на сборке —
  `group_member_dropped` (1.1.67) и `default` на первого живого, с кодом.
