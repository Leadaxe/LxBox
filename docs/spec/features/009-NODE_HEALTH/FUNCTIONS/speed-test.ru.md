# Спидтест

| Поле | Значение |
|------|----------|
| Фича | [009-NODE_HEALTH](../FEATURE.ru.md) |
| Обещания | P17 |
| Состояние | ✅ написана по коду, 2026-09-28 |

## Что делает

Экран Speed Test (из бокового меню) меряет задержку, скорость загрузки и
отдачи текущего пути устройства, не выходя из приложения: через туннель,
если VPN поднят, иначе напрямую. Показывает, через что шёл тест, и хранит
историю прогонов сессии.

## Параметры

| Параметр | Значения | Дефолт |
|----------|----------|--------|
| Server | 10 серверов шаблона: Cloudflare, Hostkey (Moscow / Frankfurt / Amsterdam / Helsinki / New York), Selectel (RU), Tele2 (EU), OVH (France), thinkbroadband (UK) | Cloudflare |
| Streams | 1 / 4 / 10 (шаблон) | 4 (шаблон) |

Выбор сервера запоминается по его идентификатору в шаблоне, не по позиции;
неизвестный — первый сервер.

## Входы / Выходы

**Входы:** адреса сервера (`ping_url`, `download_url`, `upload_url`,
`upload_method`); состояние туннеля и активный узел.

**Выходы:** Ping (мс или «Failed»), Download и Upload (Мбит/с), полоса
прогресса и статус фазы, подпись «Via: <группа/узел>» или «Direct (no
VPN)», история «Session History».

## Правила и инварианты

- **Ping:** 5 последовательных HTTP GET на `ping_url` (иначе
  `download_url`), таймаут 5 с на попытку; учитываются ответы со статусом
  < 400. При 3+ удачных — среднее без минимума и максимума. Ни одного —
  «Failed».
- **Download:** N параллельных потоков GET на `download_url`, общий предел
  15 с; скорость на экране обновляется каждые 0,5 с. Если выбранный сервер
  дал 0 — по очереди пробуются остальные серверы шаблона.
- **Upload:** 2 параллельных потока по 5 МБ методом `upload_method`
  (POST или PUT, дефолт PUT) на `upload_url`, при его отсутствии — на
  `download_url`; общий предел 30 с. Замер — объём отправленных тел за
  время, без учёта ответа сервера.
- История — до 10 прогонов в памяти, до перезапуска приложения.
- Остановить идущий тест нельзя: кнопка неактивна до конца прогона.
- Ошибка фазы — «Error: <причина>» в строке статуса.

## Границы

- Тест не адресует узел и не переключает его: меряется текущий путь.
- Скорость на главном экране — 012-LIVE_STATE.
