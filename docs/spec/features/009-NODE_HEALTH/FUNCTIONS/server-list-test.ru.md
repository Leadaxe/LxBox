# Проверка серверов списка — тест подписки или папки без подключения VPN

Все узлы подписки или папки можно проверить при выключенном VPN, а по
результатам массово выключить медленные узлы и выключить или удалить
мёртвые.

| Поле | Значение |
|------|----------|
| Фича | [009-NODE_HEALTH](../FEATURE.ru.md) |
| Обещания | P3, P9, P10, P11, P12 |
| Состояние | ✅ написана по коду, 2026-09-28 |

## Что делает

Проверяет все узлы подписки или папки без подключения VPN: «добавил пачку
серверов → сразу проверил → выкинул мусор». Кнопка в полосе над списком
запускает и останавливает проверку; у каждого узла появляется бейдж, сверху —
сводка; меню «Test actions» применяет решения к результатам.

## Параметры

| Параметр | Значения | Дефолт |
|----------|----------|--------|
| URL / таймаут | глобальные настройки пинга; у папки — свои, если заданы | таймаут 3000 мс, если не задан глобально |
| Пороги цвета | Green up to / Yellow up to / Orange up to, мс | 250 / 500 / 700 |
| Параллельность | до 6 замеров в сессии | — |
| Узлов naive в одной сессии | 1 | — |
| WireGuard/AmneziaWG-endpoint'ов в одной сессии | 4 | — |

Настройки проверки (адрес/таймаут и пороги) открываются долгим тапом по
кнопке в папке; у подписки своих настроек нет. Непозитивный или пустой
порог сохраняется как дефолт.

## Входы / Выходы

**Входы:** узлы списка, включая выключенные (у папки — и нечитаемые члены);
состояние VPN; ответы временной сессии ядра.

**Выходы:**

| Бейдж | Смысл |
|-------|-------|
| `…` | ещё не проверен |
| `N ms` | жив; цвет — по порогам (зелёный / жёлтый / оранжевый / красный) |
| `err` | ядро вернуло ошибку или таймаут; тап — текст ошибки |
| `broken` | запись не читается — проверять нечего |
| `invalid` | узел не собирается в конфиг или снят проверкой реестра |
| `auto` | узел-группа: не проверяется, нейтральный цвет |

Сводка: `Test servers` → `Testing… N done` → `N ok · N err · N broken`.

| Действие | Папка | Подписка |
|----------|-------|----------|
| Disable slower than… (порог, по умолчанию оранжевый) | ✓ | ✓ |
| Disable unreachable (`err`, `broken`, `invalid`) | ✓ | ✓ |
| Delete unreachable | ✓ | — |
| Sort by ping (живые по возрастанию, затем непроверенные, в конце ошибки) | ✓ | — |

## Правила и инварианты

- **Только при выключенном VPN.** Проверке нужна своя сессия ядра, которая
  не может работать рядом с туннелем. При живом VPN — окно «VPN is running»
  с кнопкой Stop VPN; после остановки проверка стартует сама. Если VPN успел
  подняться между проверкой и стартом сессии — то же окно, а не ошибка.
- **Проверяется чистый узел.** Политика detour Направлений не применяется;
  собственная цепочка узла из его записи сохраняется.
- **Порции.** Узлы без naive и WireGuard идут одной сессией; дорогие по
  памяти добиваются в порции до лимитов, порции идут последовательно, каждая
  сессия закрывается до старта следующей. Узел с цепочкой неделим. Все узлы
  получают вердикт.
- **Результат — по узлу.** Бейдж привязан к идентичности узла (имя внутри
  источника), а не к позиции: удаление или вставка соседа, обновление
  подписки его не сдвигают. Переименование — смена идентичности.
- Выключенные узлы проверяются: вопрос — «жив ли сервер», а не «в конфиге ли».
- Узел-группа в «недоступные» не входит и в сводке не считается.
- Меню действий доступно с первого завершённого вердикта. Если у подписки
  есть правило фильтра, включающее узлы, массовое выключение предупреждает:
  следующее обновление снимет ручные отметки.
- Проверка отменяется кнопкой, остановкой туннеля и сворачиванием
  приложения. Результаты живут, пока открыт экран.
- Фатальная ошибка старта сессии показывается текстом; ошибки отдельных
  узлов — только в их бейджах.
