# Диагностика узла — HTTP-запрос через один узел, чтобы увидеть то, что видят сайты

Вкладка Diagnostics отправляет один HTTP-запрос через выбранный узел и
показывает сырой ответ; это объясняет случаи вроде «пинг есть, а сайты не
открываются» или чужой страны выхода.

| Поле | Значение |
|------|----------|
| Фича | [009-NODE_HEALTH](../FEATURE.ru.md) |
| Обещания | P13 |
| Состояние | ✅ написана по коду, 2026-09-28 |

## Что делает

Отвечает на вопросы, на которые пинг не отвечает: «пинг есть, а сайты не
открываются», «сервисы считают меня другой страной», «WARP подключён, а
`warp=off`». Вкладка Diagnostics в деталях узла отправляет через этот узел
один HTTP-запрос к выбранному сервису и показывает ответ как есть — не
переключая активный узел и не трогая живые соединения.

## Параметры

| Проверка | Адрес |
|----------|-------|
| Cloudflare trace (дефолт) | `https://1.1.1.1/cdn-cgi/trace` |
| Cloudflare trace (hostname) | `https://cloudflare.com/cdn-cgi/trace` |
| IP & location | `https://api.ip2location.io/` |
| IP info | `https://ipinfo.io/json` |

Таймаут обмена — 10 с; тело ограничено 64 КиБ. Своего адреса ввести нельзя
намеренно: вкладка не должна стать HTTP-клиентом через чужие туннели.

## Входы / Выходы

**Входы:** узел (разобранный узел подписки, папки или сервера; с экрана
просмотра собранного конфига — только тег); состояние VPN; ответ ядра
`getURLViaOutbound` — статус, тело, признак обрезки, адрес назначения,
время обмена или текст ошибки.

**Выходы:**

| Что видно | Когда |
|-----------|-------|
| `<статус> · <N>ms`, тело моноширинно, кнопка копирования | обмен состоялся (любой HTTP-статус; 2xx выделен) |
| «Response was longer and got cut off.» | тело обрезано ядром |
| «Connected to %s from inside the tunnel» | ядро сообщило адрес назначения |
| Подпись источника: «Through this node in the running core — not through your current route» / «Through this node in a temporary core session» | всегда при результате |
| Текст ошибки ядра красным | обмен не состоялся |
| Пояснение вместо результата | прогон невозможен (причины ниже) |

## Правила и инварианты

- **Ветка выбирается сама** по состоянию VPN, переключателя нет:

  | VPN | Через что |
  |-----|-----------|
  | включён | боевое ядро, узел адресован своим тегом в конфиге (с префиксом списка) |
  | выключен | временная сессия ядра из одного этого узла и его собственной цепочки; гасится сразу после ответа |

- **Причины «прогон невозможен»:**

  | Причина | Что видит пользователь |
  |---------|------------------------|
  | `group` — узел автовыбора | «This is an auto-select node — it has no connection of its own. Open a member to diagnose it.» |
  | `no_node` — известен только тег, VPN выключен | «Start the VPN to check this node from here, or open it from its subscription to check it with the VPN off.» |
  | узел не собирается в конфиг | причина сборки |
  | не поднялась временная сессия | текст ошибки сессии |
  | `cancelled` | прогон снят остановкой или сворачиванием |

- Не-2xx (например, 429 лимитированного сервиса) — обычный результат, а не
  признак мёртвого узла.
- Тело не разбирается: пользователь читает то, что прислал сервис; смена
  формата сервиса вкладку не ломает.
- Запуск только по кнопке Run: открытие вкладки ничего не отправляет.
- У узла Tailscale без действующего exit node внешняя проверка скрыта с
  пояснением «This node has no exit. Check devices on the Network tab.».
- Отмена — как у проверки серверов: стоп туннеля и сворачивание снимают
  прогон.
- Ниже проверки — секция Notifications с предупреждениями узла (если есть);
  точка на ярлыке вкладки — жёлтая, красная при уровне error.

## Границы

- Не отвечает «через что я хожу сейчас»: живой маршрут с правилами и выбором
  групп проверяется обычным запросом с устройства.
- Послойная проба цепочки (блок над проверкой на экране цепочки) —
  [006-DETOUR_AND_BALANCE](../../006-DETOUR_AND_BALANCE/FEATURE.ru.md).
- Тексты и группировка уведомлений — [013-DIAGNOSTICS](../../013-DIAGNOSTICS/FEATURE.ru.md).
