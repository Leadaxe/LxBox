# URLTest-группа — как группа автовыбора ядра меряет и выбирает узел

Группа автовыбора `urltest` по расписанию меряет свои члены и переключается
на лучший; приложение задаёт её параметры и умеет запустить перепроверку.

| Поле | Значение |
|------|----------|
| Фича | [009-NODE_HEALTH](../FEATURE.ru.md) |
| Обещания | P6, P7, P8 |
| Состояние | ✅ написана по коду, 2026-09-28 |

## Что делает

Даёт группе автовыбора ядра (`urltest`) параметры проверки здоровья её
членов и выбора лучшего: как часто и каким адресом мерить, при какой разнице
переключаться, распределять ли нагрузку по пулу. Позволяет вручную
заставить группу перемерить всех членов и перевыбрать узел — пунктом «Run
URLTest» в меню группы.

## Параметры

| Параметр | Ключ ядра | ✨auto (шаблон) | Направление / узел автовыбора |
|----------|-----------|-----------------|-------------------------------|
| Test URL | `url` | `https://cp.cloudflare.com/generate_204` | то же |
| Test interval | `interval` | `15m` (пресеты `30s`…`30m`) | `15m` |
| Tolerance, мс | `tolerance` | 30 (пресеты 10…200) | 50 |
| Idle timeout | `idle_timeout` | — (дефолт ядра `30m`) | `30m` |
| Рвать живые соединения при смене | `interrupt_exist_connections` | вкл | выкл |
| Passive health check | `passive_check` | — | вкл (одна настройка на все группы Направлений) |
| Режим | `mode` | `least_test` | `least_test` · `round_robin` |
| Размер пула | `balancer.pool` | — | 3, не меньше 1 |
| Порог пула, мс | `balancer.pool_tolerance` | — | 0 |
| Ключ липкости | `balancer.sticky_hash` | — | `process` + `domain` |

Компоненты липкости: `process`, `domain`, `source_ip`, `dest_ip`,
`dest_port`; неизвестный компонент отбрасывается. Смысл режимов, пула и
штрафов — фича ядра 007-URLTEST_BALANCE.

## Входы / Выходы

**Входы:** значения из редактора Направления, узла автовыбора, свёртки
источника или переменных шаблона; группы из тела подписки (sing-box, Xray
балансер) со своими таймингами; жест «Run URLTest».

**Выходы:** запись `urltest` в конфиге ядра; RPC `urlTestGroup` — ядро
тестит всех членов адресом группы, переселектирует живой узел и рвёт
зависшие соединения группы; новый выбор приходит потоком групп.

## Правила и инварианты

- **`tolerance` — целое 0…65535.** Значение вне диапазона клампится;
  строка-число из старого хранения читается как число, в конфиг уходит числом.
- **`balancer` и `mode` — только при `round_robin`.** При `least_test` ни
  того, ни другого в конфиге нет: ядро отвергает `balancer` вне
  `round_robin`, а плоские `pool`/`pool_tolerance` — как неизвестные поля.
- **Выключенная липкость — `["none"]`.** Пустой набор компонентов в конфиг
  уходит сентинелом; пустой список ядро прочло бы как дефолт.
- **`pool_tolerance` у узла автовыбора** ограничен 15000 мс (предел ядра);
  у Направления и свёртки — только диапазоном `tolerance` (см. отчёт о
  расхождениях).
- **Пара таймингов.** Если действующий `interval` больше действующего
  `idle_timeout` (с учётом дефолтов ядра `3m`/`30m` при отсутствии или нуле),
  сборка поднимает `idle_timeout` до `interval`, а при отсутствии `interval`
  — до `3m`. `interval` не меняется никогда. Каждое вмешательство —
  предупреждение сборки с обеими величинами. Нераспознанное ядром значение не
  трогается — ядро назовёт ошибку само. Правило общее для Направлений, узлов
  автовыбора, групп подписок и Xray-балансеров, для обоих режимов.
- В редакторе под полями interval/idle timeout показывается серая подсказка
  «Idle timeout will be raised to %s when the config is built» — сохранить
  можно.
- **Run URLTest** доступен только у URLTest-групп при поднятом туннеле;
  ответ ядра приходит сразу, выбор меняется асинхронно. Отказ RPC —
  сообщение об ошибке в баннере.
- **Автоматический переселект** запускается также при провале пинга
  выбранного группой узла и в конце массового пинга
  ([node-ping](node-ping.ru.md)). Повторные запуски во время идущего теста ядро
  гасит само.
- Пустая группа в конфиг не эмитится: `urltest` без членов роняет ядро.
