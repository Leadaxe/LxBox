# Настройки пинга

| Поле | Значение |
|------|----------|
| Фича | [009-NODE_HEALTH](../FEATURE.md) |
| Обещания | P5 |
| Состояние | ✅ написана по коду, 2026-09-28 |

## Что делает

Задаёт, куда и с каким бюджетом времени пингуются узлы: общий адрес и
таймаут на все Направления либо свои для отдельного Направления. Открывается
долгим тапом по кнопке пинга на главном экране; общий адрес также правится из
настроек проверки в папке.

## Параметры

| Параметр | Значения | Дефолт |
|----------|----------|--------|
| Test URL | любой URL; пресеты Google 204, Cloudflare, Apple, Firefox, Yandex | `https://www.gstatic.com/generate_204` |
| Timeout (ms) | целое > 0 | 5000 |
| Область | All directions / текущее Направление | переопределение есть → Направление, иначе All |
| Reset to global | снимает переопределение Направления | — |

Пресеты и дефолты берутся из шаблона (`ping_options.url`,
`ping_options.timeout_ms`, `ping_options.presets`), имена пресетов — на
языке интерфейса.

## Входы / Выходы

**Входы:** ввод пользователя в шторке; Debug API (чтение и запись секции).

**Выходы:** действующие URL и таймаут для одиночного и массового пинга
([node-ping](node-ping.md)); для проверки серверов
([server-list-test](server-list-test.md)) и послойной пробы цепочки — только
глобальные значения.

## Правила и инварианты

- **Цепочка разрешения** для пинга на главном экране: переопределение
  текущего Направления → глобальное значение → дефолт шаблона. Пустой URL и
  неположительный таймаут считаются незаданными.
- Переопределение хранит URL и таймаут независимо: заданное одно поле не
  обязывает задавать второе.
- Шторка открывается в режиме Направления, если у него уже есть
  переопределение, и показывает его значения; иначе — глобальные.
- **Удаление Направления** снимает его переопределение; переопределения
  прочих Направлений не трогаются. Пустой набор переопределений удаляется
  целиком, а не остаётся пустым.
- Переопределения Направлений едут в резервную копию вместе с Направлениями.
- Проверка серверов в папке и подписке переопределения Направлений не видит:
  там URL и таймаут глобальные, а у папки — свои, если заданы (такие задаёт
  сканер WARP).
- Изменение настроек конфиг ядра не пересобирает: значения читаются при
  каждом замере.

## Границы

- Адрес теста URLTest-группы ядра (`url` группы) — отдельная настройка
  группы, см. [urltest-group](urltest-group.md); настройки пинга на
  групповой тест не влияют.
- Экспорт и импорт — 017-BACKUP_AND_STORAGE.
