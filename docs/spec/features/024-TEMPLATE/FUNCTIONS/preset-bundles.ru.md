# Язык и каталог пресетов — как пресет объявляется в шаблоне и какие пресеты поставляются

Пресет — самодостаточный бандл в `selectable_rules[]`: метаданные каталога, переменные, rule set,
правила маршрута и DNS-части, записанные на языке шаблона; пользователь добавляет его по ссылке и
настраивает несколькими переменными.

| Поле | Значение |
|------|----------|
| Фича | [024-TEMPLATE](../FEATURE.ru.md) |
| Обещания | P8 P9 P12 |
| Состояние | ✅ написана по коду, 2026-09-29 |

## Что делает

Задаёт язык, на котором пишется пресет, и каталог поставляемых пресетов.
На экране Routing каталог — таб **Presets** с кнопкой «Add to Rules» (после
добавления — «In Rules»). Пресет в списке правил — ссылка на шаблон плюс
значения его переменных: обновилось приложение — обновилось поведение у
всех. Пресет может нести сразу rule set'ы, несколько правил маршрута,
DNS-серверы и DNS-правила.

## Параметры

**Объявление пресета** (ключи одной записи `selectable_rules[]`):

| Ключ | Смысл |
|---|---|
| `preset_id` | стабильный id; запись в хранении ссылается на него; пространство тегов пресета |
| `ui{label, description, default, locked, num, isSortable}` | запись каталога: название и описание, включён на чистой установке, не выключается и не удаляется, место на оси порядка, можно перетаскивать |
| `vars[]` | свои переменные пресета с тем же объявлением, что у переменных секций; `{"ref": "<глобальная>"}` показывает глобальную; переменная с именем `outbound` — заменяемая цель |
| `rule` / `rules` | одно правило маршрута или массив, на языке шаблона; `"@outbound"` — цель |
| `rule_set[]` | определения rule set, на которые ссылаются правила; `#enable` гейтит набор переменной |
| `dns_servers[]`, `dns_rule` / `dns_rules` | DNS-часть; описана в [005-DNS](../../005-DNS/FEATURE.ru.md) |
| `for_each{node_type, as, filter}` | тело повторяется на узел; становятся доступны `@node` и `#tpl` |
| псевдопеременные `rule_enable`, `dns_enable` с `#on_change` | реагируют на переключение пресета и его DNS-части; пересчитывают глобальные |

**Каталог** (11 пресетов в поставляемом шаблоне):

| Пресет | Умолч. | Номер | Что делает | Переменные |
|---|---|---|---|---|
| Traffic Processing | вкл, закреплён | 0 | `sniff`, `hijack-dns` для `protocol: dns`, `resolve` | Packet sniffing, Sniff timeout, Hijack DNS, Resolve destination IP¹, Resolve strategy¹ |
| Tailscale networks | вкл | 945 | на каждый узел Tailscale: `preferred_by` → узел, резолв его DNS | DNS |
| Private IPs | выкл | 950 | `ip_is_private` | Outbound (`direct-out`) |
| Block Ads | выкл | 960 | внешний `ads-all` → reject | — |
| Google push (FCM) | выкл | 970 | хосты FCM и порты 5228–5230 | Outbound, Limit to Google Play Services |
| BitTorrent | вкл | 980 | `protocol: bittorrent` | Outbound (`direct-out`) |
| VoWiFi (carrier calling) | вкл | 990 | `pub.3gppnetwork.org`, UDP 500/4500 | Outbound, Match IKE ports |
| Russia-only services | выкл | 1110 | внешний список «доступно только из РФ» | Outbound, Force IPv4 |
| Ru internet segment | вкл | 1120 | ru-TLD, сервисы, GeoIP-RU, российские приложения | Outbound, DNS, UDP server IP, GeoIP IP-range fallback, Russian apps by package, Force IPv4 |
| FakeIP | выкл | 1130 | только DNS (см. 005) | DNS, Block HTTPS records |
| Unknown traffic | выкл | 1150 | трафик без приложения-владельца | outbound (`reject`) |

¹ глобальная переменная по `ref`: общая для всего приложения, а не для правила.

Виды переменных в редакторе пресета: переключатель, выбор из списка,
текст/число, цель (Направление), DNS-сервер. Скрытые переменные шаблона
(`wizard_ui: hidden`) не показываются.

## Входы / Выходы

**Входы:** `selectable_rules` шаблона; запись пресета (id, значения, отличные
от умолчаний, переопределение цели); глобальные переменные; кэш внешних
наборов; узлы итогового конфига (для `for_each`).
**Выходы:** фрагменты в `route.rule_set`, `route.rules` (в позиции пресета),
DNS-часть — в [005-DNS](../../005-DNS/FEATURE.ru.md); теги в пространстве
`<preset_id>:<tag>`.

## Правила и инварианты

- Хранится только id пресета и значения, отличные от умолчания; выбор
  умолчания снимает ключ. Имя в редакторе только для чтения — живое название
  из шаблона текущей локали.
- Цель пресета, выбранная пикером, заменяет решение шаблона целиком:
  reject ↔ Направление ↔ `direct`; промежуточные `resolve`/`sniff` не
  затрагиваются. `reject` всегда становится `action: reject`.
- Фрагмент, выключенный переменной (`#if`/`#enable`), не эмитится; правило,
  у которого после подстановки не осталось ни цели, ни условий, выпадает с
  предупреждением.
- Пресет, которого нет в шаблоне: пропуск сборкой, в списке «Preset not
  found — tap to fix».
- Теги, объявленные внутри пресета (DNS-серверы, rule set), и ссылки на них
  получают префикс `<preset_id>:`; ссылка на чужой тег остаётся как есть; у
  пресета с `for_each` префикса нет (`<узел>-dns`). Одинаковые rule set двух
  пресетов регистрируются один раз; разные с одним тегом — первый побеждает,
  предупреждение.
- **Traffic Processing:** засевается всегда, если его нет; его свич
  недоступен, удаление скрыто, drag запрещён. Выключение Packet sniffing
  отключает матч по протоколу (и по домену без FakeIP); выключение Hijack
  DNS отключает FakeIP и все DNS-правила — предупреждение в подсказке.
- Засев на чистой установке: пресеты с `default: true`, один раз. Пресет,
  ставший дефолтным позже (Tailscale networks), добавляется существующим
  пользователям один раз — [жизненный цикл шаблона](template-lifecycle.ru.md).
- Копии одного пресета при загрузке схлопываются — остаётся последняя.
- `on_change` псевдопеременной срабатывает из каждого места, где меняется
  состояние пресета (свич маршрутизации, тумблер DNS, редактор, настройки
  DNS); включение FakeIP выключает «Resolve destination IP» — см. 005.
- Строка пресета в списке: подпись из изменённых переменных, чип «DNS», если
  пресет трогает DNS; пикер цели — только у пресетов с целью.

## Границы

- Сами конструкции (`#if`, `#enable`, `for_each`, `#tpl`, ref-переменные,
  приведение) — [язык шаблона](template-language.ru.md).
- Ось порядка, drag, неподвижная голова —
  [004-ROUTING](../../004-ROUTING/FEATURE.ru.md); пресеты не переносятся
  обменом правилами — [rule-transfer](../../004-ROUTING/FUNCTIONS/rule-transfer.ru.md).
- Своих пресетов пользователь не создаёт.

## Документация

- Раздел каталога пресетов в [`docs/TEMPLATE.md`](../../../../TEMPLATE.md)
  (`selectable_rules[]`, объект `ui`, полевая матрица, магические
  переменные, `for_each`).
- Текст пресета одинаков в шаблонах обеих сторон; новый пресет или новая
  конструкция пресета идёт в контракт лаунчера вместе со случаем корпуса —
  см. [Развитие клиента](extending-the-client.ru.md).
