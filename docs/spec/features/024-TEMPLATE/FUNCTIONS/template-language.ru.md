# Язык шаблона — типизированные переменные, условия и обход узлов

Язык шаблона превращает переменные, условия `#if` и обход узлов (`for_each_node`,
`for_each_node_do`) в конкретный JSON sing-box; объявленный тип решает, как записывается значение.

| Поле | Значение |
|------|----------|
| Фича | [024-TEMPLATE](../FEATURE.ru.md) |
| Обещания | P1 P2 P3 P5 P6 P7 P15 |
| Состояние | ✅ написана по коду, 2026-09-28; контракт 1.1.119 ([643](../../../tasks/643-contract-1-1-119-node-loops.md)), 2026-10-14 |

## Что делает

Превращает декларативный шаблон с переменными и условиями в конкретный
JSON. Правило разметки одно: `#` — ключевое слово движка, `@` — ссылка на
переменную, всё остальное — данные. Норматив языка — общий с лаунчером
(см. раздел «Документация» ниже).

## Параметры

**Типы переменных и приведение:**

| `type` | В конфиг | Замечание |
|---|---|---|
| `bool` | `true`, если значение после trim без учёта регистра = `true`, иначе `false` | |
| `int` | число, зажатое в 0..65535; не число — строкой + `template_int_invalid` | вне 0..65535 — `template_int_clamped` |
| `text_list` | массив строк: построчно, trim, пустые выброшены | |
| `text`, `secret`, `enum`, `outbound`, `dns_servers` | строка дословно | `options` на приведение не влияют |
| без объявления | строка дословно | legacy-значения |

Значение переменной: запись пользователя, иначе `default_value`. Пустое
при `required` и непустом умолчании → умолчание (не для `secret`).
Переменная с границами (`dns_cache_capacity` 1024..65535): вне границ —
умолчание.

**Поля объявления, меняющие хранение значения:**

| Поле | Действие |
|---|---|
| `unique: true` | только у `text_list` (у другого типа — ошибка загрузки); значение никогда не держит дубликатов, побеждает первое появление: редактор снимает их при сохранении, хранимое значение нормализуется при чтении, то же — для `default_value` и для списка, собранного `#do` |
| `wizard_ui: "internal"` | переменная только для сборки: строки нет ни в одной форме; значение из состояния и из бэкапа игнорируется, база — `default_value`; в состояние не пишется, не экспортируется; импорт снимает её с `backup_var_skipped` (`reason: internal`). В отличие от `hidden`, чьё значение остаётся данными пользователя. Вне пресета с `#do` это константа `default_value` без строки в форме |

**Конструкции:**

| Конструкция | Смысл |
|---|---|
| `"@name"` (вся строка) | подстановка типизированного значения; внутри строки `@` — литерал |
| `{"#tpl": "@{node}-dns"}` | составная строка; пустое или неизвестное → узел снят |
| `"#if…": {"#and"\|"#or": […], "#value": …, "#else": …}` | ключом объекта — поля ветки вливаются в объект; единственным ключом элемента массива — элемент заменяется веткой или выпадает |
| `"#enable": <условие>` | узел существует, только если условие истинно; содержимое не вычисляется |
| `"#on_change": {"#set": {"@x": …}}` | при переключении переменной разово записать производные |
| `{"ref": "<глобальная>"}` в `vars` пресета | переменная по ссылке на глобальную |
| `for_each_node: {"#filter": …}` у пресета | тело повторяется для каждого прошедшего узла; в области видимости `@node`, `@node.skip_presets`, `@node.body.<путь>` |
| `for_each_node_do: {"#filter": …, "#do": …, "#final": …}` у пресета | обход собирает значения в собственные переменные пресета типа `text_list`; тело раскрывается один раз после обхода, без `@node` |

Предикаты: `"@v"` (bool), `{"@v": "литерал"}`, `{"@v": "#notEmpty"|"#isEmpty"}`,
`{"@v": {"#in"|"#notIn": […]}}`, `{"@v": {"#matches": "re"}}`,
`{"#not": …}`; вложение условий на любую глубину. Легаси-написания без `#`
(`and`, `value`, `enabled: "@var"`) читаются бессрочно.

**Обход узлов** (`TEMPLATE_LANG.md` §6.5–§6.7). Ключ обхода у пресета не
больше одного. Ключи внутри — закрытый список, все с `#`, непомеченных
алиасов нет:

| Ключ | `for_each_node` | `for_each_node_do` | Смысл |
|---|---|---|---|
| `#filter` | необязателен | необязателен | полное условие `#if` без обёртки `#if`/`#value`; ключа нет — проходит каждый узел; тип узла — условие на `@node.body.type` |
| `#do` | ошибка загрузки | обязателен | `{"@имя": {"#append": <ссылка или #tpl>}}`: имя — `text_list`, объявленный в `vars` этого пресета; пустое значение пропускает узел; дедупа нет |
| `#final` | ошибка загрузки | необязателен | `{"@имя": {"#unique": true, "#sort": true, "#limit": N}}` один раз после обхода; применяется как unique → sort (порядок байтов) → limit при любом порядке ключей |

Сборка `for_each_node_do` идёт так: база (значение пользователя или
`default_value`) → обход → `#do` → `#final` → `unique` объявления → тело
один раз. Собранный список живёт только в сборке и не хранится; пустой итог —
`[]`, а правило, оставшееся без условий, снимается с
`template_fragment_dropped`.

**Доступ к узлу** (`TEMPLATE_LANG.md` §6.6). Имя фиксировано:

| Ссылка | Значение |
|---|---|
| `@node` | итоговый тег узла в конфиге |
| `@node.<поле>` | поле записи узла в хранилище; сегодня только `skip_presets` |
| `@node.body.<путь>` | поле тела узла, путь через точку |

Отсутствующее поле — пустое значение: в условии ложь, ключ или элемент
выпадает из тела. У узла подписки записи нет, поэтому `@node.skip_presets`
для него ложь.

## Входы / Выходы

**Входы:** фрагмент шаблона (каркас, тело пресета, тело шаблонного DNS-
сервера), значения переменных, для обхода — узлы итогового конфига.
**Выходы:** JSON-фрагмент; предупреждения движка с кодом и параметрами
(`template_var_undeclared`, `template_unknown_directive`,
`template_int_clamped`, `template_int_invalid`, `template_fragment_dropped`),
без дублей по паре «код + параметры».

## Правила и инварианты

- Ветка выбирается до обхода; отброшенная ветка не вычисляется и не даёт
  предупреждений. Несколько `#if` на одном объекте различаются суффиксом
  (`#if1`, `#if tun-only`) и применяются в отсортированном порядке.
- Ветка `#if` элемента массива, сама являющаяся массивом, вливается в
  родителя на один уровень.
- В рантайме необъявленное `@имя` остаётся литералом, неизвестная
  `#`-директива-сосед снимается — оба с предупреждением. На загрузке те же
  ошибки в поставляемом шаблоне отвергают шаблон.
- Предупреждения шаблона идут первыми в отчёте сборки, показываются снеком
  с раскрытием списка и сохранение конфига не блокируют.
- Ref-переменная не имеет своих метаданных и значения: тип, варианты и
  значение берутся у глобальной; в редакторе правила она показывается с
  метаданными глобальной, правка пишет в глобальную. Копия в записи
  пресета игнорируется и вычищается.
- В записях шаблонных DNS-серверов и пресетов значение, равное умолчанию,
  не хранится; необъявленное имя снимается (`outbound` законен у любого
  пресета как универсальная замена цели).
- `on_change` — разовый эффект в момент переключения, не замок: цель можно
  переопределить руками. Пример: `ipv6_enabled` ставит `dns_strategy` и
  `resolve_strategy` в `prefer_ipv4` / `ipv4_only`. Псевдопеременные
  пресета `@rule_enable` / `@dns_enable` пересчитывают глобальные цели при
  включении пресета и его DNS-части (FakeIP гасит `resolve_enabled`).
- Обход проходит только включённые узлы, попавшие в итоговый конфиг (не
  снятые гейтом реестра, гейтом ядра или деградацией), в порядке конфига;
  контейнер значения не имеет (свой сервер, член папки, узел подписки). Теги
  пресета с `for_each_node` без префикса пресета (`<узел>-dns`); у тела
  `for_each_node_do` узла нет, поэтому его теги с префиксом, как у обычного
  пресета. Проба узла пресеты с обходом не раскрывает.
- Структурная ошибка обхода — ошибка загрузки всего шаблона: снятый
  `for_each` (с `node_type` / `as`), оба ключа обхода в одном пресете, любой
  другой ключ внутри обхода, включая непомеченные `filter` / `do` / `final`,
  `#do` или `#final` в `for_each_node`, `#do` на имя вне переменных
  `text_list` этого пресета, `@node` в теле `for_each_node_do`, переменная с
  именем `node` или `node.*`. Пресет один не снимается никогда: прежний мягкий
  снос (§83) ушёл вместе с `for_each`.
- `@runtime.platform/arch/target` на телефоне объявлены без значения: ключ
  или элемент выпадает, в условии — ложь.
