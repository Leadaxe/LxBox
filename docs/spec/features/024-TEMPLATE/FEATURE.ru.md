# Шаблон конфига — встроенный шаблон, его язык, пресеты и развитие клиента через него

LxBox поставляет один шаблон конфига, `wizard_template.json`, который объявляет каждую настройку
VPN, каркас конфига sing-box, каталог пресетов и каталог DNS; приложение развивается правкой
этого шаблона, а не только кодом. Язык шаблона — типизированные переменные, подстановка `@var`,
условия `#if`, `for_each` по узлам — общий с десктопным лаунчером, у него есть норматив и
тестовый корпус. Фича владеет шаблоном как сущностью: его схемой, языком, языком пресетов, тем,
что происходит с переопределениями пользователя, когда с обновлением приложения приходит новый
шаблон, и процедурой добавления возможности через шаблон.

## Назначение

Шаблон — единственный источник структуры и умолчаний: какие настройки
существуют, какого они типа и на каком экране показываются, как выглядит
каркас конфига ядра, какие пресеты и DNS-серверы можно включить. Экраны
настроек и сборка читают один файл, поэтому умолчание на экране и в конфиге
совпадает по построению. Шаблон — самостоятельная сущность: большая часть
новых продуктовых возможностей — пресет, DNS-сервер, переменная с полем на
экране, rule set внутри пресета — добавляется правкой одного шаблона, а код
меняется только когда сам язык получает новую конструкцию.

Принципы, которые фича защищает:

1. **Шаблон — данные, а не код.** `#` — ключевое слово движка, `@` — ссылка
   на переменную, всё остальное — JSON sing-box; язык один и тот же на
   телефоне и в лаунчере.
2. **Кривой поставляемый шаблон — дефект поставки.** Он отвергается при
   загрузке, а не при сборке; данные пользователя никогда не делают шаблон
   невалидным.
3. **Хранение держит только переопределения.** Значение пользователя, равное
   умолчанию шаблона, не хранится; новое умолчание шаблона доходит до всех,
   кто его не менял, а изменение пользователя переживает обновление шаблона.
4. **Пресет — ссылка, а не копия.** Обновление приложения меняет поведение
   пресета у всех; пользователь хранит только id пресета, значения, отличные
   от умолчаний, и переопределение цели.

## Обещания

- **P1. Значение переменной приводится по объявленному типу, а не по виду.**
  `bool`/`int` приводятся, `text`/`secret`/`enum`/`outbound`/`dns_servers`
  идут строкой дословно: пароль `1234` остаётся строкой, `urltest_tolerance`
  уходит числом. Свидетель: юниты «secret/text: НЕ коэрсятся даже если
  выглядят как число/bool», «urltest_tolerance подставляется числом, а не
  строкой». Мутация: угадывать тип по содержимому строки.
- **P2. В конфиг не уходит значение, которое ядро отвергнет.** `int`
  зажимается в 0..65535; у переменной с границами (`dns_cache_capacity`
  1024..65535) значение вне границ заменяется умолчанием; пустое
  обязательное — умолчанием (кроме `secret` и необязательных). Свидетель:
  юниты «int зажимается в 0..65535», «размер кэша вне границ не попадает в
  конфиг — действует 4000», «пустое обязательное int → умолчание»,
  «пустое необязательное умолчанием не заменяется». Мутация:
  подставлять сохранённую строку как есть.
- **P3. Условие вычисляется лениво, ложное без `#else` убирает узел.**
  Отброшенная ветка не обходится; элемент массива выпадает, ключ снимается.
  Свидетель: юниты «внешнее условие ложно — вложенное в отброшенной ветке
  не влияет», «ложно без else — элемент выпадает», корпус контракта
  по движку шаблона. Мутация: обходить обе ветки.
- **P4. Кривой поставляемый шаблон отвергается при загрузке, а не при
  сборке.** Исключение: пресет с неполным `for_each` снимается один, шаблон
  живёт. Свидетель: юниты «реальный bundled wizard_template.json проходит
  валидацию», «сломанный #enable поставляемого шаблона отвергается на
  загрузке», «for_each без as — снимается только этот пресет», «боевой пресет
  tailscale проходит валидацию». Мутация: валидация только в сборке.
- **P5. Неизвестное в рантайме не роняет сборку, но видно.** Необъявленное
  `@имя` остаётся литералом, неизвестная `#`-директива снимается — оба с
  кодом предупреждения; предупреждения шаблона идут первыми в отчёте сборки
  и сохранение не блокируют. Свидетель: юниты «неизвестное @имя →
  плейсхолдер остаётся», «неизвестный #-ключ-сосед снимается», виджет-тест
  «N предупреждений — снек, кнопка открывает шторку». Мутация: тихий дроп.
- **P6. Ref-переменная пресета читает глобальное значение.** Своё значение
  в записи пресета игнорируется. Свидетель: юниты «ref-переменная: значение
  из глобальных → включён», «глобального значения нет, есть только в записи
  пресета → выключен». Мутация: читать ref из записи пресета.
- **P7. `for_each` даёт одно тело на каждый узел, реально попавший в
  конфиг.** Ноль узлов — пресет пуст; `filter` (например `skip_presets`)
  исключает узел. Свидетель: юниты «ноль узлов — пресет пуст», «два узла —
  повторы подряд в порядке узлов, теги без неймспейса», «filter ложен
  (skip_presets)». Мутация: обслуживать выключенный или снятый гейтом узел.
- **P8. Пресет — ссылка на шаблон:** разворачивается на каждой сборке;
  умолчания переменных не хранятся; цель пользователя заменяет решение
  шаблона целиком, промежуточные `resolve`/`sniff` не трогает. Свидетель:
  юниты «outbound override == vpn-tag», «override vpn-1 → #if-гейт роняет
  resolve; route получает override», «все пресеты шаблона: умолчания в vars
  ≡ пустые vars». Мутация: копия тела пресета в правиле.
- **P9. Битый пресет не ломает сборку:** нет в шаблоне — пропуск и «Preset
  not found — tap to fix»; правило без полей-условий выпадает. Свидетель:
  юниты «broken preset (presetId не найден) → warning + skip», «§571:
  правило без полей-условий реестра выпадает с кодом». Мутация: правило
  без условий матчит весь трафик.
- **P10. Дефолтный пресет засевается один раз.** На чистой установке пресеты
  с `default: true` добавляются однократно; пресет, ставший дефолтным в более
  позднем шаблоне, добавляется один раз пользователю с сохранённым
  состоянием и не возвращается после того, как пользователь его удалил.
  Свидетель: юниты «дефолты засеяны раньше: пресет добавляется один раз»,
  «пресет уже есть — дубля нет», «свежая установка не трогается; первый seed
  закрывает шаг». Мутация: засев на каждом старте.
- **P11. Хранятся только переопределения.** В записях пресетов и шаблонных
  DNS-серверов значение, равное умолчанию шаблона, не пишется, выбор
  умолчания в редакторе снимает ключ, а имя, которого шаблон не объявил,
  снимается при следующей записи (`outbound` разрешён у любого пресета).
  Свидетель: юниты «умолчание, пустое и необъявленное снимаются, значение
  подрезано», «редактор: выбор умолчания снимает ключ», «outbound законен у
  пресета без объявления». Мутация: хранить полную копию переменных.
- **P12. Теги пресета живут в его пространстве.** DNS-сервер или rule set,
  объявленный внутри пресета, получает в конфиге тег `<preset_id>:<tag>`, и
  ссылки на него внутри пресета следуют за ним; чужой тег (общий rule set,
  Направление, `direct-out`) не трогается; у пресета с `for_each` теги без
  пространства. Запись формы 2.23.2 читается в то же пространство.
  Свидетель: юниты «теги сборки — в пространстве пресета», «запись: ref без
  повтора пространства», «ранняя запись 2.23.3 с повтором пространства
  читается терпимо», «два узла — теги без неймспейса». Мутация: два пресета
  с одним локальным тегом — второй молча теряет свой сервер.
- **P13. Резервная копия несёт переопределения, а не шаблон.** Переменные
  принимаются только по именам, объявленным шаблоном этой сборки, плюс
  флаги приложения; неизвестные отбрасываются и считаются; перенос на
  десктоп берёт только переменные, помеченные portable в реестре контракта.
  Свидетель: юниты «replaceRaw отбрасывает чужой vars-подключ, оставляет
  известные», «allowlist ⊆ export»;
  [017-BACKUP_AND_STORAGE · P5, P15](../017-BACKUP_AND_STORAGE/FEATURE.ru.md#обещания).
  Мутация: принимать любой ключ из файла.
- **P14. Языковой оверлей меняет только отображаемые тексты.** Оверлей
  активного языка переписывает `name`, `description`, `title`, `tooltip` и
  подписи вариантов; поддерево `config` и все поля данных остаются как в
  английском шаблоне; каждый объявленный оверлей загружается. Свидетель:
  юниты «ru overlay локализует отображаемые поля, поддерево config не
  тронуто», «каждый объявленный оверлей шаблона загружается и разбирается».
  Мутация: перевести `default_value`.

## Документация и примеры

Шаблон описывают три документа; фича — их указатель, а не копия:

- [`docs/TEMPLATE.md`](../../../TEMPLATE.md) — полная схема поставляемого
  файла: каждый раздел, переменная, пресет, запись каталога DNS, стиль
  оформления и список «что ломается, когда».
- `contract/docs/TEMPLATE_LANG.md` в репозитории лаунчера
  ([Leadaxe/singbox-launcher](https://github.com/Leadaxe/singbox-launcher)) —
  норматив языка: ключевые слова, типы переменных, приведение, семантика
  `#if`, `for_each`, `#tpl`, коды предупреждений. Приложение забирает копию в
  `app/contract/` скриптом `app/tool/sync_contract.sh`; копия в git не
  хранится, поэтому внутренней ссылки нет.
- Общий корпус `contract/corpus/template/` в том же репозитории — фикстуры,
  на которых тесты движка гоняются с обеих сторон; новая конструкция
  добавляется вместе с фикстурой.

Синтаксис, дословно из `wizard_template.json`:

**Переменная с типом и вариантами** — объявлена в секции; экран рисует
поле, сборка приводит значение по `type`:

```json
"name": "tun_stack",
"type": "enum",
"wizard_ui": "edit",
"title": "Stack",
"tooltip": "system (default), gvisor (userspace), mixed",
"default_value": "system",
"options": [
  "system",
  "gvisor",
  "mixed"
]
```

**Подстановка `@var`** — строка целиком из `@имя` заменяется типизированным
значением; `timestamp` — данные, остаётся как есть:

```json
"log": {
  "level": "@log_level",
  "timestamp": true
}
```

**`#if` единственным ключом элемента массива** — адрес IPv6 существует
только при истинном условии, иначе элемент выпадает:

```json
"address": [
  "@tun_address",
  {
    "#if": {
      "#and": [
        "@ipv6_enabled"
      ],
      "#value": "@tun_address6"
    }
  }
]
```

**`for_each` у пресета** — тело повторяется для каждого узла типа; `filter`
читает поле записи узла:

```json
"for_each": {
  "node_type": "tailscale",
  "as": "node",
  "filter": {
    "#not": "@node.skip_presets"
  }
}
```

**Составная строка `#tpl`** — тег из тега узла; пустое или неизвестное
значение снимает узел:

```json
"server": {
  "#tpl": "@{node}-dns"
}
```

**Объявление пресета с `on_change`** — объект `ui` есть запись каталога;
скрытая псевдопеременная `rule_enable` пересчитывает глобальную при
переключении пресета:

```json
"preset_id": "fakeip",
"ui": {
  "label": "FakeIP",
  "default": false,
  "num": 1130,
  "isSortable": true
},
```

```json
"#on_change": {
  "#set": {
    "@resolve_enabled": {
      "#if": {
        "#and": [
          "@rule_enable",
          "@dns_enable"
        ],
        "#value": "false",
        "#else": "true"
      }
    }
  }
}
```

**Запись `dns_options`** — сервер каталога; `server` — тело sing-box,
`description` и `enabled` — поля каталога:

```json
{
  "description": "System DNS",
  "enabled": true,
  "server": {
    "type": "local",
    "tag": "local_dns_resolver"
  }
}
```

**Ref-переменная** — пресет показывает в своём редакторе глобальную
переменную вместо объявления своей; значение живёт в глобальной:

```json
{
  "ref": "resolve_enabled"
},
{
  "ref": "resolve_strategy"
}
```

## Контролируемые параметры

| Ручка | Значения | Умолчание |
|---|---|---|
| Значение переменной (по секции, на VPN Settings / Routing / DNS) | по объявлению: `bool`, `int` (0..65535, у ограниченных — их границы), `text`, `text_list`, `secret`, `enum` с `options`, `outbound`, `dns_servers` | `default_value` |
| Пресет: вкл/выкл, переменные, цель | каталог `selectable_rules`; переменная по объявлению; цель — `direct`, Направление, `block`, Reject | `ui.default`, `default_value`, цель шаблона |
| Шаблонный DNS-сервер: вкл/выкл, переменные | каталог `dns_options.servers`; `outbound`, IP из списка | `enabled` каталога, `default_value` |
| Язык | оверлей для языка приложения | английский (сам шаблон) |

У самого шаблона пользовательских ручек нет: пользовательского шаблона не
существует, шаблон меняется только с обновлением приложения. Ключи конфига
ядра, которые отдаёт шаблон, принадлежат фичам-владельцам (см. Границы).

## Входы / Выходы

**Входы:** поставляемый файл шаблона; оверлей отображаемых текстов
активного языка; значения переменных пользователя; записи пресетов и
DNS-серверов (id, переопределения, цель); узлы итогового конфига для
`for_each`; реестр переменных контракта (признаки portable).

**Выходы:** загруженная модель шаблона для экранов и сборки; каркас,
фрагменты пресетов и DNS с подставленными значениями; предупреждения движка
с кодом; ошибка загрузки при кривой поставке; засеянные пресеты и
Направления на чистой установке; перечень имён переменных, которые принимает
резервная копия.

## Data flow

```
обновление приложения ─► новый шаблон ─► загрузка: оверлей → проверка конструкций → модель (раз на язык)
                                              │
   чистая установка ─► засев: дефолтные пресеты, дефолтные Направления, умолчания DNS
   сохранённое состояние ─► поздние дефолтные пресеты один раз; записи держат только переопределения
                                              ▼
 переменные (значение ← умолчание, тип, границы) ─► КАРКАС @var/#if ─► ПРЕСЕТЫ (разворот, пространство,
                                                    for_each, on_change) ─► каталог DNS ─► сборка (003)
                                              ▼
 бэкап / перенос: vars фильтруются шаблоном этой сборки ∪ флаги приложения; записи с ref + переопределения
```

## Правила и гарантии

- Шаблон грузится один раз на язык; оверлей меняет только отображаемые
  поля; нечитаемый оверлей даёт английский шаблон и ошибку в журнале вместо
  падения.
- Все условные конструкции (`#if`, `#enable`, `#on_change`, `for_each.filter`,
  плейсхолдеры тел DNS-серверов) проверяются при загрузке против объявленных
  переменных; нарушение отвергает шаблон, кроме неполного `for_each`, который
  снимает только свой пресет.
- Метаданные переменной (тип, умолчание, варианты) — только из шаблона;
  границы `int`-переменной (сегодня `dns_cache_capacity`) задаёт приложение;
  хранение держит лишь значение. Секция `internal` не рисуется, её
  переменные доступны пресетам по `ref`.
- Своей версии у шаблона нет: его версия — сборка приложения. Поле
  `parser_config.version` (5) читается в модель, но ни одна миграция на него
  не завязана — ломающее изменение формы шаблона обслуживается формой
  хранения ([017-BACKUP_AND_STORAGE](../017-BACKUP_AND_STORAGE/FEATURE.ru.md)),
  а не версией шаблона.
- `on_change` — разовый эффект в момент переключения, не замок.

## Особенности сопровождения

- **Два документа держать в ногу с шаблоном.** `docs/TEMPLATE.md` (схема
  поставляемого файла) и норматив языка `TEMPLATE_LANG.md` в репозитории
  лаунчера; правка шаблона, задевающая любой из них, не закончена, пока они
  не совпали (текущие расхождения — в аудите 591: 8 vs 11 пресетов, старые
  ключи `#if`).
- Ключ `#if` с суффиксом (`#if1`, `#if tun-only`) — единственный способ
  повесить два условия на один объект: второй одноимённый ключ JSON молча
  затирает первый.
- Псевдопеременной пресета с `#on_change` нужны `default_value` и
  `required: false`, иначе пресет молча ничего не эмитит.
- Пресет, ставший `default: true` после того, как у пользователей уже есть
  сохранённое состояние, доходит до них только через список поздних
  дефолтов; одного `default: true` недостаточно.
- Новый ключ состояния, хранящий переопределение шаблона, обязан быть
  классифицирован для allowlist бэкапа и для слота Workspaces, иначе он молча
  отбрасывается на импорте или становится общим для всех наборов.
