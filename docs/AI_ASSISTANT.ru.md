# L×Box — ИИ-ассистент и ваша сеть

L×Box даёт ИИ-ассистенту набор функций: проверить, почему адрес не
открывается, прочитать и изменить маршрутизацию, включить или выключить
подключение. Вы говорите, что нужно; ассистент сам выбирает функции и
вызывает их. Здесь описано, что ассистент получает, как это разрешить, что
говорить и как пользоваться теми же функциями с компьютера через Debug API.

## Два входа

| Кто вызывает | Как | Что нужно |
|---|---|---|
| Ассистент на устройстве | Android AppFunctions: система показывает ассистенту функции, которые объявил L×Box | Android 16 или новее, ассистент, которому Android разрешает вызывать функции приложений, тумблер **AI assistant control** |
| Агент на компьютере | [Debug API](ADVANCED_USER_GUIDE.ru.md#debug-api) через `adb forward` | Отладка по USB, тумблер **Debug API** и его токен |

Оба входа ведут к одному коду. Агент на компьютере работает на любой
поддерживаемой версии Android и от системного ассистента не зависит.

> ⚠️ AppFunctions — экспериментальный API Android. Google разрешает вызывать
> функции приложений только ассистентам из своей программы раннего доступа,
> поэтому на большинстве устройств голосовая просьба до L×Box пока не
> доходит. Вход через Debug API работает независимо от этого. Проверка
> командой `adb shell cmd app_function` требует образа системы, где эта
> команда есть: в образе эмулятора Android 16 она есть с API 36.1, в образе
> 36.0 её нет.

## Разрешить ассистенту на устройстве

Что можно ассистенту на устройстве, задают два тумблера. Оба по умолчанию
выключены.

Где находятся: App Settings → Automation → AI assistants. Раздел виден на
Android 16 и новее.

| Тумблер | Что открывает |
|---|---|
| **AI assistant control** | Включение и выключение VPN, его статус, проверки сети, список выходов, смену выхода, чтение правил, Направлений и источников |
| **Let assistants change settings** | Добавление, правку и удаление правил маршрутизации и Направлений, включение и выключение источников и подключений, смену маршрута по умолчанию и списка приложений туннеля |

Второй тумблер действует, только пока включён первый. При включённом втором
ассистент меняет настройки сразу, без подтверждения каждого изменения. При
выключенном просьба изменить настройки возвращает ошибку с названием этого
тумблера.

Для включения VPN нужно разрешение Android на VPN. L×Box получает его, когда
вы первый раз нажимаете Start в приложении; ассистент выдать его не может.

## Почему сайт или приложение не открывается

Говорите так, как сказали бы человеку:

- «Почему не открывается example.com?»
- «Приложение Example Chat не подключается — проверь.»
- «VPN работает? Какой у меня сейчас IP?»

Ассистент запускает проверку адреса — тот же URL Check, что в
Diagnostics → URL Check. Ядро проводит запрос по стадиям и сообщает, на какой
он остановился. Если вы назвали приложение, проверка идёт по правилам,
которые действуют для этого приложения.

| Стадия в ответе | Что не прошло | Что обычно помогает |
|---|---|---|
| `dns` | Имя не превратилось в адрес | Другой DNS-сервер или другой выход |
| `route` | Правило заблокировало адрес, либо маршрут не выбран | Посмотреть правило, названное в ответе |
| `tunnel`, `connect` | Сервер выхода или сайт не ответил | Другой выход |
| `tls` | Защищённое соединение отклонено | Другой выход или прямой маршрут |
| `http` | Сайт ответил кодом ошибки | Путь по сети работает; отказывает сам сайт |

В ответе также названы Направление (Direction) и выход, через которые пошёл
запрос, либо сказано, что он пошёл напрямую или был заблокирован; к ответу
приложен короткий совет.

Проверка идёт, только пока VPN включён. При выключенном VPN ассистент получает
`vpn_off`; сама проверка VPN не включает.

Проверка выхода отвечает на вопрос «из какой страны я выхожу»: она делает
запрос через Направление к `1.1.1.1/cdn-cgi/trace` и возвращает внешний
IP-адрес и код страны.

## Пустить приложение через выход или страну

- «Пусти Example Chat через Германию.»
- «Example Chat должен ходить через vpn-1 только в моём Wi-Fi Home.»
- «Приложение Example Bank пусти напрямую, мимо VPN.»
- «Переключи основное Направление на сервер в Нидерландах.»

Направление — группа выходов (серверов), в которую правила отправляют трафик.
Страну сервера L×Box не хранит. Ассистент читает имена выходов — поставщики
пишут в них флаг или название страны — и сам решает, какие подходят под вашу
просьбу. После изменения он может запустить проверку выхода и сравнить код
страны с тем, что вы просили.

Что делает ассистент по просьбе «пусти Example Chat через Германию»:

1. находит имя пакета приложения по его названию;
2. читает выходы Направления и по именам отбирает немецкие;
3. создаёт Направление, ограниченное этими выходами, и правило «это
   приложение → это Направление», затем перезагружает туннель;
4. запускает проверку выхода на новом Направлении.

Правило может нести любые условия, которые есть в редакторе правил:
приложения, сети Wi-Fi, тип сети, домены, диапазоны IP, порты.

Два вида изменений различаются:

- **Смена выхода внутри Направления** действует на все правила, которые
  ведут в это Направление, и держится до перезапуска туннеля. Для неё
  хватает **AI assistant control**.
- **Правило или новое Направление** сохраняется в настройках и остаётся. Для
  него нужен **Let assistants change settings**.

Направление с автоматическим выбором лучшего сервера ручной выход не
принимает.

> ⚠️ Имя выхода пишет поставщик подписки. Флаг в имени страну не
> подтверждает; страну, из которой трафик выходит на деле, показывает
> проверка выхода.

## Подключить рабочую сеть

- «Подключи меня к рабочей сети.»
- «Выключи офисный WireGuard.»
- «Tailscale подключён?»

Подключения здесь — серверы пяти типов: WireGuard, AmneziaWG, OpenVPN,
OpenConnect и Tailscale. Ассистент видит их список: имя, тип, включено ли
каждое, и состояние:

| Состояние | Значение |
|---|---|
| `up` | Подключено |
| `connecting` | Устанавливается |
| `idle` | Туннель WireGuard приостановлен, пока не используется; просыпается от трафика |
| `needs_login` | Нужен вход в приложении |
| `down` | Не подключено, либо VPN выключен |
| `disabled` | Выключено в списке серверов |
| `unknown` | Состояние не сообщается; у OpenVPN так всегда |

Включение подключения ставит его переключатель в списке серверов,
пересобирает конфиг и перезагружает туннель. Если VPN был выключен, L×Box
включает его — при условии, что разрешение на VPN выдано. Выключение
подключения VPN не останавливает.

Подключение внутри папки или подписки, которая сама выключена, не
включается: ассистент получает ошибку с названием причины.

Вход в OpenConnect или Tailscale остаётся в приложении: пароли и коды
ассистент не вводит.

## Что получает ассистент

- Имена: выходов (серверов), Направлений, подключений, приложений и правил.
  Имена серверов приходят от поставщика подписки как есть.
- Правила маршрутизации и Направления с их условиями, список источников с их
  состоянием.
- Результат проверки: стадию сбоя, текст ошибки ядра, код HTTP, выход.
  Проверка выхода возвращает внешний IP-адрес и код страны.
- Список установленных приложений, подходящих под поиск по названию.

Ассистент не получает: файл конфига, адреса и ключи серверов, ссылки
подписок, бэкапы, логи.

Что ассистент делает с этими данными, определяют условия самого ассистента, а
не L×Box. Сам L×Box эти данные никуда не отправляет.

## Чего ассистент не может

- Добавлять и удалять серверы, подписки и папки.
- Менять настройки DNS, миксины и файл конфига.
- Менять переключатели безопасности туннеля и настройки Debug API.
- Включать **AI assistant control** и **Let assistants change settings**.
- Выдавать разрешение на VPN и входить в подключение.
- Выгружать бэкап, читать логи и файлы.

Просьба о любом из этих действий возвращает ошибку; ничего не меняется.

## Когда L×Box не открыт

Часть функций исполняется без окна приложения: включение и выключение VPN,
его статус, проверка адреса, проверка выхода, список выходов, смена выхода,
поиск приложения.

Всё, что читает или меняет настройки, — правила, Направления, источники,
обзор сети — требует окна приложения. Если L×Box не открыт, он пробует
открыть своё окно и после этого исполняет просьбу. Если Android не разрешает
открыть окно из фона, ассистент получает ошибку «L×Box is not open. Open the
app and repeat.», и появляется уведомление; нажатие на него открывает
приложение.

## То же с компьютера: Debug API

Агент на компьютере — ассистент для программирования с терминалом, скрипт —
вызывает те же функции по HTTP. Debug API два тумблера ассистента не
спрашивает: разрешением служат его собственный тумблер и токен. Что такое
Debug API, его тумблер, токен и порт:
[руководство для опытных пользователей → Debug API](ADVANCED_USER_GUIDE.ru.md#debug-api);
все маршруты с примерами: [справочник Debug API](api/debug-api-reference.md).

1. На устройстве: App Settings → Diagnostics → Developer → **Debug API**,
   затем скопируйте токен.
2. На компьютере:

```bash
adb forward tcp:9269 tcp:9269
TOK="<token>"
BASE="http://127.0.0.1:9269"
HDR="Authorization: Bearer $TOK"
```

Почему адрес не открывается:

```bash
curl -s -X POST -H "$HDR" -H "Content-Type: application/json" \
  -d '{"url":"https://example.com","app":"org.example.chat"}' \
  "$BASE/assistant/check-url"
```

Приложение через выбранные выходы, только в одной сети Wi-Fi:

```bash
curl -s -H "$HDR" "$BASE/assistant/apps?q=chat"
curl -s -H "$HDR" "$BASE/assistant/exits?direction=vpn-1&q=germany"
curl -s -X POST -H "$HDR" -H "Content-Type: application/json" \
  -d '{"label":"Germany","node_filter":"Germany","auto":{}}' "$BASE/directions"
curl -s -X POST -H "$HDR" -H "Content-Type: application/json" \
  -d '{"kind":"inline","name":"Chat at home","packages":["org.example.chat"],"wifi_ssids":["Home"],"outbound":"vpn-2"}' \
  "$BASE/rules?rebuild=true"
curl -s -X POST -H "$HDR" "$BASE/action/reload-vpn"
curl -s -X POST -H "$HDR" -H "Content-Type: application/json" \
  -d '{"direction":"vpn-2"}' "$BASE/assistant/check-exit"
```

Рабочее подключение:

```bash
curl -s -H "$HDR" "$BASE/assistant/overview"
curl -s -X POST -H "$HDR" -H "Content-Type: application/json" \
  -d '{"id":"Office","enabled":true}' "$BASE/assistant/connection"
```

Разделы справочника для маршрутов из примеров:

| Маршруты | Раздел |
|---|---|
| `/assistant/*` — обзор, выходы, проверки, поиск приложения, подключения | [Assistant](api/debug-api-reference.md#assistant--assistant-750) |
| `/rules/*` — правила маршрутизации и их условия | [Rules CRUD](api/debug-api-reference.md#rules-crud--rules) |
| `/directions/*` — Направления и их фильтр выходов | [Directions CRUD](api/debug-api-reference.md#directions-crud--directions) |
| `/subs/*`, `/folders/*` — источники | [Subscriptions CRUD](api/debug-api-reference.md#subscriptions-crud--subs), [Folders CRUD](api/debug-api-reference.md#folders-crud--folders) |
| `/action/*` — включение, выключение и перезагрузка VPN, смена сервера | [Actions](api/debug-api-reference.md#actions--триггеры) |
| `/state` — текущее состояние | [State & introspection](api/debug-api-reference.md#state--introspection) |
| Коды ошибок | [Common errors](api/debug-api-reference.md#common-errors) |

Настройка и модель безопасности Debug API:
[Setup](api/debug-api-reference.md#setup-one-time),
[Security model](api/debug-api-reference.md#security-model--root-доступ-by-design).

## Справочник функций

Функции, которые получает ассистент на устройстве:

| Функция | Что делает | Нужно окно приложения |
|---|---|---|
| `startVpn`, `stopVpn`, `getVpnStatus` | Включение, выключение, статус VPN | нет |
| `checkUrl` | Проверка адреса по стадиям | нет |
| `checkExit` | Внешний IP-адрес и страна выхода Направления | нет |
| `listExits` | Имена выходов Направления, с поиском по подстроке | нет |
| `selectExit` | Смена выхода внутри Направления | нет |
| `findApps` | Поиск установленного приложения по названию | нет |
| `getApiHelp` | Список маршрутов, доступных через `callApi` | да |
| `callApi` | Вызов маршрута: обзор, правила, Направления, источники, подключения | да |

`callApi` достаёт часть маршрутов Debug API: разделы
[Assistant](api/debug-api-reference.md#assistant--assistant-750), [Rules](api/debug-api-reference.md#rules-crud--rules),
[Directions](api/debug-api-reference.md#directions-crud--directions), чтение и переключение
источников и действия с VPN. Точный список возвращает `getApiHelp`.

Проверка без ассистента, на устройстве, в системе которого эта команда есть
(`adb shell cmd app_function help` печатает список):

```bash
adb shell cmd app_function list-app-functions --package com.leadaxe.lxbox
adb shell cmd app_function execute-app-function --package com.leadaxe.lxbox \
  --function 'com.leadaxe.lxbox.appfunctions.LxBoxAppFunctions#checkUrl' \
  --parameters '{"url":"https://example.com"}'
```

Технические детали объявления AppFunctions:
[Automation → AI assistants](AUTOMATION.ru.md#ии-ассистенты-appfunctions).
