Xray nodes that set TLS fragmentation in finalmask.tcp now get the core's fragmentation; these fields used to be ignored. A node that goes through another node (a chain or a subscription detour) no longer carries TLS fragmentation and shows an info notice, including nodes with tls.fragment in sing-box JSON. Fewer "field not read" notices on Xray nodes; notices with the same code are grouped into one entry. Parser and build follow contract 1.1.84.
