# L×Box v2.5.1

**Хотфикс к v2.5.0.** Чинит регрессию lifecycle: после «смахивания» приложения из недавних и повторного открытия туннель оставался жив (правильно), но UI показывал `Connected` с пустыми данными — Channel/Nodes/Stats не подгружались, таймер соединения сбрасывался. Теперь cold-start корректно пере-синхронизирует все каналы данных с ядром.

## 🐛 Исправлено

| # | Было | Стало |
|---|---|---|
| §185 | После swipe-from-recents + повторного открытия: `Connected`, но Channel/Nodes пусты, Stats — спиннер, скорость ↑↓ висит. Лечилось только перезапуском VPN | Cold-start пере-поднимает все каналы ядра (статус, группы, соединения) на свежий движок → данные сразу на месте |
| §187 | Таймер соединения сбрасывался на 0 при каждом swipe-reopen | Время старта берётся из native (переживает swipe) → таймер показывает реальную длительность сессии |
