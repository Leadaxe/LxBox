# L×Box v2.5.2

Настройки приведены в порядок: VPN-тумблеры переехали туда, где им место, все
настройки теперь хранятся в одном месте (прозрачно для бэкапа), и починен баг,
из-за которого режим «только прокси» отключал VPN другого приложения.

## 🐛 Исправлено

| # | Было | Стало |
|---|---|---|
| §192 | Режим «только прокси» (port-only, без TUN) при запуске **отключал активный VPN другого приложения** | В proxy-режиме системный VPN-слот не запрашивается — чужой VPN остаётся работать |
| §193 | Со временем вкладка **Stats** переставала показывать соединения (0, хотя VPN работал и соединения были) | Список соединений переэмитится при открытии Stats — больше не пропадает |

## 🔧 Изменено

| # | Что | Зачем |
|---|---|---|
| §189 | Настройки VPN (автостарт, keep-alive, фоновый режим, обход, логи ядра) теперь хранятся в **одном файле настроек** (раньше — отдельно в системных prefs Android) | Прозрачно: бэкап и импорт берут всё из одного места; настройки не теряются |
| §188 | **Keep VPN on exit** и **Allow VPN bypass** переехали из App Settings в **VPN Settings → Mode** (группа «Tunnel options») | Эти настройки имеют смысл только при туннеле — теперь видны только в режимах VPN / VPN+Proxy, скрыты в Proxy. Keep-alive включён по умолчанию |
| §194 | Счётчик соединений на главном теперь **раздельный**: 🔗 соединения приложений (как на Stats) + 🗄 соединения к серверам. Conns показывает «N активных / M всего» | Раньше главный показывал сумму, которая не сходилась с числом на Stats — путало. Long-press по значкам → пояснение |

## 🗑 Удалено

| # | Что |
|---|---|
| §191 | Секция «Clash API» (Address + Secret) из VPN Settings → Core — мёртвый рудимент (Clash API убран ещё в v2.5.0) |
